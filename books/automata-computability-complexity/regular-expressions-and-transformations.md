
# Regular Expressions, Closure, and Effective Transformations

Regular languages have several complete representations: deterministic automata, nondeterministic automata, regular expressions, finite right congruences, and finite monoid morphisms. Equivalence of expressive power is only the first question. A proof/reference treatment must also give effective transformations, their invariants, their size costs, and decision procedures that do not confuse existence with efficient construction.

## Preparation and outcomes

Use the DFA and epsilon-NFA definitions from [Chapter 1](#/books/automata-computability-complexity/finite-automata-regular-languages), together with finite induction and graph reachability. No monoid theory from the later algebraic chapter is required: the homomorphisms used below are defined directly by replacement of letters with words. The alphabet is finite and fixed when taking complements or comparing languages. You will construct equivalent finite descriptions, prove their path invariants, and distinguish language preservation from a small-output guarantee.

## 1. Regular-expression syntax and semantics

Fix alphabet $\Sigma$. Regular expressions are generated by

- $\varnothing$, denoting the empty language;
- $\varepsilon$, denoting $\{\varepsilon\}$;
- each $a \in \Sigma$, denoting $\{a\}$;
- union $R+S$;
- concatenation $RS$;
- star $R^{\ast} $.

The semantics map $[\![ R]\!]$ is defined recursively using the corresponding language operations. Syntax is a finite tree; semantics is a set of words. Parentheses and precedence belong to syntax, while algebraic identities such as $R+R=R$ are semantic equalities.

The class of languages denoted by expressions is, by definition, the class of **regular languages**. Chapter 1 used the same name for finite-state languages. We now prove the definitions agree.

## 2. Expressions to epsilon-NFAs: Thompson's invariant

For every expression $R$, construct an epsilon-NFA fragment with one entry and one exit such that paths from entry to exit spell exactly $[\![ R]\!]$.

- $\varnothing$: no path from entry to exit.
- $\varepsilon$: one epsilon edge.
- $a$: one $a$-edge.
- $R+S$: new entry epsilon-branches to each fragment; their exits epsilon-join a new exit.
- $RS$: connect the exit of $R$ by epsilon to the entry of $S$.
- $R^{\ast} $: allow an epsilon path directly to the new exit, enter $R$, loop from its exit to its entry, and exit after any iteration.

**Theorem 2.3 (Correctness).** The fragment for $R$ has an entry-to-exit path labeled $w$ if and only if $w \in [\![ R]\!]$.

**Proof.** Use structural induction on $R$. Atomic cases follow from their sole paths. A union path selects exactly one branch. A concatenation path splits at the connecting epsilon edge into a word from each operand. A star path makes finitely many traversals of the body, including zero traversals. These decompositions match the recursive semantics in both directions.

The construction is linear in expression-tree size before determinization. Subset construction may then create exponentially many deterministic states.

## 3. Automata to expressions: state elimination

A generalized NFA (GNFA) labels each directed edge by a regular expression. Eliminating intermediate state $k$ updates every remaining edge $i \to  j$ by

$R_{ij}+R_{ik}(R_{kk})^{\ast}R_{kj}$.

The first term covers paths avoiding $k$; the second covers paths entering $k$, looping there any finite number of times, then leaving. Missing edges denote $\varnothing$.

**Elimination invariant.** After eliminating set $E$ of states, the label from $i$ to $j$ denotes exactly the words labeling paths from $i$ to $j$ whose internal vertices lie in $E$.

The base case has no allowed internal vertices and is represented by direct edges, with $\varepsilon$ added for $i=j$ where appropriate. Eliminating $k$ partitions every allowed path according to whether it avoids $k$ or has a first entry, zero or more returns, and a final departure. Induction proves the update. When only new start and final states remain, their edge denotes the automaton language.

Different elimination orders produce different expressions and sometimes drastically different sizes. Semantic correctness does not imply canonical syntax.

## 4. Arden's lemma and equation solving

Language equations provide another automaton-to-expression route.

**Lemma 2.4 (Arden's).** If $\varepsilon \notin A$, then the equation $X=AX \cup B$ has the unique solution $X=A^{\ast} B$.

First, $A^{\ast}B=AA^{\ast}B\cup B$ because $A^{\ast}=AA^{\ast}\cup\{\varepsilon\}$. For uniqueness, any solution contains $B$, then $AB$, then $A^2B$, and hence $A^{\ast} B$. Conversely, repeatedly expanding membership in $X=AX \cup B$ must reach $B$: because every word in $A$ has positive length, one cannot peel off infinitely many nonempty prefixes from a finite word. Thus $X \subseteq A^{\ast} B$.

The condition is essential. If $\varepsilon \in A$, the equation can have multiple solutions; for $A=\{\varepsilon\}$ and $B=\varnothing$, every language $X$ is a solution.

## 5. Closure constructions are algorithms

For complete DFAs, Boolean closure uses product states. Union accepts when either component accepts; intersection when both; difference when the left accepts and right rejects. Complement flips accepting states after totality is ensured.

Concatenation and star are naturally built using epsilon-NFAs: epsilon-link accepting states of the first to the initial state of the second; for star, add zero-iteration acceptance and repeat edges. Determinize only if a downstream operation requires a DFA.

Reversal reverses every NFA edge and swaps the roles of initial and accepting states, using a new epsilon-branching initial state when necessary. The path-label invariant proves that the resulting language is $\{\operatorname{rev}(w):w \in L\}$.

These constructions prove closure and provide finite descriptions. A closure theorem without a construction is insufficient when later chapters need an executable transformation.

## 6. Homomorphisms and inverse images

A word homomorphism $h:\Sigma^{\ast} \to \Gamma^{\ast} $ is determined by its letter images. For language $L$, its image is $h(L)=\{h(w):w \in L\}$ and its inverse image is $h^{-1}(K)=\{w:h(w) \in K\}$.

Regular languages are closed under homomorphic image: replace each transition labeled $a$ by a path spelling $h(a)$, using epsilon when $h(a)=\varepsilon$. They are closed under inverse homomorphism: given DFA $A$ for $K$, define a transition on $a$ to be the extended transition of $A$ on the word $h(a)$. Induction gives the state after $w$ as the original machine's state after $h(w)$.

Inverse constructions are often cheaper because they preserve the state set; image constructions may add intermediate states and nondeterminism.

## 7. Decision pipelines

Given regular descriptions, the following questions are decidable:

- **membership:** run a DFA or propagate an NFA state set;
- **emptiness:** search for a reachable accepting state;
- **finiteness:** after restricting to reachable and co-reachable states, test whether a directed cycle remains;
- **universality:** complement a complete DFA and test emptiness;
- **inclusion/equivalence:** product search for a counterexample;
- **minimality:** remove unreachable states and test all state pairs for distinguishability, or minimize and compare counts.

The input representation controls complexity. Universality for an explicit DFA is simple graph search after complement; for an NFA, implicit subset exploration can require exponential space in the naive form and the problem is fundamentally harder. Statements should name the representation.

### Finiteness theorem

For a DFA, $L$ is infinite exactly when some directed cycle is reachable from the start and can reach an accepting state.

If such a cycle exists, traverse to it, repeat it arbitrarily many times, then reach acceptance, obtaining unbounded word lengths. Conversely, if infinitely many words are accepted, accepted lengths are unbounded. A sufficiently long accepting run repeats a state between the start and final state, yielding the required cycle.

## 8. Pumping and its limits

If a DFA has $n$ states and accepts word $w$ with $|w|\ge n$, then among the first $n+1$ visited states some state repeats. Write $w=xyz$ so $y$ labels the resulting nonempty loop and $|xy|\le n$. Then $xy^iz$ is accepted for every $i\ge 0$.

To prove nonregularity, the correct quantifier pattern is

for every $p$, choose $w$; for every legal split $w=xyz$, choose $i$; the pumped word leaves $L$.

Choosing the split yourself proves nothing. Also, the pumping property is necessary but not sufficient for regularity. Myhill–Nerode often gives a cleaner and stronger lower bound.

## 9. Transformation audit

Every transformation should declare:

1. input representation and well-formedness;
2. output representation;
3. the semantic invariant proving equivalence;
4. termination and size bounds;
5. whether epsilon transitions, partial tables, or unreachable states are permitted;
6. certificates or counterexamples produced by decisions.

Expressions, NFAs, and DFAs are expressively equivalent, but translations can be exponentially expensive and minimization can expose that cost. There is no contradiction: expressive class and descriptional complexity are different axes.


## Construction details that make the equivalences effective

**Theorem 2.1 (Kleene equivalence, fixed finite alphabet).** A language is accepted by a DFA if and only if it is denoted by an expression built from $\varnothing,\varepsilon$, letters, union, concatenation and star.

*Proof.* For an expression, use fresh disjoint copies of the child fragments in the Thompson construction. Each fragment has one entry with no incoming internal edge and one exit with no outgoing internal edge. Union adds a new pair of endpoints and epsilon branching; concatenation connects the first exit to the second entry; star adds new endpoints with skip, enter, repeat and finish edges. These endpoint restrictions ensure that a path cannot jump between unrelated operand fragments. A union path chooses one operand; a concatenation path traverses the first then the second; a star path traverses its body a finite number of times, including zero. Conversely every concatenation specified by the expression yields such a path. Structural induction proves the exact language statement for all fragments, even when an operand accepts epsilon. The finite subset construction of Chapter 1 then gives a DFA.

For the reverse direction, take a DFA, add a fresh start with an epsilon edge to the old start, and add a fresh sole final vertex with epsilon edges from old accepting states. There are no edges into the new start or out of the new final. Label ordinary transitions by letters, joining alternatives with union. A missing label is the empty expression. Remove all old vertices one at a time with the elimination update. There are finitely many old vertices, and each update combines finite expressions, so the procedure ends with one expression between the two new endpoints. The path invariant proved below says its language is precisely that of the original DFA. ∎

The use of fresh fragment copies is a representation condition. Reusing a child automaton as shared mutable state can introduce unintended paths when new connecting edges are installed. A syntax tree may repeat the same written subexpression, but its direct Thompson construction gives those occurrences distinct internal states unless sharing has separately been justified.

**Lemma 2.2 (Elimination invariant, both directions).** Suppose edge labels describe paths whose internal vertices belong to an eliminated set $E$. Removing another vertex $k$ and applying $R_{ij}+R_{ik}(R_{kk})^*R_{kj}$ gives exactly paths whose internal vertices belong to $E\cup\{k\}$.

*Proof.* A permitted path avoiding $k$ belongs to the first label. Otherwise split it at its first visit to $k$, successive returns to $k$, and final departure. Each piece has internal vertices only in $E$, so its label belongs respectively to $R_{ik}$, a finite sequence from $R_{kk}$ and $R_{kj}$. This proves containment in the update. Conversely, choose a word from any factor in the updated expression and corresponding old paths guaranteed by the prior invariant. Concatenate those paths in factor order. All internal vertices lie in the enlarged set, so the result is a permitted path. The zero-return case is included by star, and a zero-length path at equal endpoints has label epsilon where needed. ∎

State elimination must not confuse a path of zero edges with absence of a path. Epsilon is the label of the former; the empty language describes the latter. This distinction explains both the star base case and the diagonal convention in the path invariant.

## Closure with explicit language guarantees

Every Boolean product assumes one common alphabet and two total deterministic tables. A product state records both unique runs, so intersection, union and difference follow by choosing the appropriate truth condition on final-state membership. Complement is relative to all words of that alphabet. If a machine was described over a smaller alphabet, completing it over the common alphabet is an additional required step.

For concatenation, use disjoint epsilon-NFAs and add an epsilon move from each first-machine final state to the second-machine initial set. An accepting run chooses a split $w=uv$ and recognises the two parts. Conversely, any successful split gives a run by concatenation. Empty parts work because the operand machines can accept without consuming a symbol. For star, an added accepting entry handles zero factors, while repeat edges permit any finite positive number. These are existential decompositions, so nondeterminism is the natural representation.

For an erasing word homomorphism, replacing a letter edge by epsilon is intentional: the output word can be shorter than the input path. Fresh intermediate vertices along longer replacement paths prevent runs from exiting midway through a replacement. Inverse image is simpler: one input letter instructs the existing DFA to read its finite image word. Induction then shows its state after $w$ equals the old state after $h(w)$. Erasing a letter makes that letter's inverse-image transition the identity; it does not delete the letter from the new alphabet.

## Worked example 1: optional input and an epsilon choice

Take expression $(a+\varepsilon)b^*$ over $\{a,b\}$. It accepts $b^j$ and $ab^j$ for every $j\ge0$. A complete DFA has start state $s$, state $t$ meaning that the optional initial part has finished and only $b$ symbols are permitted, and rejecting sink $d$. Both $s,t$ accept. From $s$, either letter leads to $t$; from $t$, $b$ loops and $a$ leads to $d$; the sink loops on both letters.

The empty word accepts at $s$. The word $abb$ goes $s,t,t,t$ and accepts; $ba$ goes $s,t,d$ and rejects. The invariant says that every nonempty accepted prefix has at most one $a$, necessarily first, followed only by $b$ symbols. All other prefixes are in the sink. This matches exactly the expression's two cases, proving equivalence rather than only agreement on the displayed words.

## Worked example 2: eliminating one intermediate vertex

Suppose a GNFA has start $i$, final $j$ and one intermediate vertex $k$. Its nonempty edge languages are $R_{ij}=\{\varepsilon\}$, $R_{ik}=\{a\}$, $R_{kk}=\{b\}$ and $R_{kj}=\{a\}$. No other edge is available. Eliminating $k$ gives expression $\varepsilon+ab^*a$.

A path either uses the direct epsilon edge or enters $k$ on $a$, takes a finite number of $b$ loops and leaves on $a$. Thus $\varepsilon,aa,aba,abba$ are accepted, while $a$ is not: it neither completes both outer edges nor equals the direct empty word. Every word in the resulting expression supplies exactly one of these permitted path shapes, which is the converse direction required by elimination correctness.

## Worked example 3: erasure in an inverse image

Let $h(a)=01$ and $h(b)=\varepsilon$. Let the target language over $\{0,1\}$ consist of words ending in $01$. For any source word $w$, its image is $(01)^r$, where $r$ counts the occurrences of $a$. Therefore $h(w)$ lies in the target exactly when $r\ge1$. The inverse language is all source words containing at least one $a$.

The inverse-transition construction reaches the same conclusion without guessing an expression: a source $b$ performs the empty target transition, while a source $a$ performs the target word $01$. A two-state source DFA tracks whether an $a$ has appeared. The word $bab$ maps to $01$ and accepts, whereas $bbb$ maps to the empty word and rejects. This example includes an erasing image and shows why inverse image remains regular under it.

## Finite certificates for decisions

For emptiness, a transition-closed state set containing the start and avoiding all final states certifies rejection of every word. It need not be guessed by sampling words; reachability computes such a set if the language is empty. For infinitude, a reachable nonempty cycle with a path to acceptance gives accepted words with strictly increasing lengths. Conversely, infinitely many accepted words over a finite alphabet have unbounded lengths, so a run longer than the state count repeats a state before acceptance. These finite paths are checkable witnesses for the two directions of the finiteness criterion.

A size bound should name which object is counted. Thompson states and edges are linear in a fully expanded expression tree. GNFA labels may duplicate subexpressions, and subset states may be exponential in the NFA size. Neither growth invalidates expressive equivalence. It changes the cost of using that equivalence as an algorithm on the chosen descriptions.

<details>

</details>
<details>

## Summary

Expressions and finite automata recognize the same languages through explicit path-preserving constructions. Epsilon paths, missing edges and fresh fragment boundaries have different meanings and must be kept distinct. Products give Boolean closure for complete DFAs; epsilon branching supports concatenation, star and projections. Erasing homomorphisms preserve the stated image and inverse-image guarantees. Finite certificates decide emptiness, infinitude and equivalence, while representation growth remains a separate cost question. The next chapter proves the canonical residual-state theorem and minimisation.
