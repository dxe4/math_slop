## Cross-problem finder

- **The loss decreases but the model is useless:** contracts and baselines (1), leakage (1, 20–21), loss semantics (15), shift (4, 21).
- **A matrix expression runs but seems wrong:** axes and shapes (2), broadcast reductions (6), saved-layer shapes (16–17).
- **The gradient check fails:** differentiability and scale (9), mutation or missing branches (7–8), reductions (6, 16), state and randomness (20).
- **Training oscillates or diverges:** smoothness and steps (10), conditioning (12), stochastic state (13), initialization and normalization (16–17).
- **Parameters differ but predictions agree:** symmetry and equivalence classes (18); compare functions in a declared input geometry.
- **A constrained solver claims success:** check feasibility, stationarity, complementarity, and dual gap (11), or a proximal-gradient mapping (14).
- **A hypergradient looks precise:** inspect inner optimality, Hessian or system conditioning, and linear-solve residuals (19).
- **A probability threshold seems arbitrary:** separate proper scoring, calibration, class weighting, and decision costs (15).
- **A result cannot be reproduced:** inspect immutable data identities, fitted preprocessing state, random streams, update order, environment record, and failure ledger (20).
