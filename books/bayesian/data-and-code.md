# Data sets, lab scripts and results

Everything the chapters refer to that is not a page: the course data (with licences and provenance), the Python lab for each chapter, the results the labs recorded, and the figures. The notebooks of the original course are not included; each lab script runs on its own with Python (see the [data README](../../downloads/bayesian/data/README.md) for the data and [labs/EXTENSIONS.md](../../downloads/bayesian/labs/EXTENSIONS.md) for the extension labs).
