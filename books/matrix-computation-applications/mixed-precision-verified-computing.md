
# Mixed-Precision and Verified Computing

For mixed-precision matrix correction, use the error and contraction analysis in [Randomized Numerical Linear Algebra](randomized-numerical-linear-algebra.md); for outward rounding, dependency, existence and uniqueness checks, and solution enclosures, continue to [Verified and Interval Computation](../numerical-mathematics-error-algorithms/verified-interval-computation.md) in Numerical Mathematics. A small residual, a convergent correction, and a rigorous enclosure support different conclusions, so retain the hypotheses and error budgets of the chosen theorem. The [additional mixed-precision worked reading](randomized-numerical-linear-algebra.md) preserves the earlier matrix examples and solutions. This short bridge connects the two treatments; the next substantive chapter develops the book's synthesis.
