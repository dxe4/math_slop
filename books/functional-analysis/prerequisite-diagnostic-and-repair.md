
# Prerequisite Diagnostic and Repair

Use [Real Analysis](#/books/proof-safe-real-analysis) for completeness, compactness, uniform convergence, total differentiation and Baire category. Use [Measure and Integration](#/books/measure-and-integration) through Lp spaces for the full book’s function-space examples when that continuation is complete. Elementary linear algebra should include kernels, images, quotient vectors and eigenvalues.

Before starting, prove that a uniform limit of continuous functions is continuous and explain why a Cauchy sequence in an incomplete subspace can converge outside it. Distinguish a bounded sequence with a convergent subsequence from a sequence that is itself Cauchy. In the first chapter these distinctions produce the completeness and noncompactness examples.

Before uniform boundedness, write the quantifiers for pointwise boundedness and for a common operator norm bound. State Baire’s theorem for a complete metric space. The proof uses Baire exactly once, to find an interior ball; subtraction and rescaling then use linearity. If either stage is unclear, return to the corresponding prerequisite instead of treating the theorem as a formal name.
