# Appendix B — Glossary and notation {#sec-topology-glossary}

| Term | Meaning |
|---|---|
| basis | local family whose unions form every open set |
| compact | every open cover has a finite subcover |
| connected | admits no separation into two nonempty opens |
| covering map | locally a disjoint union of homeomorphic sheets |
| cycle / boundary | chain killed by boundary / chain produced as a boundary |
| embedding | homeomorphism onto a subspace image |
| homotopy | continuous deformation between maps |
| local system | coefficient fibers equipped with homotopy-invariant path transport |
| manifold | Hausdorff, second-countable, locally Euclidean space |
| paracompact | every open cover has a locally finite open refinement (Hausdorff here) |
| partition of unity | locally finite supported continuous weights summing to one |
| quotient | space obtained by identification with the final topology |
| relative homology | homology of chains in $X$ modulo chains in a subspace $A$ |
| sheaf | locally determined data with unique compatible gluing |
| topology | family containing empty and whole sets, closed under arbitrary unions and finite intersections |

## Core notation

- $\mathcal T$: topology; $\mathcal B$: basis.
- $\overline A$, $A^\circ$, $\partial A$: closure, interior, boundary.
- $X/{\sim}$: quotient by an equivalence relation.
- $\pi_1(X,x_0)$: based fundamental group.
- $C_k,Z_k,B_k,H_k$: chains, cycles, boundaries, homology.
- $H^k$ and $H_{\mathrm{dR}}^k$: cohomology and de Rham cohomology.
- $\chi$: Euler characteristic; $b_k$: Betti number.
- $\deg f$, $L(f)$: degree and Lefschetz number of a map.
- $\operatorname{Tor}$, $\operatorname{Ext}$: derived coefficient terms.
- $\mathcal O_M$: orientation local system of a manifold.

All homology coefficients are integers unless a field is explicitly named.
Computational examples often use the two-element field and state that choice.
