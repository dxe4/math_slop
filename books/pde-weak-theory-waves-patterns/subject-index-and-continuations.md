
# Subject Index and Continuations

The [Sobolev opening](sobolev-spaces.md) contains almost-everywhere representatives, weak derivatives, distributional point masses, completeness, interval absolute continuity, traces, zero-boundary closure, Poincaré estimates, coercive forms, dual data, and continuous dependence. Exercises 1–3 distinguish corner, singular-power and jump behavior; 4 treats the boundary norm; 5–6 solve the smooth Poisson model and analyze the point-load model; 7–9 treat coefficient bounds, failed coercivity and stability; 10 treats a derivative limit.

For model classification and classical equations use [Partial Differential Equations](#/books/partial-differential-equations). For Hilbert duality use [Functional Analysis](../functional-analysis/orthonormal-bases-riesz.md). For physical stress, flux and closure use [Fields and Continua](#/books/fields-fluids-continuum). For computational enclosures, conditioning and error use [Numerical Mathematics](#/books/numerical-mathematics-error-algorithms).

For coercivity, Neumann compatibility, trace lifts and Galerkin estimates use [elliptic problems](elliptic-parabolic-weak-theory.md). For coefficient interfaces, corner singularities and derivative gains use [regularity](regularity.md). For initial traces and Galerkin evolution use [parabolic equations](parabolic-equations.md); for generators, resolvents and perturbations use [semigroups](semigroups-evolution-equations.md).

For wave displacement/velocity spaces, cones and acoustic flux use [hyperbolic energy](hyperbolic-conservation-laws.md). For characteristic breaking, jump defects, fans and viscosity use [entropy shocks](conservation-laws-shocks.md). For obstacles, double wells and nonattained infima use [direct methods](variational-direct-methods.md). For invariant rectangles, discrete domain bands and nonlinear-instability boundaries use [reaction–diffusion](reaction-diffusion-patterns.md).

The complete earlier [elliptic/parabolic](retained-elliptic-parabolic-reading.md) and [hyperbolic/conservation](retained-hyperbolic-conservation-reading.md) readings remain available outside the primary route. Original files remain on disk, and old semantic addresses have explicit aliases to the actual primary destinations.
