
# Subject Index by Stable Chapter {#section-1-subject-index-by-stable-chapter}

This index includes earlier retained readings as well as chapters in the current main route. Earlier chapter IDs remain valid reading locations.

This index uses the exact `chapter_id` printed in each chapter's front matter instead of format-specific page numbers. A locator names the chapter in which the subject is defined, proved, applied, computed, or diagnosed. Several locators indicate that the idea is deliberately revisited from different viewpoints.

For accessible use, entries are ordered alphabetically, written as text, and do not depend on color, indentation alone, or a visual diagram. A screen-reader user can search for an entry or copy its backticked stable ID into the library search. “See” redirects a synonym to the preferred entry; “see also” gives a conceptual cross-reference. “Boundary” identifies a warning about the limits of a method rather than a complete treatment. This index is a substantive navigation aid whose stable locators survive layout changes.
