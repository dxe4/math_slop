## Glossary {#section-5-glossary}

**Arithmetic sequence.** A sequence in which the difference between consecutive terms is constant. The $n$-th term is $a_{n} = a_{1} + (n - 1)d$. Ch. **Patterns and Sequences**.

**Common difference.** The constant difference between consecutive terms of an arithmetic sequence. Ch. **Patterns and Sequences**.

**Common ratio.** The constant ratio between consecutive terms of a geometric sequence. Ch. **Patterns and Sequences**.

**Consistent system.** A system of linear equations that has at least one solution. Ch. **Equations with Two Unknowns**.

**Coordinate pair.** An ordered pair $(x, y)$ that locates a point on a plane. Ch. **Graphing Stories**.

**Dependent system.** A system of linear equations that describes the same line, giving infinitely many solutions. Ch. **Equations with Two Unknowns**.

**Difference of squares.** The identity $a^{2} - b^{2} = (a + b)(a - b)$. Ch. **Equivalent Expressions**.

**Distributive property.** $a(b + c) = ab + ac$. Used for expanding brackets and justifying equivalence. Ch. **A letter can hold a place**.

**Domain.** The set of allowed inputs for a function or formula. Ch. **Graphing Stories**.

**Elimination.** A method for solving systems of equations by adding or subtracting equations to remove a variable. Ch. **Equations with Two Unknowns**.

**Equivalent expressions.** Expressions that yield the same value for every valid substitution. Ch. **Equivalent Expressions**.

**Factorise.** To write an expression as a product of simpler expressions. Ch. **Equivalent Expressions**.

**Feasible region.** The set of points that satisfy all constraints in a system of inequalities. Ch. **Inequalities and Regions**.

**Geometric sequence.** A sequence in which the ratio between consecutive terms is constant. The $n$-th term is $a_{n} = a_{1} r^{n - 1}$. Ch. **Patterns and Sequences**.

**Half-plane.** The region on one side of a line in the coordinate plane. Ch. **Inequalities and Regions**.

**Inconsistent system.** A system of linear equations with no solution; the lines are parallel. Ch. **Equations with Two Unknowns**.

**Independent variable.** The quantity that is chosen or controlled in a relationship. Ch. **A letter can hold a place**.

**Intercept.** The value of the dependent variable when the independent variable is zero. Ch. **Graphing Stories**.

**Like terms.** Terms that contain exactly the same variables raised to exactly the same powers. Ch. **Equivalent Expressions**.

**Linear function.** A function whose graph is a straight line, expressible as $y = mx + c$. Ch. **Graphing Stories**.

**Range.** The set of possible outputs of a function. Ch. **Graphing Stories**.

**Recurrence relation.** A rule that defines each term of a sequence from earlier terms. Ch. **Patterns and Sequences**.

**Slope.** The ratio of vertical change to horizontal change between two points on a line: $m = \frac{y_{2} - y_{1}}{x_{2} - x_{1}}$. Ch. **Graphing Stories**.

**Slope-intercept form.** The equation $y = mx + c$, where $m$ is the slope and $c$ is the $y$-intercept. Ch. **Graphing Stories**.

**Solution of a system.** A pair $(x, y)$ that satisfies both equations simultaneously. Ch. **Equations with Two Unknowns**.

**Substitution.** A method for solving equations or systems by replacing a variable with an equivalent expression. Ch. **A letter can hold a place**; Ch. **Equations with Two Unknowns**.

**Unknown.** A symbol representing a specific value to be determined. Ch. **A letter can hold a place**.

**Variable.** A symbol representing a quantity that may vary within a given context. Ch. **A letter can hold a place**.
