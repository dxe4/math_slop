
# Glossary

**Algebraic element:** an element satisfying a nonzero polynomial over the named base. **Degree:** dimension over the named base field. **Minimal polynomial:** the monic irreducible polynomial generating the evaluation kernel. **Splitting field:** the field generated by all roots of a nonzero polynomial over its base. **Normal extension:** an algebraic extension containing all conjugate roots of every irreducible base polynomial with one root in the extension. **Separable element:** an algebraic element with distinct conjugate roots. **Primitive element:** one element generating the whole field extension. **Fixed field:** the subfield fixed pointwise by a specified automorphism subgroup. **Constructible real number:** a coordinate obtainable from the fixed unit segment by finitely many ruler and compass operations.
