# Algebra and functions from machines to proof

**Audience.** Independent learners moving from a first encounter with rules through secondary algebra to proof-oriented function theory.

**Goal.** Build a connected command of equations, inequalities, functions, polynomial and rational structure, exponential models, recurrences, and functional equations.

**Estimated time.** About 190 hours.

> This is a reading and exploration path across selected resources; it does not supply one primary-book course syllabus. Its existing activities and study identities remain available.
