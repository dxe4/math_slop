# Discrete mathematics from relations to exchange

**Audience.** Learners moving from elementary proof and counting into structural graph theory, extremal combinatorics, and matroids.

**Goal.** Model finite structures precisely, prove and count with several methods, audit exact experiments, and recognize when exchange supports greedy reasoning.

**Estimated time.** About 145 hours.

> Use the named course for the current chapter sequence. The earlier path and its original study records remain available separately. See the [course](#/courses/atlas-discrete-mathematics-structures).

## Capstone

Build a bounded finite structure dossier containing definitions, relation and graph views, a structural count, a proof, an extremal bound, a game or probability lens, and a deterministic matroid or non-matroid audit.
