# Graduate analysis

**Audience.** Advanced undergraduates or graduate learners preparing for analysis research.

**Goal.** Progress from rigorous real analysis to measure, operators, frequencies, PDE, and probability.

**Estimated time.** About 600 hours.

> This is a reading and exploration path across selected resources; it does not supply one primary-book course syllabus. Its existing activities and study identities remain available.
