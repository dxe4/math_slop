## Numeracy progression and intervention versions

The new teaching sequence has four connected sessions, each proposed as twenty minutes in an operational protocol: three minutes eliciting a response, five comparing quantities/representations, seven constructing and explaining a solution, and five on a changed case. Those eighty instructional minutes define the proposed routine version; they do not estimate course workload or observed delivery.

Call the proposed intervention **R4** and the comparator **C4**. R4 uses an explicit contrast, asks for a rival explanation of one authored error, then fades its prompts. C4 has the same mathematical items, total time, materials, permitted access formats and worked answers, but uses individual solution followed by comparison with the worked answer, without the explicit rival-explanation prompts. This isolates a declared routine contrast in the proposal, not in observed practice. Teachers would know their scripts; masking scorers does not blind teachers. A deviation ledger records time, items, access support, extra hints and departures from script. Changing content or help by arm changes the treatment version.

| --- | --- | --- |
| S1: reference and measure | Name L in cm, an instrument reading in ticks and u in cm; derive L=(r−z)/s and q=L/u. Compare the valid inverse with dividing the raw reading by s. Show q·u=L before symbols are faded. | Fix r,s and change z only to test attention to offset; then fix physical L and change u to distinguish unit change from object change. |
| S2: signed change and rate | Put initial and final values in an ordered table. Compute ΔT=T_end−T_start, then ΔT/Δt for Δt>0. ## Constructs, tasks and measurement identification

“Numeracy understanding” is too broad for one total. Define four task-specific indicators, each 0 or 1, before examining outcomes:

- **K1, coordinate references:** explicitly invert calibration and identify L, u and the dimensionless count q, with a valid inverse check q·u=L.
- **K2, signed rate:** use final minus initial over positive elapsed time, give units and interpret the sign.
- **K3, sharp feasibility:** derive the correct closed interval, justify the order/positivity conditions and feasible endpoint attainment.
- **K4, generality:** give the algebraic S4 order proof with s>0 and distinguish it from sampled examples and the raw-ratio claim.

A one requires every named component; otherwise retain the partial evidence and code zero for this declared indicator. Missing responses are missing, not automatic zeros. The sum 0–4 is a transparent scoring convention, not an interval-scale validation or a measure of fixed ability. Report the profile with the sum. Two profiles can have equal sums and different teaching needs; ceiling scores can conceal additional reasoning.

Map at least two tasks to each indicator: an anchor form and a changed form using the same indicator definition. For K1, the calibration and a changed unit test separate offset and unit explanations. For K2, forward and reversed motion separate signed change from magnitude. For K3, an anchor and a changed closed interval test the same endpoint criterion; a separate half-open teaching/response-process probe distinguishes a maximum from a supremum and is not scored under the fixed K3 rule. For K4, an arbitrary pair r_1,r_2 plus a numerical counterexample separates general proof from examples. Giving a formula can change K1 if selecting that formula is part of the target; a glossary defining “tick” does not by itself select it. Keep a support ledger and inspect actual response processes.

A small formal example exposes a measurement identification issue. Let θ be a latent account of the four constructs and let task scores satisfy a proposed model Y=Aθ+ε. If two columns of A are identical, changing θ by adding t to one corresponding component and subtracting t from the other leaves Aθ unchanged. Those components cannot be distinguished from those tasks even with zero noise. In particular A=[[1,1],[1,1]] maps (1,0) and (0,1) to the same (1,1). Adding a row [1,0] separates them. This is an algebraic identification demonstration, not a fitted psychological model; actual response evidence might reject additivity, the constructs or the scoring rule.

For fairness, compare the mathematical demand and barriers in each format before comparing scores. A text table, tactile/static number line, speech with a verbatim transcript, typed equations or switch-based selection can preserve givens and reasoning opportunities. Screen-reader compatibility, translation quality and assistive-technology effectiveness would need actual use and review. Same raw scores or one accommodation cannot establish measurement invariance. A mathematical proof that two forms ask the same numerical relation is necessary evidence about content, not a demonstration that they are equally difficult or interpreted identically.

**FND-SP-Q03.** Give two distinct K profiles with sum 2 and distinct next questions. **Model:** 1100 needs a feasible-endpoint argument and a general proof; 0011 needs a quantity/unit reconstruction and signed-rate explanation. Neither is a fixed learner type. **FND-SP-Q04.** Exhibit a nonzero invisible change in the two-column measurement example and repair the design. **Model:** v=(1,−1) gives Av=0; [1,0]v=1, so adding that discriminating row makes this particular ambiguity observable. It does not prove a valid latent scale.

## Agreement, disagreement and score sensitivity

Two masked initial coders can disagree, agree for different reasons or agree on an invalid criterion. Preserve the initial labels, then reconcile against the full task, response and scoring rule with written reasons. ## Matched-pair assignment and identification

There are six fixed fictional classes, paired **AB, CD, EF** before assignment using declared pre-assignment information. In a proposed implemented randomized version, three independent fair coins assign exactly one member of each pair to R4 and the other to C4. Thus ACE, ACF, ADE, ADF, BCE, BCF, BDE, BDF each have probability 1/8. Displayed ACE receives R4. This is not the original uniform-three-of-six design with 20 possible triples.

Let Y_j(z) be class j's full-fixed-roster mean post-minus-pre score under assignment z and the specified version, timing and support policy. The finite equal-class target is τ_C=(1/6)Σ_j(Y_j(1)−Y_j(0)). Require consistency of observed and potential outcomes and no interference between classes under this version. The observed paired statistic is D_C=(1/3)Σ_pairs(y_treated−y_control). Within pair {a,b}, averaging the two coin outcomes gives
E[y_T−y_C]=((Y_a(1)−Y_b(0))+(Y_b(1)−Y_a(0)))/2,
half the sum of its two class effects. Averaging the three pairs proves E[D_C]=τ_C. Matching need not make the two potential outcomes equal; the fair design supplies this expectation.

Roster-weighted arm means define a different descriptive D_S. A fixed-student causal target is τ_S=Σ_j N_j(Y_j(1)−Y_j(0))/Σ_jN_j. A general realized arm-ratio contrast is not automatically unbiased for τ_S. In these particular fixtures the two members of each pair have equal N, so each allocation has treated and control roster totals 18. Therefore here D_S=(1/18)Σ_pairs N_pair(y_T−y_C), and the same expectation argument gives E[D_S]=τ_S. That special fixed-denominator proof must not be transferred to unequal-within-pair rosters; the software reports a descriptive statistic and makes no automatic causal certification.

Under the **classwise sharp null** Y_j(1)=Y_j(0) for every j and with complete valid outcomes, fix the observed class outcomes and reassign within pairs. Count absolute contrasts at least as large as the displayed contrast, including ties. A weak average-zero null permits effects to cancel and does not supply these fixed outcomes. Changing coin probabilities, pairing, statistic, missingness or assignment history changes the reference law.

Every assignment has a complementary assignment reversing D_C. Hence the observed absolute statistic is attained by at least two of eight assignments; a nonzero exact two-sided p-value is at least 1/4. If the observed statistic is zero the tail is all eight. This tiny design cannot produce a tail below 0.05. No power claim or empirical effectiveness follows from that design-resolution result.

**FND-SP-Q09.** Exhibit a triple disallowed here but allowed in original Protocol P; derive the paired unbiasedness equation. **Complete model:** ABC takes both A and B and neither E nor F, so is disallowed. The preceding average of the two outcomes of one coin within each pair, then division by three, gives (1/6) times all six effects. **FND-SP-Q10.** Explain why outcome-guided re-pairing or using the old 20-row table is invalid. **Model:** pairing and assignment were fixed before outcomes; changing them changes the analysis design. ## Missing outcomes and bounded sensitivity

Let each class have a fixed roster N, baseline total B on the 0–4 convention, r observed follow-up scores with total S, and N−r missing scores. The complete fixed-roster gain would be (S+M−B)/N, where M is the missing-score total. With no additional information, 0≤M≤4(N−r), so its sharp deterministic range is
[(S−B)/N,(S+4(N−r)−B)/N].
All-zero and all-four missing scores attain the endpoints, independently by class in this exercise. An observed score of zero differs from an absent score. The code preserves both N and r, and accepts r=0 only with S=0.

For an ACE contrast, the lower endpoint takes A,C,E lower gains and B,D,F upper gains; reverse those choices for the upper endpoint. Full-roster weighted contrasts use arm total post-minus-pre over arm roster total, with the same opposing endpoint choice. The targets and weights remain explicit. A respondent-only post mean compared with the **whole-roster** baseline is a changed-population descriptive comparison, not a matched complete-case mean gain: matched baseline totals for the respondents were not supplied. Do not infer their values from the full-roster mean.

Missingness prevents the complete-data classwise sharp-null table from being computed for this full-roster outcome without an additional specified analysis. We do not insert zeros, choose a favorable completion or report an old p-value. The software returns no randomization tail when outcomes are missing or assignment is voluntary. Bounds still describe stipulated feasible recorded contrasts, but neither bounds nor exact arithmetic create random assignment.

**FND-SP-Q11.** Prove the class gain endpoints, including r=N and r=0. **Complete model:** the expression is affine increasing in M; at full follow-up M=0 and the interval collapses; with no observed follow-up S=0, the range is [−B/N,4−B/N]. The respondent mean is undefined if r=0. **FND-SP-Q12.** If a descriptive bound is strictly positive, does voluntary assignment identify τ_C? **Model:** no; the unobserved potential outcomes and confounding remain unconstrained by that observed-arm calculation. Positivity of a stipulated descriptive interval does not identify an intervention effect.

    }

      const mean=p => {
        const rows=arm(p);
        return sub(R(rows.reduce((s,row) => s+row.post,0),rows.reduce((s,row) => s+row.r,0)),
          R(rows.reduce((s,row) => s+row.pre,0),rows.reduce((s,row) => s+row.n,0)));
      };

    }

    if (assignment!=='paired-random') unavailable.push('voluntary-assignment');
    if (classes.some(row => row.r!==row.n)) unavailable.push('missing-outcomes');

    if (unavailable.length===0) {
      const values=[];
      allocations=Array.from({length:8},(_,mask) => {
        const chosen=[], terms=[];

          chosen.push(classes[first].id);
          terms.push(sub(low[first],low[other]));
        }
        const value=div(sum(terms),R(3));
        values.push(value);
        return {treated:chosen.join(''),value:text(value)};
      });
      const extreme=values.filter(value => cmp(abs(value),abs(values[0]))>=0n).length;
      tail={extreme,total:8,p:text(R(extreme,8))};
    }
    const counts=[0,0,0,0];

    const [a,b,c,d]=counts, observed=R(a+d,8);
    const expected=R((a+b)*(a+c)+(c+d)*(b+d),64);
    const kappa=cmp(expected,R(1))===0n ? null : text(div(sub(observed,expected),sub(R(1),expected)));
    return {
      classGainBounds:low.map((value,i) => interval([value,high[i]])),
      respondentClassContrast,respondentStudentContrast,
      classBounds:interval(classRange),studentBounds:interval(studentRange),
      correctedClassBounds:interval(corrected(classRange)),
      correctedStudentBounds:interval(corrected(studentRange)),
      agreement:{table:counts,observed:text(observed),expected:text(expected),kappa},
      allocations,tail,unavailable
    };
  }
