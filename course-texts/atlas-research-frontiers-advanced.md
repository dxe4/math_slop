## RFA-3 — Landscapes, averaging and two finite proofs

Take the underlying interval modules over $\mathbb F_2$ throughout this project. Landscape heights, integrals and arithmetic means use ordinary real arithmetic, not addition modulo two. For a finite interval $[b,d)$ with real $b<d$, define its tent

$$T_{b,d}(t)=\max\{0,\min(t-b,d-t)\}.$$

It rises with slope 1 from $b$ to $(b+d)/2$, then falls with slope -1 to $d$, and vanishes elsewhere. Given a finite barcode, sort its tent heights at each $t$: $\lambda_k(t)$ is the $k$th largest height, padded by zeros when $k$ exceeds the number of bars. Repeated bars contribute repeated heights. This is the finite-bar form of Paper B's landscape definition. It also agrees with its centred-rank definition: the number of bars containing a centred interval of radius $h$ decreases as $h$ grows; the supremum of radii covered by at least $k$ bars is exactly the $k$th tent height. Use value zero when the admissible nonnegative-radius set is empty. At a half-open death endpoint the supremum need not be attained, which is why the tent still has that boundary value.

For these continuous, compactly supported finite landscapes define

$$I(\lambda)=\sum_k\int_{\mathbb R}\lambda_k(t)\,dt,\qquad
\|\lambda\|_\infty=\max_{k,t}\lambda_k(t).$$

**Finite Proposition 5 reconstruction.** Sorting preserves the sum of heights, so $\sum_k\lambda_k(t)=\sum_iT_{b_i,d_i}(t)$. Integrate the finite sum. Each tent is a triangle of base $L_i=d_i-b_i$ and height $L_i/2$, hence area $L_i^2/4$. Therefore

$$I(\lambda)=\frac14\sum_iL_i^2,\qquad
\|\lambda\|_\infty=\frac12\max_iL_i.$$

The maximum identity follows because the largest tent peak is attained and every level is at most the first. For an empty barcode take both quantities to be zero. Finiteness and finite endpoints matter: an essential bar is not a finite triangle with one endpoint quietly replaced by our plotting limit.

For two landscapes, our primary comparison is the **squared** L₂ distance

$$S(\lambda,\mu)=\sum_k\int_{\mathbb R}(\lambda_k(t)-\mu_k(t))^2\,dt.$$

It is nonnegative and invariant under exchanging the two arguments. It is not itself a metric: taking a square root gives the L₂ distance. Its exact integration on each linear segment uses RFA-1's squared-linear formula. For a collection of landscapes, average them pointwise, separately at each $(k,t)$, as in Paper B's equation (4). Scalar summaries such as $I$ and longest lifetime answer narrower questions; they can discard location information.

**Finite Theorem 13 reconstruction.** Consider a permitted bottleneck matching of two finite diagrams. Paired bars whose endpoints differ by at most $\varepsilon$ have tent heights differing by at most $\varepsilon$ at every $t$: both min and max are 1-Lipschitz under the coordinate sup metric. A bar sent to the diagonal has half-lifetime at most $\varepsilon$, so its tent differs from zero by at most $\varepsilon$. Pad both lists with zero tents to account for all unmatched bars on both sides.

If two equally long lists have a pairing with coordinate errors at most $\varepsilon$, their sorted $k$th values also differ by at most $\varepsilon$. Otherwise at least $k$ entries on one side would exceed the other side's $k$th value plus $\varepsilon$, forcing at least $k$ larger entries there, a contradiction. Interchange the sides for the reverse inequality. Thus every landscape level has pointwise error at most $\varepsilon$. Minimize over the finitely many finite-bar matching choices, including diagonal costs, to obtain

$$\sup_{k,t}|\lambda_k(t)-\mu_k(t)|\le d_B(D,E).$$

This proves the finite-diagram result under the stated conventions. It is not a new theorem, a proof of Paper B's unrestricted module statement, or a theorem about the distance between unknown generating populations. The earlier stability clinic supplies its own exact fixed-path and imported common-space boundaries.

function landscapeAudit(records) {
  const fail = message => { throw new RangeError(message); };
  if (!Array.isArray(records) || records.length !== 4) fail('four complete records required');
  const ids = new Set(), units = new Map();
  for (const row of records) {
    if (!row || typeof row.id !== 'string' || !/^[A-Za-z0-9]{1,12}$/.test(row.id) || ids.has(row.id)) fail('unique record ID required');
    ids.add(row.id);
    if (typeof row.unit !== 'string' || !/^[A-Za-z0-9]{1,12}$/.test(row.unit) || !['X','Y'].includes(row.group)) fail('unit and group required');
    if (!Array.isArray(row.bars) || row.bars.length !== 2) fail('two finite bars required');
    const bars = row.bars.map(bar => {
      if (!Array.isArray(bar) || bar.length !== 2 || !bar.every(Number.isInteger) || bar[0] < 0 || bar[1] > 32 || bar[0] >= bar[1]) fail('finite integer interval required');
      return [...bar];
    }).sort((a,b) => a[0]-b[0] || a[1]-b[1]);
    const encoded = JSON.stringify(bars);
    if (units.has(row.unit)) {
      const previous = units.get(row.unit);
      if (previous.group !== row.group || previous.encoded !== encoded) fail('copies within a unit must agree');
    } else units.set(row.unit, {name:row.unit, group:row.group, bars, encoded});
  }
  const data = [...units.values()];
  if (![2,4].includes(data.length)) fail('two or four units required');
  const m = data.length/2;
  if (data.filter(row => row.group === 'X').length !== m) fail('balanced observed unit groups required');
  const layers = row => Array.from({length:65}, (_,j) => row.bars.map(([b,d]) => Math.max(0,Math.min(j-2*b,2*d-j))).sort((a,b)=>b-a));
  const heights = data.map(layers);
  const area4 = data.map(row => row.bars.reduce((sum,[b,d])=>sum+(d-b)**2,0));
  const life = data.map(row => Math.max(...row.bars.map(([b,d])=>d-b)));
  const gcd = (a,b) => { while (b) [a,b]=[b,a%b]; return a; };
  const fraction = (a,b) => { const g=gcd(a,b); a/=g; b/=g; return b===1?String(a):a+'/'+b; };
  const assignments = [];
  for (let mask=0;mask<2**data.length;mask++) {
    const chosen=data.flatMap((_,i)=>(mask&(1<<i))?[i]:[]);
    if (chosen.length===m) assignments.push(chosen);
  }
  const score = chosen => {
    const signs=data.map((_,i)=>chosen.includes(i)?1:-1);
    let s=0;
    for(let k=0;k<2;k++) for(let j=0;j<64;j++) {
      const a=signs.reduce((sum,sign,i)=>sum+sign*heights[i][j][k],0);
      const b=signs.reduce((sum,sign,i)=>sum+sign*heights[i][j+1][k],0);
      s+=a*a+a*b+b*b;
    }
    const q=Math.abs(signs.reduce((sum,sign,i)=>sum+sign*area4[i],0));
    const z=Math.abs(signs.reduce((sum,sign,i)=>sum+sign*life[i],0));
    if (![s,q,z].every(Number.isSafeInteger)) fail('arithmetic bound exceeded');
    return [s,q,z];
  };
  const observed=data.flatMap((row,i)=>row.group==='X'?[i]:[]);
  const observedScores=score(observed);
  const raw=assignments.map(chosen=>({units:chosen.map(i=>data[i].name),raw:score(chosen)}));
  const denominators=[24*m*m,4*m,m];
  const counts=observedScores.map((value,k)=>raw.filter(row=>row.raw[k]>=value).length);
  return {
    unitCount:data.length, assignmentCount:raw.length,
    rows:raw.map(row=>({units:row.units,S:fraction(row.raw[0],denominators[0]),Q:fraction(row.raw[1],denominators[1]),M:fraction(row.raw[2],denominators[2])})),
    tailCounts:counts, p:counts.map(count=>fraction(count,raw.length))
  };
}
