const Q = k + (z0 / c) ** 2,
  kind = Q < 0 ? 'empty' : Q === 0 ? 'point' : 'ellipse',
  semiaxes = Q > 0 ? [a * Math.sqrt(Q), b * Math.sqrt(Q)] : null;
report({
  experiment: 'quadric-traces',
  units: 'm',
  input: { a, b, c, k, z0 },

  relation: 'x²/a²+y²/b²−z²/c²=k; not one global height graph',
  result: {
    Q,
    kind,

Analytic comparison and limits

At z=z0z=z_0, Q=k+(z0/c)2Q=k+(z_0/c)^2. Q<0Q<0: empty; Q=0Q=0: point; Q>0Q>0: ellipse semiaxes aQ,bQa\sqrt Q,b\sqrt Q. k=1k=1 is one-sheet; −1 two-sheet-1\text{ two-sheet}; 0 cone0\text{ cone}. The whole relation is not one global height graph. Non-finite numeric output raises an explicit precision error; null is reserved for a deliberately absent derivative.

  • Changed z0=3 mz_0=3\,\mathrm m, otherwise default: Q=2Q=2 and world trace semiaxes (22,2) m(2\sqrt2,\sqrt2)\,\mathrm m.

Boundary and failure behavior

Boundary: k=−1,z0=ck=-1,z_0=c gives a regular two-sheet vertex point; k=0,z0=0k=0,z_0=0 gives a singular cone apex point. Q<0Q<0 is empty.
