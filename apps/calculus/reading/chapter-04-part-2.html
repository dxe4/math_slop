Chapter synthesis

  • Limits concern nearby inputs; continuity additionally requires agreement with the value at the point.
  • Limit laws and squeezing establish limits under explicit hypotheses; epsilon–delta proofs state the full tolerance guarantee.
  • Infinite limits describe unbounded outputs, whereas limits at infinity describe distant inputs.
  • Continuity on a closed interval guarantees intermediate values, providing the foundation for reliable root bracketing.

Common mistakes to check

  • “The limit equals the function value.” A limit ignores the target point; a function can have limit 2 there and assigned value 7. Equality is an additional continuity condition. Test with problem 1
  • “A graph that looks connected proves continuity.” Finite resolution can hide holes, jumps, and rapid oscillations. A proof must control every sufficiently nearby input. Test with problem 33
  • “Opposite signs guarantee a root.” They do so under the intermediate value theorem’s continuity hypothesis; a step function can skip zero. Test with problem 34
