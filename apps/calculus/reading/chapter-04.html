1. Approaching a point without arriving

Suppose a sensor formula gives f(x)=(x2−1)/(x−1)f(x)=(x^2-1)/(x-1). At x=1x=1 the denominator is zero, so the formula does not define a value. Nevertheless, at every other input it equals x+1x+1. Inputs 0.90.9 and 1.11.1 give outputs 1.91.9 and 2.12.1; inputs 0.9990.999 and 1.0011.001 give 1.9991.999 and 2.0012.001. The nearby outputs suggest 22. A limit describes this nearby behavior, independently of whether the function has a value at the target input.

We write lim⁡x→af(x)=L\lim_{x\to a}f(x)=L when values of f(x)f(x) become arbitrarily close to LL whenever domain inputs xx are sufficiently close to aa but different from aa. Throughout, an approach point must have domain inputs arbitrarily near it. Otherwise there is no meaningful approach to inspect. A limit is not a story about an input moving in time: it is a statement about every eligible input in a sufficiently small neighborhood. For the two-sided convention used here, domain inputs must approach aa from both sides before comparing left and right limits. For example, x\sqrt{x} at a=0a=0 has a right-hand approach but no domain inputs approaching from the left.

A left-hand limit, written lim⁡x→a−f(x)\lim_{x\to a^-}f(x), restricts inputs to x<ax<a. A right-hand limit, written lim⁡x→a+f(x)\lim_{x\to a^+}f(x), restricts inputs to x>ax>a. When the domain has nearby points on both sides, a finite two-sided limit exists exactly when both one-sided limits exist and agree. For the step function j(x)=0j(x)=0 when x<0x<0 and j(x)=1j(x)=1 when x≥0x\ge0, lim⁡x→0−j(x)=0\lim_{x\to0^-}j(x)=0 and lim⁡x→0+j(x)=1\lim_{x\to0^+}j(x)=1. Its two-sided limit does not exist, even though j(0)j(0) is defined.

Domain restrictions matter. The function x\sqrt{x} has only a right-hand approach at the endpoint zero of its domain [0,∞)[0,\infty). We describe its endpoint behavior by lim⁡x→0+x=0\lim_{x\to0^+}\sqrt{x}=0. When discussing continuity on a closed interval, endpoint limits will always be taken from within the interval. Unless physical units are specified, the examples in this chapter use dimensionless inputs and outputs.

Changing the value at the target point never changes a limit. Define g(x)=x+1g(x)=x+1 for x≠1x\ne1, but set g(1)g(1) equal to any number, or leave it undefined. All punctured-neighborhood values are identical, so lim⁡x→1g(x)=2\lim_{x\to1}g(x)=2 in every version. Continuity asks the additional question whether the assigned value is also two. This separation matters when measured data contain a bad reading at one instant: a limiting trend may survive a single corrupted sample, while the record as a function is not continuous at that point. A limit concerns arbitrarily near inputs, not the isolated central value.

The requirement that eligible domain points approach the target avoids vacuous claims. If a function is defined only at the integers, there are no distinct domain points arbitrarily close to the integer 33. Standard calculus therefore does not assign an ordinary limit there from this domain. In contrast, the domain (0,∞)(0,\infty) has points arbitrarily close to zero from the right, and a right-hand limit at zero is meaningful even though the function may be undefined at zero. At each endpoint or gap, state which approaches the domain actually supports.

There is a useful sequential test in the real line. If f(x)→Lf(x)\to L as x→ax\to a, then every sequence of allowed inputs xn≠ax_n\ne a with xn→ax_n\to a has f(xn)→Lf(x_n)\to L. Conversely, if a finite limit fails, some fixed output tolerance is violated arbitrarily close to aa; choose one violating input within 1/n1/n for each nn to build a counterexample sequence. Thus two sequences with different output limits disprove a proposed limit. A single favorable sequence cannot prove one, because the definition must cover all nearby inputs.

2. Laws, cancellation, and squeezing

Limit laws let us assemble complicated conclusions from simpler ones. If f(x)→Lf(x)\to L and g(x)→Mg(x)\to M as x→ax\to a, where LL and MM are finite real numbers, then f+g→L+Mf+g\to L+M, f−g→L−Mf-g\to L-M, cf→cLcf\to cL for a fixed constant cc, and fg→LMfg\to LM. The quotient tends to L/ML/M provided M≠0M\ne0. Polynomial limits can therefore be found by substitution; rational functions also permit substitution wherever their denominator is nonzero.

A quotient producing 0/00/0 after substitution has not evaluated to zero, infinity, or any other answer. The quotient law simply does not apply. Different expressions with this same preliminary form have different limits: x/x→1x/x\to1, x2/x→0x^2/x\to0, and x/x2x/x^2 has no finite two-sided limit as x→0x\to0. Algebra can reveal the nearby behavior. Factoring (x2−1)/(x−1)(x^2-1)/(x-1) gives x+1x+1 for x≠1x\ne1, which is exactly the set of inputs relevant to the limit. Cancellation changes the domain if treated as a global identity, but preserves the limit at the hole.

The squeeze theorem handles functions whose values are difficult to track individually. Suppose p(x)≤f(x)≤q(x)p(x)\le f(x)\le q(x) for all eligible xx sufficiently near aa, with x≠ax\ne a. If both p(x)p(x) and q(x)q(x) tend to the same finite number LL, then f(x)f(x) also tends to LL. Indeed, once both bounds lie within any prescribed tolerance of LL, the trapped value must lie there too. The inequalities must hold throughout a neighborhood, not merely at selected sample points.

For x≠0x\ne0, the bound −1≤sin⁡(1/x)≤1-1\le\sin(1/x)\le1 implies −x2≤x2sin⁡(1/x)≤x2-x^2\le x^2\sin(1/x)\le x^2. Both outer functions tend to zero, so the middle function tends to zero despite oscillating more rapidly near zero. Trigonometric arguments here are dimensionless and measured in radians. The oscillation sin⁡(1/x)\sin(1/x) alone has no limit: inputs 1/(π/2+2πn)1/(\pi/2+2\pi n) give value 11, whereas inputs 1/(3π/2+2πn)1/(3\pi/2+2\pi n) give −1-1 as the positive integers nn grow. Shrinking amplitude, rather than shrinking oscillation frequency, makes the product converge.

Rationalization is another way to uncover a hidden limit. For x≠0x\ne0 near zero, (1+x−1)/x(\sqrt{1+x}-1)/x becomes 1/(1+x+1)1/(\sqrt{1+x}+1) after multiplying by the conjugate. The new expression tends to 1/21/2 as x→0x\to0. We did not assert that the two formulas agree at zero; they agree on the punctured neighborhood relevant to the limit. Always check the square-root domain 1+x≥01+x\ge0 and that the conjugate denominator is nonzero nearby. The same reasoning later becomes the derivative calculation for a square root.

A vanishing factor times a bounded factor tends to zero, even if the bounded factor has no limit. In symbols, if u(x)→0u(x)\to0 and ∣v(x)∣≤C|v(x)|\le C near the target, then ∣u(x)v(x)∣≤C∣u(x)∣→0|u(x)v(x)|\le C|u(x)|\to0. Boundedness is essential: x(1/x)=1x(1/x)=1 for x≠0x\ne0, so a zero-tending factor times an unbounded one need not tend to zero. Nor does the written form 0⋅∞0\cdot\infty identify a limit; x2(1/x)→0x^2(1/x)\to0 while x(1/x2)x(1/x^2) has no finite two-sided limit. Rewrite the actual function and check hypotheses.

Limit laws are local. They require functions to be defined on a common punctured neighborhood of the approach point, and the quotient law requires a nonzero denominator limit. If g(x)→M≠0g(x)\to M\ne0, then g(x)g(x) is nonzero for every sufficiently near eligible input: require ∣g(x)−M∣<∣M∣/2|g(x)-M|<|M|/2. This establishes a neighborhood where division is legal. If the denominator limit is zero, further algebra, one-sided analysis, or an unbounded-limit argument is needed. A symbolic substitution that produces 0/00/0 is a request for analysis, not a result.

Why the ordinary limit laws work

If f(x)→Lf(x)\to L and g(x)→Mg(x)\to M as x→ax\to a within a common domain, then f+g→L+Mf+g\to L+M and fg→LMfg\to LM. If M≠0M\ne0, f/g→L/Mf/g\to L/M wherever the quotient is defined near aa.

Reasoning and proof

For the sum, let ε>0\varepsilon>0. The two limit definitions provide neighborhoods where ∣f(x)−L∣<ε/2|f(x)-L|<\varepsilon/2 and ∣g(x)−M∣<ε/2|g(x)-M|<\varepsilon/2. In their intersection, the triangle inequality gives ∣(f+g)−(L+M)∣≤∣f−L∣+∣g−M∣<ε|(f+g)-(L+M)|\le|f-L|+|g-M|<\varepsilon. The same xx must satisfy both estimates; using the smaller of the two δ\delta values achieves that. This is why a finite number of limits may be combined without changing the order of the quantifiers.

For the product, first use g→Mg\to M to make ∣g(x)∣≤∣M∣+1|g(x)|\le|M|+1 on a punctured neighborhood. The identity fg−LM=(f−L)g+L(g−M)fg-LM=(f-L)g+L(g-M) then gives ∣fg−LM∣≤(∣M∣+1)∣f−L∣+∣L∣∣g−M∣|fg-LM|\le(|M|+1)|f-L|+|L||g-M|. Make the two terms smaller than ε/2\varepsilon/2 by choosing sufficiently small neighborhoods. Local boundedness is the missing step in the casual statement that a small factor times “something” is small. We did not assume ff or gg is globally bounded.

For the quotient, M≠0M\ne0 lets us require ∣g(x)−M∣<∣M∣/2|g(x)-M|<|M|/2; then ∣g(x)∣>∣M∣/2|g(x)|>|M|/2, so division is defined nearby. Moreover ∣1/g−1/M∣=∣g−M∣/(∣gM∣)≤2∣g−M∣/∣M∣2|1/g-1/M|=|g-M|/(|gM|)\le2|g-M|/|M|^2, proving reciprocal convergence. Apply the product result to ff and 1/g1/g. If M=0M=0, this protection disappears: 1/x1/x near zero is an immediate counterexample. The limit laws are proofs about neighborhoods, not formal instructions to substitute a value into an undefined expression.

3. Turning closeness into a proof

Graphs and tables help us propose a limit, but every finite display leaves unexamined inputs. The epsilon–delta definition expresses the guarantee a proof must supply. For every ε>0\varepsilon>0, there must be a δ>0\delta>0 such that every domain input satisfying 0<∣x−a∣<δ0<|x-a|<\delta also satisfies ∣f(x)−L∣<ε|f(x)-L|<\varepsilon. Epsilon is the requested output tolerance; delta is an input tolerance sufficient to meet it. The strict inequality 0<∣x−a∣0<|x-a| deliberately excludes the point aa.

The order of choices is essential. A challenger may request any positive ε\varepsilon. We then choose δ\delta, possibly depending on ε\varepsilon, but before knowing which eligible xx will be tested. One lucky input is insufficient, and one fixed small tolerance does not establish the limit. If xx has units of seconds and f(x)f(x) has units of metres, δ\delta is measured in seconds and ε\varepsilon in metres; the conversion between them reflects the function’s sensitivity.

For f(x)=3x−2f(x)=3x-2 at a=4a=4, the proposed limit is 1010. Calculate the exact output error: ∣(3x−2)−10∣=3∣x−4∣|(3x-2)-10|=3|x-4|. To make this less than ε\varepsilon, it is enough to require ∣x−4∣<ε/3|x-4|<\varepsilon/3. Proof: given any ε>0\varepsilon>0, choose δ=ε/3\delta=\varepsilon/3. If 0<∣x−4∣<δ0<|x-4|<\delta, then ∣f(x)−10∣=3∣x−4∣<3δ=ε|f(x)-10|=3|x-4|<3\delta=\varepsilon. This completes a proof for all positive tolerances, rather than a numerical check of a few cases.

A smaller positive delta would also work; there is usually no need to find the largest one. For a general nonconstant linear function mx+bmx+b, choose δ=ε/∣m∣\delta=\varepsilon/|m| to prove its limit at any aa is ma+bma+b. If m=0m=0, the output error is already zero, so any positive δ\delta works. This separate constant case prevents an invalid division by zero. Nonlinear proofs often require first restricting ∣x−a∣<1|x-a|<1 to control an extra factor; chapter 5 will use this kind of control when defining derivatives.

A nonlinear epsilon–delta proof often begins by restricting the neighborhood before choosing the final tolerance. To show 1/x→11/x\to1 at x=1x=1, first require ∣x−1∣<1/2|x-1|<1/2; then x>1/2x>1/2 and ∣1/x−1∣=∣x−1∣/∣x∣≤2∣x−1∣|1/x-1|=|x-1|/|x|\le2|x-1|. Given ε>0\varepsilon>0, choose δ=min⁡(1/2,ε/2)\delta=\min(1/2,\varepsilon/2). Every allowed xx with 0<∣x−1∣<δ0<|x-1|<\delta satisfies both the denominator bound and the requested output bound. This proof avoids trying to choose a δ\delta that depends on the unknown test input.

To disprove a proposed finite limit LL, it is enough to find one positive ε0\varepsilon_0 such that every proposed δ>0\delta>0 admits an eligible xx with 0<∣x−a∣<δ0<|x-a|<\delta but ∣f(x)−L∣≥ε0|f(x)-L|\ge\varepsilon_0. For example, the right and left values of the step function near zero stay one unit apart. No single number can be within less than half a unit of both branches. Another route is to produce two approach sequences with different output limits. These are constructive failures of the universal claim, not merely statements that a graph looks jumpy.

Proofs should state the candidate limit before searching for delta. Algebra then expresses the output error in terms of the input distance. For a polynomial one often factors a difference; for a reciprocal one first bounds the denominator away from zero; for an oscillating function one bounds its amplitude. The final sentence must use the chosen delta for an arbitrary eligible input. A table of ten increasingly close inputs can help guess LL or detect an algebra mistake, but no finite table supplies the required universal guarantee.

The order of the quantifiers is the heart of a limit proof. In lim⁡x→af(x)=L\lim_{x\to a}f(x)=L, an arbitrary positive output tolerance ε\varepsilon is announced first. We must then choose an input tolerance δ>0\delta>0 that works for every allowed xx with 0<∣x−a∣<δ0<|x-a|<\delta. A choice of δ\delta may depend on ε\varepsilon, on fixed constants in the function, and on the fixed point aa; it cannot depend on the particular xx that arrives afterward. This explains why checking a long table of inputs is only evidence. The table picks finitely many xx values, while the proof must handle all sufficiently close inputs at once. It also explains why the value f(a)f(a) is irrelevant to the limit: the punctured condition deliberately excludes x=ax=a. When a bound contains a factor such as ∣x+a∣|x+a|, first keep xx in a simple neighborhood of aa so that factor has a uniform bound, and only then choose δ\delta to control ε\varepsilon.

For f(x)=1/xf(x)=1/x on R∖{0}\mathbb R\setminus\{0\} near 22, the output error is ∣1/x−1/2∣=∣x−2∣/(2∣x∣)|1/x-1/2|=|x-2|/(2|x|). The denominator moves with xx, so first require ∣x−2∣<1|x-2|<1. Every input in that band has x>1x>1, giving the uniform bound 1/(2∣x∣)<1/21/(2|x|)<1/2. Given ε>0\varepsilon>0, choose δ=min⁡(1,2ε)\delta=\min(1,2\varepsilon) before an input is named. Then every eligible xx with 0<∣x−2∣<δ0<|x-2|<\delta has output error <∣x−2∣/2<δ/2≤ε<|x-2|/2<\delta/2\le\varepsilon. Problem 04.38 asks you to build this proof and compare the sufficient radius with the greatest one. Figure 4.4 gives a separate x2x^2 view of how the output request and input choice interact.

The order is ∀ε>0  ∃δ>0  ∀x∈dom⁡(f)\forall\varepsilon>0\;\exists\delta>0\;\forall x\in\operatorname{dom}(f), followed by the punctured-input implication. If we choose δ\delta after seeing each xx, we can make the antecedent false and claim success without controlling any output. Problem 04.39 exposes that trap for 1/x1/x near zero. One failed proposed radius at a tolerance rejects that radius only; a failed limit needs one fixed positive output tolerance that defeats every positive radius. Keep those claims distinct when you write a counterexample.

4. Unbounded behavior and distant behavior

An infinite limit describes unbounded growth, not convergence to a real number called infinity. The notation lim⁡x→af(x)=+∞\lim_{x\to a}f(x)=+\infty means that for every threshold M>0M>0, some δ>0\delta>0 makes f(x)>Mf(x)>M whenever 0<∣x−a∣<δ0<|x-a|<\delta within the domain. For −∞-\infty, require f(x)<−Mf(x)<-M instead. One-sided versions restrict xx to the indicated side. These statements demand arbitrarily large magnitude, not merely an impressive value on a screen.

For 1/x21/x^2 as x→0x\to0, choose δ=1/M\delta=1/\sqrt M. Then 0<∣x∣<δ0<|x|<\delta implies 1/x2>M1/x^2>M, proving the limit is +∞+\infty. By contrast, lim⁡x→0−1/x=−∞\lim_{x\to0^-}1/x=-\infty and lim⁡x→0+1/x=+∞\lim_{x\to0^+}1/x=+\infty. Its two-sided limit is neither +∞+\infty nor −∞-\infty. A vertical line x=ax=a is a vertical asymptote when at least one one-sided limit there is +∞+\infty or −∞-\infty. A missing value alone does not create an asymptote: the hole in (x2−1)/(x−1)(x^2-1)/(x-1) has finite nearby behavior.

Limits at infinity ask a different question: what happens when inputs grow without bound? The statement f(x)→Lf(x)\to L as x→+∞x\to+\infty means that every ε>0\varepsilon>0 admits a threshold RR such that x>Rx>R in the domain implies ∣f(x)−L∣<ε|f(x)-L|<\varepsilon. If such a finite limit exists, y=Ly=L is a horizontal asymptote in that direction. Dividing numerator and denominator by xx shows (2x+1)/(x−3)=(2+1/x)/(1−3/x)→2(2x+1)/(x-3)=(2+1/x)/(1-3/x)\to2 as x→+∞x\to+\infty, and also as x→−∞x\to-\infty. Its denominator forbids x=3x=3. A horizontal asymptote describes distant behavior; it does not forbid the graph from crossing that line elsewhere.

At a vertical pole, orientation matters. Near x=3x=3, the function 1/(x−3)1/(x-3) has lim⁡x→3−1/(x−3)=−∞\lim_{x\to3^-}1/(x-3)=-\infty and lim⁡x→3+1/(x−3)=+∞\lim_{x\to3^+}1/(x-3)=+\infty. Its magnitude becomes arbitrarily large, but there is no two-sided +∞+\infty or −∞-\infty limit. For 1/(x−3)21/(x-3)^2, both one-sided values tend to +∞+\infty. The parity of the denominator power explains this sign difference. A rational function can also have a removable zero-over-zero hole rather than a pole, so factor before classifying a suspicious denominator zero.

For rational functions at infinity, divide numerator and denominator by the highest denominator power or compare leading degrees. If the numerator degree is smaller, the limit is zero; if equal, the limit is the ratio of leading coefficients. If the numerator degree is larger, there is no finite horizontal limit, though polynomial division may reveal a slant or curved asymptote. Sign and direction still matter: x2+1/x→1\sqrt{x^2+1}/x\to1 as x→+∞x\to+\infty but x2+1/x→−1\sqrt{x^2+1}/x\to-1 as x→−∞x\to-\infty, because x2=∣x∣\sqrt{x^2}=|x|, not xx on the negative half-line.

Being unbounded is weaker than tending to infinity. For x>0x>0, the function g(x)=x(1+sin⁡x)g(x)=x(1+\sin x) grows arbitrarily large along x=π/2+2πnx=\pi/2+2\pi n for nonnegative integers nn, where g(x)=2xg(x)=2x. Yet it returns to zero along x=3π/2+2πnx=3\pi/2+2\pi n. Both sequences of inputs tend to +∞+\infty, so no single threshold can force g(x)>Mg(x)>M for every later input, even when M=1M=1. Nor does g(x)g(x) approach a finite horizontal limit. This pair of sequences is a practical way to disprove a proposed distant limit: find two arbitrarily distant input families with incompatible output behavior. The function is continuous throughout its domain, so continuity alone cannot guarantee a limit at infinity.

The threshold definition keeps infinity honest. To prove 1/x2→+∞1/x^2\to+\infty as x→0x\to0, a requested height M>0M>0 is met whenever 0<∣x∣<1/M0<|x|<1/\sqrt M. To prove 1/x→01/x\to0 as x→+∞x\to+\infty, a requested tolerance ε>0\varepsilon>0 is met whenever x>1/εx>1/\varepsilon. These are different quantifier patterns: input distance from a finite point in the first, input size beyond a threshold in the second. Neither proof treats infinity as a real number that can be substituted into an algebraic expression.

5. Continuity and values that cannot be skipped

A function is continuous at an interior point aa when f(a)f(a) exists, the finite limit as x→ax\to a exists, and that limit equals f(a)f(a). Each condition matters. Defining the hole example to have value 77 at x=1x=1 leaves its limit equal to 22 and creates a removable discontinuity. Redefining just that value to 22 repairs it. A jump cannot be repaired by choosing a different value at its single break, because the one-sided limits disagree. Infinite discontinuities also cannot be repaired by inserting one finite value.

Polynomials are continuous everywhere, rational functions wherever their denominators do not vanish, and compositions of continuous functions are continuous wherever defined. The composition assertion requires the inner function to approach a point where the outer function is continuous. Continuity on [a,b][a,b] means continuity at every interior point, right continuity at aa, and left continuity at bb. This convention matches an instrument observed over a finite time interval, where there may be no recorded earlier or later time.

The intermediate value theorem states that if ff is continuous on [a,b][a,b], with a<ba<b, then for every number NN between f(a)f(a) and f(b)f(b), there exists c∈[a,b]c\in[a,b] with f(c)=Nf(c)=N. If NN lies strictly between the endpoint values, c∈(a,b)c\in(a,b). The theorem guarantees existence, not uniqueness or a formula for cc. A continuous temperature record rising from 18 °C to 23 °C must pass through 20 °C, provided continuity is a justified model assumption; a sensor that rounds to whole degrees reports a different, discontinuous function.

As a mathematical application, f(x)=x3+x−1f(x)=x^3+x-1 is continuous on [0,1][0,1], and its endpoint values are f(0)=−1f(0)=-1 and f(1)=1f(1)=1. Therefore it has a zero strictly between them. Computing f(0.6)=−0.184f(0.6)=-0.184 and f(0.7)=0.043f(0.7)=0.043 narrows the guaranteed interval to (0.6,0.7)(0.6,0.7). The sign computations become conclusive because continuity supplies the theorem’s hypothesis. A jump from −1-1 to 11 would have the same endpoint signs without any zero. Chapter 9 turns repeated interval narrowing into a numerical algorithm.

To locate the value rather than trust a drawing, assume first that f(a)<N<f(b)f(a)<N<f(b). Bisect [a,b][a,b] repeatedly, retaining a closed half whose left endpoint has value at most NN and whose right endpoint has value at least NN. If a midpoint already has value NN, the claim is proved. Otherwise the retained intervals have length (b−a)/2n(b-a)/2^n after nn bisections. The theorem below explains exactly how completeness gives their common point and how continuity forces its value. Finite bisection only brackets that point; it does not prove that the process reaches it in finitely many steps.

Existence is separate from uniqueness. The continuous function x3−xx^3-x changes sign from −6-6 at −2-2 to 66 at 22, so the theorem guarantees at least one root. In fact it has three: −1-1, 00, and 11. Conversely, a function may have a root without a sign change, as x2x^2 does at zero. A sign change is a sufficient certificate for a continuous function, not a necessary condition for every root. Later, monotonicity can certify that a particular bracket contains at most one root.

Continuity is a model assumption when the function represents physical data. A water level can jump in a recorded table because the sensor rounds values or samples discretely, even when the underlying level varies continuously. Conversely, a valve may introduce a real abrupt change in a rate model. Before invoking the intermediate value theorem, identify the function to which it applies: the idealized physical quantity, the rounded readout, or a piecewise rule. Matching endpoint numbers alone cannot replace continuity on the whole closed interval.

Why a continuous function cannot skip an intermediate value

If a<ba<b, ff is continuous on [a,b][a,b], and NN lies between f(a)f(a) and f(b)f(b), then some c∈[a,b]c\in[a,b] satisfies f(c)=Nf(c)=N.

Reasoning and proof

If NN equals an endpoint value, use that endpoint. Otherwise define g=fg=f when f(a)<N<f(b)f(a)<N<f(b), and g=2N−fg=2N-f when f(b)<N<f(a)f(b)<N<f(a). In either case gg is continuous, g(a)<N<g(b)g(a)<N<g(b), and g(c)=Ng(c)=N exactly when f(c)=Nf(c)=N. Set I0=[a,b]I_0=[a,b]. At each step bisect In=[an,bn]I_n=[a_n,b_n] and retain a half with g(an+1)≤N≤g(bn+1)g(a_{n+1})\le N\le g(b_{n+1}). Equality at a midpoint already finishes the proof. The halves are closed and nested, and bn−an=(b−a)/2n→0b_n-a_n=(b-a)/2^n\to0.

Completeness of the real numbers means every nonempty set bounded above has a least upper bound. The left endpoints form a nondecreasing set bounded by bb; let c=sup⁡{an:n≥0}c=\sup\{a_n:n\ge0\}. For each fixed nn, all later left endpoints lie in [an,bn][a_n,b_n], so an≤c≤bna_n\le c\le b_n. Thus cc lies in every retained interval. Because their widths tend to zero, 0≤c−an≤bn−an→00\le c-a_n\le b_n-a_n\to0 and 0≤bn−c≤bn−an→00\le b_n-c\le b_n-a_n\to0: both endpoint sequences approach the same real point. This is the nested-interval step supplied by completeness, not by a finite decimal approximation.

Continuity of gg at cc along the interval gives g(an)→g(c)g(a_n)\to g(c) and g(bn)→g(c)g(b_n)\to g(c), using the appropriate one-sided continuity if cc is an endpoint. Since g(an)≤N≤g(bn)g(a_n)\le N\le g(b_n) at every step, taking these limits gives g(c)≤N≤g(c)g(c)\le N\le g(c), hence g(c)=Ng(c)=N and therefore f(c)=Nf(c)=N. For descending original endpoint data, f(an)f(a_n) and f(bn)f(b_n) have the opposite bracket order; the transformed gg keeps the ascending one. The proof needs continuity throughout the closed interval; endpoint signs alone would permit a jump that skips NN.

An ε–δ proof with the constants exposed

To prove lim⁡x→3x2=9\lim_{x\to3}x^2=9 from the definition, begin with the output error: ∣x2−9∣=∣x−3∣∣x+3∣|x^2-9|=|x-3||x+3|. The first factor is controlled directly by the input distance, but the second factor also changes with xx. A claim such as “take δ=ε/∣x+3∣\delta=\varepsilon/|x+3|” is not a valid fixed choice, because δ\delta must be selected before an arbitrary nearby xx is given. We need one bound for ∣x+3∣|x+3| throughout a whole input neighborhood.

First require ∣x−3∣<1|x-3|<1. Then 2<x<42<x<4, hence 5<x+3<75<x+3<7. Therefore ∣x2−9∣≤7∣x−3∣|x^2-9|\le7|x-3|, including at x=3x=3. Given any ε>0\varepsilon>0, choose δ=min⁡(1,ε/7)\delta=\min(1,\varepsilon/7). If 0<∣x−3∣<δ0<|x-3|<\delta, both requirements hold and ∣x2−9∣<7δ≤ε|x^2-9|<7\delta\le\varepsilon. The conclusion follows for every eligible xx, not merely along sampled values or one side of 33. The strict inequality remains valid even when δ\delta equals one of the two bounds. A smaller positive δ\delta also works; the proof seeks a fixed sufficient choice, not the largest possible one.

The same technique proves continuity of the square function at any real center aa. If ∣x−a∣<1|x-a|<1, then ∣x+a∣=∣(x−a)+2a∣≤∣x−a∣+2∣a∣<1+2∣a∣|x+a|=|(x-a)+2a|\le|x-a|+2|a|<1+2|a|. Thus δ=min⁡(1,ε/(1+2∣a∣))\delta=\min(1,\varepsilon/(1+2|a|)) works for ∣x2−a2∣<ε|x^2-a^2|<\varepsilon. The number 1 is a convenient local neighborhood, not a mysterious theorem constant; another fixed positive radius could be used with a corresponding bound.

A numerical plot can suggest that x2x^2 approaches 99 near 33, but it cannot express the order of quantifiers: every ε\varepsilon must have a δ\delta that works for every xx in the punctured neighborhood. Once the estimate is written, the proof is short and also reveals a local sensitivity bound. It does not require evaluating x2x^2 at x=3x=3 to establish the limit, although the function value there happens to agree.

The same pattern clarifies units. If xx is time and f(x)f(x) is position, δ\delta has time units and ε\varepsilon has length units; a coefficient such as the local bound on a derivative has units of length per time. Writing δ=ε/7\delta=\varepsilon/7 without units is meaningful only when the function and variables are dimensionless or the constant 7 carries the corresponding conversion units. The neighborhood radius written as 11 in δ=min⁡(1,ε/7)\delta=\min(1,\varepsilon/7) also needs time units in that application. A mathematical proof may suppress units, but an application should not. A valid limit establishes arbitrarily fine local control; it does not claim that a finite-resolution measuring device can verify every tolerance.

A second proof pattern uses the triangle inequality directly. To show ∣x∣→∣a∣|x|\to|a| as x→ax\to a, use the reverse triangle inequality ∣∣x∣−∣a∣∣≤∣x−a∣||x|-|a||\le|x-a|. Given any output tolerance ε>0\varepsilon>0, choose δ=ε\delta=\varepsilon. Every eligible input within that delta has output error below ε\varepsilon. This works at positive, negative, and zero centers without splitting into cases, and it proves continuity of absolute value everywhere. More generally, suppose there are fixed constants ρ>0\rho>0 and 0≤K<∞0\le K<\infty such that ∣f(x)−f(a)∣≤K∣x−a∣|f(x)-f(a)|\le K|x-a| for every domain input with ∣x−a∣<ρ|x-a|<\rho. Then ff has a limit equal to f(a)f(a) there: choose δ=min⁡(ρ,ε/K)\delta=\min(\rho,\varepsilon/K) if K>0K>0, or any 0<δ≤ρ0<\delta\le\rho if K=0K=0. Such a local Lipschitz estimate is stronger than continuity because it gives an explicit linear response bound. The proof still depends on checking the inequality on a whole neighborhood, not merely at one plotted input. For a nonlinear function the best local constant may depend on the chosen neighborhood, which is why the earlier quadratic argument first confined xx near its center.

The limit and derivative questions are related but not interchangeable. The absolute-value function approaches zero at zero from both sides and is continuous there, yet its left and right slope limits differ. Conversely, a function can have a limit at a point where its displayed formula is undefined. Keep the output-closeness question separate from the quotient-of-changes question as you move to chapter 5.

When choosing δ\delta, first isolate what depends on the arbitrary nearby input. For a product such as ∣x−a∣∣x+a∣|x-a||x+a|, a preliminary restriction ∣x−a∣<1|x-a|<1 provides a fixed bound on the second factor; only then choose the remaining part of δ\delta from ε\varepsilon. The chosen δ\delta may depend on ε\varepsilon and the fixed target aa, but it may not depend on the particular xx selected afterward. To disprove a proposed limit, reverse the task: find one positive ε\varepsilon for which every positive δ\delta admits a domain point violating the required bound. Writing these quantifiers in order is more informative than a numerical table.

The local-bound method also works for x2x^2 near 22: requiring ∣x−2∣<1|x-2|<1 gives ∣x+2∣<5|x+2|<5, so δ=min⁡(1,ε/5)\delta=\min(1,\varepsilon/5) is sufficient. That proof answers whether we can guarantee a requested tolerance. A learner who chooses epsilon and delta independently faces another question: does this particular delta work for every input in its open band? In Figure 4.4, predict the answer before opening the comparison. A point exactly on an input-band boundary is excluded from the test.

A failed choice needs an input strictly inside the band whose output reaches or crosses the requested boundary. Finding one rejects that choice of delta; it does not reject the limit, because a smaller choice may work. Deeper derivation · Why a nonlinear ε–δ proof needs two bounds

For a linear function, output error is a constant multiple of input error. For f(x)=x2f(x)=x^2 at x=2x=2, the proposed limit is 44, but ∣x2−4∣=∣x−2∣∣x+2∣|x^2-4|=|x-2||x+2|. The factor ∣x+2∣|x+2| varies with xx. Choosing δ=ε/∣x+2∣\delta=\varepsilon/|x+2| is invalid: δ\delta has to be chosen before an arbitrary nearby xx is supplied. The proof needs one bound that works for every xx in a whole neighborhood.

First require ∣x−2∣<1|x-2|<1. Then 1<x<31<x<3, so ∣x+2∣<5|x+2|<5. This preliminary restriction turns the moving factor into a fixed bound. To achieve ∣x2−4∣<ε|x^2-4|<\varepsilon, also require ∣x−2∣<ε/5|x-2|<\varepsilon/5. Thus choose δ=min⁡(1,ε/5)\delta=\min(1,\varepsilon/5). Given any ε>0\varepsilon>0 and any xx with 0<∣x−2∣<δ0<|x-2|<\delta, we have ∣x2−4∣<5∣x−2∣<5δ≤ε|x^2-4|<5|x-2|<5\delta\le\varepsilon. The strict inequality comes from ∣x−2∣<δ|x-2|<\delta; equality in the last comparison is harmless.

This pattern is reusable: factor the output error, restrict the input to a convenient neighborhood, bound all factors that do not vanish, and make the vanishing factor small enough. The choice of 1 is convenient, not sacred. A smaller neighborhood may yield a sharper constant but is unnecessary for establishing the limit. A graph or table can suggest 4; the proof handles every real xx in the selected punctured neighborhood.

For a non-limit, reversing the quantifiers is essential. To show a proposed number is not the limit, find one output tolerance that defeats every input radius, however small. For the sign function at zero, a positive point always has value one and a negative point always has value minus one. No single proposed value can be close to both sides within a tolerance smaller than one. This argument proves failure of the two-sided limit; it is stronger than displaying a few points on a graph. It also explains why two one-sided limits must agree before a two-sided limit can exist.

When writing a delta proof, work backward on scratch paper but present the forward guarantee to the reader. Start with an arbitrary positive output tolerance, name one positive delta depending only on that tolerance and the fixed target, and then take an arbitrary input satisfying the punctured-neighborhood condition. Check separately that the input lies in the function domain. If the target is a domain endpoint, use the one-sided version instead of silently quantifying over unavailable inputs. This order prevents a common circular mistake: choosing a radius after seeing the particular input. A completed proof should state exactly where any local bound came from and whether a strict or non-strict estimate is needed.
