Biomass growth: calibrate and challenge a logistic law

Fit a synthetic logistic biomass model, test withheld observations, and explain what the calibration identifies.

A synthetic culture starts with 100 g100\,\mathrm g of biomass. Its day 0, 2, and 4 calibration values were generated exactly by a constant-parameter logistic law. Two later, deliberately perturbed observations are withheld from fitting. Derive the law and physical conditions; infer capacity and rate; predict the holdouts; compare an exponential alternative; and explain which parameters the data identify.

Prepare with these lessons

  • Exponentials and logarithms
  • Separation and growth

  • Logistic solution and restored equilibria
  • Reproducible reporting

Working assumptions

  • Biomass is continuous; the three calibration values are exact synthetic model values.
  • The two holdouts are synthetic observations with injected discrepancy, not field measurements.
  • Constant positive capacity and rate, a closed culture, and no observation-error distribution define the model. Fit only days 0, 2, and 4.

Stages

1. Define the growth law

Derive P′=rP(1−P/K)P'=rP(1-P/K); state units, initial condition, equilibria, and why 0≤P≤K0\le P\le K is forward invariant for 0<P0<K,r>00<P_0<K,r>0.

Evidence to produce. Dimensioned parameter table, derivation, and direction sketch.

Guidance. Check P=0,KP=0,K in the original ODE before dividing. Rate has day inverse units; capacity and state have grams. Uniqueness prevents equilibrium crossing.

2. Calibrate and test identifiability

Derive the reciprocal fitting equations from days 0, 2, 4; calculate K,rK,r. Then fit days 0 and 2 alone with two distinct capacities and show why one endpoint does not identify both parameters.

Evidence to produce. Equations, fit table, and continuum argument.

Guidance. Use yn=1/P(2n)=c+(y0−c)qny_n=1/P(2n)=c+(y_0-c)q^n. Check 0<q<10<q<1 and K>max⁡PiK>\max P_i before accepting a growth fit.

3. Predict and validate

Predict days 6 and 8 without refitting; report signed observation-minus-prediction residuals. Compare the two-point exponential fit. Reproduce changed cases A and B. Address P0=0P_0=0, P0=KP_0=K, and no-growth fitting data.

Evidence to produce. Auditable prediction table and reproducible formula or code.

Guidance. Separate calibration and holdouts. A model contrast does not prove the logistic law. No-growth data can make the reciprocal ratio undefined.

4. Write a qualified conclusion

Explain exact three-value identifiability within the model, two-value nonidentifiability, rounded-data sensitivity, and the limits of two holdout residuals.

Evidence to produce. Short memo with assumptions, source or formulas, prediction table, and limitations.

Guidance. If y1=y0y_1=y_0, the fitting denominator vanishes. Without an error model, do not turn residual size into a statistical claim.

const P = [100, 2000 / 11, 4000 / 13],
  y = P.map((v) => 1 / v);
if (!P.every((v) => Number.isFinite(v) && v > 0))
  throw Error('positive finite calibration required');
const q = (y[2] - y[1]) / (y[1] - y[0]),
  c = (y[1] - q * y[0]) / (1 - q),
  K = 1 / c,
  r = -Math.log(q) / 2;
if (!(
  q > 0 &&
  q < 1 &&
  Number.isFinite(K) &&
  Number.isFinite(r) &&
  r > 0 &&
  K > Math.max(...P)
))
  throw Error('not an identifiable positive growth fit');
const predict = (capacity, ratio, n, p0 = 100) =>
  capacity / (1 + (capacity / p0 - 1) * ratio ** n);
const holdouts = [6, 8].map((day, i) => ({
  day,
  predicted: predict(K, q, day / 2),
  observed: [469, 638][i],
  residual: [469, 638][i] - predict(K, q, day / 2),
}));
const alternatives = [800, 1200].map((capacity) => {
  const ratio = (capacity / P[1] - 1) / (capacity / P[0] - 1);
  return {
    capacity,
    rate: -Math.log(ratio) / 2,
    day4: predict(capacity, ratio, 2),
  };
});
const changed = [
  { capacity: 800, ratio: 0.5 },
  { capacity: 1000, ratio: 0.25 },
].map((item) => ({
  ...item,
  days: [2, 4, 6].map((day) => predict(item.capacity, item.ratio, day / 2)),
}));
console.log(
  JSON.stringify({
    K,
    r,
    q,
    calibration: P,
    holdouts,
    exponential: [6, 8].map((day) => 100 * (P[1] / 100) ** (day / 2)),
    alternatives,
    changed,
  }),
);

Self-assessment criteria

Judge each criterion as not yet evidenced, developing, or supported by your work.

  • Setup and units. I stated the dimensioned model, assumptions, initial condition, equilibria, and physical interval.
  • Derivation. I derived the solution and reciprocal fitting equations and checked parameter conditions.
  • Identifiability. I showed unique recovery from three exact equally spaced values under the model and a continuum from one later value.
  • Validation. I kept holdouts out of fitting, reproduced changed cases and the exponential comparison, and reported signed residuals with units.
  • Communication. My formulas or code, provenance, boundaries, and limitations make the result repeatable.

Limitations to address

  • Exact synthetic calibration does not establish a biological law.
  • Two holdouts do not supply a noise distribution or uncertainty interval.
  • Time-varying resources and measurement error can change inferred parameters.
