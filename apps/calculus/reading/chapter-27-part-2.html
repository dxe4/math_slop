Editable laboratory · Compare exponential and logistic growth

Edit the growth rate r (in day−1\mathrm{day}^{-1}), carrying capacity K and initial population P0 (individuals), duration T (days), and samples (plot intervals). The exact-formula plots have time in days on the horizontal axis and population in individuals on the vertical axis. The logged table compares the two populations and their ratio at selected times; evaluation incurs floating-point rounding but no time-stepping error.

Source code

// Adjustable physical parameters; P0 and K must be positive.
const r = 0.5;
const K = 1000;
const P0 = 100;
const T = 10;
const samples = 200;
if (![r, K, P0, T].every(Number.isFinite) || r < 0 || K <= 0 || P0 <= 0 || T <= 0 || !Number.isInteger(samples) || samples < 1 || samples > 1999) {
  throw new Error('Use finite nonnegative r, positive K, P0 and T; integer samples 1..1999.');
}
const exponential = t => t === 0 || r === 0 ? P0 : Math.exp(Math.log(P0) + r*t);
const logistic = t => {
  if (t === 0 || r === 0 || P0 === K) return P0;
  if (P0 > K) {
    // Add denominator contributions on a log scale so tiny growth is not lost.
    const logInitial = Math.log(K) - Math.log(P0);
    const gained = -Math.expm1(-r*t);
    const logGained = Math.log1p(-K/P0) + (gained > 0 ? Math.log(gained) : Math.log(r) + Math.log(t));
    const high = Math.max(logInitial, logGained);
    const logDenominator = high + Math.log(Math.exp(logInitial-high) + Math.exp(logGained-high));
    return Math.exp(Math.log(K) - logDenominator);
  }
  const logOdds = Math.log(K - P0) - Math.log(P0) - r*t;
  const logDenominator = logOdds > 0 ? logOdds + Math.log1p(Math.exp(-logOdds)) : Math.log1p(Math.exp(logOdds));
  return Math.exp(Math.log(K) - logDenominator);
};
const expPoints = [];
const logPoints = [];
const capacity = [];
for (let i = 0; i <= samples; i++) {
  const t = T * (i / samples);
  const e = exponential(t);
  const p = logistic(t);
  if (!Number.isFinite(e) || !Number.isFinite(p)) throw new Error('Population overflow: reduce parameter magnitudes.');
  expPoints.push([t,e]);
  logPoints.push([t,p]);
  capacity.push([t,K]);
}
const expRate = r === 0 ? 0 : Math.exp(Math.log(r) + Math.log(P0));
const logRate = r === 0 || P0 === K ? 0 : Math.sign(K-P0) * Math.exp(Math.log(r) + Math.log(P0) + Math.log(Math.abs(K-P0)) - Math.log(K));
if (![expRate, logRate].every(Number.isFinite)) throw new Error('Initial rate overflows; reduce parameters.');
plot(expPoints, 'Exponential population; time in days');
plot(logPoints, 'Logistic population; time in days');
plot(capacity, 'Carrying capacity (individuals)');
console.log('time (days) | exponential | logistic | logistic/exponential');
for (let i = 0; i <= 5; i++) {
  const t = T * (i / 5);
  console.log(t.toFixed(2), exponential(t).toFixed(6), logistic(t).toFixed(6), (logistic(t)/exponential(t)).toFixed(6));
}
console.log('Initial rates (individuals/day):', expRate, logRate);

    Answer. A multiple of tsin⁡(2t)t\sin(2t). The operator applied to tsin⁡(2t)t\sin(2t) produces cosine forcing.

    Why the other choices fail.

    • cos⁡(2t)\cos(2t) alone — The unmultiplied cosine is homogeneous.
    • tcos⁡(2t)t\cos(2t) — The last trial produces sine forcing.

    Review Constructing forced solutions

  7. Why use a pair with nonzero Wronskian on the working interval?

    • The parameter-derivative system is solvable throughout that interval
    • It makes forcing zero
    • It makes a solution constant

    Answer. The parameter-derivative system is solvable throughout that interval. The Wronskian is the system determinant; Abel’s identity propagates nonzero values on the connected coefficient interval.

    Why the other choices fail.

    • It makes forcing zero — The forcing is prescribed independently.
    • It makes a solution constant — Neither homogeneous solution needs to be constant.

    Review Variation of parameters

  8. Formal coefficient cancellation in a series ODE leaves what to prove?

    • Convergence of the function and needed derivative series on the claimed interval
    • Only the constant coefficient
    • Only one numerical value

    Answer. Convergence of the function and needed derivative series on the claimed interval. Termwise operations require an interval of validity, and initial data must be checked.

    Why the other choices fail.

    • Only the constant coefficient — One coefficient cannot establish convergence.
    • Only one numerical value — One sample cannot establish an ODE identity.

    Review Building an ODE solution from a series

Chapter synthesis

  • A differential equation specifies a rate rule; initial conditions and an interval identify the solution problem.
  • Separation uses the chain rule, while integrating factors turn linear equations into product derivatives.
  • Phase lines and uniqueness hypotheses explain behavior that formulas and sampled graphs alone cannot certify.
  • Second-order linear equations require two initial conditions and connect characteristic roots to growth, decay, and oscillation.

Common mistakes to check

  • Dividing by the state variable preserves every solution. It can discard equilibria: dividing y′=ryy^{\prime}=ry by yy loses y=0y=0 unless it is recorded first. Test with problem 8
  • A smooth differential equation has a solution for all time. The smooth equation y′=y2y^{\prime}=y^2 has the solution y(t)=1/(1−t)y(t)=1/(1-t) through (t,y)=(0,1)(t,y)=(0,1), which blows up at t=1t=1. Test with problem 2
  • Carrying capacity is a rigid upper bound on initial population. With growth rate r>0r>0 and capacity K>0K>0, a logistic population starting at P(0)>KP(0)>K decreases toward KK; KK is an attracting equilibrium, not an upper bound on admissible initial data. Test with problem 30
