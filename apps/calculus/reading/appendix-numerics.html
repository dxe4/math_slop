Appendix D · Numerical methods and error

Computational evidence becomes useful when the error mechanism and stopping rule are explicit. These notes connect the code laboratories to mathematical guarantees.

Floating-point numbers and stable formulas

A finite binary floating-point number usually cannot represent an arbitrary decimal fraction exactly. Arithmetic rounds each operation, so algebraically equal expressions may behave differently. Subtracting nearly equal rounded values can lose leading digits; rationalizing (1+h−1)/h(\sqrt{1+h}-1)/h to 1/(1+h+1)1/(\sqrt{1+h}+1) is a concrete repair for real h≥−1h\geq-1 with h≠0h\ne0. Avoid judging an algorithm only by one agreeable output.

Absolute error is ∣estimate−truth∣|\text{estimate}-\text{truth}|. Relative error divides by ∣truth∣|\text{truth}| when truth is nonzero; near zero, absolute error may be more informative. A measured error ratio under step halving can reveal asymptotic order, but cancellation or roundoff can spoil the pattern. Count work as well as accuracy: for an ODE method, rate evaluations often dominate.

Roots and quadrature

Bisection starts with a continuous ff whose endpoint values have opposite signs. It preserves a bracket and halves its width each step; after nn steps, the width is the original width divided by 2n2^n. Newton’s method can converge faster near a simple root but can fail when a derivative is zero, the initial guess is poor, or an update leaves the model domain. Keep a known bracket when reliability matters.

A Riemann sum approximates accumulation with chosen sample points. Trapezoidal and Simpson rules use increasingly rich local models; Simpson’s standard composite form needs an even number of subintervals and a bounded fourth derivative on the interval for its classic fourth-order error bound. On an infinite interval or at a singular endpoint, first define the improper integral as a limit. No quadrature output proves that limit exists. Compare refinements and use known bounds where available.

ODE error and stability

A one-step defect is measured from exact starting data. Under smoothness and controlled propagation, Euler has local O(h2)O(h^2) and global O(h)O(h) error; Heun has local O(h3)O(h^3) and global O(h2)O(h^2) error; classical RK4 has local O(h5)O(h^5) and global O(h4)O(h^4) error. These orders describe asymptotic behavior on a fixed interval, not a fixed number of correct digits for any hh.

For y′=−ayy^{\prime}=-ay with a>0a>0 and step size h>0h>0, Euler multiplies by 1−ah1-ah. Numerical disturbances decay only if 0<ah<20<ah<2; nonnegative updates from nonnegative data need ah≤1ah\leq1. A smooth plot can hide instability or model error. Compare multiple resolutions at a common final time, a known exact case, and physically derived invariants where possible. A singularity or event between grid points needs separate treatment.

Evaluating an inverse hyperbolic logarithm

The real identity arsinh⁡x=ln⁡(x+x2+1)\operatorname{arsinh}x=\ln(x+\sqrt{x^2+1}) is valid for every real xx, and its logarithm argument is strictly positive in exact arithmetic. Direct floating-point evaluation can cancel to zero for a large negative xx; computing x2x^2 can also overflow. Oddness gives arsinh⁡x=−arsinh⁡(−x)\operatorname{arsinh}x=-\operatorname{arsinh}(-x) for negative xx. In a JavaScript laboratory, Math.asinh(x) is the direct numerical choice. Keep a valid analytic identity distinct from an evaluation recipe.
