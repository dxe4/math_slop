From a differential equation to an update rule

An initial value problem specifies a rate y′=f(t,y)y'=f(t,y) and a starting state y(t0)=y0y(t_0)=y_0. A numerical solver replaces the continuous trajectory with states yny_n at times tn=t0+nht_n=t_0+nh. The positive step hh has units of time, while ff has units of state per time, so hfhf can be added to yy. Before choosing a solver, specify the interval, the meaning and units of the state, and a region where ff is defined. A computer cannot repair an undefined rate or justify a physical assumption.

Euler follows the tangent at the beginning of each interval: yn+1=yn+hf(tn,yn)y_{n+1}=y_n+h f(t_n,y_n). Integrating the equation exactly would require the integral of the changing rate over the interval; Euler replaces that rate by its initial value. This is a left-endpoint accumulation rule. If the exact solution has a bounded second derivative, Taylor’s formula bounds the error of one step starting from exact data by a constant times h2h^2; the error can be zero for a linear exact solution. The geometrical simplicity explains both the method and its limitations.

Improved Euler here means the explicit trapezoidal method, also called Heun’s method. First predict p=yn+hf(tn,yn)p=y_n+h f(t_n,y_n). Then correct using yn+1=yn+h2[f(tn,yn)+f(tn+h,p)]y_{n+1}=y_n+\frac h2\bigl[f(t_n,y_n)+f(t_n+h,p)\bigr]. The second slope is evaluated at the predicted endpoint, not at the unknown true endpoint. Thus there is no equation to solve inside the step. Some books use “improved Euler” for the midpoint method instead; a reproducible report must give the actual formula.

For sufficiently smooth ff and solution, the corrected one-step defect is O(h3)O(h^3), compared with Euler’s O(h2)O(h^2). This statement concerns starting the step exactly; later steps start with accumulated errors. It does not promise that halving hh improves every calculation by a fixed factor, especially near a singularity, at a discontinuity, or when floating-point rounding dominates.

Start from an exact state and assume the needed smoothness. Taylor expansion at the predicted point gives f(t+h,y+hf)=f+h(ft+fyf)+O(h2)f(t+h,y+hf)=f+h(f_t+f_yf)+O(h^2). Heun’s update is therefore y+hf+12h2(ft+fyf)+O(h3)y+hf+\frac12h^2(f_t+f_yf)+O(h^3). Along the exact solution, the chain rule gives y′′=ft+fyfy^{\prime\prime}=f_t+f_yf, so these terms match its Taylor expansion. This is why the one-step defect is O(h3)O(h^3).

The exact step identity y(t+h)−y(t)=∫tt+hf(s,y(s)) dsy(t+h)-y(t)=\int_t^{t+h}f(s,y(s))\,ds explains Euler's left-slope approximation from paragraph 2. If y′′y^{\prime\prime} is merely bounded on the step, the exact-data local defect is bounded by a constant times h2h^2. If y′′y^{\prime\prime} is continuous at tt, Taylor's formula gives the more precise defect h2y′′(t)/2+o(h2)h^2y^{\prime\prime}(t)/2+o(h^2). An O(h3)O(h^3) remainder after that leading term needs stronger regularity, for example a locally Lipschitz second derivative. Later inputs contain inherited error, so this local calculation alone cannot establish a fixed-interval global bound; the next lesson develops the propagation sum.

The time grid must hit the requested endpoint. If T−t0T-t_0 is not an integer multiple of hh, a solver can shorten its final step to TT or choose NN steps with h=(T−t0)/Nh=(T-t_0)/N. Comparing runs that end at slightly different times confounds numerical error with actual evolution of the solution. In a reproducible study, record NN and the resulting hh, not only a rounded display value. For a model with events, such as impact with the ground, the event time may fall between grid points and requires interpolation or a dedicated event solver.

Local error order is measured when a step begins at the exact solution value; global error includes errors inherited from earlier steps. This distinction explains why an O(h2)O(h^2) local defect for Euler yields only O(h)O(h) global accuracy on a fixed interval. An instability can amplify inherited errors so strongly that the expected convergence pattern is not visible at coarse steps. Before estimating an order from data, use a range of steps small enough to enter the method's stable, smooth asymptotic regime.

For vector states, the update applies to the whole vector at once. If y=(x,v)y=(x,v), Euler forms (xnew,vnew)=(x+hfx(t,x,v),v+hfv(t,x,v))(x_{\mathrm{new}},v_{\mathrm{new}})=(x+h f_x(t,x,v),v+h f_v(t,x,v)) using the same old state for both components. Accidentally computing vnewv_{\mathrm{new}} from xnewx_{\mathrm{new}} creates a different sequential method, which may have different stability or conservation properties. This distinction is not merely a coding style issue. Write the mathematical stages first, then implement each stage as an immutable vector or simultaneous assignment.

The exact integral identity also gives a way to evaluate a one-step rule's defect. Insert the exact value y(t)y(t) into the numerical formula and subtract the exact y(t+h)y(t+h). For Euler, Taylor expansion gives a leading discrepancy proportional to h2y′′(t)/2h^2y^{\prime\prime}(t)/2 when enough derivatives exist. If y′′y^{\prime\prime} is large, even a nominally small step can produce a visible error. Heun uses a predicted endpoint slope to cancel that leading term under smoothness, leaving a higher-order defect. This analysis explains the method design rather than treating order labels as unexplained badges.

Four slopes and the meaning of order

Classical Runge–Kutta 4, abbreviated RK4, combines four slopes. Define k1=f(tn,yn)k_1=f(t_n,y_n), k2=f(tn+h/2,yn+hk1/2)k_2=f(t_n+h/2,y_n+hk_1/2), k3=f(tn+h/2,yn+hk2/2)k_3=f(t_n+h/2,y_n+hk_2/2), and k4=f(tn+h,yn+hk3)k_4=f(t_n+h,y_n+hk_3). Then add h(k1+2k2+2k3+k4)/6h(k_1+2k_2+2k_3+k_4)/6 to yny_n. Each kk is a rate, not an increment; mixing these two conventions inserts an extra factor of hh. The weighted average matches the Taylor expansion through fourth order without asking the programmer to calculate higher derivatives.

Under sufficient smoothness on a fixed finite interval, and a Lipschitz bound in the state variable on a region containing the relevant trajectories, Euler, Heun and RK4 have global errors O(h)O(h), O(h2)O(h^2) and O(h4)O(h^4), respectively. Their unscaled one-step defects are O(h2)O(h^2), O(h3)O(h^3) and O(h5)O(h^5). Here O(hp)O(h^p) means an error bounded by ChpCh^p for sufficiently small hh, with CC independent of hh but dependent on the problem and interval. A high order says how error eventually scales; it does not say the constant is small.

Let ene_n be the error at a common grid time. Under a state Lipschitz bound and uniform local defect Dhp+1Dh^{p+1} on a fixed interval, a one-step method with stability factor at most 1+Ch1+Ch gives ∣en+1∣≤(1+Ch)∣en∣+Dhp+1|e_{n+1}|\le(1+Ch)|e_n|+Dh^{p+1}. The local propagation lemma below sums these inherited defects. With exact initial data and N=(T−t0)/hN=(T-t_0)/h, it yields a fixed-interval O(hp)O(h^p) bound. These constants require a common region containing exact and numerical states for all sufficiently small steps; the argument does not certify an arbitrary coarse run.

RK4 costs four rate evaluations per step, Heun two and Euler one. A fair comparison reports both error and work. A complicated ff may dominate runtime, while a tiny example may mostly measure browser overhead. For a first investigation, count evaluations instead of treating an unstable timing measurement as evidence of mathematical efficiency.

For y′=λyy^{\prime}=\lambda y with constant λ\lambda, every explicit Runge–Kutta method produces yn+1=R(hλ)yny_{n+1}=R(h\lambda)y_n for a polynomial RR. Classical RK4's polynomial matches the first five terms of eze^z through z4z^4. This explains its high accuracy when ∣z∣|z| is small, but a polynomial cannot approximate eze^z uniformly across the entire negative real axis. For sufficiently large negative zz, ∣R(z)∣|R(z)| grows and the method becomes unstable. High order does not remove the need to consider step-size restrictions.

A convergence table should include errors at a common final time and ratios between successive refinements. If error behaves like ChpCh^p, halving hh divides it approximately by 2p2^p, so Euler ratios approach two, Heun four, and RK4 sixteen. The ratios are approximate because higher-order terms and floating-point effects remain. If the exact solution is known, use it directly; otherwise successive differences can estimate order only after the asymptotic regime is reached.

Work must be counted as well as error. For NN fixed steps, Euler evaluates ff about NN times, Heun about 2N2N, and classical RK4 about 4N4N. If a fourth-order method reaches a requested tolerance with many fewer steps, it can use fewer total evaluations despite its higher cost per step. The tradeoff depends on the equation, tolerance, stability, and implementation overhead. A fair capstone report includes evaluation count or wall time under a controlled setup, not just the number of plotted points.

RK4 stages depend on one another. k2k_2 uses the state shifted by hk1/2hk_1/2, k3k_3 uses hk2/2hk_2/2, and k4k_4 uses hk3hk_3. Replacing all three intermediate states with the Euler prediction produces a different formula with different accuracy. Likewise the final weighted average must use 1,2,2,11,2,2,1 coefficients divided by six. A simple exact test equation such as y′=yy^{\prime}=y can expose stage mistakes by comparing one-step output with ehe^h for shrinking hh.

Order results need smoothness. If ff or the exact trajectory has a kink, a discontinuity, or an event that is not aligned with the grid, the expected global rate may degrade. For a piecewise forcing that switches at time τ\tau, splitting the integration interval at τ\tau can restore clean behavior on each smooth piece. A high-order method cannot infer an unreported jump from evaluations that miss it. Document discontinuities and event handling alongside the method name.

A ratio table should be read cautiously near floating-point limits. As hh shrinks, truncation error falls, but more steps are taken and subtraction of nearby values can expose roundoff. Endpoint errors may stop decreasing or fluctuate, especially when the exact value is extremely small compared with intermediate values. Plotting log⁡(error)\log(\text{error}) against log⁡h\log h can reveal a straight asymptotic section whose slope estimates order, followed by a roundoff floor. Report the range used for the estimate and avoid fitting an order to only two noisy points.

Stability is a separate question

Consider decay y′=−ayy'=-ay with a>0a>0 and y(0)=1y(0)=1. The exact solution e−ate^{-at} is positive and decreases. Euler instead multiplies the current state by 1−ah1-ah. Numerical disturbances decay only if ∣1−ah∣<1|1-ah|<1, or 0<ah<20<ah<2. For 1<ah<21<ah<2 the values alternate in sign while approaching zero, so stability alone does not preserve positivity. Absolute stability tests a method on y′=λyy^{\prime}=\lambda y through its amplification factor R(hλ)R(h\lambda). Euler has R(z)=1+zR(z)=1+z; Heun has R(z)=1+z+z2/2R(z)=1+z+z^2/2; classical RK4 has R(z)=1+z+z2/2+z3/6+z4/24R(z)=1+z+z^2/2+z^3/6+z^4/24. Decay modes require ∣R(z)∣<1|R(z)|<1. Heun, like Euler, has 0<ah<20<ah<2 on the negative real axis. Higher order therefore need not enlarge this stability interval. RK4 also has a bounded stability region: arbitrarily large steps are unsafe.

A system can contain a rapidly decaying component and a slowly changing component. The fast component may force an explicit method to take very small steps even when the visible solution looks smooth. This is a basic sign of stiffness. An implicit step can address some stability restrictions, as the scalar decay comparison later in this chapter shows, but its equation may be costly to solve in a nonlinear system. Distinguish a stability restriction from a requested accuracy and avoid claiming convergence merely because plotted points form a smooth line.

For real decay, read the multiplier table from the first paragraph: 0<ah<10<ah<1 gives strictly positive shrinking iterates for positive initial data; ah=1ah=1 sends the state to zero in one step; 1<ah<21<ah<2 gives alternating signs with shrinking magnitude; ah=2ah=2 alternates without decay. These boundaries distinguish mathematical magnitude stability from a model’s positivity requirement. The exact solution remains strictly positive for all finite tt.

Stiff systems often justify that cost. Introducing this comparison makes clear that numerical stability is a property of the method and step size, not solely of the differential equation.

Absolute stability is diagnosed on linear modes, but a nonlinear problem can change its local behavior as the state moves. Linearizing near a trajectory may reveal a large negative eigenvalue and a restrictive explicit step size. A fixed hh chosen from early behavior may become unsuitable later. Adaptive solvers estimate local error and adjust hh, yet an error controller alone may still struggle with stiff modes if the underlying method has a small stability region. Method choice and step control are distinct decisions.

Deeper derivation · Local error, accumulated error, and unstable steps

A one-step method has a local defect measured by starting that step from exact data and comparing one numerical update with the exact value one step later. Euler’s local defect is O(h2)O(h^2) for a smooth solution. Over a fixed interval of length TT, about T/hT/h steps occur. If earlier perturbations remain controlled, these defects accumulate to a global O(h)O(h) error. A fourth-order method has local O(h5)O(h^5) and global O(h4)O(h^4) under the corresponding smoothness and stability conditions.

For decay y′=−ayy^{\prime}=-ay with a>0a>0 and h>0h>0, Euler multiplies by 1−ah1-ah each step. The exact flow multiplies by e−ahe^{-ah}, a positive number below one. Euler values decay in magnitude only when ∣1−ah∣<1|1-ah|<1, or 0<ah<20<ah<2. Nonnegative updates from nonnegative data need the tighter condition ah≤1ah\le1. A calculation can therefore be stable while alternating sign, and a method can be high order while still having a finite stability region.

To measure order, compare solutions at a common final time using NN, 2N2N, and 4N4N steps. For an error approximately ChpCh^p with nonzero leading coefficient CC, the coarser-step error magnitude divided by the next finer-step error magnitude approaches 2p2^p. This is evidence about the method on the tested problem; it is not a proof of the general order and may mislead when an endpoint error cancels. Check a trajectory-wide error, a known exact case, and a physically derived invariant when possible. Count rate evaluations when comparing methods with different costs per step.

function step(name, t, y, h) {
  const factor = -(a*h);
  const k1 = factor*y;
  if (name === 'Euler') return y+k1;
  if (name === 'Heun') return y+(k1+factor*(y+k1))/2;

}
