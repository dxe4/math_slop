1. A new coordinate grid changes area

An integral combines two ingredients: the value being accumulated and the size of each small piece. Rewriting xx and yy in terms of uu and vv changes both. Imagine drawing a rectangular grid on a rubber sheet and stretching it into the region of interest. Equal rectangles on the original sheet may become unequal parallelograms. Substituting new formulas into the integrand without changing the area element would count these unequal pieces as though they were still equal.

Let T(u,v)=(x(u,v),y(u,v))T(u,v)=(x(u,v),y(u,v)). Its derivative matrix has columns TuT_u and TvT_v. Near a point, a parameter rectangle with side lengths Δu\Delta u and Δv\Delta v becomes approximately the parallelogram spanned by TuΔuT_u\Delta u and TvΔvT_v\Delta v. Its area is ∣xuyv−xvyu∣ Δu Δv|x_u y_v-x_v y_u|\,\Delta u\,\Delta v. The determinant J=xuyv−xvyuJ=x_u y_v-x_v y_u can be negative when the map reverses orientation; geometric area remains nonnegative, so an ordinary double integral uses ∣J∣|J|.

A standard change-of-variables theorem assumes a continuously differentiable, one-to-one map between the interiors of suitable bounded regions, with nonzero determinant there, and an integrable transformed integrand; continuity of the original integrand on the image closure is a convenient sufficient assumption in regular examples. Piecewise smooth boundaries are adequate here. Coordinate seams and isolated degeneracies can be handled by splitting regions or removing sets of area zero and taking limits. A singular integrand still requires an integrability check: a coordinate change does not automatically make an improper integral converge.

On a compact regular parameter piece where TT is C1C^1, one-to-one, and J≠0J\ne0, divide it into small cells. The derivative approximation makes each image-cell area approach ∣J(ui,vi)∣ΔuiΔvi|J(u_i,v_i)|\Delta u_i\Delta v_i; continuity controls the total area error and the variation of ff inside each image cell. One-to-one coverage counts each cell once, so the sums approach the transformed integral. Seams, degeneracies, and unbounded integrands require separate limiting checks. For example, T(u,v)=(u+u2,v)T(u,v)=(u+u^2,v) maps [0,1]2[0,1]^2 onto [0,2]×[0,1][0,2]\times[0,1] with J=1+2uJ=1+2u. The transformed domain is E={(u,v):T(u,v)∈D}E=\{(u,v):T(u,v)\in D\}, with parameter restrictions that avoid repeated coverage. Determine EE by translating every boundary and inequality, rather than merely copying the old bounds. If a map covers the same region twice, the usual integral over its entire parameter domain counts the contribution twice.

Orientation and physical area must be separated. The map (u,v)↦(2u,3v)(u,v)\mapsto(2u,3v) sends a unit square to a rectangle of area 66 with determinant 66; (u,v)↦(2u,−3v)(u,v)\mapsto(2u,-3v) also gives area 66 but determinant −6-6. Hence ordinary area and mass use ∣J∣|J|, while the sign records orientation for later vector-calculus integrals.

A nonzero determinant checks local area scale but does not guarantee global one-to-one coverage. The polar map over 0≤θ≤4π0\le\theta\le4\pi counts most of a disk twice even though its determinant rr is correct at r>0r>0. Restrict the angle to one full turn, apart from its zero-area seam, or account for multiplicity. The later polar lesson develops this domain choice; the local Jacobian alone cannot decide it.

An affine shear illustrates that visual distortion does not always change area. Let T(u,v)=(u+v,v)T(u,v)=(u+v,v). Its derivative has determinant 11. The unit square E=[0,1]2E=[0,1]^2 becomes a slanted parallelogram DD, but its base and height are both 11, so area remains 11. The transformed domain must be described before integration. For T(u,v)=(2u,3v)T(u,v)=(2u,3v), the ellipse x2/4+y2/9≤1x^2/4+y^2/9\le1 becomes u2+v2≤1u^2+v^2\le1, while its integrand f(x,y)=x2+y2f(x,y)=x^2+y^2 becomes f(T(u,v))=4u2+9v2f(T(u,v))=4u^2+9v^2. In less symmetric problems, drawing both the physical and parameter regions helps track which boundaries become constants and which remain curves.

At a point where the determinant vanishes, the linearized image of a small parameter square has zero area to first order. Polar coordinates at r=0r=0 have this property because changing angle at the origin changes no Cartesian point. Many useful coordinate formulas allow such exceptional sets of area zero, but one should not divide by the determinant there or claim a local inverse exists at the singular point. The precise theorem handles interior regularity and harmless boundary exceptions; computations should state the range that gives almost-everywhere one-to-one coverage.

A practical verification uses an easy integrand first. If a proposed transformation of a region DD yields an area different from a known geometric area when f=1f=1, then either the new domain, determinant, or coverage is wrong. Only after that check should a difficult transformed integrand be trusted. Similarly, units provide a check: if uu and vv are dimensionless and x,yx,y are metres, the Jacobian has units m2\mathrm{m}^2. Multiplying by du dvdu\,dv then restores a physical area element. The determinant is not an optional decoration of the formula.

A transformation can have a variable determinant, so one local scale factor cannot be pulled out of the whole integral. For T(u,v)=(u2,v)T(u,v)=(u^2,v) on 0≤u≤10\le u\le1, 0≤v≤10\le v\le1, the Jacobian is 2u2u. For a nonconstant integrand such coincidences disappear. At u=0u=0 the determinant vanishes, but that boundary line has zero area and does not prevent this area calculation.

The Jacobian factor is local area or volume scaling, so it belongs in the transformed measure even when the integrand is a probability density. In polar coordinates a small coordinate rectangle has approximate sides drdr and r dθr\,d\theta, giving area r dr dθr\,dr\,d\theta. A density p(x,y)p(x,y) therefore becomes p(rcos⁡θ,rsin⁡θ)rp(r\cos\theta,r\sin\theta)r in the polar integral; omitting rr changes both normalization and expected values. The polar map is many-to-one at the origin and periodic in angle, so choose an angular interval that covers the region once, apart from boundary overlap of area zero. A probability answer offers an independent check: total mass should equal 11, and the expected value of a bounded quantity must lie between its smallest and largest values on the support. These checks do not replace the Jacobian derivation, but they catch many setup errors.

2. Polar coordinates organize circular regions

Polar coordinates use x=rcos⁡θx=r\cos\theta and y=rsin⁡θy=r\sin\theta, with r≥0r\ge0 and θ\theta measured in radians. The derivative columns are (cos⁡θ,sin⁡θ)(\cos\theta,\sin\theta) and (−rsin⁡θ,rcos⁡θ)(-r\sin\theta,r\cos\theta); their determinant is rr. Consequently dA=r dr dθdA=r\,dr\,d\theta. A sector of thickness drdr and angular width dθd\theta has approximate area drdr times the arc length r dθr\,d\theta, giving the same factor geometrically. Equal angular steps sweep wider pieces farther from the origin.

The disk x2+y2≤R2x^2+y^2\le R^2 with R≥0R\ge0 becomes 0≤r≤R0\le r\le R and 0≤θ<2π0\le\theta<2\pi. The missing endpoint of the angular interval is only a seam; including it in integral bounds changes no area, although we do not interpret it as a second copy of that radial line. At r=0r=0 every angle represents the origin and the Jacobian vanishes. This degeneracy is harmless for bounded integrands because the origin has area zero. An annular sector a≤r≤ba\le r\le b, α≤θ≤β\alpha\le\theta\le\beta is especially simple, but a shifted disk may need variable radial bounds or several pieces.

For a less automatic example, x2+y2≤2xx^2+y^2\le2x becomes r2≤2rcos⁡θr^2\le2r\cos\theta. Taking −π/2≤θ≤π/2-\pi/2\le\theta\le\pi/2 gives 0≤r≤2cos⁡θ0\le r\le2\cos\theta. These bounds describe the disk centered at (1,0)(1,0) of radius 11 exactly once, apart from boundary coincidences. Allowing the same radial expression for every angle would produce negative upper bounds and would cease to describe the intended region.

Coordinates are a choice of description, not a change in the quantity being measured. Over a centered disk, a function of x2+y2x^2+y^2 becomes a function of r2r^2, so both the geometry and integrand simplify. Conversely, a rectangle with a function depending only on xx may be easier in Cartesian coordinates. Before calculating, inspect the region and the integrand separately and decide whether the proposed substitution improves both.

The polar radius is nonnegative; allowing negative rr duplicates points unless the angular interval is adjusted. For example, (r,θ)(r,\theta) and (−r,θ+π)(-r,\theta+\pi) map to the same Cartesian location. The usual choice r≥0r\ge0 and θ\theta in one full 2π2\pi interval avoids this duplication except at the angular seam and origin. When a problem describes angles using degrees, convert to radians before integrating: a 90∘90^\circ sector has width π/2\pi/2 radians, rather than 9090 radians. The Jacobian rr assumes θ\theta is measured in radians.

3. Cylindrical and spherical volume elements

Cylindrical coordinates retain height: x=rcos⁡θx=r\cos\theta, y=rsin⁡θy=r\sin\theta, z=zz=z. The volume factor is rr, so dV=r dr dθ dzdV=r\,dr\,d\theta\,dz, with the integration order adjusted to the chosen bounds. For a cylinder of radius RR and height HH, the bounds 0≤r≤R0\le r\le R, 0≤θ≤2π0\le\theta\le2\pi, 0≤z≤H0\le z\le H yield volume πR2H\pi R^2H. A solid below z=4−x2−y2z=4-x^2-y^2 and above z=0z=0 instead uses 0≤z≤4−r20\le z\le4-r^2, 0≤r≤20\le r\le2, and 0≤θ≤2π0\le\theta\le2\pi. The curved top becomes a simple limit on height.

We use spherical coordinates ρ≥0\rho\ge0, azimuth 0≤θ<2π0\le\theta<2\pi, and polar angle 0≤ϕ≤π0\le\phi\le\pi measured down from the positive zz-axis. Then x=ρsin⁡ϕcos⁡θx=\rho\sin\phi\cos\theta, y=ρsin⁡ϕsin⁡θy=\rho\sin\phi\sin\theta, and z=ρcos⁡ϕz=\rho\cos\phi. Other texts interchange the angle names, so the defining formulas matter more than the symbols. The volume factor is ρ2sin⁡ϕ\rho^2\sin\phi. One small box has approximate edge lengths dρd\rho, ρ dϕ\rho\,d\phi, and ρsin⁡ϕ dθ\rho\sin\phi\,d\theta, which explains why the factor shrinks near the polar axis.

A ball of radius a≥0a\ge0 becomes 0≤ρ≤a0\le\rho\le a with the full angular ranges 0≤ϕ≤π0\le\phi\le\pi and 0≤θ≤2π0\le\theta\le2\pi. Integrating ρ2sin⁡ϕ\rho^2\sin\phi gives (a3/3)(2)(2π)=4πa3/3(a^3/3)(2)(2\pi)=4\pi a^3/3. The upper hemisphere changes the polar-angle range to 0≤ϕ≤π/20\le\phi\le\pi/2. A cone about the positive zz-axis often becomes an upper bound ϕ≤ϕ0\phi\le\phi_0, while spherical shells become bounds on ρ\rho. Carefully distinguish the cylindrical radius rr, distance from the zz-axis, from the spherical radius ρ\rho, distance from the origin: r=ρsin⁡ϕr=\rho\sin\phi.

When lengths are in metres, dAdA has units m2\mathrm{m}^2 and dVdV has units m3\mathrm{m}^3; angles in radians are dimensionless. Multiplying a volume density in kg/m3\mathrm{kg}/\mathrm{m}^3 by the spherical volume element produces mass in kg\mathrm{kg}. The coordinate axes, angular seams, and origin are exceptional sets of volume zero, but a density that blows up near them may still make the total mass infinite. Cylindrical coordinates are useful when the xyxy projection is circular but height bounds are simple. Writing all three bounds before integrating helps prevent a missing or duplicated rr.

Spherical coordinates use two angular factors for distinct geometric reasons. At radius ρ\rho, an angular change dϕd\phi traces length approximately ρ dϕ\rho\,d\phi. At polar angle ϕ\phi, an azimuth change dθd\theta traces length approximately ρsin⁡ϕ dθ\rho\sin\phi\,d\theta. This geometric derivation makes the volume element easier to remember than a bare determinant formula.

The convention for ϕ\phi matters. Here ϕ\phi is measured down from the positive zz-axis, so the upper hemisphere has 0≤ϕ≤π/20\le\phi\le\pi/2 and the lower has π/2≤ϕ≤π\pi/2\le\phi\le\pi. Some physics texts call the azimuth ϕ\phi instead. A formula copied across conventions can place a cone or hemisphere in the wrong region while still producing a plausible volume. Always write x,y,zx,y,z in terms of the coordinates beside the bounds, especially when comparing sources or software libraries.

If the cone has a finite height rather than a spherical cap, the ρ\rho upper bound depends on ϕ\phi and must be derived from the plane cutting it.

Radial power integrals in three dimensions have a threshold set by ρ2\rho^2. A density behaving like ρ−p\rho^{-p} near the origin contributes approximately ∫0aρ2−p dρ\int_0^a\rho^{2-p}\,d\rho for a>0a>0, finite exactly when p<3p<3. The corresponding two-dimensional threshold was p<2p<2 because the area element carries one power of radius. This is a dimensional pattern: in nn dimensions, a radial shell contributes rn−1 drr^{n-1}\,dr. The threshold holds when the region contains a full neighborhood of the origin or a cone with a fixed positive solid angle. A cusp whose angular width shrinks toward the origin can change the available volume and hence the threshold.

The spherical map has coordinate singularities at ρ=0\rho=0 and on the polar axis, where angles cease to identify unique directions. These sets have zero volume in ordinary ball integrals, so the formula still computes volume correctly. They are not evidence that the physical ball has a hole or an infinite density. When transforming vector fields or derivatives, however, singular coordinate denominators require more care than a scalar volume calculation. Keep the distinction between a chart singularity and a singular integrand.

4. Probability is mass with total amount one

When a random pair (X,Y)(X,Y) has a joint probability density f(x,y)f(x,y), that density is nonnegative almost everywhere and its integral over the plane equals 11. Probability in a region AA is ∬Af dA\iint_A f\,dA. The density itself is not a probability: its value may exceed 11, and changing its value at a single point does not change any probability. For a pair with a joint density, an individual point has probability zero even though observations must land somewhere. Only integrated density gives the probability of an event.

To normalize a proposed shape h≥0h\ge0, calculate Z=∬R2h dAZ=\iint_{\mathbb R^2}h\,dA and set f=h/Zf=h/Z if 0<Z<∞0<Z<\infty. If Z=0Z=0 or Z=∞Z=\infty, no finite positive constant can turn that shape into a density. The support, the region outside which the density is zero, is part of the model. If XX and YY are lengths in metres, the joint density has units m−2\mathrm{m}^{-2}, so its area integral is dimensionless. A normalization constant therefore may carry units.

The marginal density of XX is fX(x)=∫Rf(x,y) dyf_X(x)=\int_{\mathbb R}f(x,y)\,dy, integrating over all allowed yy at that xx. It describes XX without recording YY. Its bounds generally depend on xx when the support is not rectangular. Similarly, fY(y)=∫Rf(x,y) dxf_Y(y)=\int_{\mathbb R}f(x,y)\,dx. Nonnegativity permits iterated integration by Tonelli’s theorem, and normalization ensures the marginals integrate to one. Independence requires the factorization f(x,y)=fX(x)fY(y)f(x,y)=f_X(x)f_Y(y) almost everywhere; symmetry alone does not establish it.

Expectation weights a quantity by probability: E[g(X,Y)]=∬R2g(x,y)f(x,y) dA\mathbb E[g(X,Y)]=\iint_{\mathbb R^2}g(x,y)f(x,y)\,dA. For a signed gg, absolute integrability is a sufficient condition for a finite expectation and free exchange of integration order. Editable laboratory · Compare Cartesian and polar integration

Integrate the normalized density p(x,y)=c(x2+y2)p(x,y)=c(x^2+y^2) on the disk x2+y2≤R2x^2+y^2\le R^2, where RR is edited as radius and c=2/(πR4)c=2/(\pi R^4). The Cartesian and polar midpoint grids use coordinates scaled by RR, so their computed estimates do not vary with radius. The plot shows approximation versus grid size, and the console gives absolute errors relative to the exact target 11.

Source code

// Adjust radius and grid sizes; keep each grid at most 400 by 400.
const radius = 1;
const sizes = [10, 20, 40, 80, 160];
if (!(radius > 0 && radius <= 10)) throw new Error('Use radius in (0, 10].');
if (!Array.isArray(sizes) || sizes.length < 1 || sizes.length > 2000) throw new Error('sizes must contain 1 to 2000 grids.');
// Scale coordinates by radius before summing; the radius cancels analytically.
const cartesian = [];
const polar = [];
for (const n of sizes) {
  if (!Number.isInteger(n) || n < 2 || n > 400) throw new Error('Grid sizes must be integers from 2 to 400.');
  const h = 2 / n;
  let squareSum = 0;
  for (let i = 0; i < n; i++) {
    const x = -1 + (i + 0.5) * h;
    for (let j = 0; j < n; j++) {
      const y = -1 + (j + 0.5) * h;
      const r2 = x*x + y*y;
      if (r2 <= 1) squareSum += 8 * r2 / (Math.PI * n*n);
    }
  }
  const dr = 1 / n;
  let polarSum = 0;
  for (let i = 0; i < n; i++) {
    const r = (i + 0.5) * dr;
    for (let j = 0; j < n; j++) {
      // Density times Jacobian times parameter-cell area.
      polarSum += 4 * r ** 3 / (n*n);
    }
  }
  cartesian.push([n, squareSum]);
  polar.push([n, polarSum]);
  console.log('n', n, 'Cartesian', squareSum.toFixed(8), 'polar', polarSum.toFixed(8), 'absolute errors', Math.abs(squareSum-1).toFixed(8), Math.abs(polarSum-1).toFixed(8));
}
if (sizes.length >= 2) {
  plot(cartesian, 'Cartesian estimate; x = cells per side, y = total probability');
  plot(polar, 'Polar estimate; x = cells per coordinate, y = total probability');
  plot(sizes.map(n => [n, 1]), 'Exact normalization = 1');
} else console.log('Only one grid: refinement plots need at least two points.');
