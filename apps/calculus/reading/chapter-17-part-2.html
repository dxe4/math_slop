An interval with unequal endpoints

Find the radius and interval of convergence of ∑n=1∞(x−2)n/(n 3n)\sum_{n=1}^{\infty}(x-2)^n/(n\,3^n).

Editable laboratory · Move the center and certify a Taylor model

Approximate exe^x on an editable dimensionless interval. Plot the function and polynomial, report a sampled maximum absolute error, and compare it with a whole-interval Lagrange bound. Choose the center within the interval; an endpoint is allowed.

Source code

// Adjustable center, degree, and interval; keep these modest.
const center = 0;
const degree = 4;
const left = -0.5;
const right = 0.5;
if (![center, left, right].every(Number.isFinite) || left >= right || center < left || center > right || Math.max(Math.abs(left), Math.abs(right)) > 10) throw new Error('Choose a finite increasing interval within [-10, 10] containing the center.');
if (!Number.isInteger(degree) || degree < 0 || degree > 30) throw new Error('Degree must be an integer from 0 to 30.');
function taylor(x) {
  let term = Math.exp(center);
  let sum = term;
  for (let k = 1; k <= degree; k++) {
    term *= (x - center) / k;
    sum += term;
  }
  return sum;
}
let factorial = 1;
for (let k = 2; k <= degree + 1; k++) factorial *= k;
const distance = Math.max(center - left, right - center);
const bound = Math.exp(right) * distance ** (degree + 1) / factorial;
const exactPoints = [];
const modelPoints = [];
let sampledMax = 0;
for (let j = 0; j <= 200; j++) {
  const x = left + (right - left) * j / 200;
  const exact = Math.exp(x);
  const approx = taylor(x);
  exactPoints.push([x, exact]);
  modelPoints.push([x, approx]);
  sampledMax = Math.max(sampledMax, Math.abs(exact - approx));
}
plot(exactPoints, 'e^x (x dimensionless)');
plot(modelPoints, 'Taylor polynomial (x dimensionless)');
console.log('center, degree:', center, degree);
console.log('sampled maximum absolute error:', sampledMax);
console.log('whole-interval truncation bound:', bound);
console.log('right endpoint polynomial:', taylor(right));

Concept checks

  1. What is the derivative of a power series inside its convergence radius?

    • Termwise differentiation is allowed
    • Termwise differentiation never works
    • Only the constant term survives

    Answer. Termwise differentiation is allowed. Power series may be differentiated term by term strictly inside their radius of convergence.

  2. Does the ratio test settle endpoints of a power series interval?

    • Always
    • Never needs to
    • Usually endpoints need separate tests

    Answer. Usually endpoints need separate tests. At ∣x−a∣=R|x-a|=R the ratio limit is typically 11 and separate analysis is needed.

  3. What is the Maclaurin polynomial of cos⁡x\cos x through degree 22?

    • 1−x2/21-x^2/2
    • x−x3/6x-x^3/6
    • 1+x2/21+x^2/2

    Answer. 1−x2/21-x^2/2. Cosine’s value at zero is 11, first derivative zero, and second derivative −1-1.

  4. What controls a Lagrange remainder for degree nn?

    • A bound on derivative n+1n+1
    • Only f(a)f(a)
    • A graph at a few points

    Answer. A bound on derivative n+1n+1. A derivative bound throughout the interval gives the explicit Taylor error bound.

  5. Can a smooth function differ from its Taylor series near the center?

    • No
    • Yes
    • Only if discontinuous

    Answer. Yes. Smoothness alone does not imply analyticity; e−1/x2e^{-1/x^2} for x≠0x\ne0, extended by 00 at x=0x=0, is a standard example.

Chapter synthesis

  • A power series has a symmetric open interval of absolute convergence; each finite endpoint requires a separate test.
  • Termwise differentiation and integration preserve the radius, with endpoint behavior checked again.
  • Taylor coefficients match derivatives; derivative bounds certify finite polynomial approximations.
  • A smooth function need not equal its Taylor series, and sampled error does not establish a uniform certificate.

Common mistakes to check

  • “A convergent Taylor series must equal its source function.” The smooth function f(x)=e−1/x2f(x)=e^{-1/x^2} for x≠0x\ne0, extended by f(0)=0f(0)=0, has an everywhere-convergent zero Taylor series at zero but is positive elsewhere. Test with problem 23
  • “The radius decides the endpoints.” The power series centered at zero with coefficients 11, 1/n1/n, and 1/n21/n^2 for n≥1n\ge1 all have radius one. At x=−1x=-1 they respectively diverge, converge conditionally, and converge absolutely. Test with problem 3
  • “Adding terms always improves computed accuracy.” Truncation bounds may improve while cancellation and rounding limit the computed result. Test with problem 33
