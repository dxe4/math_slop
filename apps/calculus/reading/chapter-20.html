One output, several independent inputs

A temperature map assigns a number to every permitted position on a plate. Write T(x,y)T(x,y) for temperature at the point with coordinates (x,y)(x,y). The ordered pair is one input location, though its two coordinates can vary independently. A scalar function of two variables is a rule f:D→Rf:D\to\mathbb R, where DD is a subset of R2\mathbb R^2. A function of three variables might describe temperature throughout a solid. Its values are still numbers; it is different from a vector-valued function whose output has several components.

Find the domain before drawing or differentiating. For f(x,y)=9−x2−y2f(x,y)=\sqrt{9-x^2-y^2}, the radicand must be nonnegative, so DD is the closed disk x2+y2≤9x^2+y^2\le 9. Its boundary circle is included. For g(x,y)=ln⁡(y−x2)g(x,y)=\ln(y-x^2), the logarithm requires y>x2y>x^2, an open region above a parabola; the parabola itself is excluded. For a quotient, exclude every zero of the denominator, even if simplification later suggests an extension. A physical model can impose further restrictions: negative concentrations might be algebraically allowed but physically meaningless.

An interior point has some entire small disk around it inside DD. A boundary point has arbitrarily nearby points both in DD and outside DD. This distinction matters for limits and derivatives: an ordinary two-sided partial derivative needs coordinate perturbations on both sides. At the edge of a physical plate only a one-sided rate may be available unless the model extends beyond the plate. Closed means containing all boundary points, whereas bounded means fitting inside a disk of finite radius; these are separate properties.

Coordinate units belong to the model. If xx and yy are lengths in metres, a dimensionless expression such as 9−x2−y29-x^2-y^2 needs appropriate coefficients or explicitly nondimensional coordinates. In geometric examples here we use dimensionless coordinates unless units are stated. A temperature model later includes coefficients with the units necessary to make every term a temperature.

The domain is a set of input points, not a list of separate allowed xx-values and yy-values. For ln⁡(4−x2−y2)/y−x\ln(4-x^2-y^2)/\sqrt{y-x}, the logarithm requires x2+y2<4x^2+y^2<4 and the denominator requires y−x>0y-x>0. The domain is the intersection of the open disk of radius two with the half-plane above y=xy=x. Neither circular boundary nor line y=xy=x is included. Listing −2<x<2-2<x<2 and −2<y<2-2<y<2 would be necessary but far from sufficient; many pairs in that square violate one or both coupled conditions.

A level curve is a subset of the domain. For f(x,y)=9−x2−y2f(x,y)=\sqrt{9-x^2-y^2}, the value cc can range only from zero to three. If 0≤c≤30\le c\le3, solving f=cf=c gives x2+y2=9−c2x^2+y^2=9-c^2, a circle for 0≤c<30\le c<3 and a single point at c=3c=3. The c=0c=0 level is the boundary circle of the domain, which is included because the square root permits zero. If the domain were physically restricted to an open plate, that boundary level might be absent even though the algebraic formula still makes sense there. State the domain before classifying contours.

An input can have different status relative to a domain: interior, boundary, exterior, or isolated. On the closed disk x2+y2≤9x^2+y^2\le9, the center is interior and a point with radius three is boundary; outside points are not eligible inputs. For a domain formed by a curve alone, no point has a full two-dimensional disk around it, so ordinary open-domain partial-derivative theorems need reconsideration. This geometric classification guides which limits, directional changes, and optimization conditions are meaningful. A plotted border is not enough; inclusion follows from the defining inequalities.

A physical domain may be smaller than the mathematical domain of a formula. If a temperature model is fitted only on a metal plate, extrapolating it beyond the plate may be algebraically possible but empirically unsupported. A boundary derivative might be computed from the formula's extension, but the plate provides observations only from its own side. Distinguish a formula's natural domain, the region where a model is trusted, and the region over which a theorem is applied. These sets can differ, and conclusions should name the one being used.

Graphs, slices, and level sets

The graph of z=f(x,y)z=f(x,y) consists of triples (x,y,f(x,y))(x,y,f(x,y)) in three-dimensional space. The domain lies in the input plane; the graph sits above or below it. Holding y=by=b gives a vertical slice z=f(x,b)z=f(x,b). Holding x=ax=a gives another slice. These one-variable graphs are useful windows into a surface, but a few slices cannot determine every feature between them.

A level set fixes the output instead: f(x,y)=cf(x,y)=c. For f(x,y)=x2+y2f(x,y)=x^2+y^2, positive levels are circles of radius c\sqrt c, level zero is a single point, and negative levels are empty. The graph is an upward-opening paraboloid. For f(x,y)=x2−y2f(x,y)=x^2-y^2, positive levels are hyperbolas opening along the xx direction, negative levels open along the yy direction, and level zero consists of the intersecting lines y=xy=x and y=−xy=-x. Its graph is a saddle, rising along one coordinate axis and falling along the other.

A contour map labels several level sets in the input plane. Closely spaced contours for equal output increments suggest rapid variation across them; movement along a contour keeps the output constant. This interpretation depends on the coordinate scale and on using equal contour increments. Unevenly chosen contour values can make a gently varying region look steep. Contours also need not be smooth curves: the saddle’s zero level has a crossing, and the paraboloid’s zero level is a point.

For a function f(x,y,z)f(x,y,z), a level set f=cf=c usually forms a surface in ordinary three-dimensional space. For example x2+y2+z2=cx^2+y^2+z^2=c is a sphere when c>0c>0. The full graph would require four coordinates, so slices and level surfaces become especially valuable. Always say whether a displayed surface is a graph of a two-variable function or a level set of a three-variable function.

Slices and contours answer different questions. For f(x,y)=x2+y2f(x,y)=x^2+y^2, the slice y=0y=0 gives z=x2z=x^2, a parabola; the slice x=0x=0 is the same shape in the other vertical plane. The level f=1f=1 gives a circle in the input plane. A vertical slice shows how output changes along one chosen line, while a contour shows where output stays fixed as both inputs vary. Neither representation alone captures the full surface, but together they can reveal symmetry and distinguish a bowl from a saddle.

Contours carry a local rate interpretation when the function is differentiable and its gradient is nonzero. Closely spaced equal-value contours often indicate a large gradient magnitude in the direction perpendicular to them. However, plotting with unequal x and y scales distorts apparent distances, and choosing uneven contour increments distorts the rate cue. A map should label contour values, axis scales, and units. Near a critical point, contours may change topology or collapse to a point, so a simple spacing rule may become unreliable without derivative analysis.

For the saddle f=x2−y2f=x^2-y^2, the zero contour consists of both diagonals y=xy=x and y=−xy=-x. Along y=0y=0 the surface rises as x2x^2, while along x=0x=0 it falls as −y2-y^2. This proves the origin is neither a local maximum nor a local minimum without needing a perspective rendering. A few slices chosen along meaningful directions can therefore be decisive, even though arbitrary slices are not enough to prove every possible property. The positive and negative contour families show how the same output level can have disconnected branches.

When ff has three inputs, a two-dimensional contour is replaced by a level surface. For x2+y2+z2=c>0x^2+y^2+z^2=c>0, the set is a sphere of radius c\sqrt c; for c=0c=0 it is one point; for c<0c<0 it is empty. A slice at fixed z=z0z=z_0 is a circle only when c−z02>0c-z_0^2>0. These descriptions have different dimensions: the graph of a three-input scalar field would live in four dimensions, but its level surfaces live in ordinary space. Specify which construction a visualization shows so the reader does not mistake a level set for a graph.

Limits must survive every approach

In one variable a point can be approached from the left or right. In a plane there are infinitely many straight and curved approaches. The statement f(x,y)→Lf(x,y)\to L as (x,y)→(a,b)(x,y)\to(a,b) means that all allowed inputs sufficiently close to (a,b)(a,b), except the point itself, give outputs close to LL. Formally, for every ε>0\varepsilon>0 there is δ>0\delta>0 such that (x,y)∈D(x,y)\in D and 0<(x−a)2+(y−b)2<δ0<\sqrt{(x-a)^2+(y-b)^2}<\delta imply ∣f(x,y)−L∣<ε|f(x,y)-L|<\varepsilon. The point must be an accumulation point of DD, so there really are domain points approaching it.

A path is a convenient way to select some of those inputs. If two paths approaching the same point produce different output limits, the full limit does not exist. For xy/(x2+y2)xy/(x^2+y^2) at the origin, the xx axis gives zero while y=xy=x gives 1/21/2. No single LL can match both. But agreement along two paths, or even every straight line, does not prove existence: curves may still expose different behavior. A numerical sample of paths can discover an obstruction; it cannot exhaust the definition.

A straight-path check can miss a multivariable limit failure. The rational function q(x,y)=x2y/(x4+y2)q(x,y)=x^2y/(x^4+y^2) has value zero on both axes. On a fixed nonhorizontal, nonvertical line y=mxy=mx with m≠0m\ne0, q(t,mt)=mt/(t2+m2)→0q(t,mt)=mt/(t^2+m^2)\to0; the horizontal and vertical axes give zero directly. Yet q(t,t2)=1/2q(t,t^2)=1/2 for t≠0t\ne0. Lesson 6 develops the balancing-scale reason and the whole curved-path family. Here the contrast establishes the decision rule: two paths with different limits disprove a full limit, while even many agreeing paths cannot prove one.

To prove a limit, seek a bound depending only on distance. For p(x,y)=x2y/(x2+y2)p(x,y)=x^2y/(x^2+y^2), define r=x2+y2r=\sqrt{x^2+y^2}. Since x2/(x2+y2)≤1x^2/(x^2+y^2)\le1, we have ∣p(x,y)∣≤∣y∣≤r|p(x,y)|\le|y|\le r. Choosing δ=ε\delta=\varepsilon proves p→0p\to0. This argument controls every point of the punctured disk at once, including curved paths. Algebraic limit laws also apply when their component limits exist; a quotient law needs a nonzero limiting denominator.

To disprove a proposed two-variable limit, one contradictory path is enough if another path gives a different limit. To prove a limit, paths are generally insufficient because infinitely many untested approaches remain. The epsilon–delta definition demands one δ\delta that works for every eligible point in the punctured disk. This quantifier order is the conceptual difference: “for each chosen path there is a scale” does not imply “there is one scale for all directions and curves.” The radial bound ∣p(x,y)∣≤r|p(x,y)|\le r supplies the latter and is why it proves the full limit.

Polar coordinates can help when the transformed expression has a bound uniform in angle. If f(rcos⁡θ,rsin⁡θ)=rg(θ)f(r\cos\theta,r\sin\theta)=r g(\theta) and ∣g(θ)∣≤M|g(\theta)|\le M for all θ\theta, then ∣f∣≤Mr→0|f|\le Mr\to0; choose δ=ε/M\delta=\varepsilon/M when M>0M>0. If gg depends on rr in a way that grows as θ\theta changes with rr, fixing θ\theta before sending r→0r\to0 can hide trouble. For q=x2y/(x4+y2)q=x^2y/(x^4+y^2), the dangerous balance y≈x2y\approx x^2 corresponds to an angle that approaches zero with radius for x>0x>0, or approaches π\pi for x<0x<0, rather than one fixed ray. A polar rewrite is a tool, not an automatic proof.

The elementary inequality 2∣xy∣≤x2+y22|xy|\le x^2+y^2 provides many useful bounds. It follows from (∣x∣−∣y∣)2≥0(|x|-|y|)^2\ge0. Hence ∣xy∣/(x2+y2)≤1/2|xy|/(x^2+y^2)\le1/2 away from the origin, but that bound does not tend to zero; indeed xy/(x2+y2)xy/(x^2+y^2) has different limits along y=xy=x and y=−xy=-x. The epsilon–delta definition also specifies which points are tested. A limit at a point asks about domain points arbitrarily close to that point but excludes the point itself. Changing the function value at the center cannot alter an existing limit. If a domain has no other points approaching a candidate location, a two-variable limit there is not meaningful in the usual accumulation-point setting. On a restricted domain, the allowed approaches may cover only part of a disk, such as the upper half-plane; the same quantifier then ranges over all nearby domain points, not over points where the function is undefined.

For a proposed limit LL, write the target inequality ∣f(x,y)−L∣<ε|f(x,y)-L|<\varepsilon before searching for δ\delta. A multivariable limit can exist even when different paths have different formulas or rates of approach. For f(x,y)=x2y/(x2+y2)f(x,y)=x^2y/(x^2+y^2) away from zero, the xx-axis gives zero while the diagonal y=xy=x gives x/2x/2; both tend to zero. This asymmetry is useful when choosing between a path counterexample and a uniform estimate.

Continuity and coordinate rates

A function f:D→Rf:D\to\mathbb R is continuous at p∈Dp\in D if, for every ε>0\varepsilon>0, some δ>0\delta>0 makes ∣f(q)−f(p)∣<ε|f(q)-f(p)|<\varepsilon for every q∈Dq\in D with ∥q−p∥<δ\|q-p\|<\delta. At an accumulation point of DD, this is equivalent to the limit of f(q)f(q) within DD equalling f(p)f(p). At an isolated domain point, continuity holds automatically. Polynomials are continuous everywhere, and quotients of continuous functions are continuous where their denominators are nonzero. Compositions preserve continuity where defined. The function pp from the preceding section becomes continuous at the origin if we define p(0,0)=0p(0,0)=0. The function qq cannot be made continuous there by assigning any single value because its limit does not exist.

The partial derivative fx(a,b)f_x(a,b) varies xx while holding yy exactly equal to bb. It is the derivative of the slice x↦f(x,b)x\mapsto f(x,b). Similarly fyf_y varies yy with xx fixed. Compute partial derivatives using familiar rules, treating other independent coordinates as constants. If f(x,y)=x2ey+sin⁡(xy)f(x,y)=x^2e^y+\sin(xy), then fx=2xey+ycos⁡(xy)f_x=2xe^y+y\cos(xy) and fy=x2ey+xcos⁡(xy)f_y=x^2e^y+x\cos(xy). The product xyxy inside the sine is a reminder that a variable held constant can still multiply the variable being differentiated.

A partial derivative measures a controlled comparison, not automatically a rate along a moving path. In a temperature field, TxT_x has units degrees Celsius per metre when xx is measured in metres. It describes change per displacement in the xx direction with yy fixed. If a sensor moves so that both coordinates change with time, both influences matter; chapter 21 develops the chain rule for that motion. A partial derivative does not itself include the sensor’s speed.

Existence of both partial derivatives at a point does not guarantee continuity there. Extend qq above by q(0,0)=0q(0,0)=0. Along each coordinate axis qq is identically zero, so both partial derivatives at the origin exist and equal zero. Along y=x2y=x^2 the values stay 1/21/2, so qq is discontinuous. Partial derivatives inspect only two slices. A genuinely accurate linear model in all directions requires the stronger concept of differentiability, introduced in the next chapter.

Partial derivatives are defined by one-variable limits on coordinate slices. For fx(a,b)f_x(a,b), hold y=by=b exactly and take [f(a+h,b)−f(a,b)]/h[f(a+h,b)-f(a,b)]/h as h→0h\to0 through permitted inputs. For fyf_y, hold x=ax=a. This makes their units transparent: output per xx-unit and output per yy-unit can differ. If xx is metres and yy is seconds, fxf_x and fyf_y have different units and cannot be added without multiplying by rates of change of xx and yy. The chain rule in chapter 21 supplies exactly those factors.

A partial derivative may exist on a domain boundary as a one-sided quantity, but standard open-neighborhood theorems do not automatically apply there. For f(x,y)=9−x2−y2f(x,y)=\sqrt{9-x^2-y^2}, the boundary circle belongs to the domain, yet moving outward is not permitted and the radial derivative can become unbounded from inside. The formula fx=−x/9−x2−y2f_x=-x/\sqrt{9-x^2-y^2} applies only at interior points with positive radicand. Evaluating it at the boundary by writing a zero denominator is not a derivative value. State the region where a symbolic derivative formula is valid.

The qq example exposes why two partials are not enough for continuity. On both coordinate axes qq is zero, so difference quotients along those axes at the origin are zero. Along y=x2y=x^2, qq is one-half near the origin. A hypothetical linear approximation from partials would predict almost no change, but actual nearby values remain separated from zero. Differentiability is a uniform first-order approximation across all small displacement vectors, and it implies continuity. Coordinatewise behavior is only a pair of one-dimensional tests.

A controlled coordinate change can be useful in experiments. If a temperature field is T(x,y)T(x,y), moving from (a,b)(a,b) to (a+h,b)(a+h,b) measures an xx-direction change with yy fixed; moving to (a,b+k)(a,b+k) measures a yy-direction change. A diagonal move to (a+h,b+k)(a+h,b+k) combines both influences and cannot be attributed to one partial alone. Sampling each axis separately may identify local sensitivities, but inferring a diagonal prediction needs a differentiability assumption. This is the conceptual bridge from partial derivatives to the gradient and total differential.

Higher partial derivatives and the order of differentiation

Differentiate a partial derivative again to obtain a higher partial. We use fxyf_{xy} to mean (fx)y(f_x)_y: first differentiate with respect to xx, then with respect to yy. Thus fxxf_{xx} measures how the xx-slope changes as xx varies, while fxyf_{xy} measures how that same slope changes as yy varies. If ff is temperature with both coordinates in metres, these second derivatives have units degrees Celsius per square metre. When coordinates represent different quantities, the mixed derivative has output units divided by the product of those input units.

For f(x,y)=x2y3f(x,y)=x^2y^3, direct calculation gives fx=2xy3f_x=2xy^3, fxx=2y3f_{xx}=2y^3, and fxy=6xy2f_{xy}=6xy^2. Starting in the other order gives fy=3x2y2f_y=3x^2y^2 and fyx=6xy2f_{yx}=6xy^2. Agreement is not accidental for this polynomial. Clairaut’s theorem supplies a sufficient condition: if both mixed second partial derivatives exist and are continuous throughout an open neighborhood of (a,b)(a,b), then fxy(a,b)=fyx(a,b)f_{xy}(a,b)=f_{yx}(a,b). In particular, a function with continuous second partial derivatives on an open region has interchangeable mixed second derivatives there.

Proof sketch: form the rectangular difference f(a+h,b+k)−f(a+h,b)−f(a,b+k)+f(a,b)f(a+h,b+k)-f(a+h,b)-f(a,b+k)+f(a,b), then divide by hkhk. Reversing the order gives the other mixed derivative at another nearby point. Their continuity lets both expressions converge to the corresponding values at (a,b)(a,b), forcing equality. The neighborhood and continuity hypotheses make this passage to the limit legitimate.

The hypotheses are sufficient, not necessary; failure of a hypothesis means the theorem gives no conclusion. Unequal mixed partials are possible. For a polynomial such as x2y3x^2y^3, all derivatives are continuous everywhere, and equality fxy=fyxf_{xy}=f_{yx} follows from Clairaut's theorem. Explicit calculation is still a useful check: fxy=fyx=6xy2f_{xy}=f_{yx}=6xy^2. In an application, the mixed derivative describes how one directional sensitivity changes when the other input moves. Continuity of mixed partials in an open neighborhood is sufficient for equality, but equality at one point can happen without that full hypothesis. A theorem's sufficient conditions should not be read as necessary conditions. Conversely, existence of fxyf_{xy} and fyxf_{yx} at a point alone does not force equality, as the provided counterexample shows. In numerical data, mixed partials are especially sensitive to noise because they involve four nearby values and division by hkhk. A family of paths that exposes a hidden limit failure

A failed multivariable limit need not involve unbounded output. Consider q(x,y)=x2y/(x4+y2)q(x,y)=x^2y/(x^4+y^2), defined away from the origin. Put a=x2a=x^2 and b=yb=y. Boundedness by itself says nothing about whether nearby values settle toward one number; qq will provide a sharp example of the difference.

Take a family of curved paths y=cx2y=cx^2 for fixed real cc. At a point (x,cx2)(x,cx^2) with x≠0x\ne0, substitution and cancellation give q(x,cx2)=c/(1+c2)q(x,cx^2)=c/(1+c^2). Varying cc fills a whole interval of path values, but two distinct values already suffice to disprove the full limit.

Why might a preliminary test miss the problem? Along a nonvertical straight line y=mxy=mx with fixed m≠0m\ne0, q(x,mx)=mx/(x2+m2)→0q(x,mx)=mx/(x^2+m^2)\to0. Searching for paths that balance competing powers is a useful diagnostic technique for rational expressions in several variables.

Polar coordinates do not automatically solve this problem. A fixed polar angle describes a straight ray, so checking each fixed θ\theta reproduces the misleading line evidence. The parameter θ\theta may vary with the radius as the input approaches the origin, and the definition permits that. A successful proof of a limit needs a bound uniform in direction, such as ∣p(x,y)∣≤r|p(x,y)|\le r for the different function p=x2y/(x2+y2)p=x^2y/(x^2+y^2). The bound for qq is only ∣q∣≤1/2|q|\le1/2, which does not tend to zero and cannot establish convergence.

This example also shows why a finite-resolution surface plot or grid is not a proof. The positive ridge along y=x2y=x^2 becomes narrower relative to ordinary rectangular sampling near the origin. A display can help discover the balancing scale, but only the explicit path calculation establishes failure. Conversely, an explicit radial bound establishes a limit for every eligible path, including those never drawn.

The path family is discovered by balancing powers, not by guessing a picture. The values c/(1+c2)c/(1+c^2) have maximum 1/21/2 at c=1c=1 and minimum −1/2-1/2 at c=−1c=-1. A numerical investigation should plot both paths against distance to the origin or against a common parameter approaching zero.
