  11. Problem 11. Interpretation Why can a narrow peak make TnT_n and T2nT_{2n} agree while both are wrong?

    Hint. Consider sample locations.

    Solution. If neither grid samples a narrow peak, both TnT_n and T2nT_{2n} can omit its area. Agreement of the two sampled sums does not establish accuracy without a smoothness bound or separate check.

  22. Problem 22. Fluency Does ∫−111∣x∣ dx\int_{-1}^1\frac{1}{\sqrt{|x|}}\,dx converge?

  23. Problem 23. Interpretation A numerical program returns zero for ∫−221x dx\int_{-2}^2 \frac{1}{x}\,dx by using symmetric samples. Is zero the improper integral?

    Hint. Evaluate the two one-sided limits independently.

Concept checks

  1. For which pp does ∫1∞1/xp dx\int_1^{\infty}1/x^p\,dx converge?

    • p>1p>1
    • p≥0p\ge0
    • p<1p<1

    Answer. p>1p>1. The pp-integral threshold for a tail at infinity is p>1p>1.

  2. For which pp does ∫011/xp dx\int_0^1 1/x^p\,dx converge?

    • p>1p>1
    • p<1p<1
    • p=1p=1 only

    Answer. p<1p<1. The singular endpoint threshold is reversed: p<1p<1.

  3. How many subintervals does composite Simpson’s rule require?

    • Any positive number
    • An even number
    • Only one

    Answer. An even number. The standard composite rule groups adjacent pairs, so nn must be even.

  4. Does a principal value equal an ordinary improper integral automatically?

    • Yes
    • No
    • Only for odd functions

    Answer. No. Symmetric cancellation can exist even when each one-sided improper integral diverges.

Chapter synthesis

  • Trapezoidal and Simpson rules approximate bounded-interval integrals; their standard bounds require controlled derivatives.
  • Adaptive refinement allocates samples using local estimates that must be interpreted with their assumptions.
  • Improper integrals are limits; every singular endpoint and infinite tail must converge independently.
  • Comparison and substitutions guide computation, while total error includes excluded tails and endpoint regions.
  • A principal value is a specified cancellation limit and need not equal an existing ordinary improper integral.

Common mistakes to check

  • “Two refinements agree, so the error is certified.” Agreement can miss an unsampled spike; a certificate needs a valid bound or additional justified information. Test with problem 11
  • “An odd function integrates to zero across a symmetric interval.” This requires an existing integral. For f(x)=1/xf(x)=1/x on [−1,1][-1,1], the ordinary improper integral diverges, while its symmetric Cauchy principal value is zero. Test with problem 23
  • “A convergent improper integral is easy to compute.” Slow tails and endpoint singularities can require analytic bounds or a change of variables. Test with problem 18
