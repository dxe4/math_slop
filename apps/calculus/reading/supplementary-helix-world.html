const R=2,h=0.5,t=Math.PI/2;
const report = (value) => {
  const check = (v) => {
    if (typeof v === 'number' && !Number.isFinite(v))
      throw Error(
        'Numeric output is outside binary64 representability; use symbolic mathematics or representable inputs.',
      );
    if (v && typeof v === 'object') Object.values(v).forEach(check);
  };
  check(value);
  console.log(JSON.stringify(value));
};
if (
  ![R, h, t].every(Number.isFinite) ||
  R <= 0 ||
  R > 10 ||
  Math.abs(h) > 5 ||
  Math.abs(t) > 2 * Math.PI
)
  throw Error('Require 0<R≤10 m, |h|≤5 m/parameter, |t|≤2π.');
const point = [R * Math.cos(t), R * Math.sin(t), h * t],
  velocity = [-R * Math.sin(t), R * Math.cos(t), h],
  acceleration = [-R * Math.cos(t), -R * Math.sin(t), 0],
  speed = Math.hypot(R, h);
report({
  experiment: 'helix-world',
  units: { point: 'm', speed: 'm/parameter', curvature: 'm⁻¹' },
  input: { R, h, t },
  result: {
    point,
    velocity,
    acceleration,
    speed,
    unitTangent: velocity.map((v) => v / speed),
    curvature: R / speed / speed,
    turnRise: 2 * Math.PI * h,
  },
});
plot(
  Array.from({ length: 121 }, (_, i) => {
    const u = -Math.PI + (2 * Math.PI * i) / 120;
    return [R * Math.cos(u), R * Math.sin(u)];
  }),
  'xy projection of world helix (m); height omitted',
);

Analytic comparison and limits

r(t)=(Rcos⁡t,Rsin⁡t,ht)\mathbf r(t)=(R\cos t,R\sin t,ht) m\mathrm m; speed=R2+h2\text{speed}=\sqrt{R^2+h^2} m\mathrm m per parameter; κ=RR2+h2\kappa=\frac{R}{R^2+h^2} m−1\mathrm{m}^{-1}; one turn rises 2π2\pi hh m\mathrm m. An xyxy plot is a projection only. Evaluate curvature as R/speedspeed\frac{R/\text{speed}}{\text{speed}} to avoid underflow from first squaring a tiny radius; this equals RR2+h2\frac R{R^2+h^2}. Non-finite numeric output raises an explicit precision error; null is reserved for a deliberately absent derivative.

Boundary and failure behavior

Boundary: R=0R=0 is excluded by the helix contract. h=0h=0 gives a circle and zero rise; equal xyxy projections need not be equal world points when hh is nonzero.
