Choose a bounded question, derive and implement a model, compare independent evidence, and publish a qualified conclusion.

Choose a bounded question in growth, motion, optimization, or accumulation. State domain, units, provenance, assumptions, and a prediction before computing. Derive the mathematics, implement a repeatable calculation, validate against an independently derived exact result, theorem bound, or withheld data, vary at least two inputs, and publish enough detail for another learner to reproduce and qualify the result. Stages

1. Commit to a question

Choose a topic and measurable output; specify finite domain, units, provenance, assumptions, and a prediction. For the reference, predict whether biomass reaches capacity by day 3 and whether midpoint refinement changes the estimate.

Evidence to produce. One-page question and input/output contract.

Guidance. Require a finite endpoint, an independent benchmark, and a failure case before seeing results.

2. Derive the model

Derive governing equations and conditions, a comparison result, and invariants or theorem hypotheses. For the reference derive cumulative rate and both constant solutions.

Evidence to produce. Unit-checked derivation with stated boundary cases and hypotheses.

Guidance. The invariant interval follows from uniqueness or the exact formula; ∣a∣≤1|a|\le1 also makes the reference rate nonnegative.

3. Implement and check

Supply code or unambiguous pseudocode, exact inputs, output for N=3,6,12N=3,6,12, an independent benchmark, changed cases A and B, and a boundary or invalid-input test.

Evidence to produce. Reproducible common-endpoint table.

Guidance. Integrate the rate by midpoint sums and map through exact logistic odds. Do not run saved source on page load.

4. Bound and conclude

Derive an applicable bound, compare observed errors and refinement ratios, distinguish numerical error from model and parameter uncertainty, and publish a report with citations if external data were chosen.

Evidence to produce. Data, derivation, source, results, error argument, and qualified conclusion.

Guidance. A refinement ratio is evidence, not proof. The midpoint certificate applies to the smooth reference rate, not real biomass.

Reproducible reference source

This source is inert text in the printed and interactive editions.

const K = 1000,
  P0 = 100,
  r0 = 0.4,
  a = 0.5,
  omega = Math.PI / 2,
  T = 3;
if (
  ![K, P0, r0, a, omega, T].every(Number.isFinite) ||
  K <= 0 ||
  P0 < 0 ||
  P0 > K ||
  r0 <= 0 ||
  Math.abs(a) > 1 ||
  omega <= 0 ||
  T <= 0
)
  throw Error('invalid reference input');
if (
  !Number.isFinite(omega * T) ||
  !Number.isFinite(r0 * T) ||
  !Number.isFinite(K * T * T * T * r0 * Math.abs(a) * omega * omega)
)
  throw Error('reference calculation exceeds binary64 range');
const population = (R) =>
  P0 === 0 ? 0 : P0 === K ? K : K / (1 + (K / P0 - 1) * Math.exp(-R));
const rate = (t) => r0 * (1 + a * Math.cos(omega * t));
const Rexact = r0 * (T + (a * Math.sin(omega * T)) / omega),
  exact = population(Rexact);
const table = [3, 6, 12].map((N) => {
  const h = T / N;
  let Rmid = 0;
  for (let j = 0; j < N; j++) Rmid += h * rate((j + 0.5) * h);
  const Pmid = population(Rmid);
  return {
    N,
    Rmid,
    Pmid,
    signedError: Pmid - exact,
    Rbound: (T * h * h * r0 * Math.abs(a) * omega * omega) / 24,
    Pbound: (K * T * h * h * r0 * Math.abs(a) * omega * omega) / 96,
  };
});
console.log(JSON.stringify({ Rexact, exact, table }));

Self-assessment criteria

Judge each criterion as not yet evidenced, developing, or supported by your work.

  • Question. I stated a testable question, finite domain, units, provenance, assumptions, prediction, and input/output contract.
  • Derivation. I derived the mathematics and checked boundaries, invariants, and hypotheses.
  • Implementation. I supplied repeatable code or pseudocode, exact inputs, and default plus two changed cases.
  • Validation. I used an independent benchmark, common-endpoint errors, refinement, and an applicable error bound.
  • Conclusion. I separated numerical, parameter, measurement, and model limits without external grading claims.

Limitations to address

  • The reference periodic rate is synthetic.
  • Its numerical certificate does not quantify model uncertainty.
  • Other learner choices require their own benchmark and hypotheses.
