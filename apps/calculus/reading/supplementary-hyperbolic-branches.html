Complete editable source

const t=Math.LN2, q=0.6;
const report = (value) => {
  const check = (v) => {
    if (typeof v === 'number' && !Number.isFinite(v))
      throw Error(
        'Numeric output is outside binary64 representability; use symbolic mathematics or representable inputs.',
      );
    if (v && typeof v === 'object') Object.values(v).forEach(check);
  };
  check(value);
  console.log(JSON.stringify(value));
};
if (
  !Number.isFinite(t) ||
  t < -4 ||
  t > 4 ||
  !Number.isFinite(q) ||
  Math.abs(q) >= 1
)
  throw Error('Require −4 ≤ t ≤ 4 and −1 < q < 1.');
const sinh = Math.sinh(t),
  cosh = Math.cosh(t),
  tanh = Math.tanh(t);
const result = {
  sinh,
  cosh,
  tanh,
  identity: cosh * cosh - sinh * sinh,
  asinh: Math.asinh(sinh),
  acosh: Math.abs(t),
  directAcoshCosh: Math.acosh(cosh),
  atanh: Math.atanh(q),
  logAtanh: (Math.log1p(q) - Math.log1p(-q)) / 2,
  directLogAtanh: Math.log((1 + q) / (1 - q)) / 2,
  branch: 'acosh is nonnegative',
};
report({
  experiment: 'hyperbolic-branches',
  units: 'dimensionless',
  input: { t, q },
  result,
});
plot(
  Array.from({ length: 101 }, (_, i) => {
    const u = -2 + (4 * i) / 100;
    return [Math.cosh(u), Math.sinh(u)];
  }),
  'Right hyperbola branch: world x,y, dimensionless',
);

Analytic comparison and limits

cosh⁡2t−sinh⁡2t=1\cosh^2t-\sinh^2t=1; asinh⁡(sinh⁡t)=t\operatorname{asinh}(\sinh t)=t; acosh⁡(cosh⁡t)=∣t∣\operatorname{acosh}(\cosh t)=|t|; atanh⁡q=12ln⁡1+q1−q\operatorname{atanh}q=\frac12\ln\frac{1+q}{1-q} for ∣q∣<1|q|<1. Samples cannot prove the identity. Non-finite numeric output raises an explicit precision error; null is reserved for a deliberately absent derivative. The real identity acosh⁡(cosh⁡t)=∣t∣\operatorname{acosh}(\cosh t)=|t| is evaluated as ∣t∣|t|; the separate directAcoshCosh field shows what happens after cosh⁡\cosh has rounded to binary64. Near zero that direct composition can give zero because cosh⁡t\cosh t rounds to 1. The logarithmic atanh⁡\operatorname{atanh} comparison uses log1p⁡(q)−log1p⁡(−q)2\frac{\operatorname{log1p}(q)-\operatorname{log1p}(-q)}2 to retain small qq; directLogAtanh shows cancellation in the unmodified quotient formula. Algebraic identities and rounded numerical compositions are different comparisons.

Default and changed-input cases

  • Default t=ln⁡2t=\ln2, q=0.6q=0.6: sinh⁡t=0.75\sinh t=0.75, cosh⁡t=1.25\cosh t=1.25, tanh⁡t=0.6\tanh t=0.6, cosh⁡2t−sinh⁡2t=1\cosh^2t-\sinh^2t=1, both inverse checks and atanh⁡(q)=ln⁡2\operatorname{atanh}(q)=\ln2.
  • Changed t=−ln⁡2t=-\ln2, q=−0.6q=-0.6: sinh⁡t=−0.75\sinh t=-0.75, cosh⁡t=1.25\cosh t=1.25, tanh⁡t=−0.6\tanh t=-0.6; asinh⁡(sinh⁡t)=−ln⁡2\operatorname{asinh}(\sinh t)=-\ln2, acosh⁡(cosh⁡t)=ln⁡2\operatorname{acosh}(\cosh t)=\ln2, atanh⁡(q)=−ln⁡2\operatorname{atanh}(q)=-\ln2.
  • Changed t=0t=0, q=0q=0: sinh⁡t=tanh⁡t=atanh⁡q=0\sinh t=\tanh t=\operatorname{atanh}q=0, cosh⁡t=1\cosh t=1, and both inverse checks give zero.

Boundary and failure behavior

Boundary: q=±1q=\pm1 is outside the real atanh⁡\operatorname{atanh} domain and is rejected. acosh⁡\operatorname{acosh} uses its nonnegative branch; tanh⁡\tanh never reaches ±1\pm1 at finite tt.
