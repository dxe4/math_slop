Complete editable source

const lambda=10,h=0.3,n=1,y0=1;
const report = (value) => {
  const check = (v) => {
    if (typeof v === 'number' && !Number.isFinite(v))
      throw Error(
        'Numeric output is outside binary64 representability; use symbolic mathematics or representable inputs.',
      );
    if (v && typeof v === 'object') Object.values(v).forEach(check);
  };
  check(value);
  console.log(JSON.stringify(value));
};
if (
  ![lambda, h, n, y0].every(Number.isFinite) ||
  lambda <= 0 ||
  lambda > 20 ||
  h <= 0 ||
  h > 1 ||
  !Number.isInteger(n) ||
  n < 1 ||
  n * h > 5 ||
  y0 <= 0 ||
  y0 > 10
)
  throw Error('Require 0<lambda≤20/s, 0<h≤1 s, integer n≥1, nh≤5 s, 0<y0≤10.');
const z = lambda * h,
  cumulative = n * z,
  exact = y0 * Math.exp(-cumulative),
  implicit = y0 * Math.exp(-n * Math.log1p(z));
const forwardMagnitude =
  z < 1
    ? y0 * Math.exp(n * Math.log1p(-z))
    : z === 1
      ? 0
      : y0 * Math.exp(n * Math.log(z - 1));
const forward = z > 1 && n % 2 === 1 ? -forwardMagnitude : forwardMagnitude;
const exponent = (cumulative * z) / 2;
const implicitErrorCertificate =
  exponent > 700 ? implicit : Math.min(implicit, exact * Math.expm1(exponent));
report({
  experiment: 'implicit-decay',
  units: { time: 's', state: 'model units' },
  input: { lambda, h, n, y0 },
  result: {
    z,
    exact,
    forward,
    implicit,
    forwardError: Math.abs(forward - exact),
    implicitError: Math.abs(implicit - exact),
    implicitErrorCertificate,
    forwardStrictlyPositive: z < 1,
    forwardMagnitudeDecays: z < 2,
    forwardNeutral: z === 2,
    implicitStrictlyPositive: true,
    implicitMagnitudeDecays: true,
  },
});

Analytic comparison and limits

For z=λhz=\lambda h, yexact=y0e−nzy_{\mathrm{exact}}=y_0e^{-nz}, yfwd=y0(1−z)ny_{\mathrm{fwd}}=y_0(1-z)^n, yimp=y0(1+z)ny_{\mathrm{imp}}=\frac{y_0}{(1+z)^n}. Implicit multiplier lies in (0,1); forward magnitude decays for 0<z<20<z<2 and is strictly positive for 0<z<10<z<1. 0≤yimp−yexact≤yexact(enz2/2−1)0\le y_{\mathrm{imp}}-y_{\mathrm{exact}}\le y_{\mathrm{exact}}(e^{nz^2/2}-1). The reported certificate also uses the tighter trivial bound yimp−yexact≤yimpy_{\mathrm{imp}}-y_{\mathrm{exact}}\le y_{\mathrm{imp}} to stay finite in binary64. z=2z=2 is neutral for forward Euler.

Closed multiplier iterates use log1p so tiny zz is retained instead of rounding 1±z1\pm z to 1. The finite certificate preserves the smaller of the implicit-value bound and logarithmic bound; it avoids evaluating an overflowing exponential. Certificates concern real-arithmetic discretization, not roundoff.

Positivity statements concern mathematical multipliers; an unrepresentably small computed value may round to zero. Non-finite numeric output raises an explicit precision error; null is reserved for a deliberately absent derivative.

Boundary and failure behavior

Boundary: z=1z=1 makes forward Euler zero, not strictly positive; z=2z=2 gives multiplier −1-1, neutral rather than decaying. The implicit multiplier remains in (0,1) for z>0z>0.
