Substitution reverses a composition

Differentiation has a rule for every familiar combination of elementary functions. Integration requires a more selective question: which derivative rule could have produced this particular expression? The chain rule suggests substitution. If an integrand contains a function g(x)g(x) together with its derivative g′(x)g^{\prime}(x), setting u=g(x)u=g(x) may turn a complicated composition into a familiar integral. The symbol du=g′(x) dxdu=g^{\prime}(x)\,dx records the entire factor that must be replaced; it is not permission to discard an inconvenient multiplier.

For example, in ∫2xcos⁡(x2) dx\int 2x\cos(x^2)\,dx, choose u=x2u=x^2 and du=2x dxdu=2x\,dx. The transformed integral is ∫cos⁡(u) du=sin⁡(u)+C\int\cos(u)\,du=\sin(u)+C, giving sin⁡(x2)+C\sin(x^2)+C. With ∫xcos⁡(x2) dx\int x\cos(x^2)\,dx the answer has an extra factor 1/21/2. With ∫cos⁡(x2) dx\int\cos(x^2)\,dx, the required factor xx is absent, so this substitution does not produce the same simplification. Recognizing an inner expression is only half the method; accounting for its derivative is the other half.

A precise definite substitution theorem says that if gg is continuously differentiable on [a,b][a,b] and ff is continuous on an interval containing g([a,b])g([a,b]), then ∫abf(g(x))g′(x) dx=∫g(a)g(b)f(u) du\int_a^b f(g(x))g^{\prime}(x)\,dx=\int_{g(a)}^{g(b)}f(u)\,du. This chain-rule form does not require gg to be one-to-one. A substitution involving an inverse expression, such as x=asin⁡θx=a\sin\theta, does require a suitable branch to recover xx consistently. Once the variable is uu, the bounds must also be uu-values; alternatively, return to xx before using the original bounds.

For ∫02x1+x2 dx\int_0^2\frac{x}{1+x^2}\,dx, u=1+x2u=1+x^2 gives bounds 11 and 55 and the answer 12ln⁡5\frac12\ln 5. Because uu is positive, ln⁡u\ln u is appropriate. In general ∫duu=ln⁡∣u∣+C\int\frac{du}{u}=\ln|u|+C on an interval avoiding zero. Constants of integration may differ on disconnected intervals. In physical models, a logarithm's argument should be dimensionless: ln⁡∣u/u0∣\ln|u/u_0| uses a nonzero reference scale u0u_0, whose contribution is absorbed into the constant.

Substitution is a change of variable, not a pattern match on visual similarity. For ∫(3x+2)5 dx\int(3x+2)^5\,dx, choose u=3x+2u=3x+2, so du=3 dxdu=3\,dx and dx=du/3dx=du/3. The answer is u6/18+C=(3x+2)6/18+Cu^6/18+C=(3x+2)^6/18+C. Differentiating returns (3x+2)5(3x+2)^5 because the outer power contributes 66 and the inner derivative contributes 33, which cancel the denominator 1818. If the inner derivative is a nonzero constant, it can be supplied by a fixed factor. If it depends on xx in a way not present, more algebra or a different method is needed.

Domains determine which antiderivative family is meant. For ∫2xx2−1 dx\int\frac{2x}{x^2-1}\,dx, u=x2−1u=x^2-1 yields ln⁡∣x2−1∣+C\ln|x^2-1|+C, but the original integrand is undefined at x=±1x=\pm1. The formula is valid separately on (−∞,−1)(-\infty,-1), (−1,1)(-1,1), and (1,∞)(1,\infty); the constants may differ on these disconnected intervals. One cannot use a single endpoint subtraction across a pole just because the written logarithm has finite values at the chosen endpoints. The derivative identity holds only where the denominator is nonzero, and a definite integral crossing a pole requires separate improper limits.

For a definite substitution, transformed bounds can reverse. In ∫01−2xe−x2 dx\int_0^1-2xe^{-x^2}\,dx, setting u=−x2u=-x^2 gives du=−2x dxdu=-2x\,dx and bounds 00 and −1-1. The result is e−1−1e^{-1}-1, which is negative as the original integrand is on (0,1](0,1]. Swapping the new bounds to −1-1 and 00 without changing the sign loses orientation. This rule is the same one developed for oriented integrals: ∫abf(x) dx\int_a^b f(x)\,dx changes sign when aa and bb are exchanged. A useful final check is the sign of the integrand over the original interval.

A substitution can be valid but unhelpful. For ∫x2cos⁡x dx\int x^2\cos x\,dx, u=cos⁡xu=\cos x makes du=−sin⁡x dxdu=-\sin x\,dx, which is absent; u=x2u=x^2 makes du=2x dxdu=2x\,dx, leaving a difficult factor. Integration by parts is more promising because differentiating x2x^2 reduces its degree. Conversely, ∫xcos⁡(x2) dx\int x\cos(x^2)\,dx has the derivative of the inner square and needs only substitution. State what simplifies and what remains after the proposed transformation. This habit prevents writing several lines of formal dudu algebra that merely disguise the original difficulty.

A reverse substitution sometimes begins with a differential factor that is present only after rearranging. In ∫x4+x2 dx\int\frac{x}{4+x^2}\,dx, the denominator's derivative is 2x2x, so write the integrand as 12⋅2x4+x2\frac12\cdot\frac{2x}{4+x^2} before setting u=4+x2u=4+x^2. This explicit factor one-half is easy to forget if the substitution is performed mentally. The result 12ln⁡(4+x2)+C\frac12\ln(4+x^2)+C differentiates back to x/(4+x2)x/(4+x^2). The same idea handles ∫5x+15x2+2x+7 dx\int\frac{5x+1}{5x^2+2x+7}\,dx because the denominator derivative is 10x+210x+2, exactly twice the numerator. A constant mismatch is repairable; an x-dependent mismatch requires another step.

Substitution can be understood as preserving the accumulated value under a change of clock or coordinate. If u=g(x)u=g(x) runs twice as fast as x at one point, then a small dxdx corresponds to du≈g′(x) dxdu\approx g^{\prime}(x)\,dx; the derivative factor adjusts the width of each contribution. This is why transforming only the function height and leaving the width unchanged gives a wrong integral. In a definite calculation, the transformed endpoints record where the new coordinate starts and ends. If gg reverses direction, the signed width reverses too. The formula follows from the chain rule, but this local-width view explains its geometry.

Substitution is also a bookkeeping rule for limits and units. In a definite integral, changing from xx to u=g(x)u=g(x) changes the differential to du=g′(x) dxdu=g^{\prime}(x)\,dx and changes the endpoints from a,ba,b to g(a),g(b)g(a),g(b). If gg reverses direction, the new endpoints appear in reverse order and the sign is already accounted for; adding a separate negative sign would double-count it. A physical check can expose mistakes. If xx is time in seconds and v(x)v(x) is metres per second, then v(x) dxv(x)\,dx is metres; after substitution, the transformed integrand times dudu must still represent metres. When the integrand lacks the full derivative of the inner expression, an adjustment may be required, and some proposed substitutions simply do not simplify the integral. Verify the final antiderivative by differentiating it, or verify a definite answer against a rough geometric or numerical estimate.

Integration by parts reverses a product

The product rule says (uv)′=u′v+uv′(uv)^{\prime}=u^{\prime}v+uv^{\prime}. Integrating and rearranging transfers a derivative from one factor to another: ∫u dv=uv−∫v du\int u\,dv=uv-\int v\,du. For the definite formula, continuously differentiable functions uu and vv on [a,b][a,b] suffice. Here uu and vv are functions, while dudu and dvdv denote their derivative factors with dxdx. The method helps when differentiating uu simplifies it and integrating dvdv is feasible. It can fail strategically even when the algebra is valid: the remaining integral might be harder than the original.

In ∫xex dx\int xe^x\,dx, take u=xu=x and dv=ex dxdv=e^x\,dx. Then du=dxdu=dx and v=exv=e^x, so the answer is xex−ex+Cxe^x-e^x+C. Choosing u=exu=e^x and dv=x dxdv=x\,dx instead creates an integral containing x2exx^2e^x and moves in the wrong direction. A polynomial times an exponential or sine often benefits from repeated parts because repeated differentiation eventually removes the polynomial. The usual preferences for logarithms or inverse trigonometric functions as uu are useful heuristics, not theorems guaranteeing success.

A product can be hidden. For ∫ln⁡(x) dx\int\ln(x)\,dx on x>0x>0, write ln⁡(x)⋅1\ln(x)\cdot1, choose u=ln⁡(x)u=\ln(x), and integrate dv=dxdv=dx. The result is xln⁡(x)−x+Cx\ln(x)-x+C. Some repeated-parts calculations return the starting integral: twice applying parts to ∫excos⁡(x) dx\int e^x\cos(x)\,dx yields a linear equation for that integral. Solving gives ex(sin⁡x+cos⁡x)/2+Ce^x(\sin x+\cos x)/2+C. Check the result with the product rule rather than trusting a remembered sign pattern.

Derive parts for definite integrals before memorizing a sign. From (uv)′=u′v+uv′(uv)^{\prime}=u^{\prime}v+uv^{\prime}, integrate over [a,b][a,b] to get [uv]ab=∫abv du+∫abu dv[uv]_a^b=\int_a^b v\,du+\int_a^b u\,dv. Rearranging gives ∫abu dv=[uv]ab−∫abv du\int_a^b u\,dv=[uv]_a^b-\int_a^b v\,du. The boundary term is part of the answer; omitting it makes a definite calculation wrong even if the remaining integral is correct. This derivation also shows why functions and derivatives must be chosen together: uu and vv are the differentiated and integrated objects, not arbitrary labels on two factors.

For ∫x2ex dx\int x^2e^x\,dx, let u=x2u=x^2 and dv=ex dxdv=e^x\,dx. One application gives x2ex−2∫xex dxx^2e^x-2\int xe^x\,dx. A tabular presentation can save writing, but the underlying justification is still repeated use of the product rule.

A cyclic parts calculation is not a failure. In this indefinite calculation, equalities are understood up to additive constants until the final answer. Let I=∫excos⁡x dxI=\int e^x\cos x\,dx. If instead it reappears with the same coefficient on both sides, recheck signs and choices before claiming a result.

The choice of uu should reduce complexity after differentiation, but “complexity” is contextual. For ∫arctan⁡x dx\int\arctan x\,dx, write arctan⁡x⋅1\arctan x\cdot1, choose u=arctan⁡xu=\arctan x and dv=dxdv=dx. Parts is an identity; strategic success is a separate judgment.

For a definite example, ∫01xex dx\int_0^1xe^x\,dx can be evaluated without first writing an indefinite family. Choose u=xu=x and dv=ex dxdv=e^x\,dx. An integration-by-parts choice need not make the remaining integral elementary even when the first step is valid. For ∫xe−x2 dx\int xe^{-x^2}\,dx, taking u=xu=x and dv=e−x2 dxdv=e^{-x^2}\,dx requires an antiderivative of the Gaussian factor, which is the difficult part. Integration by parts is the product rule integrated

For differentiable uu and vv with integrable derivatives on [a,b][a,b], integration by parts trades one derivative from one factor to the other.

∫abu(x)v′(x) dx=[u(x)v(x)]ab−∫abu′(x)v(x) dx\int_a^b u(x)v^{\prime}(x)\,dx=[u(x)v(x)]_a^b-\int_a^b u^{\prime}(x)v(x)\,dx
Reasoning and proof

The product rule says (uv)′=u′v+uv′(uv)^{\prime}=u^{\prime} v+uv^{\prime}. Integrate both sides over [a,b][a,b]. The fundamental theorem turns the left side into u(b)v(b)−u(a)v(a)u(b)v(b)-u(a)v(a). Move the ∫u′v\int u^{\prime} v term to the other side to obtain the formula. This derivation explains both the boundary term and the minus sign; memorizing a slogan without them invites mistakes.

For ∫01xex dx\int_0^1 x e^x\,dx, choose u=xu=x and v′=exv^{\prime}=e^x. Then u′=1u^{\prime}=1 and v=exv=e^x, giving [xex]01−∫01ex dx=e−(e−1)=1[xe^x]_0^1-\int_0^1e^x\,dx=e-(e-1)=1. Different choices of which factor to differentiate can make the remaining integral harder, so the method includes a judgment about simplification.

If a boundary is infinite or the integrand has a singularity, first work on a finite nonsingular interval and then pass to the appropriate improper limits. A formal boundary term may fail to converge even when cancellations occur in a different sense. The finite-interval theorem is the safe starting point.

Trigonometric identities and substitutions

Trigonometric integrals often become substitutions after an identity exposes a derivative factor. In ∫sin⁡3(x)cos⁡2(x) dx\int\sin^3(x)\cos^2(x)\,dx, save one sin⁡(x)\sin(x) and replace sin⁡2(x)\sin^2(x) by 1−cos⁡2(x)1-\cos^2(x). With u=cos⁡(x)u=\cos(x), du=−sin⁡(x) dxdu=-\sin(x)\,dx, the integral becomes −∫(1−u2)u2 du=−u3/3+u5/5+C-\int(1-u^2)u^2\,du=-u^3/3+u^5/5+C. An odd sine or cosine power suggests this strategy. When both powers are even, the half-angle identities sin⁡2(x)=(1−cos⁡(2x))/2\sin^2(x)=(1-\cos(2x))/2 and cos⁡2(x)=(1+cos⁡(2x))/2\cos^2(x)=(1+\cos(2x))/2 lower the powers instead.

For products of tangent and secant, the derivative pairs are different: (tan⁡x)′=sec⁡2x(\tan x)^{\prime}=\sec^2x and (sec⁡x)′=sec⁡xtan⁡x(\sec x)^{\prime}=\sec x\tan x. For instance, ∫tan⁡3(x)sec⁡2(x) dx\int\tan^3(x)\sec^2(x)\,dx becomes ∫u3 du\int u^3\,du with u=tan⁡(x)u=\tan(x). The answer tan⁡4(x)/4+C\tan^4(x)/4+C is valid separately between poles of tangent. Such domain restrictions are part of the answer, even when a symbolic manipulation looks identical on every branch. All trigonometric derivative formulas here use angles measured in radians.

Trigonometric substitution works in the opposite direction, replacing an algebraic radical by a trigonometric identity. For a>0a>0, x=asin⁡θx=a\sin\theta, with −π/2<θ<π/2-\pi/2<\theta<\pi/2, turns a2−x2\sqrt{a^2-x^2} into acos⁡θa\cos\theta for ∣x∣<a|x|<a. The even-power identity comes from cos⁡(2x)=1−2sin⁡2x=2cos⁡2x−1\cos(2x)=1-2\sin^2x=2\cos^2x-1. Solving gives sin⁡2x=(1−cos⁡2x)/2\sin^2x=(1-\cos2x)/2 and cos⁡2x=(1+cos⁡2x)/2\cos^2x=(1+\cos2x)/2. For radicals, the interval and branch deserve explicit attention. If x=asin⁡θx=a\sin\theta with −π/2<θ<π/2-\pi/2<\theta<\pi/2 and a>0a>0, then cos⁡θ>0\cos\theta>0 and a2−x2=acos⁡θ\sqrt{a^2-x^2}=a\cos\theta. The transformed integral may simplify to an ordinary θ\theta-integral on an open interval, but an original definite integral with a reciprocal-radical singularity at an endpoint must still be interpreted as an improper limit. An integral of the continuous radical itself is proper. Cancellation of factors inside an open interval does not grant continuity at a removed endpoint.

Trigonometric substitution should end with an expression in the original variable and a domain statement. Rational functions and completing the square

A rational integrand P(x)/Q(x)P(x)/Q(x) can be decomposed into simpler rational pieces. First use polynomial division if the numerator's degree is at least the denominator's. Next factor the denominator over the real numbers. A simple linear factor x−rx-r contributes A/(x−r)A/(x-r). A repeated factor (x−r)m(x-r)^m requires terms for every power from 11 through mm. An irreducible quadratic contributes a linear numerator, (Bx+C)/(quadratic)(Bx+C)/(\text{quadratic}); repeated quadratics likewise require all powers. Multiply through by the denominator and equate polynomial coefficients to determine the constants.

For 1/((x−1)(x+2))1/((x-1)(x+2)), write A/(x−1)+B/(x+2)A/(x-1)+B/(x+2). Multiplying gives 1=A(x+2)+B(x−1)1=A(x+2)+B(x-1). Setting x=1x=1 and x=−2x=-2 yields A=1/3A=1/3 and B=−1/3B=-1/3. These substitutions are made in a polynomial identity, not in the original undefined fractions. Integrating gives 13ln⁡∣x−1∣−13ln⁡∣x+2∣+C\frac13\ln|x-1|-\frac13\ln|x+2|+C on any interval excluding −2-2 and 11. A definite integral crossing a pole cannot be evaluated by blindly subtracting endpoint values of this expression.

Completing the square treats quadratic denominators that do not factor over the reals. A decision guide, and knowing when to stop

Begin an integration decision guide with the domain and purpose: are we finding an antiderivative on an interval or a definite accumulation? Simplify algebra first, then look for an inner function with its derivative. For a product whose factor simplifies under differentiation, try parts. For powers of trigonometric functions, try identities. For radicals of quadratic expressions, complete the square and consider a branch-controlled trigonometric substitution. For rational functions, divide and decompose. Each choice should name the structural feature it exploits; simply writing 'use substitution' does not explain why that substitution helps.

Several methods can succeed, and several may need to cooperate. The goal is a simpler remaining integral, not loyalty to a technique. After finding a candidate FF, differentiate it and compare with the original integrand on the stated domain. If the problem is definite, evaluate the endpoints only after checking continuity or addressing improper limits. The units of FF differ from those of ff by the units of xx: integrating a rate in litres per minute over minutes produces litres. A lost scale factor can therefore be a mathematical and dimensional mistake.

Not every elementary integrand has an elementary antiderivative. A central example is e−x2e^{-x^2}: its antiderivative cannot be expressed using a finite combination of the usual algebraic, exponential, logarithmic and trigonometric functions and their inverses. Establishing that impossibility requires theory beyond this chapter; failure of our favorite methods is not its proof. Nevertheless A(x)=∫0xe−t2 dtA(x)=\int_0^x e^{-t^2}\,dt is a perfectly valid differentiable function, with A′(x)=e−x2A^{\prime}(x)=e^{-x^2} by the FTC. Exact definitions, numerical integration and later power-series approximations remain available.

The lab checks derivatives with a central difference. Its residual is an approximation to F′(x)−f(x)F^{\prime}(x)-f(x), not a symbolic identity. A wrong coefficient produces a systematic discrepancy; a missing additive constant produces none because every constant has derivative zero. A finite sample can also miss a local error, while an extremely small difference step can increase rounding error. Numerical checks are useful for finding mistakes, but proof still comes from differentiation and domain analysis.

Compare three integrands on [0,1][0,1] before looking at their algebra. For x2/(1+x2)x^2/(1+x^2), u=1+x2u=1+x^2 leaves an unmatched factor xx; divide to get 1−1/(1+x2)1-1/(1+x^2). For x/(1+x2)x/(1+x^2), du=2x dxdu=2x\,dx supplies exactly the needed differential, so substitution works directly. For xln⁡(1+x2)x\ln(1+x^2), the same substitution leaves 12∫ln⁡u du\frac12\int\ln u\,du, which then needs parts. Lesson 6 works all three values. The decision turns on the full numerator and differential, not the shared denominator.

A definite integral may be easy even when the antiderivative is not. If a>0a>0 and ff is odd and integrable on [−a,a][-a,a], symmetry gives ∫−aaf(x) dx=0\int_{-a}^a f(x)\,dx=0 without finding a primitive. If ff is even, the integral is twice ∫0af(x) dx\int_0^a f(x)\,dx. Comparison can supply bounds, and a convergent series can supply an approximation. These routes are legitimate calculations. The purpose of integration is to answer an accumulation question, not to force every integrand into a catalog of elementary formulas.

Verification has several levels. Differentiating a proposed FF and obtaining ff proves the local antiderivative identity on a connected domain. Checking F(b)−F(a)F(b)-F(a) against rough area or rate bounds detects sign and size errors in a definite result. Numerical sampling of F′−fF^{\prime}-f may reveal mistakes but cannot prove equality at unsampled inputs. Unit analysis can expose lost scale factors in applied models. Use all four when they are available; each catches a different class of error, and none excuses ignoring a singularity within the interval.

A sound stopping decision is also a method choice. For e−x2e^{-x^2} on a finite interval, define its accumulation by the integral, use the FTC to describe its derivative, and use a numerical rule with a justified error bound if a number is needed. The assertion that no elementary primitive exists is a later-theory result, not something failed substitutions prove. An odd integrand on a symmetric interval can instead be integrated by symmetry without finding any primitive.

A decision guide should also recognize when no integration is needed. If a definite integrand is odd on a symmetric interval, its signed contributions cancel; if it is nonnegative and bounded, comparison yields a quick magnitude check. If the question asks for a derivative of an accumulation function, the fundamental theorem may answer it without evaluating the integral. If a model asks for total distance, absolute value and sign intervals matter before any technique. Choosing the operation that matches the question avoids solving a harder symbolic problem than necessary. This is especially important when an expression has no elementary primitive but its requested property is simple.

When a primitive contains a logarithm, check its argument and interval. The derivative of ln⁡∣g(x)∣\ln|g(x)| is g′(x)/g(x)g^{\prime}(x)/g(x) wherever gg is nonzero; the absolute value handles negative values on a branch, but it does not bridge a zero of gg. A logarithm of a positive quadratic needs no absolute-value sign, while ln⁡x\ln x assumes x>0x>0. If a definite integral runs through a zero of gg in the denominator, neither version grants permission to cross it. This domain check should be recorded alongside the technique, rather than appended only after a contradictory endpoint calculation appears.

Substitution reverses the chain rule. If F′=fF^{\prime}=f and u=g(x)u=g(x) is differentiable, then ddxF(g(x))=f(g(x))g′(x)\frac{d}{dx}F(g(x))=f(g(x))g^{\prime}(x). Integration by parts reverses the product rule: ∫u dv=uv−∫v du\int u\,dv=uv-\int v\,du. It is useful when one factor becomes simpler after differentiation and the other has an accessible antiderivative. The choice of uu and dvdv is a strategy, not a theorem; a poor choice may make the remaining integral harder. Different valid antiderivatives can differ by a constant on a connected interval, so derivative checking is a clean way to verify a proposed result.

An antiderivative need not be expressible with the elementary functions in a course’s toolkit.
