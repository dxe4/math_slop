1. Sets describe the inputs we allow

This single-variable Calculus book is an L1–L2 route. Chapters 1–3 are optional preparation: use them to repair functions, algebra, trigonometry or laboratory notation, or begin with Chapter 4 if those tools are familiar. The main route reads chapters 04–18, then the differential-equation previews in chapters 27–28. Chapters 19–26 and 29–30 form the separate Multivariable and Vector Calculus book.

Calculus studies changing quantities, but before asking how a quantity changes we must say what values it may take. A set is a collection of objects. We write x∈Ax\in A when xx belongs to the set AA, and x∉Ax\notin A when it does not. The real numbers, written R\mathbb{R}, include integers, fractions, and irrational numbers such as 2\sqrt{2}. Unless a problem says otherwise, the functions in this chapter take real inputs and give real outputs. This convention matters: a square root of a negative number is not a real output.

Intervals describe uninterrupted portions of the real line. The interval [a,b][a,b] includes both endpoints and means a≤x≤ba\le x\le b. The interval (a,b)(a,b) excludes both and means a<x<ba<x<b. Mixed brackets, such as [a,b)[a,b), include only the endpoint next to the square bracket. Infinity is a direction of unbounded extent, not a real endpoint: write [2,∞)[2,\infty), never [2,∞][2,\infty]. The empty set, ∅\varnothing, contains no values. A single allowed value is a set too: {2}\{2\} is not the same as an interval of positive length.

Two operations combine restrictions. The intersection A∩BA\cap B contains values in both sets; the union A∪BA\cup B contains values in at least one. Thus x≥1x\ge1 and x<4x<4 gives [1,4)[1,4), while x<0x<0 or x>2x>2 gives (−∞,0)∪(2,∞)(-\infty,0)\cup(2,\infty). The word 'or' here is inclusive: membership in both sets is permitted. Set-builder notation {x∈R:x2<4}\{x\in\mathbb R:x^2<4\} means the set of real xx satisfying the condition after the colon; in this case it is (−2,2)(-2,2). With equality allowed, {x∈R:x2≤9}=[−3,3]\{x\in\mathbb R:x^2\le9\}=[-3,3]; the strict version gives (−3,3)(-3,3). A denominator restriction must still remove its zeros after the inequality is solved.

Inequalities obey familiar algebra except that multiplying or dividing by a negative number reverses the direction. From −2x<6-2x<6 we obtain x>−3x>-3. Dividing by an expression of unknown sign requires cases, and dividing by zero is forbidden. For instance, solving 1x>0\frac1x>0 by multiplying indiscriminately by xx loses precisely the sign information the question asks for. Split into x>0x>0 and x<0x<0, or use the sign of a reciprocal directly.

Empty intersections are possible. The conditions x<1x<1 and x≥2x\ge2 have no common solution, written ∅\varnothing. By contrast, x<1x<1 or x≥2x\ge2 gives two unbounded pieces. An interval drawing can show this difference immediately, but a drawing should also label open and closed endpoints. A hollow dot means an excluded boundary, while a filled dot means included. The symbols << and ≤\le, not the visual thickness of a plotted line, determine inclusion.

When solving a product inequality, a sign chart separates intervals at zeros and undefined points. For x−1x+2>0\frac{x-1}{x+2}>0, the critical values are −2-2 and 11. The quotient is positive on (−∞,−2)(-\infty,-2) and (1,∞)(1,\infty), negative between them. The point −2-2 is undefined and 11 gives zero, so neither belongs to the strict solution. Testing one point in each interval is safer than multiplying both sides by x+2x+2 without knowing its sign.

Finite unions of intervals describe many one-variable domains, but not every set is an interval. The natural domain of 1x2−1\frac{1}{x^2-1} is R\mathbb R without −1-1 and 11: (−∞,−1)∪(−1,1)∪(1,∞)(-\infty,-1)\cup(-1,1)\cup(1,\infty). Each component is a maximal connected piece of the domain. Later continuity and derivative arguments often work on one such piece at a time. A statement about “all xx” must include only the xx values where its expressions exist.

A mathematical model may impose stricter limits than an algebraic expression. If xx is a time since launch, x≥0x\ge0 even when a polynomial formula accepts negative numbers. If a sensor is calibrated only for 1≤v≤31\le v\le3 volts, predictions outside that range are extrapolations. Distinguish a formula's natural real domain, a problem's stipulated domain, and a model's trusted physical range. The first is determined by operations; the others come from the context or the author.

It is useful to distinguish a condition from the set it defines. The inequality x2<9x^2<9 is a sentence whose truth depends on xx; the set (−3,3)(-3,3) collects exactly the real xx values that make it true. Equivalent inequalities define the same set only under a stated universe. For example x2<9x^2<9 and −3<x<3-3<x<3 agree over real numbers, while interpreting xx as a whole-number count changes the solution set to finitely many integers. The universe of discourse also controls whether a square root is real or complex. This book uses real calculus unless a chapter explicitly says otherwise.

2. Absolute value measures distance

The absolute value ∣x∣|x| is the distance of xx from zero: it equals xx when x≥0x\ge 0 and −x-x when x<0x<0. The second expression is positive because xx itself is negative. More generally, ∣x−c∣|x-c| is the distance between xx and cc. This geometric meaning turns a symbolic restriction into a location on the number line. For r>0r>0, ∣x−c∣<r|x-c|<r describes points strictly within distance rr of cc, giving c−r<x<c+rc-r<x<c+r.

For example, ∣x−3∣≤0.2|x-3|\le0.2 gives [2.8,3.2][2.8,3.2], including the endpoints. If xx measures a length in metres, cc and rr must also be in metres, and the statement means the length differs from 3 metres by at most 0.2 metres. In a mathematical example without specified physical quantities, we treat the numbers as dimensionless. An equation that adds a distance to a temperature has no consistent physical interpretation merely because its algebra looks valid.

An outside-distance condition uses a union: ∣x−c∣≥r|x-c|\ge r, with r>0r>0, means x≤c−rx\le c-r or x≥c+rx\ge c+r. Endpoint cases need attention. The condition ∣x−c∣<0|x-c|<0 has no solutions; ∣x−c∣≤0|x-c|\le0 has exactly x=cx=c. These are small examples of a habit needed throughout calculus: check whether a parameter can be zero and whether a boundary is included before applying a remembered rule.

Absolute value obeys the triangle inequality ∣a+b∣≤∣a∣+∣b∣|a+b|\le|a|+|b|. Geometrically, traveling from zero to aa and then by bb cannot produce a final distance larger than the total distance traveled. A useful consequence is ∣∣a∣−∣b∣∣≤∣a−b∣\bigl||a|-|b|\bigr|\le|a-b|, obtained by applying the triangle inequality twice. These bounds appear throughout calculus: they let us control a complicated error by simpler pieces. The inequality is about magnitude, so it remains valid regardless of signs. Indeed, write a=(a−b)+ba=(a-b)+b and apply the triangle inequality to obtain ∣a∣−∣b∣≤∣a−b∣|a|-|b|\le|a-b|. Interchanging aa and bb gives ∣b∣−∣a∣≤∣a−b∣|b|-|a|\le|a-b|. Together these inequalities give the stated absolute difference.

To solve ∣2x−6∣<4|2x-6|<4, first factor 2∣x−3∣<42|x-3|<4, giving ∣x−3∣<2|x-3|<2. The distance from xx to 33 is less than 22, so 1<x<51<x<5. Equivalently, −4<2x−6<4-4<2x-6<4 leads to the same interval. Both endpoints are excluded because the original inequality is strict. A common error is to solve only 2x−6<42x-6<4 and omit the lower side of the distance condition.

An error tolerance can be written as an absolute-value inequality. If an approximation aa to a target LL has absolute error at most ε\varepsilon, then ∣a−L∣≤ε|a-L|\le\varepsilon. This says aa lies in [L−ε,L+ε][L-\varepsilon,L+\varepsilon]. Relative error divides by ∣L∣|L| when L≠0L\ne0, so it answers a different question and is undefined at a zero target. Later numerical chapters use both notions; the distance interpretation here keeps the distinction clear.

The inequality ∣x−c∣<r|x-c|<r describes an open neighborhood of cc when r>0r>0. A punctured neighborhood adds x≠cx\ne c; limits concern nearby points without requiring the function to be defined at the center. Continuity will add the value at the center back into the comparison. These definitions grow naturally from the number-line geometry rather than from a mysterious epsilon–delta notation. The radius rr is a bound on input distance, not on output error unless a function relates them.

For a compound expression, isolate the entire quantity inside the bars before splitting cases. The equation ∣x2−1∣=3|x^2-1|=3 becomes x2−1=3x^2-1=3 or x2−1=−3x^2-1=-3. The first gives x=±2x=\pm2; the second gives x2=−2x^2=-2 and no real solutions. Replacing ∣x2−1∣|x^2-1| by x2−1x^2-1 without a sign check would miss the logic. When the inner expression changes sign across the domain, a piecewise representation can also be useful for graphing and integration.

3. A function includes its domain

A function assigns exactly one output to each allowed input. Writing f:D→Cf:D\to C specifies the domain DD and a target set, or codomain, CC. The range is the set of outputs actually attained, {f(x):x∈D}\{f(x):x\in D\}; it may be smaller than CC. The formula is only one part of the description. The functions x↦x2x\mapsto x^2 on R\mathbb{R} and x↦x2x\mapsto x^2 on [0,1][0,1] use the same rule but have different domains and ranges. Their ranges are [0,∞)[0,\infty) and [0,1][0,1], respectively.

When given a real formula without an explicit domain, we usually seek its natural real domain: every input for which all its operations are defined. A denominator must be nonzero, and the quantity inside a real square root must be nonnegative. Restrictions apply together, so we take their intersection. For x+2x−1\frac{\sqrt{x+2}}{x-1}, the root requires x≥−2x\ge-2 and the denominator excludes 11. The domain is [−2,1)∪(1,∞)[-2,1)\cup(1,\infty). Cancellation later in a calculation never retroactively supplies a missing input.

Range questions ask which outputs can actually occur, not merely which outputs seem plausible. For f(x)=x2f(x)=x^2 on R\mathbb R, every output is nonnegative, and every y≥0y\ge0 is attained by x=yx=\sqrt y. Both parts are needed to establish that the range is [0,∞)[0,\infty). A plot can suggest the answer, but its viewing window cannot establish unboundedness. Conversely, an input restriction can remove an output even when the formula remains perfectly well behaved nearby. Restricting the same rule to [1,3][1,3] changes its range to [1,9][1,9]: the domain endpoints are attained, and no input in this interval has a smaller or larger square.

The graph of ff is the set of ordered pairs (x,f(x))(x,f(x)) for xx in its domain. A vertical line can meet it at most once, because one input cannot have two outputs. A circle fails this test, although its upper and lower halves can separately define functions on suitable domains. A physical model may restrict the domain further than algebra does: a formula for a tank's volume after tt seconds may only apply until the tank fills. Always separate mathematical admissibility from the interval where the model describes the situation.

Two functions are equal only when they have the same domain and agree at every input in it, under the usual set-of-ordered-pairs view. The formulas x2−1x−1\frac{x^2-1}{x-1} and x+1x+1 agree for x≠1x\ne1, but the first is undefined at 1 while the second is defined there. They are not the same function on their natural domains. One may extend the first by assigning the missing value 2, producing a new function. This distinction becomes central when limits and removable discontinuities are introduced.

The domain of 5−xx+1\frac{\sqrt{5-x}}{x+1} is determined by two simultaneous conditions: 5−x≥05-x\ge0 and x+1≠0x+1\ne0. Thus x≤5x\le5 but x≠−1x\ne-1, giving (−∞,−1)∪(−1,5](-\infty,-1)\cup(-1,5]. The square-root boundary at x=5x=5 is included; the denominator zero at x=−1x=-1 is excluded. A correct answer should state both conditions before combining them, so a reader can inspect why each endpoint has its status.

A function can be represented by a formula, graph, table, piecewise rule, or verbal procedure. Each representation should assign at most one output to each allowed input. A vertical line test checks that property for a graph, but it cannot determine units, measurement uncertainty, or whether a plotted endpoint is included unless those are labeled. An isolated data table gives only sampled outputs, not necessarily a rule for values between them. State what the representation actually specifies.

The codomain matters when discussing surjectivity and inverses. The rule f:R→Rf:\mathbb R\to\mathbb R, f(x)=x2f(x)=x^2, is not onto its stated codomain because negative real numbers are never outputs. The same rule f:R→[0,∞)f:\mathbb R\to[0,\infty) is onto, though still not one-to-one. In elementary range problems, the range is the actual output set regardless of codomain. Keeping these words separate avoids describing a function as invertible just because its output values are known.

A piecewise function must assign one value at every included boundary point. Define f(x)=x2f(x)=x^2 for x<0x<0 and f(x)=x+1f(x)=x+1 for x≥0x\ge0. The value at zero comes from the second rule, so f(0)=1f(0)=1. If both branches included zero and gave different values, the description would not define a function. If neither included zero, the function would have a gap in its domain. Later continuity tests compare the branch limits with the actual boundary value, so this bookkeeping is not merely notation.

When does an inverse function exist?

A function f:D→Cf:D\to C has an inverse function from its range back to DD exactly when it is one-to-one on DD.

f−1:f(D)→D exists⟺f is injective on Df^{-1}:f(D)\to D\text{ exists}\quad\Longleftrightarrow\quad f\text{ is injective on }D
Reasoning and proof

Suppose an inverse gg exists and two inputs satisfy f(x1)=f(x2)f(x_1)=f(x_2). Apply gg to both sides. Because g(f(x))=xg(f(x))=x for each input in DD, we obtain x1=x2x_1=x_2. Thus an inverse forces injectivity: two distinct inputs cannot share an output. A graph that fails the horizontal-line test displays exactly this obstruction, but the equation gives the proof.

Conversely, if ff is injective, every value yy in the range f(D)f(D) has at least one preimage by the definition of range and at most one by injectivity. Define g(y)g(y) to be that unique preimage. Then g(f(x))=xg(f(x))=x for x∈Dx\in D and f(g(y))=yf(g(y))=y for y∈f(D)y\in f(D). This constructs an inverse on the range without assuming that the original codomain contains no unused values.

For f(x)=x2f(x)=x^2 on all real inputs, f(1)=f(−1)f(1)=f(-1) and no inverse exists. Restricting the domain to [0,∞)[0,\infty) makes it injective and gives f−1(y)=yf^{-1}(y)=\sqrt y. A physical model may supply this restriction naturally, but it must be stated. The proof also explains why an inverse branch is a mathematical choice, not an automatic calculator output.

4. Composition and reversing a rule

Composition feeds one function's output into another. The expression (f∘g)(x)(f\circ g)(x) means f(g(x))f(g(x)): evaluate gg first, then ff. Its domain consists of inputs xx in the domain of gg whose outputs g(x)g(x) belong to the domain of ff. Order matters. If f(u)=uf(u)=\sqrt{u} and g(x)=x−2g(x)=x-2, then f(g(x))=x−2f(g(x))=\sqrt{x-2} has domain [2,∞)[2,\infty), whereas g(f(x))=x−2g(f(x))=\sqrt{x}-2 has domain [0,∞)[0,\infty). Their values at x=4x=4 are 2\sqrt{2} and 00.

An inverse reverses the input-output assignment. Such a reversal is a function only when distinct inputs of the original function give distinct outputs: this property is called injectivity or being one-to-one. If ff is one-to-one on DD, its inverse f−1f^{-1} has domain range⁡(f)\operatorname{range}(f) and returns values in DD. If we demand an inverse on the entire stated codomain CC, ff must also attain every element of CC; this additional property is called surjectivity. A function satisfying both properties is bijective.

The rule f(x)=x2f(x)=x^2 on R\mathbb R is not one-to-one because f(2)=f(−2)f(2)=f(-2). Restricting its domain to [0,∞)[0,\infty) gives the inverse f−1(y)=yf^{-1}(y)=\sqrt y for y≥0y\ge0. Restricting instead to (−∞,0](-\infty,0] gives the inverse −y-\sqrt y. The choice of domain decides which reversal is valid. To find an inverse algebraically, write y=f(x)y=f(x), solve for the allowed xx, then specify the new domain and range. Check both compositions: f−1(f(x))=xf^{-1}(f(x))=x on the original domain and f(f−1(y))=yf(f^{-1}(y))=y on the original range.

The superscript −1-1 in f−1f^{-1} names an inverse function; it does not mean the reciprocal 1/f1/f. Graphically, reversing a pair (x,y)(x,y) gives (y,x)(y,x), so inverse graphs reflect across the line y=xy=x when both axes use compatible scales. A horizontal line meeting the original graph more than once exposes the failure of one-to-one behavior.

The domain of f∘gf\circ g requires two checks in sequence: xx must be allowed for gg, and g(x)g(x) must be allowed for ff. Let f(u)=uf(u)=\sqrt u and g(x)=x−2g(x)=x-2. Then (f∘g)(x)=x−2(f\circ g)(x)=\sqrt{x-2} has domain x≥2x\ge2. But (g∘f)(x)=x−2(g\circ f)(x)=\sqrt x-2 has domain x≥0x\ge0. The formulas look similar, yet their allowed inputs and outputs differ. Parentheses and the order of evaluation are part of the mathematical statement.

If f(x)=1xf(x)=\frac1x and g(x)=x2−4g(x)=x^2-4, then f∘g=1x2−4f\circ g=\frac{1}{x^2-4} with x≠±2x\ne\pm2. Conversely g∘f=1x2−4g\circ f=\frac{1}{x^2}-4 with x≠0x\ne0. Neither composition inherits only the domain of the outer function. This is an example where algebraic simplification is easy but domain tracking is the real work. Write the inner output first, then apply every outer restriction to it.

An inverse swaps domain and range. For f(x)=3x−5f(x)=3x-5 on R\mathbb R, solve y=3x−5y=3x-5 for xx to obtain x=y+53x=\frac{y+5}{3}. The inverse has domain R\mathbb R and range R\mathbb R, and substitution in both directions gives f−1(f(x))=xf^{-1}(f(x))=x and f(f−1(y))=yf(f^{-1}(y))=y. A single algebraic rearrangement is not enough if the original rule is not one-to-one or if the inverse's proposed domain includes unattained outputs.

A strictly increasing function on an interval is one-to-one because larger inputs always produce larger outputs. A strictly decreasing function is also one-to-one. A horizontal line intersects either graph at most once. The condition is sufficient, not necessary on arbitrary disconnected domains; however it is a practical test for many continuous elementary functions. A turning point often prevents a global inverse, prompting a domain restriction to one monotone branch.

Inverse functions undo values, not physical dimensions. If F(s)=s2F(s)=s^2 maps nonnegative side lengths in metres to areas in square metres, then F−1(B)=BF^{-1}(B)=\sqrt B returns a length in metres for any attainable area B≥0B\ge0. The inverse domain is the nonnegative areas. Writing “±B\pm\sqrt B” would describe solutions of the equation s2=Bs^2=B on all real ss, not the inverse of the physical function whose domain is s≥0s\ge0. Model restrictions and mathematical injectivity support the same branch choice.

5. Transformations and mathematical claims

Consider G(x)=af(b(x−h))+kG(x)=a f(b(x-h))+k with b≠0b\ne0. If (u,v)(u,v) belongs to the graph of ff, solve b(x−h)=ub(x-h)=u to obtain the corresponding point (h+u/b,k+av)(h+u/b,k+av) of GG. This point rule is more reliable than memorizing a list of shifts. The parameter hh moves the reference point horizontally and kk moves it vertically. A factor ∣a∣|a| scales vertical distances, with a negative aa reflecting them. A factor ∣b∣|b| divides horizontal distances, with a negative bb reversing horizontal orientation. Conversely, for every allowed transformed input xx, put u=b(x−h)u=b(x-h). The original point (u,f(u))(u,f(u)) maps to (x,G(x))(x,G(x)), so the point rule accounts for the entire transformed graph. This also works when a=0a=0; only b≠0b\ne0 is needed.

The transformed domain is every xx with b(x−h)b(x-h) in the original domain. When bb is negative, an interval's endpoint order reverses, along with the locations of its included and excluded ends. When a=0a=0, the output is the constant kk wherever the original composition is defined; the formula still requires that inner evaluation. The point rule cannot divide by bb when b=0b=0. In that separate case, GG is constant on all real inputs if f(0)f(0) exists, and the composition is undefined everywhere if it does not.

Mathematical statements also have domains. 'For every real xx, x2≥0x^2\ge0' is a universal claim. A proof must cover every allowed input, which here follows from the sign rules for multiplication. 'There exists a real xx with x2=4x^2=4' is an existence claim; giving x=2x=2 proves it. To disprove a universal claim, one valid counterexample suffices. The claim 'every real xx satisfies x2=x\sqrt{x^2}=x' fails at x=−2x=-2. The correct identity is x2=∣x∣\sqrt{x^2}=|x|.

An implication says that whenever a hypothesis holds, a conclusion follows. Its converse swaps these roles and needs separate justification: x=2x=2 implies x2=4x^2=4, but x2=4x^2=4 does not imply x=2x=2. A double arrow ⇔\Leftrightarrow asserts both directions. Checking a thousand sample values can disprove a claim if one fails, but cannot ordinarily prove a statement about all real inputs. Our lab is therefore an experiment to interpret an already-derived point rule, not a substitute for its algebraic justification.

The point mapping (u,v)↦(h+ub,k+av)(u,v)\mapsto(h+\frac ub,k+av) handles horizontal and vertical transformations together. If b<0b<0, the horizontal coordinate reverses orientation: a point originally to the right of u=0u=0 may appear to the left of x=hx=h. If a<0a<0, the output reflects across the horizontal line y=ky=k after scaling. This point rule avoids the common slogan error that f(2x)f(2x) stretches a graph horizontally; it compresses horizontal distances by a factor of two.

For f(x)=xf(x)=\sqrt x with domain [0,∞)[0,\infty), the transformed rule G(x)=f(−2(x−1))G(x)=f(-2(x-1)) has domain −2(x−1)≥0-2(x-1)\ge0, hence x≤1x\le1. The negative inner factor reflects and scales the input, while shifting the endpoint to x=1x=1. The graph starts at (1,0)(1,0) and extends left. Checking the transformed domain before drawing prevents a square-root curve from being sketched on the wrong side of its endpoint.

A universal claim is disproved by one counterexample in its stated domain. The assertion f(x+1)=f(x)+1f(x+1)=f(x)+1 for every real-valued ff on R\mathbb R fails for f(x)=x2f(x)=x^2 at x=0x=0: the two sides are 1 and 1, so that input does not disprove it, but at x=1x=1 they are 4 and 2. One must choose a counterexample that actually violates the equation. The identity does hold for f(x)=x+Cf(x)=x+C for any constant CC; an existence example does not rescue the universal claim.

A proof of an implication begins with its hypothesis. To prove x>2x>2 implies x2>4x^2>4 over real xx, the hypothesis guarantees xx positive, so multiplying x>2x>2 by positive xx and comparing is safe. The converse x2>4x^2>4 implies x>2x>2 is false because x=−3x=-3 also has square nine. Domain conditions can change truth: if x≥0x\ge0 is assumed, then x2>4x^2>4 does imply x>2x>2. Words such as “for all,” “there exists,” and “if” govern the logic as much as the algebra does.

A numerical plot can support a conjecture but cannot prove a universal transformation or inequality. It samples finitely many inputs and may hide excluded endpoints or narrow features. The point mapping proves the transformation for every original graph point, while an algebraic counterexample disproves a false claim at one exact value. Learning to move between visualization and proof is part of calculus preparation: graphics guide questions, and quantified arguments settle them.

A quantified statement can be strengthened or weakened by changing the domain. “For every real xx, 1x\frac1x is defined” is false because zero is an allowed counterexample. “For every nonzero real xx, x⋅1x=1x\cdot\frac1x=1” is true. The second claim carries its necessary hypothesis explicitly. When a proof divides by an expression, it should first establish that expression is nonzero on the case being considered; otherwise the derivation may silently discard solutions. This habit will recur in solving equations, proving limits, and separating differential equations. Explicit assumptions make a mathematical argument reusable and show exactly where it stops applying. This precision matters when a model has excluded inputs.

Restricting a domain to make an inverse function

Deeper derivation · Domains are part of the function, not small print

A real-valued function is specified by a domain as well as a rule. The expression 1x−2\frac{1}{x-2} defines a function only on a set that excludes 2. Multiplying that expression by x−2x-2 produces 1 at every permitted input, but does not assign the original function a value at 2. Two formulas can agree on all inputs in one domain and still define different functions when their domains differ. This distinction becomes decisive when we discuss holes and continuity.

Composition makes domain restrictions propagate. For f(u)=uf(u)=\sqrt{u} and g(x)=3−x2g(x)=3-x^2, the composition (f∘g)(x)=3−x2(f\circ g)(x)=\sqrt{3-x^2}. Its real domain is determined by 3−x2≥03-x^2\ge0, so −3≤x≤3-\sqrt{3}\le x\le\sqrt{3}. It is not enough that gg itself accepts every real input: its output must land in the domain of ff. For the reverse composition g∘fg\circ f, the rule is (g∘f)(x)=3−x(g\circ f)(x)=3-x and the domain is x≥0x\ge0. The same pair of functions can yield different formulas and different domains when their order is reversed.

An inverse requires one-to-one behavior on its chosen domain. Squaring is not invertible on all real numbers because 2 and −2 both map to 4. Restrict x2x^2 to [0,∞)[0,\infty) and its inverse is x\sqrt{x}; restrict it to (−∞,0](-\infty,0] and its inverse is −x-\sqrt{x}. Whenever a solution says “take the square root,” check whether it silently chose a branch. A graph, algebraic rule, domain and range should tell the same story.

Chapter synthesis

  • Domain restrictions belong to the function and persist through algebraic simplification.
  • Composition requires each intermediate output to be an allowed next input; an inverse requires one-to-one behavior.
  • Point mappings explain transformations, while explicit hypotheses and counterexamples keep claims precise.

Common mistakes to check
