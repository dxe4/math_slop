1. Turning an integral into a function

A definite integral over a fixed interval is a number. An accumulation function lets its upper endpoint move: A(x)=∫axf(t) dtA(x)=\int_a^x f(t)\,dt. The letter tt is a temporary integration variable; after integration the result depends on xx. The lower endpoint aa is fixed, and A(a)=0A(a)=0. Changing the lower endpoint changes the baseline from which accumulation is measured, rather than the underlying rate. This simple change of viewpoint connects the integral of Chapter 10 with the derivative of Chapter 5.

For example, if f(t)=2tf(t)=2t, then A(x)=x2−a2A(x)=x^2-a^2. You can obtain this result geometrically when 0≤a≤x0\le a\le x by subtracting two triangular areas. Differentiating gives A′(x)=2x=f(x)A^{\prime}(x)=2x=f(x). The accumulated quantity need not equal the original rate: x2−a2x^2-a^2 and 2x2x have different shapes and, in applications, different units. It is the slope of the accumulation graph that agrees with the rate graph.

Orientation matters when x<ax<a. By definition ∫axf(t) dt=−∫xaf(t) dt\int_a^x f(t)\,dt=-\int_x^a f(t)\,dt. Thus a positive rate can give negative accumulation relative to a later baseline. Conversely, when xx increases through an interval where ff is negative, AA decreases. An accumulation function is not automatically increasing, because a signed integral records losses as well as gains. If ff changes from negative to positive at cc, the accumulation function can have a local minimum there even when A(c)≠0A(c)\ne0.

If tt is measured in hours and f(t)f(t) in litres per hour, A(x)A(x) is measured in litres. A tank with initial volume V(a)V(a) has volume V(x)=V(a)+A(x)V(x)=V(a)+A(x), provided the rate describes net inflow and the tank neither empties nor overflows during the modeled interval. The integral supplies a change; a starting value supplies the absolute amount. Separating these two roles prevents a common modeling error.

A moving upper endpoint turns a completed total into a history of totals. For f(t)=t−1f(t)=t-1 and baseline a=0a=0, direct geometry gives A(x)=x2/2−xA(x)=x^2/2-x for 0≤x≤20\le x\le2. AA first decreases because the rate is negative, reaches its minimum −1/2-1/2 at x=1x=1, and then increases; at x=2x=2 the earlier loss has been recovered and A(2)=0A(2)=0. The zero of AA at 22 is not a zero of the rate. Confusing A(x)A(x) with f(x)f(x) would misidentify both the turning point and the accumulated amount. Plot both curves and compare each slope of AA with the corresponding height of ff.

The baseline can be changed without changing the local rate. Let Aa(x)=∫axf(t) dtA_a(x)=\int_a^x f(t)\,dt and Ab(x)=∫bxf(t) dtA_b(x)=\int_b^x f(t)\,dt. Interval additivity gives Ab(x)=Aa(x)−Aa(b)A_b(x)=A_a(x)-A_a(b), so the graphs differ by a vertical constant. Their derivatives are equal wherever ff is continuous. In a tank model, changing the starting time changes the recorded cumulative change; adding the actual initial volume locates the physical amount. If the measured net rate later becomes negative, a formal volume curve may dip below zero. That would signal failure of the unrestricted rate model once the tank empties.

An accumulation function can be understood without an antiderivative formula. Suppose f(t)=exp⁡(−t2)f(t)=\exp(-t^2), whose integral has no elementary expression. The function A(x)=∫0xexp⁡(−t2) dtA(x)=\int_0^x\exp(-t^2)\,dt is still well defined for every real xx, differentiable, and has derivative A′(x)=exp⁡(−x2)A^{\prime}(x)=\exp(-x^2). It is increasing because the rate is positive, and its slope is largest at x=0x=0. Numerical integration can approximate values of AA, but its differentiability follows from continuity of the integrand, not from the existence of a familiar closed form. This distinction prepares us for applications where accumulated quantities are known only through data or computation.

The function AA inherits shape information from ff. Where f>0f>0, AA increases; where f<0f<0, AA decreases. If ff itself is differentiable, then A′′=f′A^{\prime\prime}=f^{\prime}, so a rising rate makes the accumulation graph concave up and a falling rate makes it concave down. These statements hold on intervals where the required derivatives exist. A horizontal tangent of AA at x=cx=c means f(c)=0f(c)=0, but it may be a local extremum or merely a stationary crossing depending on how the sign of ff changes. Reading one graph as the derivative of the other is a central skill, not merely a symbolic identity.

There is a useful inverse relationship between this chapter and the previous one. Chapter 10 constructed a total from many local contributions, while the fundamental theorem says that differentiating the total recovers the local rate at continuity points. Neither operation erases all information in both directions. Differentiation loses the vertical constant in an accumulation function; integration over an interval needs a baseline or two endpoints to recover a number. If two tanks have the same net inflow curve but different initial volumes, their volume graphs have the same slope and differ by a constant. This is the physical meaning of the arbitrary constant in antiderivatives. Always check units and orientation.

2. The first part: the derivative of accumulation

Fundamental theorem, accumulation form: if ff is continuous on the closed interval [a,b][a,b], then A(x)=∫axf(t) dtA(x)=\int_a^x f(t)\,dt is continuous on [a,b][a,b] and differentiable on (a,b)(a,b), with A′(x)=f(x)A^{\prime}(x)=f(x). At aa and bb the corresponding one-sided derivatives equal the endpoint values. Ordinary two-sided derivatives are not asserted at endpoints without an extension beyond the interval. Continuity is a sufficient hypothesis that is easy to check for polynomials, trigonometric functions, and compositions on their domains.

Proof idea, made into an estimate: fix an interior xx. For nonzero hh small enough to remain in the interval, the difference quotient is A(x+h)−A(x)h=1h∫xx+hf(t) dt\frac{A(x+h)-A(x)}{h}=\frac1h\int_x^{x+h}f(t)\,dt. Subtract f(x)f(x) and rewrite the difference as 1h∫xx+h[f(t)−f(x)] dt\frac1h\int_x^{x+h}[f(t)-f(x)]\,dt. Its absolute value is at most the largest value of ∣f(t)−f(x)∣|f(t)-f(x)| between xx and x+hx+h. This estimate works for negative hh too, because reversing the interval and taking absolute values remove both signs. Continuity at xx makes that bound tend to zero. Therefore the difference quotient tends to f(x)f(x).

The argument says that the average value of a continuous rate over a shrinking interval tends to its value at the point. It explains why continuity matters rather than treating it as a decorative condition. Continuity of AA itself follows from boundedness: if ∣f∣≤M|f|\le M on [a,b][a,b], then ∣A(y)−A(x)∣≤M∣y−x∣|A(y)-A(x)|\le M|y-x|. Even a bounded Riemann-integrable ff gives a continuous accumulation function. Differentiability at a particular point is guaranteed by continuity of ff there, not merely by integrability elsewhere.

For a concrete failure, take f(t)=−1f(t)=-1 for t<0t<0 and f(t)=1f(t)=1 for t≥0t\ge0 on [−1,1][-1,1]. Its accumulation from −1-1 is A(x)=−x−1A(x)=-x-1 for x≤0x\le0 and A(x)=x−1A(x)=x-1 for x≥0x\ge0. The graph is continuous but has left slope −1-1 and right slope 11 at zero, so no derivative exists there. Altering only the assigned value f(0)f(0) cannot fix the corner: changing one point does not change a Riemann integral. Numerical agreement at many sampled points would miss this single exceptional point.

The proof estimate can be written uniformly for either sign of hh: ∣A(x+h)−A(x)h−f(x)∣≤sup⁡{∣f(t)−f(x)∣:t lies between x and x+h}\left|\frac{A(x+h)-A(x)}{h}-f(x)\right|\le\sup\{|f(t)-f(x)|:t\text{ lies between }x\text{ and }x+h\}. For h>0h>0 this follows by integrating the pointwise difference over [x,x+h][x,x+h] and dividing by hh. For h<0h<0, reverse the integration limits and divide by ∣h∣|h| after taking absolute values. Continuity at xx makes the supremum tend to zero. This is more than an informal picture of a thin rectangle: it gives a quantitative reason that all sufficiently short strips have average height close to f(x)f(x).

Continuity at the single point xx is enough for the derivative conclusion there, provided ff is Riemann integrable on the surrounding interval. The full statement “ff continuous on [a,b][a,b]” is a convenient global hypothesis that ensures every point works. If ff has an isolated discontinuity at cc, AA can still be differentiable at cc or fail to be. For f(t)=0f(t)=0 except f(0)=9f(0)=9, AA is identically zero and A′(0)=0A^{\prime}(0)=0, unequal to f(0)f(0). For a step from −1-1 to +1+1 at zero, AA has a corner there. The integrand's assigned value at one point cannot control an accumulated derivative by itself.

The bounded-integrand estimate ∣A(y)−A(x)∣≤M∣y−x∣|A(y)-A(x)|\le M|y-x| shows that accumulation is Lipschitz continuous when ∣f∣≤M|f|\le M. It is stronger than ordinary continuity: a bounded rate cannot make the total jump instantaneously. If ff is unbounded, AA may still be continuous under an improper integral, but this estimate no longer applies with a finite MM. In a physical model, an actual jump in stored amount would require an impulse or an instantaneous transfer not represented by an ordinary bounded rate. The mathematical hypothesis thus carries a concrete modeling meaning.

At the endpoints, one-sided difference quotients are appropriate. If ff is continuous on [a,b][a,b], then the right derivative of AA at aa equals f(a)f(a) and the left derivative at bb equals f(b)f(b). Claiming an ordinary two-sided derivative there silently assumes AA and ff have been extended outside the interval. Many textbooks abbreviate the statement as A′=fA^{\prime}=f “on [a,b][a,b]”; read that notation with the endpoint convention in mind. The interval orientation also matters: defining C(x)=∫xbf(t) dtC(x)=\int_x^b f(t)\,dt gives C′(x)=−f(x)C^{\prime}(x)=-f(x), because increasing xx removes a strip from the left.

A precise local version follows from the same estimate even when ff is not continuous everywhere. Suppose ff is bounded and Riemann integrable on [a,b][a,b], and continuous at an interior point cc. Then A(x)=∫axf(t) dtA(x)=\int_a^x f(t)\,dt is differentiable at cc with A′(c)=f(c)A^{\prime}(c)=f(c). Discontinuities elsewhere do not interfere because the difference quotient only integrates over the shrinking interval from cc to c+hc+h. This localization is useful when a piecewise rate has a small number of jumps: the accumulation curve is differentiable on each continuous piece, while its behavior at each jump must be checked separately. The global continuous-function theorem packages these local conclusions into one statement.

The argument also makes the units transparent. Dividing a small accumulated change by the endpoint change returns units of rate: litres divided by hours becomes litres per hour. If the accumulation came from a signed rate, this quotient may be negative. The limit identifies its local value at continuity points, while the finite quotient remains the average rate over the small interval. Keeping these quantities distinct helps explain why the theorem is plausible before applying its symbolic rule.

A useful refinement handles a piecewise continuous rate at a jump cc. If ff approaches finite values LL from the left and RR from the right, the same shrinking-average estimate gives AA's left derivative as LL and its right derivative as RR. Thus AA has an ordinary derivative at cc exactly when these one-sided limits agree; the separately assigned value f(c)f(c) need not equal that derivative. For example, a rate of 22 before noon and 55 after noon produces a continuous total with a corner at noon, regardless of what number the model assigns at the exact instant. This gives a direct graph test without confusing a rate's point value with its nearby behavior.

At zero, ask three questions separately. For fc(t)=t+2f_c(t)=t+2, the rate is continuous, Ac(x)=x2/2+2xA_c(x)=x^2/2+2x, and the accumulation derivative equals fc(0)=2f_c(0)=2. If only fp(0)f_p(0) changes to 99, every oriented integral stays the same: a single changed value contributes zero Riemann area. Thus Ap=AcA_p=A_c and Ap′(0)=2A_p^{\prime}(0)=2, although fpf_p is discontinuous and Ap′(0)≠fp(0)A_p^{\prime}(0)\ne f_p(0).

The actual shrinking averages distinguish these cases from a jump. At x=−hx=-h and x=hx=h, with h>0h>0, both AcA_c and ApA_p have quotients 2−h/22-h/2 and 2+h/22+h/2, so both one-sided limits are 22. If fj(t)=t+2f_j(t)=t+2 to the left and t+4t+4 to the right, with fj(0)=9f_j(0)=9, its quotients are 2−h/22-h/2 and 4+h/24+h/2. Their limits disagree, so Aj′(0)A_j^{\prime}(0) does not exist. Continuity of the rate, derivative existence, and equality to the assigned rate are different decisions; Problem 11.35 asks you to justify all three.

The accumulation theorem needs continuity only at the point

If ff is Riemann integrable on [a,b][a,b] and continuous at an interior point cc, then A(x)=∫axf(t) dtA(x)=\int_a^x f(t)\,dt is differentiable at cc with A′(c)=f(c)A^{\prime}(c)=f(c).

A′(c)=f(c),A(x)=∫axf(t) dtA^{\prime}(c)=f(c),\qquad A(x)=\int_a^x f(t)\,dt
Reasoning and proof

Riemann integrability makes ff bounded, so AA is continuous: if ∣f∣≤M|f|\le M, then ∣A(y)−A(x)∣=∣∫xyf(t) dt∣≤M∣y−x∣|A(y)-A(x)|=\left|\int_x^y f(t)\,dt\right|\le M|y-x|. Now fix cc where ff is continuous. For a nonzero hh small enough that c+hc+h remains in [a,b][a,b], additivity of the integral gives [A(c+h)−A(c)]/h=(1/h)∫cc+hf(t) dt[A(c+h)-A(c)]/h=(1/h)\int_c^{c+h}f(t)\,dt. Subtract f(c)f(c), which is the average of the constant f(c)f(c) over that oriented interval.

Given ε>0\varepsilon>0, continuity at cc supplies δ>0\delta>0 such that ∣f(t)−f(c)∣<ε|f(t)-f(c)|<\varepsilon whenever ∣t−c∣<δ|t-c|<\delta. If 0<∣h∣<δ0<|h|<\delta, every tt between cc and c+hc+h satisfies this estimate. Therefore ∣[A(c+h)−A(c)]/h−f(c)∣≤(1/∣h∣)∫min⁡(c,c+h)max⁡(c,c+h)∣f(t)−f(c)∣ dt<ε\left|[A(c+h)-A(c)]/h-f(c)\right|\le(1/|h|)\int_{\min(c,c+h)}^{\max(c,c+h)}|f(t)-f(c)|\,dt<\varepsilon. For h<0h<0 the reversed orientation and negative denominator cancel; the same bound applies. This proves the two-sided derivative without requiring ff to be continuous at distant points.

At a discontinuity of ff the conclusion may hold or fail, and changing ff at one point never changes AA. For example, if ff is zero except f(c)=9f(c)=9, then AA is identically zero and A′(c)=0A^{\prime}(c)=0, not 99. The theorem gives a sufficient local hypothesis; it does not assert that every discontinuity makes AA nondifferentiable. Distinguishing a sufficient condition from a necessary one is part of using the fundamental theorem precisely.

3. The second part: endpoints replace infinitely many sums

Fundamental theorem, evaluation form: suppose ff is continuous on [a,b][a,b], and FF is continuous on [a,b][a,b] and differentiable on (a,b)(a,b), with F′=fF^{\prime}=f there. Then ∫abf(x) dx=F(b)−F(a)\int_a^b f(x)\,dx=F(b)-F(a). The function FF is called an antiderivative of ff. This theorem is a bridge from the limiting sums that define integration to a calculation involving only two function values. It does not redefine the integral as an antiderivative, and it applies whether or not a convenient formula for FF is available.

Proof sketch using the first part: define A(x)=∫axf(t) dtA(x)=\int_a^x f(t)\,dt. On (a,b)(a,b), the function H=F−AH=F-A has derivative zero. The mean value theorem shows that HH is constant on [a,b][a,b]: between any two points its change equals a derivative value times their separation, hence is zero. Because A(a)=0A(a)=0, that constant is F(a)F(a). Evaluating F(x)=A(x)+F(a)F(x)=A(x)+F(a) at bb gives the result. Notice the role of an interval in the constant argument; it provides the uninterrupted domain needed by the mean value theorem.

All antiderivatives of a continuous ff on an interval therefore have the form F(x)+CF(x)+C. The notation ∫f(x) dx\int f(x)\,dx means this family and is called an indefinite integral. A definite integral instead has endpoints and is a single signed number. In evaluating [F(x)+C]ab[F(x)+C]_a^b, the two constants cancel. An initial condition such as V(0)=12V(0)=12 determines CC when reconstructing a quantity, but no extra arbitrary constant should be attached to the numerical value of a definite integral.

Domains still govern the calculation. For x≠0x\ne0, 1/x1/x has antiderivative ln⁡∣x∣\ln|x| on each interval avoiding zero. We cannot conclude that ∫−111x dx=ln⁡(1)−ln⁡(1)\int_{-1}^{1}\frac{1}{x}\,dx=\ln(1)-\ln(1). The integrand is undefined and unbounded at an interior point, so the present theorem does not apply. Chapter 14 treats improper integrals and explains why a symmetric cancellation is a different question. Always inspect the whole interval before evaluating endpoint expressions.

The evaluation theorem is a consequence of a uniqueness fact: two functions with the same derivative on an interval differ by a constant. Its proof uses the mean value theorem on every closed subinterval. A disconnected domain breaks the single-constant conclusion. The derivative of ln⁡∣x∣\ln|x| is 1/x1/x for x≠0x\ne0, but one may add one constant on (−∞,0)(-\infty,0) and a different constant on (0,∞)(0,\infty). The integral ∫f(x) dx\int f(x)\,dx describes a family on each connected interval of definition. When applying endpoint evaluation, first confirm that one valid antiderivative covers the entire integration interval.

For f(x)=2xf(x)=2x on [1,3][1,3], F(x)=x2F(x)=x^2 is an antiderivative, so ∫132x dx=F(3)−F(1)=9−1=8\int_1^3 2x\,dx=F(3)-F(1)=9-1=8. The result is also the area of a trapezoid with parallel vertical sides of heights 22 and 66 and width 22: (2+6)⋅2/2=8(2+6)\cdot2/2=8. This geometric check is independent of the endpoint algebra. A wrong order F(1)−F(3)F(1)-F(3) would give −8-8 and contradict the nonnegative graph. Sign, units, and rough scale are valuable checks before accepting a symbolic answer.

A definite integral cannot always be evaluated by an elementary-looking primitive. The continuous function exp⁡(−x2)\exp(-x^2) has a perfectly valid integral on [0,1][0,1] and an accumulation antiderivative A(x)=∫0xexp⁡(−t2) dtA(x)=\int_0^x\exp(-t^2)\,dt, but no elementary formula for AA is available. The fundamental theorem still holds: A′(x)=exp⁡(−x2)A^{\prime}(x)=\exp(-x^2) and ∫01exp⁡(−x2) dx=A(1)−A(0)\int_0^1\exp(-x^2)\,dx=A(1)-A(0). Numerical methods can estimate A(1)A(1) with controlled error. The theorem asserts a relationship between derivative and accumulation, not a promise that every answer simplifies to a short symbolic expression.

When an initial condition is present, use it after finding an antiderivative family. If a particle has v(t)=3t2v(t)=3t^2 metres per second with tt in seconds (so the coefficient 33 has units of metres per second cubed) and position s(0)=5s(0)=5 metres, then s(t)=t3+Cs(t)=t^3+C metres, with the coefficient of t3t^3 carrying the corresponding units, and C=5C=5 metres. Its displacement from t=1t=1 to t=2t=2 seconds is s(2)−s(1)=7s(2)-s(1)=7 metres, independent of CC, while its position at t=2t=2 seconds is 1313 metres. The integral of vv over [1,2][1,2] seconds is the displacement 77 metres, not the final position. This separation prevents a frequent confusion between change, accumulated quantity, and absolute state.

Antiderivative evaluation also provides an error check for any proposed primitive. If someone claims ∫abf(x) dx=G(b)−G(a)\int_a^b f(x)\,dx=G(b)-G(a), differentiate GG on the entire interior and verify G′=fG^{\prime}=f. Matching only at endpoints is insufficient: many unrelated functions have the same two endpoint values. Conversely, if ff is continuous and a candidate derivative identity holds everywhere inside, endpoint evaluation is exact regardless of how complicated ff looks. This is particularly helpful after substitution or integration by parts, where a missing chain factor can be exposed immediately by differentiation. The verification belongs to the proposed antiderivative, not to a few numerical sample points.

4. Moving endpoints and the chain rule

An upper limit can itself be a function. If ff is continuous on an interval containing the relevant endpoints and gg is differentiable, write B(x)=∫ag(x)f(t) dt=A(g(x))B(x)=\int_a^{g(x)} f(t)\,dt=A(g(x)). The chain rule gives B′(x)=f(g(x))g′(x)B^{\prime}(x)=f(g(x))g^{\prime}(x). The endpoint moves at speed g′(x)g^{\prime}(x), so it contributes that factor as well as the rate evaluated at its current location. The formula remains valid when g(x)<ag(x)<a because oriented integrals already encode the sign.

When both endpoints move, split the integral at any fixed point cc in the domain: ∫u(x)v(x)f(t) dt=A(v(x))−A(u(x))\int_{u(x)}^{v(x)}f(t)\,dt=A(v(x))-A(u(x)), where A(y)=∫cyf(t) dtA(y)=\int_c^y f(t)\,dt. Differentiating gives f(v(x))v′(x)−f(u(x))u′(x)f(v(x))v^{\prime}(x)-f(u(x))u^{\prime}(x). A moving lower endpoint subtracts accumulation. The endpoints need not remain ordered, and they may coincide. At a crossing the integral is zero, but its derivative can be nonzero because the endpoints may separate at different speeds.

For example, if B(x)=∫xx2cos⁡(t) dtB(x)=\int_x^{x^2}\cos(t)\,dt, then B′(x)=2xcos⁡(x2)−cos⁡(x)B^{\prime}(x)=2x\cos(x^2)-\cos(x). This calculation never required us to find the integral first. The same principle handles an integrand such as exp⁡(−t2)\exp(-t^2), whose antiderivative has no elementary expression. Be careful, however, if xx also occurs inside the integrand: ∫0xxt dt\int_0^x xt\,dt has additional dependence on xx and is not covered by simply replacing tt with xx in the integrand. Here direct calculation gives x3/2x^3/2 and derivative 3x2/23x^2/2.

The upper-limit rule is a composition of two maps. First y↦A(y)=∫ayf(t) dty\mapsto A(y)=\int_a^y f(t)\,dt has derivative A′(y)=f(y)A^{\prime}(y)=f(y). Then x↦g(x)x\mapsto g(x) selects an endpoint y=g(x)y=g(x). The chain rule multiplies by g′(x)g^{\prime}(x). For B(x)=∫0x2(1+t3) dtB(x)=\int_0^{x^2}(1+t^3)\,dt, B′(x)=[1+(x2)3]2x=2x(1+x6)B^{\prime}(x)=[1+(x^2)^3]2x=2x(1+x^6). Omitting 2x2x treats the endpoint as though it moved one unit whenever xx moves one unit, which is generally false. At x=0x=0 the endpoint moves only to second order, so B′(0)=0B^{\prime}(0)=0 even though f(0)=1f(0)=1.

A moving lower endpoint contributes a minus sign. If C(x)=∫x3t2 dtC(x)=\int_x^3 t^2\,dt, then C′(x)=−x2C^{\prime}(x)=-x^2. The integral is positive for 0≤x≤30\le x\le3, yet decreases as xx advances because less area remains. Direct calculation C(x)=9−x3/3C(x)=9-x^3/3 verifies the sign. For two moving endpoints, these effects compete; their order can change without invalidating the formula. A zero-width interval at one input does not imply zero derivative there, just as two runners can meet at a moment while having different velocities.

When xx appears inside the integrand, the boundary-only rule is incomplete. A transparent example is H(x)=∫0xxt dtH(x)=\int_0^x xt\,dt. Holding xx fixed while integrating tt gives H(x)=x3/2H(x)=x^3/2, hence H′(x)=3x2/2H^{\prime}(x)=3x^2/2. The boundary term alone would be (x⋅x)⋅1=x2(x\cdot x)\cdot1=x^2. The missing x2/2x^2/2 comes from the change of the whole integrand over the existing interval. Under appropriate continuity and differentiability hypotheses, Leibniz's rule adds ∫u(x)v(x)∂F∂x(x,t) dt\int_{u(x)}^{v(x)}\frac{\partial F}{\partial x}(x,t)\,dt to the two endpoint terms when the integrand is F(x,t)F(x,t). We will use direct evaluation when possible and state the extra hypothesis when invoking the general rule.

Units help diagnose a missing endpoint-speed factor. For two moving endpoints, a useful special case is a fixed-width window u(x)=xu(x)=x and v(x)=x+hv(x)=x+h. 5. Substitution transports the endpoints too

Substitution for definite integrals is the chain rule read through the evaluation theorem. Suppose gg is continuously differentiable on [a,b][a,b] and ff is continuous on an interval containing the image of gg. If F′=fF^{\prime}=f, then the derivative of F(g(x))F(g(x)) is f(g(x))g′(x)f(g(x))g^{\prime}(x). Integrating and evaluating endpoints yields ∫abf(g(x))g′(x) dx=∫g(a)g(b)f(u) du\int_a^b f(g(x))g^{\prime}(x)\,dx=\int_{g(a)}^{g(b)} f(u)\,du. The variable uu labels the transformed input, and its bounds must be values of uu, not unchanged values of xx.

For ∫012xcos⁡(x2) dx\int_0^1 2x\cos(x^2)\,dx, choose u=x2u=x^2. The factor 2x dx2x\,dx corresponds to dudu, and the endpoints become u=0u=0 and u=1u=1. The integral equals ∫01cos⁡(u) du=sin⁡(1)\int_0^1\cos(u)\,du=\sin(1). For an interval [1,2][1,2], the same substitution would change the bounds to [1,4][1,4]. Keeping [1,2][1,2] in the uu-integral would silently ask a different question. One can instead find an antiderivative in uu, substitute back to xx, and only then use the original xx-bounds; both methods agree when used consistently.

Monotonicity of gg is not required for this one-dimensional formula with its signed derivative factor. On [−1,1][-1,1], the substitution u=x2u=x^2 makes both bounds equal to 11, and ∫−112xcos⁡(x2) dx=0\int_{-1}^{1}2x\cos(x^2)\,dx=0. The inward and outward passages cancel. This is not a general instruction to ignore overlapping regions in geometric change of variables; it is a consequence of the chain rule and orientation. Substitution also cannot magically remove a singularity where its continuity hypotheses fail.

Substitution is most reliable when the transformed differential and bounds are recorded together. In ∫122x1+x2 dx\int_1^2\frac{2x}{1+x^2}\,dx, let u=1+x2u=1+x^2, so du=2x dxdu=2x\,dx and the bounds become u=2u=2 and u=5u=5. The integral is ∫251u du=ln⁡(5/2)\int_2^5\frac{1}{u}\,du=\ln(5/2). If one retains xx-bounds 11 and 22 after changing the integrand to 1/u1/u, the resulting ln⁡2\ln2 is a different number. A quick numerical check confirms the integrand is positive and roughly between 0.80.8 and 11, so an answer around 0.9160.916 is plausible.

Substitution can reverse orientation. For ∫01−2xexp⁡(−x2) dx\int_0^1-2x\exp(-x^2)\,dx, set u=−x2u=-x^2; then du=−2x dxdu=-2x\,dx and the bounds become 00 and −1-1. The result ∫0−1eu du=e−1−1\int_0^{-1}e^u\,du=e^{-1}-1, a negative number as the original integrand requires. Reversing the uu-bounds to [−1,0][-1,0] without also introducing a minus sign would produce the opposite answer. The sign of g′g^{\prime} and the order of transformed endpoints work together; neither may be ignored.

The chain-rule derivation avoids a hidden monotonicity assumption. Even when u=g(x)u=g(x) travels forward and then backward, F(g(b))−F(g(a))F(g(b))-F(g(a)) still equals ∫abf(g(x))g′(x) dx\int_a^b f(g(x))g^{\prime}(x)\,dx, provided the regularity hypotheses hold. What it does not do is replace an unsigned geometric area under f(g(x))f(g(x)) with a naive integral over a repeated uu-range. For unsigned quantities, absolute values and multiplicity matter. In the one-dimensional signed formula here, orientation accounts for retracing automatically. This is why substitution is often more straightforward for signed integrals than for geometric length or area.

The pattern is recognizable in derivatives: if the integrand is f(g(x))g′(x)f(g(x))g^{\prime}(x), choose u=g(x)u=g(x). If the derivative factor is missing, plain substitution may not simplify the expression. For example, ∫01cos⁡(x2) dx\int_0^1\cos(x^2)\,dx does not become sin⁡(1)\sin(1), because d(x2)=2x dxd(x^2)=2x\,dx and the original integral has no 2x2x factor. It still exists and can be approximated numerically or represented by a special function. Always verify a proposed antiderivative by differentiating it; this single check catches many invented substitutions.

The substitution rule has a quick diagnostic: after changing variables, no old variable should remain in the transformed integral, and every transformed bound must be expressed in the new variable. For ∫122x1+x2 dx\int_1^2\frac{2x}{1+x^2}\,dx, writing ∫121u du\int_1^2\frac{1}{u}\,du violates the second requirement, while writing ∫252xu du\int_2^5\frac{2x}{u}\,du violates the first. Either inconsistency signals an unfinished substitution. If the new variable is not monotone, the signed formula remains valid as shown, but using it to compute geometric area may require splitting the original interval where direction reverses. Keep the desired quantity visible throughout the algebra.

A variable upper limit and a variable lower limit can compete. For 0≤x≤10\le x\le1, define A(x)=∫x2xt2 dtA(x)=\int_{x^2}^{x}t^2\,dt. For the dimensionless rate f(x)=x2−cf(x)=x^2-c, approximate A(x)=∫0xf(t) dtA(x)=\int_0^x f(t)\,dt by midpoint sums, then estimate its derivative by a central difference. Source code

// Adjust c, the midpoint panel count n, and derivative step h.
const c = 1;
const n = 200;
const h = 0.01;
if (!Number.isInteger(n) || n < 1 || n > 2000 || !Number.isFinite(c) || Math.abs(c) > 100 || !Number.isFinite(h) || h <= 0 || h > 0.5) throw new Error('Use 1 <= n <= 2000, |c| <= 100, and 0 < h <= 0.5.');
const f = x => x*x - c;
const exact = x => x*x*x/3 - c*x;
function accumulation(x) {
  const dx = x/n; // Negative x automatically reverses orientation.
  let sum = 0;
  for (let j = 0; j < n; j++) sum += f((j+0.5)*dx)*dx;
  return sum;
}
const area = [], rates = [], slopes = [];
let maxAreaError = 0, maxSlopeError = 0;
for (let i = 0; i <= 80; i++) {
  const x = -2 + i/20;
  const a = accumulation(x);
  const d = (accumulation(x+h)-accumulation(x-h))/(2*h);
  area.push([x,a]); rates.push([x,f(x)]); slopes.push([x,d]);
  maxAreaError = Math.max(maxAreaError,Math.abs(a-exact(x)));
  maxSlopeError = Math.max(maxSlopeError,Math.abs(d-f(x)));
}
plot(area, 'Accumulation A: x versus integral');
plot(rates, 'Rate f: x versus rate');
plot(slopes, 'Central difference of A: x versus slope');
console.log('A(2), exact A(2):', accumulation(2), exact(2));
console.log('Maximum accumulation error:', maxAreaError);
console.log('Maximum derivative error:', maxSlopeError);
