Calculus transfer packet

Eighteen public forms in nine families, with two variants in each family. Every model and comparison criterion is public. Choose a form and write your response before opening its comparison if that is useful to you.

Keep your own working files

Use paper or your own text editor. Include the form ID and any public help or optional tools you used. Keep separate first-response, comparison and revised files so you can return to your earlier reasoning. Choose your own filenames, for example U12-LIM-A-first.txt, U12-LIM-A-comparison.txt and U12-LIM-A-revised.txt.

For comparison, explain how your response meets each of the four criteria, identify a gap and write a revision. These are manual self-study criteria with no score or automatic checking. This page has no editor or save function. Opening a model is voluntary; it establishes no unseen-work status, elapsed delay or learning outcome.

Preparation links open the native lessons and written problems. Follow each form's stated requirements. A calculator, symbolic tool or numerical program is optional support unless a prompt explicitly restricts its use; name any tool used in your own response.

For a paper copy, open the comparisons you want to include, then use your browser’s Print command.
