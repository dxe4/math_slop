00 / 5 minutes

A shape is more than its outline

Draw a closed loop in the plane. Can you shrink it to a point? Now remove the origin. Does your answer change?

You will learn to construct a continuous deformation, check exactly which conditions it satisfies, and use winding to explain why some deformations cannot exist. The subject is homotopy (roughly, “same by continuous deformation”).

What you need

  • Continuous functions and composition.
  • Vectors in the plane and their length ‖x‖.
  • Sine and cosine parametrizations of a circle.

What you should be able to do

  • Verify all the conditions on a proposed homotopy.
  • Keep endpoints or a basepoint fixed when required.
  • Distinguish a homotopy equivalence from a homeomorphism.
  • Explain the role of an invariant.
Preparation if continuity is new

A map is continuous when nearby inputs have nearby outputs. In a homotopy there are two inputs: position and deformation time. We require continuity in the pair of inputs, not just in each variable separately. Sums, products, and compositions of continuous real functions are continuous; division is continuous where the denominator is nonzero. These facts justify the constructions below.

01 / 10 minutes

Move a path without moving its ends

A path in a space Y is a continuous map α : [0, 1] → Y. The input s tells us where a traveler is along the path. Add a second input t to describe how the whole path changes.

α(s) = (4s − 2, sin(πs))
β(s) = (4s − 2, −0.7 sin(2πs))
H(s, t) = (1 − t)α(s) + tβ(s)Both paths start at a = (−2, 0) and end at b = (2, 0). Here the target is all of ℝ².

Predict: will the endpoints move when t changes? Will this formula work for paths in every possible target space?

Changing s moves one traveler. Changing t moves the entire path. SVG uses sampled points for drawing; the formula gives a continuous map for every pair (s, t).

Why this works

The formula is jointly continuous because it combines continuous functions by addition and multiplication. At t = 0 it is α; at t = 1 it is β. At s = 0 it equals (1 − t)a + ta = a, and similarly H(1, t) = b. Every output lies in ℝ².

The same construction works in a convex subset of ℝᵈ: the line segment between any two points remains in that subset. A punctured plane is not convex.

02 / 8 minutes

The domain is a product

Homotopy of maps

For continuous maps f, g : X → Y, a homotopy from f to g is a continuous map

H : X × [0, 1] → Y,
H(x, 0) = f(x),   H(x, 1) = g(x).

We write f ≃ g. For each fixed time t, the slice Ht(x) = H(x, t) is a map X → Y. The whole function H must be continuous in both inputs together.

A path homotopy relative to endpoints adds H(0, t) = a and H(1, t) = b for every t. More generally, “relative to A” means that every point of a specified subset A ⊆ X keeps its image throughout the deformation.

A loop based at p is a path with α(0) = α(1) = p. A based loop homotopy fixes that point for the entire deformation. A free loop homotopy can move it, while keeping each slice closed. These are different requirements.

A verification checklist

  1. Domain and target: where can each input and output live?
  2. Joint continuity: is H continuous on the whole product?
  3. Initial and final maps: do t = 0 and t = 1 give the promised maps?
  4. Relative conditions: which points must remain fixed?
Check 2. We checked that every time slice is a continuous curve. What remains?

Optional continuity clinic · Can every curve be continuous while the deformation fails?

This 10–15 minute extension makes the joint-continuity condition concrete. The target here is ℝ. Each loop is a scalar-valued function; its graph plots input s horizontally and output vertically. Both endpoint values must equal the basepoint 0, even though the graph has different horizontal endpoints.

F(s, t) = (1 − s)st/(s² + t²)   if (s, t) ≠ (0, 0),
F(0, 0) = 0,   (s, t) ∈ [0, 1]².

Predict: at t = 0 the entire slice is zero. Will the tallest point of a slice approach zero as positive t approaches zero? Check the endpoints and the target separately from joint continuity.

All slices pass, but the family fails

For a fixed positive t, the denominator is at least t², so s ↦ F(s,t) is continuous. At t = 0 it is the zero function. We also have F(0,t) = F(1,t) = 0 for every t. The outputs lie in ℝ. In fact each fixed-s time trace is continuous as well.

Joint continuity tests nearby pairs of inputs. On the diagonal s = t = r > 0,

F(r,r) = (1 − r)/2 → 1/2   as r → 0,
but F(0,0) = 0.

The inputs approach (0,0) while the outputs do not approach its value. Hence F is not a homotopy. This does not prevent a homotopy between its endpoint maps: they are loops in the convex target ℝ.

Repair the family

g(s) = F(s,1) = (1 − s)s/(s² + 1),
K(s,t) = t g(s).

K has the same initial map 0 and final map g as F. It is jointly continuous by multiplication of continuous functions and fixes both endpoint values at 0. Its whole-slice bound is |K(s,t)| ≤ t(√2 − 1)/2, which tends to zero with t. Use the comparison control to see the difference.

Optional calculus behind the peak readout

For positive t, differentiating F with respect to s gives t(t² − s² − 2st²)/(s² + t²)². The numerator changes from positive to negative at s* = t/(√(1+t²)+t). Since F vanishes at both endpoints, this is its unique maximum:

maxs∈[0,1] F(s,t) = 1/[2(√(1+t²)+t)] → 1/2.
maxs∈[0,1] K(s,t) = t(√2 − 1)/2 → 0.

At t = 0 both slices are identically zero, so every s is a maximizer; there is no unique peak. For each fixed positive s, F(s,t) tends to zero as t tends to zero. The moving peak therefore separates pointwise convergence from uniform convergence. If a real-valued family on this compact input square were jointly continuous, uniform continuity would force its slices to approach the initial slice uniformly.

Clinic task A · Give an exact discontinuity witness

Fix ε = 1/4. For any proposed δ > 0, find an input pair within distance δ of (0,0) whose output is more than ε away from zero.

Hint

Use (r,r), choosing r small enough for both the distance condition and a lower bound on (1−r)/2.

Worked solution

Set r = min(δ/4, 1/4). It is positive and lies in the domain. The distance √2r is at most √2δ/4, strictly less than δ. Since r ≤ 1/4, F(r,r) = (1−r)/2 ≥ 3/8 > 1/4. This works for every δ and disproves continuity at the origin.

Clinic task B · Explain what the grid cannot prove

For the fixed grid s = j/10, prove its maximum tends to zero as t tends to zero. Why does this not prove the same for the maximum over all s?

Hint

For a nonzero grid point s, use s²+t² ≥ s² and (1−s)/s ≤ 9.

Worked solution

The zero grid point gives zero. Every positive grid point has F(s,t) ≤ (1−s)t/s ≤ 9t. The grid maximum is therefore at most 9t and tends to zero. The full maximum instead tends to 1/2, and the diagonal value (1−t)/2 already gives that obstruction. A finite set of fixed inputs does not control a maximum over every input. A known error bound or other uniform guarantee would be needed.

The underlying separately continuous example st/(s²+t²) appears in the introduction of Ciesielski and Rodríguez-Vidanes’ paper on linearly continuous maps. The endpoint-fixing factor, repaired family, exercises, and peak analysis here are derived for this lecture. The original 75–90 minute route excludes this optional clinic.

Self-intersections are allowed. A homotopy of maps need not preserve length, angles, injectivity, or an embedded outline. An isotopy imposes additional structure. Keep the definition you are using in view.

A plausible contraction fails at one point

Take γ(s) = (cos(2πs), sin(2πs)), a loop based at p = (1, 0). We try to contract it to the constant loop at p using the same interpolation as before.

C(s, t) = (1 − t)γ(s) + t(1, 0).At time t this is a circle centered at (t, 0) with radius 1 − t. Its basepoint stays at (1, 0).

In ℝ² this is a valid based contraction. In Y = ℝ² ∖ {0}, every output must avoid the origin. Predict the time and position at which the formula fails.

An exact witness

C(½, ½) = ½(−1, 0) + ½(1, 0) = (0, 0).

This disproves this formula as a contraction in the punctured plane. It does not yet prove that every possible contraction fails. For that we need an invariant, a quantity that cannot change under a valid homotopy. Winding will provide one.

“I did not see it cross” is not a proof. A display uses finitely many frames and points. The exact witness above finds a failure even if an animation skips it. Conversely, a guarantee that every point avoids 0 must come from mathematics, not the resolution of a drawing.

04 / 12 minutes

Flatten the radius and keep the turns

There is a useful deformation that never crosses the origin. Move each nonzero point along its ray until it reaches the unit circle S¹ = {x ∈ ℝ² : ‖x‖ = 1}.

D(x, t) = (1 − t)x + t x/‖x‖ = ((1 − t) + t/‖x‖)x,
x ∈ ℝ² ∖ {0},   0 ≤ t ≤ 1.

Verify every condition

The denominator is nonzero, so D is jointly continuous. Its radius is (1 − t)‖x‖ + t, which is positive. Thus the image stays in the punctured plane. At t = 0, D(x, 0) = x; at t = 1, D(x, 1) = x/‖x‖ lies on S¹. If x already lies on S¹, D(x, t) = x at every time.

Explain the remaining obligations

Before opening the key, explain these three lines. For each, name the earlier fact that permits the step and the condition it verifies.

  1. The family is jointly continuous on the whole product.
  2. Its initial map is the identity, and its terminal map lands on the unit circle.
  3. Every point already on the unit circle stays fixed at every time.
Worked explanations of the three lines
  1. The norm is continuous and never zero on the punctured plane, so its reciprocal is continuous there. Coordinate projections, addition and scalar multiplication are continuous. Combining them gives continuity on the full product of the punctured plane and [0,1]. Differentiability is unnecessary.
  2. Substituting time 0 gives D(v,0)=v. At time 1 the output is v/‖v‖, with norm 1 by positive homogeneity. These check the two time maps.
  3. For a point of the unit circle, r=1. Its multiplier becomes (1−t)+t=1, so it remains that same point for every time. This fixes the whole subspace, not just one basepoint. It also shows that every circle point occurs in the terminal image.

A strategy summary is: change only radial scale by a positive factor, prove membership for the whole family, and make the factor 1 on the intended retract. A direct zero-exclusion proof can replace a norm bound.

Worked answer and universal verification

Take v0=(1,1/2). It has q(v0)=1, so it belongs to B and Y. Its Euclidean norm is √5/2. At time 1:

E(v0,1)=(25,15) q(E(v0,1))=25<1

Thus E leaves Y, fails to land in B at the final time, and fails to fix v0∈B. At every positive time its q-value is (1−t)+2t/√5<1. Its continuity and initial identity are not the failing conditions. This witness rejects E, not the existence of a different deformation.

Replace the Euclidean norm by the quantity that defines the shell:

H(v,t)=(1−t+tq(v))v

On Y, the continuous function q is at least 1. Its reciprocal is therefore defined and continuous. Combining it with the projections, addition and scalar multiplication proves joint continuity of H on Y×I, including above corners. No derivative is used.

Put a=q(v)∈[1,2] and λ=(1−t)+t/a. The multiplier λ is positive. Positive homogeneity gives:

q(H(v,t))=λq(v) λq(v)=(1−t)a+t∈[1,2]

The expression is a convex combination of a∈[1,2] and 1, so every output remains in Y. At time 0 the map is the identity; at time 1 its q-value is 1, so it lands in B. If v∈B, then a=1 and the multiplier is always 1: every such point stays fixed. This also proves that the terminal image is all of B.

For example, v=(2,1/4) has q=2. At time 1/2, H(v,1/2)=(3/2,3/16), with q=3/2; at time 1 it is (1,1/8), with q=1. These values illustrate the argument, while the universal calculation proves it.

Continuity, a nonzero denominator, positive homogeneity and the interval bound defining the target survive the change. Roundness and differentiability were unnecessary. An arbitrary positive continuous function cannot simply replace the norm: the homogeneity identity is used at the displayed calculation.

05 / 8 minutes

Different spaces can have the same homotopy type

A homeomorphism is a continuous bijection with continuous inverse. A homotopy equivalence allows inverse maps whose composites are homotopic to the identity maps.

Spaces X and Y are homotopy equivalent if there are continuous maps f : X → Y and g : Y → X with

g ∘ f ≃ idX,   f ∘ g ≃ idY.

We write X ≃ Y. Notice the different domains of the two composite maps.

For X = ℝ² ∖ {0} and Y = S¹, let r(x) = x/‖x‖ and let i be the inclusion of the circle into the punctured plane. Then r ∘ i = idS¹ exactly, and D supplies idX ≃ i ∘ r. They have the same homotopy type.

They are not homeomorphic: S¹ is compact, while the punctured plane is not. A continuous image of a compact space is compact, so a homeomorphism could not exist.

A space is contractible when its identity map is homotopic to a constant map. A nonempty convex subset of ℝᵈ is contractible using a straight-line homotopy to any chosen point in it. The unit circle is not contractible, as the winding argument below will explain.

06 / 12 minutes

Turn a picture into an obstruction

For a loop γ in the punctured plane based at (1, 0), first normalize it onto the circle. Track an unwrapped angle rather than an angle restricted to one turn.

γ(s)/‖γ(s)‖ = (cos θ(s), sin θ(s)),   θ(0) = 0,
wind(γ) = θ(1)/(2π) ∈ ℤ.

We use the angle lifting lemma: a continuous circle-valued path has a unique continuous angle once its initial angle is chosen. The homotopy lifting property also lets us choose the angles continuously across a based path homotopy. One proves these facts by subdividing paths and homotopies into pieces that lie in arcs with a continuous choice of angle. This lemma is the topological ingredient; the rest of the argument is short.

Why winding cannot change

Suppose H is a valid based loop homotopy in the punctured plane. Normalize H and lift its angle continuously, with θ(0, t) = 0. Since the endpoint remains (1, 0), θ(1, t)/(2π) is an integer at every time. It is also continuous in t. A continuous integer-valued function on an interval is constant. Therefore winding is invariant.

The unit loop has winding 1 and a constant loop has winding 0. They cannot be based homotopic in the punctured plane. For a free contraction, a lift on the parameter square makes (θ(1, t) − θ(0, t))/(2π) a continuous integer too, so allowing the basepoint to move does not remove this obstruction.

Why the integer also classifies these loops

After the radial retraction, a loop has a lifted angle θ with θ(0) = 0 and θ(1) = 2πn. Interpolate angles:

K(s, t) = (cos((1 − t)θ(s) + t 2πns),
           sin((1 − t)θ(s) + t 2πns)).

This based homotopy stays on the unit circle and ends at the standard n-turn loop. Concatenating the radial deformation with this one shows that every based loop is homotopic to its standard representative. Equal winding is therefore sufficient as well as necessary in this particular space.

A first view of the fundamental group

The fundamental group π₁(Y, p) consists of based loops up to homotopy relative to endpoints. Its operation follows one loop and then another. Reversing a loop gives an inverse; the constant loop gives the identity. For the punctured plane, winding identifies this operation with addition:

π₁(ℝ² ∖ {0}, (1, 0)) ≅ ℤ,
wind(α ∗ β) = wind(α) + wind(β).

The space matters. For a plane with two points removed, a pair of winding numbers does not completely classify based loops. The order of travel around the holes can matter. The fundamental group need not be commutative. Our complete classification by one integer belongs to the punctured plane and the circle.

Construct, diagnose, and prove

Write an attempt before opening a hint. The solutions explain reasoning; an answer match alone does not establish proof mastery. Exercises 1–4 consolidate the lecture; 5–8 ask you to transfer it.

1. Reverse a homotopy

Given H from f to g, construct one from g to f. Check continuity and both endpoint maps.

Hint

Run deformation time backward.

Worked solution

Set J(x, t) = H(x, 1 − t). It is continuous by composition. J(x, 0) = H(x, 1) = g(x), and J(x, 1) = H(x, 0) = f(x). If H is relative to A, J fixes the same images on A. This proves symmetry of the homotopy relation.

2. Join two deformations

Suppose H deforms f to g and J deforms g to h. Write a homotopy from f to h. What must be checked at t = ½?

Hint

Use H at twice the speed on the first half of the time interval, then J on the second half.

Worked solution

Set K(x, t) = H(x, 2t) for 0 ≤ t ≤ ½, and K(x, t) = J(x, 2t − 1) for ½ ≤ t ≤ 1. At the seam both formulas equal g(x). Each piece is continuous on a closed half of the product, so the pasting lemma gives continuity on the whole product. The endpoint maps are f and h. Relative conditions are preserved. Together with the constant homotopy H(x, t) = f(x) and Exercise 1, this proves homotopy is an equivalence relation on maps X → Y.

3. Repair a bad target

A learner proposes H(x, t) = (1 − t)x as a contraction of ℝ² ∖ {0}. Identify the failed condition. Does changing the last frame alone repair it?

Hint

Check t = 1 before worrying about the drawing.

Worked solution

H(x, 1) = 0 is outside the target. If we replace its value at t = 1 by any nonzero constant p, then for every fixed x the limit as t approaches 1 is still 0, not p. That replacement is discontinuous. D(x, t) from the lecture safely retracts onto a circle, but is not a contraction to a point. Winding proves that a contraction in the punctured plane cannot exist.

4. Compute without trusting a picture

Let α(s) = (cos(4πs), sin(4πs)) and β(s) = (cos(−2πs), sin(−2πs)). Find the winding of α, β, their concatenation, and the reverse of α. Which are based homotopic in the punctured plane?

Hint

Use the unwrapped angles 4πs and −2πs. Reverse changes the sign.

Worked solution

The windings are 2, −1, 1, and −2 respectively. No pair in this list has the same winding, so no two are based homotopic in the punctured plane. Their geometric images can all be the same unit circle; it is the parametrized travel that determines winding.

5. Retract an annulus

For A = {x ∈ ℝ² : 1 ≤ ‖x‖ ≤ 2}, construct a strong deformation retraction onto its inner boundary. Prove that intermediate points stay in A.

Hint

Try the same radial formula and bound the new radius above and below.

Worked solution

Use D(x, t) = (1 − t)x + tx/‖x‖. Its radius is (1 − t)‖x‖ + t, a convex combination of a number in [1, 2] with 1, so it remains in [1, 2]. Continuity follows from ‖x‖ ≥ 1. The initial map is the identity, the final image lies on the inner boundary, and every point on that boundary stays fixed.

6. Change the speed in an arbitrary space

For any path α : [0, 1] → Y, prove α(s) and α(s²) are homotopic relative to endpoints. Do not assume Y is a vector space.

Hint

Interpolate the inputs to α, rather than adding points in Y.

Worked solution

Set H(s, t) = α((1 − t)s + ts²). The inner expression lies in [0, 1] and is jointly continuous; composing with α gives a continuous Y-valued map. At t = 0 and t = 1 the slices are α(s) and α(s²). At s = 0 and s = 1 the inputs to α remain 0 and 1. No convexity assumption on Y is used.

7. Explain the missing proof step

Someone says, “The winding is an integer, so it is invariant.” Explain why that is incomplete, and supply the needed argument.

Hint

An integer-valued function can jump. What prevents a jump here?

Worked solution

Being integer-valued alone does not prevent change. We also need continuity in deformation time. The homotopy lifting property applied after normalizing H gives a continuous angle θ(s, t), with θ(0, t) = 0 for a based homotopy. Hence n(t) = θ(1, t)/(2π) is continuous and integer-valued. Since [0, 1] is connected, n is constant. The lifting lemma is substantive; a drawing or separate angle choices at each frame do not replace it.

8. Compare two nonzero targets

Choose points a and b in the punctured plane. Are all paths from a to b homotopic relative to endpoints? Give a counterexample or prove the claim. How does the answer change in all of ℝ²?

Hint

To disprove a universal claim you may choose a = b = (1, 0). Or, for distinct endpoints, attach an extra loop to a path.

Worked solution

No. For a = b = (1, 0), the unit loop and constant loop have different winding. For arbitrary fixed a and b, take a path σ from a to b and first traverse λa(s), the vector a rotated counterclockwise by angle 2πs. This loop stays at radius ‖a‖ and has winding 1. If σ and λa ∗ σ were endpoint homotopic, appending the reverse of σ would give based homotopic loops with windings 0 and 1, a contradiction. The path σ followed by its reverse is contractible by traversing an ever shorter initial portion of σ and then retracing it. In ℝ² every two paths with the same endpoints are endpoint homotopic by straight-line interpolation.
