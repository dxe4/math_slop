Lecture 03 · Winding and continuous choices

Lift, return,
choose a root.

Every nonzero complex number has square roots. Can we choose one continuously as the input travels around a circle? Follow a root, keep track of its return, and turn that journey into an existence proof.

01 / Start with a prediction

Each input has roots. Does one root fit the whole circle?

Write S¹={z∈ℂ:|z|=1}. On S¹, the map p₂(w)=w² has two preimages for every input. Start at input 1 and root +1. Travel once counterclockwise: γ(s)=exp(2πis), 0≤s≤1. Following the root continuously gives w(s)=exp(πis), ending at −1.

The input returned to its starting point. The root did not. A function on the circle must give one value at that point, independent of whether we describe it using s=0 or s=1.

Keep three questions separate: does a root exist at each point, does a chosen root continue along an interval, and does that continuation agree when the interval’s endpoints are identified?

Preparation. Use exp(iθ)=cos θ+i sin θ, integer powers, continuity, and winding from the first lecture. A continuous path in a finite discrete set is constant. The optional general-map extension also uses the circle angle-lifting theorem.

02 / Follow, then calculate

A loop permutes the possible starting roots

Fix an integer n≥2. The map pₙ:S¹→S¹ is pₙ(w)=wⁿ. Above 1, label the n possible roots ζₙʲ=exp(2πij/n), with j=0,…,n−1. These labels describe the fiber above 1; they are not n globally separate circles.

For the input loop γₖ(s)=exp(2πiks), k∈ℤ, the lift beginning at ζₙʲ is

wj(s)=exp(2πi(j+ks)n).

Raising it to the nth power gives γₖ(s). At the end, the sheet label is j+k modulo n. We use forward endpoint transport: the monodromy permutation is j↦j+k mod n.

Why this continuation is forced

Suppose v is another continuous lift with the same starting root. The ratio v(s)/wⱼ(s) is always an nth root of 1. It is a continuous function from an interval into a finite set, so it is constant. Its starting value is 1; hence v=wⱼ. Switching between roots cannot repair the endpoint while preserving continuity.

After r repetitions the label is j+rk modulo n. Return means n divides rk. Write d=gcd(n,|k|), with gcd(n,0)=n. Cancelling d shows the first positive return is n/d; there are d disjoint permutation cycles, each of that length.

What a return proves. Repeating γₖ r times gives a different loop, γᵣₖ. Closure after several traversals does not supply a root of the original map on its original parameter circle. A closed lift in this finite circle cover can still have nonzero winding upstairs.

03 / Identify the endpoints

A global root needs one traversal to close

Let fₖ:S¹→S¹ be fₖ(z)=zᵏ. We ask for a continuous function h:S¹→S¹ satisfying h(z)ⁿ=fₖ(z) at every input. The parameter z=exp(2πis) describes the same circle point at s=0 and s=1. Therefore h composed with this parametrization must be a closed lift.

fk has a continuous nth root on S1⇔n∣k.

Necessity, sufficiency, and all the choices

Necessity follows from the forced continuation: its endpoint agrees with its start exactly when n divides k. If k=nm for an integer m, define hⱼ(z)=ζₙʲzᵐ. Integer powers are continuous on S¹, including negative powers, and hⱼ(z)ⁿ=zᵏ.

These are all the roots. The ratio of any other root to h₀ takes values in the finite set of nth roots of 1. Since S¹ is connected, the ratio is constant. Thus there are exactly n continuous roots when n divides k, and none otherwise. For k=0 they are precisely the n constant roots of 1.

Optional clinic: an existing root does not make every selector continuous

For f₂(z)=z², the functions h(z)=z and −z are continuous square roots. Compare h(z) with the principal square-root selector applied separately to each output z². Use the convention Arg∈(−π,π], so the principal value at −1 is +i.

s=1/4. Continuous root turn: 1/4. Principal root turn: 1/4. The selector agrees with h here.

At s=1/4, the principal root has left limit +i and right limit −i. At s=3/4 the same jump occurs. The chosen seam value is +i. Both one-sided limits square to −1, but they differ. Moving the cut moves a discontinuity of this selector; it does not alter the existence of the separate continuous functions ±z.

04 / A stronger compatibility requirement

A continuous logarithm must return with no extra turn

A continuous logarithm of fₖ is a continuous L:S¹→ℂ satisfying exp(L(z))=zᵏ. Since |zᵏ|=1, its real part must be zero. Along the parameter interval, every choice has the form

L(exp(2πis)) = 2πi(ks+ℓ),   ℓ∈ℤ.

Indeed, subtract 2πiks and divide by 2πi. The result is a continuous integer-valued function, hence constant. Agreement at s=0 and s=1 now requires k=0, rather than divisibility by a finite n.

fk has a continuous logarithm on S1⇔k=0.

When k=0, all logarithms are the constants 2πiℓ. For k=2, a continuous square root exists, but a continuous logarithm does not. A root may return after an integer number of full turns upstairs; a logarithm in the angle line must return to exactly the same real angle.

05 / Optional proof extension

Keep the winding, change the formula

The same criterion applies to an arbitrary continuous f:S¹→ℂ∖{0}, now seeking a root h:S¹→ℂ∖{0}. Write f(exp(2πis))=ρ(s)exp(2πia(s)), where ρ(s)=|f(exp(2πis))| is continuous and positive, with ρ(0)=ρ(1), and a is a continuous real angle lift on [0,1]. Existence of a is the circle angle-lifting theorem used in the first lecture, not a consequence of pointwise arguments. The integer k=a(1)−a(0) is the winding of f around 0.

An nth root along the interval is ρ(s)1/nexp(2πi(a(s)+j)/n). It descends to the circle exactly when k is divisible by n. A logarithm along the interval is log ρ(s)+2πia(s), and it descends exactly when k=0. Any other root or logarithm differs by the same discrete ambiguity used above.

Endpoint agreement is sufficient because S¹ is the quotient of [0,1] identifying its endpoints: a continuous map on the interval with matching endpoints induces a continuous map on that quotient. This names the step that turns a closed parametrized path into a well-defined function on the circle.

Why this belongs in a homotopy lecture

Winding is invariant under a homotopy through maps into ℂ∖{0}. Therefore the existence of a continuous nth root, and separately the existence of a continuous logarithm, is unchanged by such a homotopy. The argument depends on keeping the entire homotopy away from 0. A plot that fails to show a crossing cannot establish that condition.

There is a local repair on the slit plane D=ℂ∖(−∞,0]. The angle Arg∈(−π,π) is continuous there, so |z|1/nexp(i Arg(z)/n) is a continuous nth root of z on D. It cannot extend as a continuous root to all ℂ∖{0}: restriction to S¹ would contradict the k=1 obstruction. Here we study continuity; no theorem about complex differentiability is needed.

Compare the real-domain questions in Conditions. In both settings, a formula’s allowed domain is part of the mathematical question. Here the obstruction also depends on how that domain loops around the omitted point.

06 / Independent practice

Change the data before looking at the answer

Attempt each task from the formula and endpoint conditions. Tasks 1–4 use the core route; Tasks 5–6 connect selection and domain changes. Notes are your written work, separate from the exact calculator.

1. Return without a global root

Use n=6, k=4 and starting label j=1. List three endpoint labels, find all cycles of the one-traversal permutation, and decide whether f₄ has a continuous sixth root. Explain why a return after three traversals does not change that answer.

Hint

Add 4 modulo 6 each time. Compare the original map f₄ with the thrice-traversed map f₁₂.

Worked explanation

The trace is 1→5→3→1. The permutation cycles are (0 4 2) and (1 5 3). The first return is 3, but 6 does not divide 4, so f₄ has no continuous sixth root. Three traversals describe f₁₂, for which 6 does divide 12. That changes the input map rather than repairing a root of f₄.

2. Reverse the loop

Keep n=6 and j=1 but change k to −4. Determine the trace and first return. What happens to the permutation? Does the global-root condition change?

Hint

Transport forward by −4, which is 2 modulo 6.

Worked explanation

The trace is 1→3→5→1, with first return 3. The cycles are (0 2 4) and (1 3 5), inverse to the previous permutation. Divisibility by 6 fails for both 4 and −4, so neither map has a continuous sixth root. Direction affects transport even when return length is unchanged.

3. A closed lift is not necessarily contractible

Let n=4 and k=8. Find every continuous fourth root of f₈. Compute each root’s winding. Does closure in this finite cover imply a null-homotopy in its total circle?

Hint

Write 8=4·2. The total space is S¹, not its universal covering line.

Worked explanation

The four roots are hⱼ(z)=iʲz², j=0,1,2,3. Each has winding 2: multiplication by a constant phase changes the starting point but not the signed turns. Each lift closes after one traversal, but winding 2 prevents contraction in S¹. Closure and null-homotopy are different conditions.

4. Count the constant choices

For n=3 and k=0, classify all continuous cube roots and all continuous logarithms of f₀. Could a nonconstant choice be hidden among the pointwise values?

Hint

A connected domain has connected continuous image. Inspect the discrete sets of possible values.

Worked explanation

The roots are the three constants ζ₃ʲ, j=0,1,2. The logarithms are the constants 2πiℓ for every integer ℓ. All take values in discrete sets, so continuity on connected S¹ forces constancy. There are three roots and infinitely many logarithms; the first return is 1.

5. Existence does not validate a selector

Show that f₂ has continuous square roots but no continuous logarithm. For z(s)=exp(2πis), compare z with the principal square root of z² just before and just after s=1/4. Use Arg∈(−π,π].

Hint

The output z² passes through the negative real axis. Its principal angle jumps from near +π to near −π.

Worked explanation

The roots are ±z because 2 divides 2. A logarithm would require winding zero, so none exists. The principal selector of z² approaches +i from the left and −i from the right at s=1/4, with seam value +i. The continuous root z approaches +i from both sides. The discontinuous selector is a different function; it does not disprove existence of ±z.

6. Change the allowed domain

Construct a continuous nth root of the identity map on D=ℂ∖(−∞,0]. Prove that it cannot extend to a continuous nth root on all ℂ∖{0}, for n≥2. Identify the exact restriction that yields a contradiction.

Hint

Use the slit-domain continuous angle for the construction. If a global extension existed, restrict it to the unit circle.

Worked explanation

Set h(z)=|z|1/nexp(i Arg(z)/n) with Arg∈(−π,π). It is continuous on D and h(z)ⁿ=z. A continuous extension with the same power identity to ℂ∖{0} would restrict to a continuous nth root of z on all S¹. The circle criterion would require n to divide 1, impossible for n≥2. The slit removes circle paths that would enforce the obstructed return; it does not fill in the missing point 0.

Return later: explain the compatibility condition

With the page closed, reconstruct the implication from a continuous root to a closed lift. Then choose a new pair n,k for which the lift returns after more than one traversal, and explain why that fact does not answer the original global-root question.
