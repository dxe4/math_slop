What helps a learner
do mathematics?

Combine an explicit mathematical question, a representation you can manipulate, an explanation of what the model guarantees, and an independent task. Tool features can support that sequence; the learner’s reasoning is what needs evaluation.

Exact lifts, subgroup bases and deck compatibility

The covering-graph study connects finite sheet transports to exact edge lifts, a rooted-tree free subgroup basis and a whole-cover compatibility test for deck maps. It separates closed-lift subgroup membership from contraction and names the lifting, tree-collapse and injectivity results behind the proofs. The implemented workshop compares two three-sheet covers, then asks for four-sheet and disconnected transfers. Finite exact checks support these examples; the general conclusions use the stated topological theorems.

When every lift must close

The relations-and-covers study proves the all-sheet criterion for extending a graph cover over attached two-cells, using normal closure and covering-space classification. The implemented workshop then counts distinct lifted edges to form cellular face boundaries. Four-sheet tasks show why a single closed lift is insufficient; optional integer-homology tasks distinguish a primitive boundary from an order-two class. Finite tables verify the specified cases; the general topological implications use the stated theorems.

Which answers have a witness?

The elimination and witness study distinguishes the generic resultant condition a²b=0, the elimination equation b=0, and actual existence b=0 with a≠0 for its authored family. The implemented workshop tests exact rational parameters and an independently entered candidate root; a changed written problem compares real and complex existence. The note states a sufficient extension condition and why failure to meet it gives no conclusion. Its optional Wolfram Language source is explicitly unexecuted; the local browser model is not a computer algebra system.

Keep four parameter arguments separate

The damping proof and source note gives an elementary difference-quotient estimate for fixed positive damping and a uniform signed-tail estimate for removing damping at a fixed nonzero frequency. Paths disprove a joint origin limit. The ordinary undamped cosine integral diverges even where the boundary function has derivative zero; an Abel-regularized value answers a different question. The implemented workshop keeps these arguments distinct, then changes the kernel in a written task about absolute convergence, continuity and a cusp. Its optional Wolfram Language source is documented and explicitly unexecuted.

What learning research supports

Freeman and colleagues’ undergraduate STEM meta-analysis supports active learning across varied implementations. It does not isolate sliders or establish the effect of this lecture.

Rohrer and Taylor’s mathematics practice study examines spacing and extra immediate practice in a specific learning task. Roediger and Karpicke’s retrieval study uses prose passages. Their results motivate return visits and recall prompts; transfer to university proof writing must be tested.

The implemented sequence: predict before moving a parameter, explain what changed, justify it from the formula, solve a new problem, and reconstruct the argument later. This is a teaching design informed by research, rather than a measured learning result for these projects.

How to evaluate the next version

  1. Observe comprehension: ask learners to explain s versus t and identify each condition on a homotopy without pointing to the page.
  2. Test transfer: use the annulus and reparametrization problems, with examples and solutions closed.
  3. Inspect written proofs: score domain, continuity, boundary conditions, and logical justification separately. Blind the rater to the learner’s path when feasible.
  4. Return later: collect delayed attempts and record what support was used. Keep hints and worked answers distinct from independent performance.
  5. Test access: examine keyboard, zoom, screen-reader, narrow-screen, offline, and print use with real learners.

Use the protocol in the pedagogy review for baseline questions, outcome definitions, and limits of a small usability pilot. No learner sessions have been conducted in this implementation pass.
