Route A · Real functions and their domains

Keep the domain through a composition

A correct identity on allowed inputs can still change the function when its domain changes. This route combines cancellation, a square root and a logarithm in one problem.

Check the starting point

Find the natural real domain of √(4−x²)/(x−1). Then invert y=(x+1)² when the input is restricted to x≤−1. State the inverse’s domain.

Check and choose a repair

The domain is [−2,1)∪(1,2]: the square root requires −2≤x≤2 and the denominator excludes 1. The restricted square function has inverse x=−1−√y for y≥0. The input restriction selects the negative square-root branch.

If either step is unclear, read the function/domain and inverse-branch stops below before attempting the capstone.

  1. Functions, inputs and domains: record what each operation allows.
  2. Cancel a factor, keep the hole and square with a sign condition: explain each direction of implication.
  3. Inverse branches, then the logarithm comparison: distinguish a restricted identity from an extension.

The combined problem

On its original natural real domain, define

G(x)=log((x2−4x−2)2).
  1. Find the domain before simplifying.
  2. Assess log(x+2) and log|x+2|, each on its own natural real domain. Which inputs are lost or added?
  3. Solve G(x)=c for every real c, including every exceptional case.
  4. Classify finite continuous extensions at x=2 and x=−2.
Hint 1 · Preserve each condition

The quotient first requires x≠2. Its square root is an absolute value. The logarithm also requires that absolute value to be positive.

Hint 2 · Check solutions against the first line

Exponentiation gives |x+2|=exp(c). Test both candidates against the original exclusions before stating a solution set.

Worked argument and dependencies

The quotient is defined only for x≠2. On that set it equals x+2. The square root of its square is |x+2|, and log requires |x+2|>0. Thus D=ℝ∖{−2,2} and G(x)=log|x+2| for x∈D.

The formula log|x+2| on its natural domain ℝ∖{−2} adds x=2, giving an extension. The formula log(x+2), whose domain is x>−2, both loses the valid inputs x<−2 and adds x=2. It is not the same function on its natural domain.

For real c, the candidates are −2−exp(c) and −2+exp(c). Neither equals −2. The second equals the excluded 2 exactly when c=log 4. Therefore there are two solutions for c≠log 4, and the sole solution −6 for c=log 4.

At 2, log|x+2| tends to log 4, so exactly that assigned value gives a continuous extension. At −2 there is no finite continuous extension: xₙ=−2+exp(−n) belongs to D and tends to −2, while G(xₙ)=−n tends to −∞.

Dependencies: factorization, the principal real square-root identity √u²=|u|, the positive-argument logarithm law, the exponential inverse, continuity, and the sequence criterion for a finite limit.

Optional topology bridge. After continuity, complex exponentials and circle winding, compare the principal-selector clinic and its changed task. The continuous root h(z)=z satisfies h(z)²=f₂(z)=z². It does not satisfy h(z)²=z. State the actual equation before judging a proposed inverse.

Route B · Bounds, winding and global choices

Turn finite samples into a global obstruction

A finite display alone cannot control the path between samples. A stated quantitative bound can supply the missing information. This route asks you to derive that certificate and then use it in a topological existence question.

Check the starting point

Derive |z|≥|w|−|z−w| from the triangle inequality. If |z−w|<|w|, prove that the entire segment from w to z avoids zero. State the continuous-root and logarithm criteria for a nonvanishing map on a parameter circle.

Check and choose a repair

Since |w|≤|z|+|w−z|, rearrangement gives the reverse triangle bound. Along the segment, |w+t(z−w)|≥|w|−t|z−w|>0 for 0≤t≤1. A continuous nth root exists exactly when n divides the winding; a continuous logarithm exists exactly when winding is zero. These criteria concern a circle, so the interval endpoints must agree.

  1. A failed contraction and the optional joint-continuity clinic: find the exact missing condition.
  2. Open Lucent’s moving-triangle lesson over HTTP, or read its source. Start Euler with npm start from the project root for the interactive reader. Compare the counterexample with the proved Lipschitz sampling bound; this focused investigation is sufficient.
  3. A safe segment homotopy and winding invariance: connect a distance estimate to an allowed deformation.
  4. Roots of a general nonvanishing circle map: keep the parameter-circle endpoint condition.

The sampled-loop problem

An unknown continuous closed path γ:[0,1]→ℂ satisfies the following global bound for every s,t∈[0,1], and the stated sample bounds:

|γ(s)−γ(t)| ≤ 16|s−t|,
|γ(j/16)−exp(πij/4)| ≤ 1/100,   j=0,…,16.

Let P linearly join the reference vertices exp(πij/4). Its regular octagon is traversed twice. Identify the parameter endpoints to regard γ as a map f:S¹→ℂ.

  1. Prove the entire path avoids zero and has winding 2.
  2. Classify continuous square roots, fourth roots and logarithms on that parameter circle.
  3. Remove the Lipschitz assumption. Construct two continuous closed paths that fit the same reference data with zero sample error but have different winding. Explain what your certificate needed.
Hint 1 · Introduce a bridge polygon

Let Q join the actual samples γ(j/16). On one interval of length h, compare γ with the convex combination of its endpoint values. Bound that error by 2Lh·u(1−u), then maximize over 0≤u≤1.

Hint 2 · Separate geometry from measurement

First bound γ−Q, then Q−P. Every side of P is at least cos(π/8) from zero. Can a segment from P(s) to γ(s) reach zero under your combined error bound?

Worked certificate and its dependencies

Write h=1/16. At s=(1−u)a+ub inside one sample interval, the endpoint interpolant Q satisfies

|γ(s)−Q(s)| ≤ (1−u)Luh+uL(1−u)h
=2Lhu(1−u) ≤ Lh/2=1/2.

Convex interpolation of endpoint errors gives |Q(s)−P(s)|≤1/100. Hence ||γ−P||∞≤51/100. A side of the inscribed octagon has minimum distance cos(π/8) from zero, so |P(s)|≥cos(π/8)>51/100.

The homotopy H(s,t)=(1−t)P(s)+tγ(s) satisfies |H(s,t)|≥cos(π/8)−51/100>0. It is jointly continuous, and H(0,t)=H(1,t), since both paths are closed. This is a free loop homotopy: its common endpoint may move because γ(0) need not equal P(0)=1.

The argument increases by π/4 along each of P’s 16 sides, giving winding 2. Winding invariance therefore gives wind(γ)=2. The map on the parameter circle has exactly two continuous square roots, no continuous fourth root and no continuous logarithm. Each square root winds once. The roots are not generally ±z, since γ itself is unknown.

Dependencies: the global Lipschitz hypothesis, triangle inequality, convex interpolation, polygon clearance, endpoint identification, winding invariance under free loop homotopy, and the general continuous-root criterion. None is supplied merely by the plotted sample points.

Worked counterexample when the Lipschitz bound is removed

Define φ(s)=−60πs for 0≤s≤1/16, and φ(s)=4πs−4π for 1/16≤s≤1. Both expressions equal −15π/4 at the seam. Let γ̃(s)=exp(iφ(s)). It is continuous, closed, and never zero.

At j=0 its value is 1; at every j=1,…,16, exp(iφ(j/16))=exp(πij/4). Thus γ̃ and the reference polygon P fit the same reference data exactly. The polygon has winding 2. Yet φ(0)=φ(1)=0, so γ̃ has winding zero. The logarithm iφ descends to the parameter circle, and exp(iφ/n) gives a continuous root of every order n≥2. The original Lipschitz bound fails even without differentiation: γ̃(0)=1 and γ̃(1/120)=−i, whose distance √2 exceeds 16/120=2/15. This does not contradict the certificate; it demonstrates why that hypothesis matters.

Review an argument, then reconstruct it later

Check four separate obligations: domain, hypotheses, quantifiers, and justification. A correct numerical candidate does not repair a missing domain. A finite set of samples does not supply a global Lipschitz hypothesis.

On another visit, hide the worked solutions and reconstruct the exceptional value in Route A or the three error estimates in Route B. State what changes when the initial assumptions change. Your notes are ungraded written work; the controls check only their authored finite cases.
