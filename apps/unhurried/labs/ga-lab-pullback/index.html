Pullback matching table

Which pairs (x,y) have matching images in Z, and what makes a mediator unique?

Make a prediction

Choose a pair whose two images disagree, then one whose images agree.

A worked setting

Controls: Finite sets X, Y, Z: X={a,b,c}, Y={u,v,w}, Z={0,1}; Function table f: X → Z: split: 0, 0, 1; Function table g: Y → Z: alternate: 0, 1, 0; Candidate pair (x,y): (a,u)

P has exactly 5 compatible pairs. For candidate (a,u), f(a)=0 and g(u)=0; the singleton cone is compatible, and its unique mediator sends t↦(a,u).

Z={0,1}; f: a↦0, b↦0, c↦1; g: u↦0, v↦1, w↦0. For every compatible cone p,q, m(t)=(p(t),q(t)).

What the result means

In Set, the pullback P is exactly {(x,y)∈X×Y : f(x)=g(y)}. Its projections send (x,y) to x and y. For any compatible cone p:T→X and q:T→Y, the mediator must send each t to (p(t),q(t)); this pair lies in P by compatibility, and the projection equations force uniqueness.

Where the model stops

The table uses three-element X and Y and a two- or three-element Z. The selected pair models a cone from a singleton T. A database join can resemble this matching rule, but bag semantics and missing values are outside this Set model.
