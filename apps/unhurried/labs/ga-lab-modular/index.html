When does a residue have a multiplicative inverse modulo n?

Make a prediction

Compare a coprime residue with a nonzero divisor of a composite modulus.

A worked setting

Controls: Modulus n: 12; Table operation: Multiplication; Integer a, reduced modulo n: 5

5 represents 5 in Z/12Z. gcd(5,12) = 1; additive inverse = 7; multiplicative inverse = 5. Z/12Z is not a field because n is composite.

a × b is reduced to 0,…,11. Euclidean trace: 12 = 2×5 + 2; 5 = 2×2 + 1; 2 = 2×1 + 0; gcd = 1.

What the result means

Bézout’s identity gives a·u + n·v = gcd(a,n). Thus a has an inverse modulo n exactly when gcd(a,n)=1. Addition always has an inverse: −a modulo n. The entire ring Z/nZ is a field exactly when n is prime.

Where the model stops

Moduli are 2–24. The input integer is reduced modulo n; an input at least n is not a separate residue. Modulus 1 is excluded from the field statement.
