What the result means

Both presets are continuous and strictly increasing. Bisection uses opposite signs; Newton uses a tangent at each iterate.

Where the model stops

Residual and root error are separate quantities. Newton rows explicitly stop if the derivative is too small or an iterate escapes the finite model.
