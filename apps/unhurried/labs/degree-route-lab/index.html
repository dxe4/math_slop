Edge degrees and routes

When can one trail use every edge exactly once?

Make a prediction

A nonempty connected edge-bearing graph has an Euler trail exactly when it has zero or two odd-degree vertices.

A worked setting

Controls: Vertices: 4; Edge 1–2: Present; Edge 1–3: Absent; Edge 1–4: Absent; Edge 1–5: Absent; Edge 2–3: Present; Edge 2–4: Absent; Edge 2–5: Absent; Edge 3–4: Present; Edge 3–5: Absent; Edge 4–5: Absent; Construct an Euler trail: Yes

3 edges; 2 odd vertices; edge-bearing part connected. Euler trail exists. Trail: 1→2→3→4.

Σ degree(v)=6=2|E|. Euler trail iff connected edge-bearing part and 0 or 2 odd vertices.

What the result means

Toggle any of the ten possible edges on up to five labeled vertices. The route uses each selected edge once.

Where the model stops

The graph is simple and undirected; loops and parallel edges are excluded. Isolated vertices do not affect the edge trail.
