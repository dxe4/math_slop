Conjecture stress test

What does a tested case tell us about a claim over every nonnegative integer?

Make a prediction

One false case refutes a universal claim; any finite run of true cases leaves it open.

A worked setting

Controls: Claim for all n≥0: n²≤2n; Test through n: 5; Show smallest failure in 0…50: Yes

At n=5: false. Smallest failure in 0…50: n=3.

What the result means

Substitute each tested n into the selected proposition. The first false row, if present, is a counterexample within the searched prefix.

Where the model stops

The domain is all nonnegative integers, while the search stops at 50. A successful finite search is never a proof.
