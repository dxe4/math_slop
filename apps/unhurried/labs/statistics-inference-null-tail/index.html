How surprising is this count under a stated fair-spinner model, and what if many tests are tried?

Make a prediction

Choosing the smallest p-value among more independent tests makes a small value more likely even when all null models hold.

A worked setting

Controls: Null blue chance: 0.5; Spins per test: 12; Observed blue count: 9; Prespecified tail: Upper: at least this many; Independent tests tried: 5; Simulated batches: 300; Random seed: 17

Observed 9/12: exact upper-tail p-value 0.072998. In 300 seeded batches of 5 independent true-null tests, 26 had minimum p ≤ 0.05; exact probability under this discrete model is 0.0927867 (one test: 0.0192871). Minimum-p bins ≤.01 / (.01,.05] / (.05,.2] / >.2: 6 / 20 / 170 / 104.

What the result means

Each prespecified test counts blue outcomes from independent spins. Its exact one-sided binomial tail is computed before independent null tests are simulated.

Where the model stops

The p-value is conditional on the null, never P(null true). Direction must be chosen in advance. Continuous-uniform minimum-p formulas are not exact for discrete binomial tests.
