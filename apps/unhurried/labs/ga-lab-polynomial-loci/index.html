Polynomial zero-set explorer

Which plotted integer points lie exactly on a polynomial zero set, and where is it singular?

Make a prediction

Check the origin on a cusp or node: what happens to both partial derivatives there?

A worked setting

Controls: Polynomial preset: Cusp; Integer window |x|, |y| ≤: 3; Sample x coordinate: 0; Sample y coordinate: 0

cusp: at sample (0,0), F = 0 and ∇F = (0, 0). The sample is a singular zero. Exact named check: F(0,0) = 0² − 0³ = 0; ∇F(0,0) = (0, 0).

F(x,y) = y² − x³. The table lists every verified integer-lattice zero with |x|,|y| ≤ 3; zero tests use exact integer arithmetic.

What the result means

An affine real zero set consists of all (x,y) with F(x,y)=0. For these polynomial presets the displayed residual and gradient are exact at integer inputs. A zero with nonzero gradient is smooth by the implicit-function criterion; a zero with gradient (0,0) is singular.

Where the model stops

The coordinate table searches integer lattice points only in the selected window. It cannot certify absence of real noninteger points or describe the entire real or complex curve. A small numerical residual at an arbitrary decimal point would not by itself establish an exact zero.
