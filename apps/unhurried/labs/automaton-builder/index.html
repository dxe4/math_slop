Finite state machine workshop

What state does a binary word lead to, and is it accepting?

Make a prediction

A complete deterministic table picks exactly one next state for each symbol.

What the result means

Start at q0. Each word symbol selects the indicated transition; the final state decides acceptance. In the accepting mask, 1 marks q0, 2 marks q1 and 4 marks q2.

Where the model stops

The editor has two or three states, a binary alphabet, and words of at most five symbols. A missing or out-of-range transition makes the machine invalid.
