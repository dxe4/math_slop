Area between two honest bounds

How tightly do endpoint rectangles trap area under an increasing curve?

Make a prediction

For x and x² on [0,1], lower ≤ integral ≤ upper, and the gap is exactly 1/n.

A worked setting

Controls: Function: x²; Equal-width rectangles: 4; Sums to emphasize: Both

Both bounds selected. For n = 4, the integral lies in [0.21875, 0.46875].

Each cell has width 1/n; Lₙ ≤ ∫₀¹f(x)dx ≤ Uₙ, with Uₙ−Lₙ = 1/n.

What the result means

On each cell an increasing function lies between its left and right endpoint heights. Adding those rectangle areas gives bounds.

Where the model stops

These endpoint bounds rely on monotonicity. They cannot be transferred to a nonmonotone function without finding cell extrema.
