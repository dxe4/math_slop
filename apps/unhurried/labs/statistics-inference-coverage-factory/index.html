How often does a repeated interval procedure cover one fixed proportion?

Make a prediction

Observed coverage moves around the procedure’s exact finite-model coverage, which can differ from its nominal label.

A worked setting

Controls: Fixed blue proportion: 0.35; Tiles per sample: 30; Nominal coverage: 95%; Repeated samples: 100; Random seed: 17

92 of 100 intervals cover p = 0.35 (observed 0.92). Nominal 95%; exact coverage under this Bernoulli model is 0.946658. First 12 intervals are listed.

Wilson interval: [c − m, c + m], c = (p̂ + z²/(2n))/(1 + z²/n), m = z√[p̂(1−p̂)/n + z²/(4n²)]/(1 + z²/n)

What the result means

Each repetition draws independent Bernoulli tiles with one fixed hidden blue proportion. Wilson score intervals are then checked against that fixed value.

Where the model stops

Wilson intervals have approximate nominal coverage; exact finite-model coverage is enumerated here. The realized interval has no assigned posterior probability.
