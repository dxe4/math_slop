Epsilon-neighborhood tester

When does a chosen neighborhood fit inside a set?

Make a prediction

An open set has a sufficiently small neighborhood around each member; a single failed radius does not make an open set closed.

A worked setting

Controls: Set S: (−1, 1); Test: S itself; Point x: 0; Radius ε: 0.5

At x=0, membership is true and Bε(x) is contained in (−1, 1). This set is open.

Bε(x)=(x−ε,x+ε), ε=0.5. S=(−1, 1). A set is open iff every one of its members has some ε>0 with Bε(x)⊆S.

What the result means

The tester uses exact interval descriptions, including a symbolic preimage under f(x)=x². It checks membership and whether the entire requested open interval lies in a component of the selected set.

Where the model stops

A neighborhood at one point and radius does not by itself establish global openness. The displayed classification follows exact endpoint definitions; decimal inputs are finite browser numbers.
