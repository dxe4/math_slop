Commuting diagram checker

Do the two routes around a square of functions agree for every input?

Make a prediction

Make the selected input agree while another row differs, then test the whole function table.

A worked setting

Controls: Finite-set square preset (f and g): g flips f; Arrow h: B → D: 0↦0, 1↦1; Arrow k: C → D: 0↦1, 1↦0; Inspect input: a

At a, h(f(a)) = 0 and k(g(a)) = 0. The square commutes: both composites agree on all three inputs.

f: a↦0, b↦1, c↦0; g: a↦1, b↦0, c↦1; h: 0↦0, 1↦1; k: 0↦1, 1↦0.

What the result means

The square has A={a,b,c}, B=C=D={0,1}; f:A→B and g:A→C come from the selected preset, while h:B→D and k:C→D are chosen function tables. It commutes precisely when h(f(t))=k(g(t)) for every t in A. One matching element cannot establish equality of functions.

Where the model stops

These are finite sets and total functions with matching domains and codomains. The checker proves equality for this three-element input set only; it does not test arbitrary category-theoretic diagrams.
