Square symmetry composer

Does applying two square symmetries always give another one, and does order matter?

Make a prediction

Try R then F, and compare it with F then R. Follow original corner 1 before inspecting all four corners.

A worked setting

Controls: First chosen symmetry: R — clockwise quarter-turn; Second chosen symmetry: F — fixed vertical flip; Application order: First, then second

Selected: F∘R = FR. Destinations of original corners: 1→1, 2→4, 3→3, 4→2. Inverse: FR; order: 2. Swapping these moves changes the labelled result.

Apply the right-hand move first: FR means R then F. R is a clockwise quarter-turn; F is the fixed vertical flip. Positions 1–4 run clockwise from top left. The table varies the second chosen selector; the application-order control decides which move acts first.

What the result means

Positions 1–4 run clockwise from the top left. R is a clockwise quarter-turn; F reflects across the fixed vertical line; E does nothing. FR means R first, then F. A destination list says where each original corner goes; a diagram places its label in that destination. The eight rigid motions form the square symmetry group. Associativity follows from function composition, rather than from testing the table. Order is the first positive repeat count returning to E.

Where the model stops

Only the eight rigid symmetries of a labelled square are modelled. The composition table is finite evidence; the general associative law is a fact about functions.
