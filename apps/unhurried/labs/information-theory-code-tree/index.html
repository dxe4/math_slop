Code a tiny alphabet

Can a frequently used symbol get a shorter prefix code?

Make a prediction

Huffman merging gives a prefix-free tree whose weighted mean length is at least the entropy.

A worked setting

Controls: A weight: 5; B weight: 3; C weight: 1; D weight: 1; Tie order: Alphabetic; Message: ABCD

Expected code length 1.7 bits/symbol; entropy 1.68548 bits/symbol; Kraft sum 1; prefix-free: yes. ABCD → 011100101 → ABCD.

What the result means

The two lowest current weights merge repeatedly. Left edges are 0 and right edges 1; ties follow the selected order.

Where the model stops

Huffman is optimal among binary prefix codes for these stipulated weights. Entropy is a bound, not generally an achievable integer-bit mean for a finite source.
