Quantifier order grid

Does every person reading a book mean one book is read by everyone?

Make a prediction

The first sentence can be true while the second is false.

A worked setting

Controls: People: 3; Books: 3; Books read by person 1 (bit mask): 1; Books read by person 2 (bit mask): 3; Books read by person 3 (bit mask): 2; Books read by person 4 (bit mask): 0; Focus: Every person has some book

∀person∃book: true. Other order: false.

∀p∃b R(p,b): true (P1→B1; P2→B1; P3→B2). ∃b∀p R(p,b): false (B1 misses P3; B2 misses P1; B3 misses P1).

Use the arrow keys to scroll the diagram horizontally on narrow screens.

What the result means

Each row mask selects books by binary place: 1 means book 1, 2 means book 2, 4 means book 3, and 8 means book 4. Change a mask to toggle its relation cells.

Where the model stops

This finite model can give counterexamples to equivalence. It does not establish statements about every possible relation.
