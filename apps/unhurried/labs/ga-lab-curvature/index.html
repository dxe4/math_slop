Curve curvature microscope

Which parts of a curve calculation change when it is traced faster?

Make a prediction

For a positive speed scale, velocity and acceleration change, while signed curvature at the same geometric point does not.

A worked setting

Controls: Curve: Radius 2 circle; Parameter t: 0.8; Positive speed scale s: 1

γ(u) = (2 cos u, 2 sin u), u = st = 0.8. Signed curvature κ ≈ 0.5; arc length from t=0 is ≈ 1.6.

For regular C² curves, κ = det(γ′, γ″)/||γ′||³; path length from 0 to t is |∫₀ᵗ ||γ′(τ)|| dτ|. Decimal values are rounded.

What the result means

Set u = st with s > 0. The circle is γ(u)=(2 cos u,2 sin u), the parabola is γ(u)=(u,u²/2), and the cusp is γ(u)=(u²,u³). Derivatives are with respect to t; the displayed arc length is accumulated from t=0 along the branch.

Where the model stops

The cusp is not regular at u=0, so neither unit tangent nor curvature is defined there. Values are rounded; appearance on a stretched screen cannot determine curvature.
