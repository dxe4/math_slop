Count the same ballots three ways

Can the same ranked ballots pick different winners under different rules?

Make a prediction

Plurality, Borda, and pairwise majority use distinct information; pairwise rankings can cycle.

A worked setting

Controls: ABC ballots: 3; ACB ballots: 0; BAC ballots: 0; BCA ballots: 3; CAB ballots: 3; CBA ballots: 0; Announced rule: Plurality

9 ranked ballots. Plurality leader(s): A, B, C; Borda leader(s): A, B, C; no Condorcet winner. Strict majority cycle: yes. Under announced plurality rule: A, B, C.

Plurality = first-place votes; Borda = 2×first + 1×second; pairwise A over B = voters ranking A above B

What the result means

Each weighted ballot ranks A, B, C exactly once. Plurality counts first choices, Borda scores 2–1–0, and pairwise comparisons count every voter once per pair.

Where the model stops

These finite ballots illustrate rule differences. Arrow’s theorem concerns a specific set of ranking axioms; it does not declare voting pointless.
