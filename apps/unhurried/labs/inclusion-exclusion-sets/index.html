Overlap ledger

How do signed intersection terms count each member of a union once?

Make a prediction

Every element in at least one set contributes exactly one to the signed sum.

What the result means

Choose a membership pattern for each of twelve labeled elements. A bit marks membership in A, B or C. In two-set mode the C bit is ignored.

Where the model stops

These are finite labeled sets; the table represents counts, not area-proportional Venn geometry.
