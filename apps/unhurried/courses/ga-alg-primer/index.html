Functions and composition

A function assigns exactly one output to each allowed input. Its domain is the set of allowed inputs; its codomain is the declared set containing the outputs. Different inputs may share an output. For f(x)=x² on the real numbers, both 2 and −2 produce 4.

Worked example. Let f(x)=2x+1 and g(x)=x². The expression f(g(3)) first applies g to 3, producing 9, and then applies f to 9, producing 19. Composition writes this as (f∘g)(3).

f(g(3))=f(9)=19

For a composition to be defined, the output of the inside function must be an allowed input for the outside function. Here both functions accept every real number, so that condition holds.

Try one. Compute g(f(3)). Does changing the order preserve the result?

Worked answer

First f(3)=7, then g(7)=49. This differs from f(g(3))=19. Composition generally depends on its order; the circle symbol names the operation, rather than promising that the two orders agree.

Watch the notation. In f(3), the parentheses name the input to f. They do not mean f multiplied by 3. Read the expression from the inside out.

Meet groups through two complete examples

This route uses a square and a modular clock to make one idea concrete: an operation can combine two objects, and the resulting system may have identity, inverses, associativity and closure. You will verify these laws in two finite settings, find a few return times, and build the square's full operation table, including a pair whose order matters. Allow about four hours including reading, calculations, the capstone and a second pass over any uncertain proof. The optional small sittings below give places to pause within that work; one question can be enough for tonight.

Entry recap. A bijection permutes a finite set without duplicating or losing an element. Compose two functions by applying the right one first. Modulo n, two integers are equivalent when their difference is divisible by n; [a] denotes the whole class, not a single chosen integer. A group has an operation with four obligations: closure, associative composition, an identity and an inverse for every element. You need not know general quotient groups or field theory for this route.

Keep the same square throughout: positions 1, 2, 3, 4 run clockwise from the top left. R is a clockwise quarter-turn, F reflects across the fixed vertical line through the centre, and E does nothing. An image list records where each original corner goes. In FR, apply R first and F second; the mirror stays fixed while you move the square.

One small sitting at a time

Choose one attempt, check it, and leave yourself a question for next time. These pauses keep the three lessons, mixed practice and full capstone in the four-hour route. They are not a promise to finish it in five short visits.

1. Follow one corner

Begin the square lesson through its picture and destination table. Before reading the explanation, follow original corner 1 under FR and then under RF. Does swapping the moves change its destination?

Check this sitting

FR takes corner 1 to position 2 under R, then back to position 1 under F. RF takes it to position 2 under F, then to position 3 under R. Thus FR and RF differ. Leave the recall question “Which move acts first in FR?”

2. Explain an undo

Recall which move acts first. Return to the square lesson's group laws. Find the inverses of R and F. Then explain why regrouping three moves differs from swapping two moves.

Check this sitting

R is undone by R³ because four quarter-turns give E. F is undone by F because reflecting twice restores every corner. Regrouping (AB)C as A(BC) keeps the order C, then B, then A, so composition is associative. Swapping R and F changes an order and can change the result. Leave “Does a group have to be commutative?” for next time.

3. Change the objects, keep the laws

Recall that commutativity is not a group requirement. Read the modular-clock lesson, including its check that addition does not depend on representatives. Modulo 7, add [5] and [2] and find the inverse of [5]. Check the same sum using 12 as a representative of [5].

Check this sitting

[5] + [2] = [7] = [0], so [2] undoes [5]. Since 12 − 5 = 7, [12] = [5]; also [12] + [2] = [14] = [0]. The brackets denote a whole remainder class. This example illustrates the lesson's general proof; checking just two representatives would not prove the rule always works. Leave “What takes the place of E in this group?”

4. Count the first positive return

Recall why [0] is the additive identity. Begin the return-time lesson. From [0], repeatedly add [2] modulo 8 until you first get back. Compare that count with the order of F.

Check this sitting

The clock path is [0], [2], [4], [6], [0], so [2] has order 4. The square path is E, F, E, so F has order 2. The initial identity at repeat zero does not count as a positive return. Leave “If F⁶ = E, why is its order not six?”

5. Build a record you can explain

Try the mixed practice before the capstone. For the full table, start with the identity row and one product you can follow on all four corners. Return for the other rows on another evening if you prefer.

The full capstone has 64 products as well as explanations. A completed row is a useful stopping point, not the whole task. Save a question about one uncertain cell so you have a clear place to resume.

Two modules, three lessons

Module 1: Concrete groups

  1. A square as an algebra machine. Begin with actual motions. Record each as a vertex image list and use the function convention fg: apply g, then f. The article proves why eight moves exhaust the possibilities and why function composition supplies associativity.
  2. Clock arithmetic is a group. Replace motions by residue classes and composition by addition. The essential bridge is that two representations of the same class must give the same sum. Work through that well-definedness proof before comparing the two group examples.

After this module, make a two-column comparison. The square identity is the do-nothing motion; the clock identity is [0]. A square rotation is undone by turning back; an additive class [a] is undone by [−a]. Both are groups, but the square's operation may depend on order while modular addition commutes. The group laws do not include commutativity, so that difference does not disqualify the square.

Module 2: Repeated action

  1. How long until a symmetry returns?. Repeated multiplication gives powers of a motion; repeated addition gives multiples of a class. Compare ord(R)=4 for a quarter-turn with ord([2])=4 under addition modulo 8. These are equal return counts in systems with different objects and operations.

Pause at the proof that the powers of one element form a subgroup. It explains why a finite return is guaranteed without asking you to enumerate an entire composition table. In the exercises, distinguish “g6=E” from “ord(g)=6”; the first can hold when the actual first return is two or three.

Mixed practice: move, then count

Find FR's image list by following all four original corners. Apply that combined move twice and find its order. Compare it with RF. Then find the order of [3] under addition modulo 4. Try the calculations before opening the answer.

Worked mixed-practice answer

R has image list 2,3,4,1 and F has 2,1,4,3. Applying R then F gives FR the list 1,4,3,2: it fixes corners 1 and 3 and swaps 2 and 4. Doing that twice fixes every corner, so (FR)² = E. FR is not E because it takes corner 2 to position 4; hence its order is two.

Applying F then R instead gives RF the list 3,2,1,4. Original corner 1 goes to position 1 under FR but position 3 under RF, proving that the products differ. Under addition modulo 4, [3] has successive multiples [0], [3], [2], [1], [0], so its order is four. “Order” means the same least positive return in both settings, even though one process composes motions and the other adds classes.

Build and audit the square table

Write the eight symbols E, R, R², R³, F, FR, FR², FR³, using the same labelled square and fixed vertical mirror as above. Build the eight-by-eight composition table: apply the column move first, then the row move. Identify the identity row and column, the inverse of each element, and one pair whose products differ. Then explain two of the group axioms without citing the table alone. Finally, compare the first-return count of R with that of [1] under addition modulo 4.

Construction hint

Use the lesson's eight destination lists. To fill row R, column F, first use F's list 2,1,4,3, then send each of those positions through R. The result is 3,2,1,4, which matches FR³. Thus RF = FR³. Row F, column R is FR. Following all four corners identifies a whole move; a single corner may fit several moves.

The first row and column show E is the identity. Rotations invert as R↔R³, R²↔R², E↔E; all four reflections are self-inverse, as their diagonal E entries show. Row R, column F is FR³, whereas row F, column R is FR, proving noncommutativity. Closure follows because every table entry is one of the eight, but associativity needs the stronger function argument: (AB)C and A(BC) send each corner i to A(B(C(i))). Inverses also have a geometric explanation: reverse a rigid motion. Finally R returns after four turns; [1] modulo 4 returns after four additions. Their equal orders do not make the two groups identical.

Self-review rubric. A complete response has 64 correctly oriented products, correct inverses and identity, a verified noncommuting pair, two justified axioms and both first-return counts. If a table is transposed, fix the composition convention before judging individual entries. If the table is right but associativity is justified only by inspecting cells, revisit the function proof.

Choose a satisfying stopping point

At a small stopping point, aim to explain one product or return count without guessing from a picture. To complete the full route, work through the three lessons, mixed practice and capstone, and use the rubric above to review both calculations and reasons. The table is a finite record, not a model for every group. You may stop here with a concrete algebra toolkit. The accelerated route adds cosets, homomorphisms, rings and fields, and assumes you want to read longer proofs.
