An accelerated route from fixed choices to strategic reports

This nine-hour route selects seven lessons. It begins with payoff matrices and pure best responses, then solves a two-action mixed equilibrium and compares several ways to count ranked ballots. Its capstone asks for both a game and a manipulable plurality election. The route is accelerated because it concentrates on calculations and counterexamples; repeated games and the full scope of Arrow's theorem are outside this selection. Allow time for each article's exercises and for checking the capstone without looking at its answer first.

Entry recap. A probability-weighted average is p times one outcome plus (1−p) times the other. When comparing two actions, hold the opposing action fixed. A ranked ballot places each option once; in plurality only the first place earns a vote, while Borda assigns points to positions. In an election with tied first-place totals, a specified tie rule is part of the mechanism. These definitions are repaired in their relevant lessons, so the route needs no hidden prerequisite beyond fractions, tables and rankings.

Module 1: Refresh core ideas

  1. Two players, four outcomes makes the order of payoff coordinates reliable. Before proceeding, explain why maximizing the sum of coordinates is a different objective from choosing a best response.
  2. A move that wins every comparison tests a move against each opposing action. Record strict and weak inequalities separately; a tie prevents strict dominance but may permit weak dominance under the lesson's convention.
  3. Stable choices are not always nicest changes the question from “works against every opponent action” to “best response at this proposed pair.” Draw a mark in every cell where a player would stay. A cell with both marks is a pure equilibrium.

The bridge to the next module is uncertainty over the other move. A pure equilibrium might not exist in hide-and-seek. Instead of predicting a fixed opposing action, compute expected payoffs under a probability distribution and choose probabilities that leave the opponent no gain from switching.

Module 2: Work across examples

  1. Why randomize a move? solves two indifference equations, one for each player's support. Verify probabilities lie between zero and one and check every available pure action, rather than stopping after the first equation.
  2. The group can prefer A to B to C to A counts all head-to-head comparisons. This shifts from strategic actions to collective rankings, while retaining the habit of specifying exactly which comparison is being made.
  3. Scoring ranked choices changes the winner counts first places and full rank points on the same ballots. Reconcile Borda's total points with the number of complete ballots.
  4. Sincere ballots can be unstable treats a report as an action. Hold other reports fixed, apply the declared plurality tie priority, and compare the two resulting winners using the voter's true preference.

Here “stable” has different meanings in different models. A Nash equilibrium checks unilateral payoff changes in a specified game. A manipulable ballot profile shows one unilateral report that improves one voter's election outcome. Neither calculation proves that voters or players will in fact choose strategically.

Worked bridge: probability and tally

A hider's payoff table is −3 when hiding L against guess L, 1 for hide L against guess R, 2 for hide R against guess L, and −2 for hide R against guess R. The guesser receives the negative. If hider chooses L with probability p, write its payoff against each pure guess. If guesser chooses L with probability q, write hider's payoff from each pure hide. Separately, three A > B > C voters and two B > C > A voters submit sincere rankings. Calculate plurality first places and Borda scores.

Worked solution

Against guess L the hider expects −3p+2(1−p) = 2−5p; against guess R it expects p−2(1−p) = 3p−2. If guesser plays L with probability q, hide L gives −3q+1(1−q) = 1−4q and hide R gives 2q−2(1−q) = 4q−2. For ballots, plurality gives A three and B two; C gets zero. Borda gives A 3×2 = 6, B 3×1+2×2 = 7, and C 2×1 = 2. The 15 points equal five ballots times three points each. Thus A wins plurality and B wins Borda on those ballots.

Capstone: design and solve a hide-and-seek game and mural vote

Use the hide-and-seek payoffs just stated. Find the equilibrium mixing probabilities and common expected hider payoff, with both indifference equations and valid-probability checks. For the mural, use five voters: two report A > B > C, two report B > C > A, and the fifth truly ranks C > B > A. Plurality counts first places, and tied leaders are resolved A before B before C. Find the sincere winner. Show whether the fifth voter can obtain a preferred winner by reporting B > C > A. Then give the Borda totals on the sincere ballots to compare what the counting rule itself changes.

Capstone model solution

Set 2−5p = 3p−2 to make the guesser indifferent: p = 1/2. Set 1−4q = 4q−2 to make the hider indifferent: q = 3/8. Both lie strictly between zero and one, and there are only two actions per player, so every supported pure action is a best response. Substitution gives hider payoff 2−5/2 = −1/2; guesser receives +1/2. In the sincere mural vote, first places are A = 2, B = 2, C = 1, so A wins by the announced tie priority. The fifth voter prefers B to A. Reporting B > C > A changes counts to A = 2, B = 3, C = 0 and elects B, a profitable manipulation at this profile. On the original sincere ballots, Borda gives A = 4, B = 2+4+1 = 7, C = 0+2+2 = 4. B wins Borda without any strategic report. That difference between rules is separate from the incentive to misreport under plurality.
