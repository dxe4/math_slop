A four-hour sampler of small decisions

This course gives you two bounded skills: read a two-player payoff table and test whether either player would switch alone; count a three-option majority cycle from actual ballots. The game and election use different kinds of input, but both require a disciplined question about whose choice or comparison is being held fixed. Allow roughly four hours for four articles, notes, the mixed practice and the capstone. The route covers selected articles; it does not teach mixed strategies, repeated games or all of voting theory.

Entry recap. In an ordered pair (3,1), the first and second positions belong to different players; order matters. In a ranking A > B > C, A beats C in that person's view even though C is not adjacent to A. A majority among three voters is two or three votes. A best response maximizes one player's own payoff while the other player's action stays fixed. The lessons refresh these ideas locally, so you can begin with tables and simple rankings.

Module 1: A short starting pair

  1. Two players, four outcomes assigns each player a coordinate in every cell. Before continuing, choose a cell and read each player's payoff aloud. The bridge is to compare just one coordinate across cells reached by that player's own change.
  2. A move that wins every comparison uses that coordinate rule to test a stronger claim: one action does at least as well against every opposing action. Write down all cases, including ties. A single counterexample defeats an “every case” assertion.

At this point you can read incentives in a table, but a dominant action need not exist. The next module asks the weaker and often more useful question: once both players have chosen, would either one change alone? This introduces equilibrium without requiring one action to work against every possible opposing move.

Module 2: One useful connection

  1. Stable choices are not always nicest checks a proposed cell from both players' viewpoints. Recreate its best-response markings yourself, then look at the model answer. The central bridge from dominance is quantifier order: Nash fixes the opponent at the proposed action; dominance checks every opponent action.
  2. The group can prefer A to B to C to A switches from payoffs to rankings. Here the fixed object is a pair of candidates, and each voter contributes one comparison. Count all three pairs. The resulting cycle shows why repeated pairwise majorities may fail to make one transitive group ranking.

The game and ballot sections make a useful contrast. In the game, each player's payoff tells us whether an individual wants to deviate from an action pair. In the vote, each person's rank tells us which of two covers they prefer. Neither procedure alone evaluates whether the result is fair or predicts actual behavior.

Worked mixed practice

Row chooses A or B; column chooses X or Y. The payoffs are (A,X) = (2,2), (A,Y) = (0,0), (B,X) = (0,0), and (B,Y) = (1,1). Find every pure Nash equilibrium. Then consider three voters ranking Red > Blue > Green, Blue > Green > Red, and Green > Red > Blue. Count Red versus Blue.

Worked solution

At (A,X), row changing to B earns 0 instead of 2, and column changing to Y earns 0 instead of 2, so neither gains. At (B,Y), row changing to A earns 0 instead of 1, and column changing to X earns 0 instead of 1. These are two equilibria. At (A,Y), row can switch to B and earn 1 instead of 0; column can switch to X and earn 2 instead of 0. At (B,X), analogous improvements exist. For Red versus Blue, voters 1 and 3 prefer Red; voter 2 prefers Blue, so Red wins 2–1. The payoff and ballot calculations both require naming the exact comparison rather than picking an attractive-looking total.

Capstone: create and solve two small models

Use a two-route puzzle with payoffs (Top,Left) = (3,3), (Top,Right) = (0,0), (Bottom,Left) = (0,0), and (Bottom,Right) = (2,2). Give each player's best response to each opposing action and list every pure equilibrium. Then use three cover ballots A > B > C, B > C > A, and C > A > B. Count A versus B, B versus C and C versus A. Decide whether a pairwise majority winner beats every rival. Show all counts, not only the final labels.

Capstone model solution

Against Left, row gets 3 from Top and 0 from Bottom, so Top is best; against Right, row gets 0 from Top and 2 from Bottom, so Bottom is best. Against Top, column gets 3 from Left and 0 from Right, so Left is best; against Bottom, column gets 0 from Left and 2 from Right, so Right is best. The mutual best-response cells are (Top,Left) and (Bottom,Right). Each mismatch has a profitable unilateral switch. For ballots, voters 1 and 3 put A above B, so A beats B 2–1. Voters 1 and 2 put B above C, so B beats C 2–1. Voters 2 and 3 put C above A, so C beats A 2–1. Every option loses to one rival. There is no Condorcet winner, even though each voter has a coherent ranking.

Read payoffsMixed practice and capstone compare the correct player's coordinate: 1 point.
Test deviationsBoth equilibria are justified by all unilateral comparisons: 1 point.
Count majorityAll three 2–1 ballot totals identify their supporting voters: 1 point.
Interpret scopeThe cycle is stated without claiming all ballots cycle: 1 point.

A satisfying stopping point is four justified answers, even if you consult the worked solution. A mark for reading is not a claim of independent mastery. If the equilibrium comparison feels uncertain, repeat the mixed practice with row and column labels reversed and verify that their scores are still read in the correct order.
