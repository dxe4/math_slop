Sets and membership

A set records which objects belong to a collection. In roster notation, braces surround its members: A={1,3,5}. Writing 3∈A says that 3 belongs to A; writing 2∉A says that 2 does not. Repeating a member or changing the listing order leaves the set unchanged.

Worked example. Let B={3,4}. The union A∪B contains every object in either set. The intersection A∩B contains exactly the objects in both sets.

A∪B={1,3,4,5}A∩B={3}

The empty set, written ∅, has no members. A subset C⊆A has all its members in A. The subset may equal the whole set; the symbol does not require a smaller collection.

Try one. With C={1,5}, find C∩B and decide whether C⊆A.

Worked answer

C and B have no common member, so C∩B=∅. Both 1 and 5 belong to A, hence C⊆A. Empty intersection and subset inclusion ask different questions.

Watch the object. The number 3 and the set {3} are different objects. Here 3∈A and {3}⊆A are both true, but they express different relationships.

Functions and composition

A function assigns exactly one output to each allowed input. Its domain is the set of allowed inputs; its codomain is the declared set containing the outputs. Different inputs may share an output. For f(x)=x² on the real numbers, both 2 and −2 produce 4.

Worked example. Let f(x)=2x+1 and g(x)=x². The expression f(g(3)) first applies g to 3, producing 9, and then applies f to 9, producing 19. Composition writes this as (f∘g)(3).

f(g(3))=f(9)=19

For a composition to be defined, the output of the inside function must be an allowed input for the outside function. Here both functions accept every real number, so that condition holds.

Try one. Compute g(f(3)). Does changing the order preserve the result?

Worked answer

First f(3)=7, then g(7)=49. This differs from f(g(3))=19. Composition generally depends on its order; the circle symbol names the operation, rather than promising that the two orders agree.

Watch the notation. In f(3), the parentheses name the input to f. They do not mean f multiplied by 3. Read the expression from the inside out.

Your entry point: routes with types

This four-hour selected gateway is for a reader who knows sets, functions and composition but has never used category language. Its destination is modest and checkable: build one path category, decide whether a finite square commutes, and verify one functor. An arrow always has a source and target. If f:A→B and g:B→C, then g∘f:A→C means f first, g second. This simple type discipline will prevent most early mistakes.

Keep a small written ledger with columns for each arrow's domain, codomain and actual action. When the objects are mere vertices, an arrow can be a route. When the objects are sets, an arrow can be a function. The point of the course is to move between those examples without blurring them. No background in abstract algebra or topology is needed, and this route does not claim to survey category theory.

Module 1: An arrow language

  1. Relationships before ingredients gives a complete path-category proof. Reconstruct its edge-list argument for identities and associativity on a different three-edge graph. The important bridge is that composition describes a route, while equality between distinct routes is not automatic.
  2. Two routes, one result turns a route comparison into an equality of functions. Its four corners are sets and its arrows are value tables. Redraw the square and compute both composites on every source element. This is where a diagram gains a falsifiable meaning: one mismatch settles the question.

These two lessons answer different questions. The first asks whether a legal composite can be formed and why parentheses do not matter. The second asks whether two legal parallel composites are equal. A category may contain parallel arrows that are unequal; a commuting diagram asserts a particular equality after the arrow meanings are supplied.

Module 2: One translation between diagrams

  1. A structure-preserving translation assigns sets to vertices and functions to edges of a path category. To bridge from the square, notice that a functor must send a composite route to the composite of the image functions. Check its identity images too. A table of images is not a functor merely because every row is a valid function.

After this lesson, try saying aloud the types in F(g∘f)=F(g)∘F(f). The left side begins at F(A) and ends at F(C); so does the right. In a free path category, assigning edge functions and defining each path image by composition builds the functor. If one assigns longer-path images separately, one must verify all the composition equations.

Worked mixed practice

Take the path category on A→B→C, with edges a and b. Assign F(A)={0,1}, F(B)={u,v}, F(C)={red,blue}; let F(a) send 0↦u, 1↦v and F(b) send u↦red, v↦blue. What must F(b∘a) be? At 0 it is red, and at 1 it is blue, by composition. F sends each empty path to the identity of its assigned set. Thus the functor laws hold: the only two-edge path has the forced table, while identity compositions add no change. Now compare a second direct arrow c:A→C assigned 0↦red, 1↦red. The routes b∘a and c do not commute as function arrows, since they disagree at 1. They remain distinct paths in the source category regardless of their assigned functions.

Capstone: build and audit a four-object diagram

Task. Use four objects A,B,C,D with arrows f:A→B, g:B→D, h:A→C and k:C→D. Choose finite sets and explicit function tables. Check whether the square commutes, and explain why the associated free path category is associative. Finally define a functor from that path category to Set by your tables, including the two A→D paths.

Model construction and solution. Let A={0,1}, B={u,v}, C={p,q}, D={red,blue}. Define f(0)=u, f(1)=v; g(u)=red, g(v)=blue; h(0)=p, h(1)=q; k(p)=red, k(q)=blue. At input 0, g(f(0))=red=k(h(0)); at input 1, g(f(1))=blue=k(h(1)). The functions A→D agree on the entire two-element domain, so the square commutes. The free path category has two distinct arrows g∘f and k∘h from A to D; their images under the functor happen to be equal. Its composition is associative because concatenating edge lists in either grouping gives the same list, and empty lists are identities. Send each vertex to its named set, each edge to its displayed function, each longer path to the corresponding function composite, and each empty path to the identity function. This defines a functor, including both path images. A commutative square in Set does not silently identify those two paths in the free source category.

Rubric. Award two points for four typed arrows with complete tables, two for checking every source input and a correct verdict, two for the empty-path and edge-list associativity explanation, two for correct functor identity and path images, and two for distinguishing equal image functions from distinct source paths. A counterexample square can also earn full credit if its mismatch and functor are checked correctly.
