A four-lesson route from symbols to codewords

This route takes a specified four-symbol source and asks two practical mathematical questions: how uncertain is its next symbol, and can its symbols be written as a binary stream that a reader can decode without separators? Work through four linked lessons and the short problems below. Allow about 210 minutes: roughly 92 minutes of article reading, 60 minutes reproducing calculations and drawing a tree, and 58 minutes for the mixed practice and capstone. Stopping after the capstone gives a complete introduction to this finite example, not a survey of all information theory.

Entry recap. A probability distribution is a list of nonnegative weights totaling one. A weighted average multiplies each outcome value by its probability, then adds. log₂8=3 means 2³=8, while log₂(1/8)=−3. In this route, every entropy and code length is measured in bits. If a symbol has probability zero, it contributes zero to entropy, but it must still receive a codeword if the protocol may need to transmit it.

Read in two deliberate modules

A short starting pair

  1. How surprising is a symbol? Start with the outcome value −log₂p. Recalculate the printer's four surprises and explain why two independent events with probabilities 1/4 and 1/8 have a combined 5 bits of surprise. The independence assumption is the bridge to treating a sequence as a product of probabilities.
  2. Average surprise in a mystery bag Now multiply each outcome's surprise by its chance. This converts information about one observed event into a before-the-draw average. Recreate the 7/4-bit four-symbol entropy by hand; check that the four source weights sum to one before accepting the average.

The first pair supplies two distinct numbers: a rare symbol's surprise and the whole source's entropy. A rare glyph can have a large surprise but a modest contribution to the average. Keep that distinction when you leave a bag of individual tiles and begin to encode a stream.

One useful connection

  1. Two clues can repeat information A repeated card shows why two symbols do not automatically double uncertainty. Write the copying and independent tables before using the chain rule. This lesson bridges single draws to sequences; the pair distribution, rather than the individual marginals alone, determines joint entropy.
  2. Make a code no symbol can confuse Switch from measured uncertainty to an actual transmission rule. Test a proposed list of binary words for prefix freedom, calculate its Kraft sum, and compute the weighted average length. A codeword is a concrete path in a tree, so integer lengths may exceed a noninteger entropy.

The prefix-code article gives a decoding guarantee and a feasibility condition for lengths. This primer does not prove optimal coding for all probability lists; that is the Huffman lesson in a longer route. The bridge here is enough to compare the entropy of a source with the average length of a valid code built for it.

Mixed practice before the capstone

Consider a source with probabilities U=1/2, V=1/4, W=1/4. Propose U→0, V→10, W→11. Its entropy is (1/2)·1 + 2(1/4)·2 = 3/2 bits. The code is prefix-free because 0, 10 and 11 are leaves with no listed word above another. It has Kraft sum 1/2+1/4+1/4=1 and weighted length (1/2)·1+2(1/4)·2=3/2 bits. The stream 01110 parses as 0|11|10, or UWV. Explain why parsing 01|110 would be invalid: neither fragment is a codeword.

For a separate two-card model, let X be a fair bit and let Y copy X exactly. Their individual marginals are fair, but the pair supports only 00 and 11, so its entropy is one bit, not two. These bits are unrelated to the U,V,W source above. This check prevents a familiar mistake: adding marginal entropies without asking how the variables depend on one another.

Capstone: invent a four-symbol alphabet

Use symbols A, B, C, D with probabilities 3/8, 3/8, 1/8, 1/8. Treat these as stipulated chances. Calculate each symbol's surprise and the source entropy. Draw or describe a prefix tree, provide codewords, calculate the Kraft sum and average code length, and encode then decode the three-symbol message DAB. Finish by stating what this single example does and does not show about entropy and code length.

Model solution

The probabilities sum to one. A and B each have surprise log₂(8/3)≈1.415 bits, while C and D each have 3 bits. The weighted entropy is 2(3/8)log₂(8/3)+2(1/8)3 = 3−(3/4)log₂3≈1.811 bits. One valid tree puts A at the root's 0 leaf; on branch 1, B is the next 0 leaf; branch 11 splits into C and D. Its words are A→0, B→10, C→110, D→111. No word prefixes another. Kraft sum is 1/2+1/4+1/8+1/8=1. Average length is (3/8)1+(3/8)2+(1/8)3+(1/8)3=15/8=1.875 bits per symbol, greater than entropy by about 0.064 bit. DAB becomes 111|0|10, so its stream is 111010; reading from the start recovers D, A, B. The gap appears because probabilities 3/8 cannot match integer codeword depths exactly. This valid tree illustrates a code, but the primer alone has not proved it optimal.

Self-review rubric. A complete solution has normalized probabilities, four correct bit surprises, an entropy computed with weights, a code with no word above another, Kraft sum at most one, a weighted average length, and a round-trip encode/decode check. If your entropy is an unweighted average, return to the second lesson. If your stream has more than one parse, return to the tree in the fourth. You can stop when you can reproduce these checks with fresh probabilities; reading a model answer is support, not certification of mastery.
