Make a small model that another person can check

This four-hour sampler uses a paper mural and a dot composition to practise the most portable modelling habits: state the question, attach units, show assumptions, perturb an input, and record enough of a generative rule to repeat its output. It covers four selected lessons, not all of mathematical modelling. A comfortable stopping point is a one-page mural estimate and a reproducible four-dot design with a candid note about uncertainty.

Entry recap. A function assigns an output to an input. A rectangle's area is width × height; multiplying metres gives square metres. If a tile side is given in centimetres, convert it to metres before dividing areas. A probability is a number from 0 to 1. A seed is an initial state for a specified algorithm; it does not turn its deterministic output into evidence of true randomness. The linked lessons supply their own local refreshers, so you may enter from this page without another course.

Allow about 95 minutes for the four readings, 55 minutes for their exercises, 45 minutes for the mixed practice here, and 45 minutes for the capstone and review: 240 minutes in all. Pause after the first module if you can already write an assumption card and test a unit.

Follow two connected modules

A short starting pair

  1. A model begins with a question. Make a list of what the mural answer is for, what dimensions are measured, and what is deliberately omitted. Its area quotient is an estimate under tile-layout assumptions. Before continuing, explain why “150” alone is not a complete purchasing instruction.
  2. Build a miniature gallery that scales. Use the same mural to distinguish a uniform two-dimensional enlargement from a change in just one dimension. The article proves the s² area factor from two scaled lengths. Write one example in which that factor does not apply.

The bridge is a dimensional question. The first lesson checks that area divided by tile area produces a count; the second asks how both areas change. If the mural gets uniformly larger while tile size stays fixed, its required count grows as s². If tile size also scales by s, both numerator and denominator grow as s² and the ideal count stays the same. State which quantity is being held fixed.

One useful connection

  1. Which assumption matters most? Return to the tile rule and change one parameter at a time. Keep the continuous estimate separate from whole packs. Its elasticity −2 for tile side is local; calculate a finite change before using it for a purchase.
  2. Rules, randomness and repeatability in art. Here the output is a dot field rather than a tile count. The same modelling cycle still applies: specify a rule, record a seed, calculate a checkable feature, and disclose if you selected a preferred preview. The iid uniform model is a probability assumption, not a quality guarantee.

The second bridge is about reproducibility. A fixed mural formula gives the same count from the same dimensions; a fixed pseudorandom algorithm and seed give the same sequence. Their uncertainties differ: uncertain measured dimensions affect the count, whereas an ideal random-art distribution describes possible unselected drawings. Do not call an aesthetically selected picture an untouched random draw.

Mixed practice: what changes?

A 2 m by 1.5 m panel uses 25 cm square tiles with 10% extra for waste. First compute the continuous procurement estimate. Then enlarge only the width by 20%, leaving height, tile size and waste unchanged. State why the area factor is 1.2 rather than 1.2². Finally explain whether a seed by itself is enough to reproduce a program-generated dot field.

Worked mixed-practice answer

The panel area is 3 m² and each tile is 0.25²=0.0625 m². The ideal coverage count is 3/0.0625=48; with 10% extra, the continuous estimate is 48×1.1=52.8, so at least 53 whole tiles if they can be bought singly. Enlarged width is 2.4 m, giving area 2.4×1.5=3.6 m². Only one length changed, so the area factor is 1.2. The new estimate is 3.6/0.0625×1.1=63.36, rounded up to 64 tiles. A seed alone is insufficient: the generator, update rule, coordinate conversion and version must also be specified.

For a useful self-check, take the ratio 63.36/52.8=1.2 before rounding. If your calculation gives 1.44, you have applied uniform scaling to a one-direction stretch. This is a model-assumption error rather than an arithmetic error.

Capstone: a mural beside a dot study

Prepare a small exhibit card. The panel is 2 m by 1.5 m, with 25 cm square tiles and a 10% waste allowance. Report the continuous estimate and whole-tile order. Recalculate for a 20% waste allowance and for 20 cm tiles, one change at a time. For an adjacent four-dot study, use the deterministic rule zₙ₊₁=(5zₙ+1) mod 97, seed z₀=2, and take successive updated values in pairs, dividing the first by 97 for x and the next by 97 for y. List the four pairs. Explain what the rule establishes and whether these four dots satisfy an iid uniform model exactly.

Model solution

The baseline is 3/0.0625×1.1=52.8, so order 53 individual tiles. At 20% waste it is 48×1.2=57.6, hence 58. At 20 cm tile side it is 3/0.04×1.1=82.5, hence 83. The seed updates to 11, 56, 87, 48, 47, 42, 17, 86. Thus the pairs are (11/97,56/97), (87/97,48/97), (47/97,42/97), and (17/97,86/97). The specified recurrence and seed reproduce these exact coordinates. Four deterministic outputs do not satisfy a stochastic iid statement by themselves; one could use a pseudorandom generator as an approximation for visual work, but its distributional quality would need separate checks. The mural count also omits grid cutting, reuse and pack sizes. Those limits belong on the exhibit card.

Outcome to practice map and rubric

OutcomeEvidence
Assumptions and unitsThe mural card converts 25 cm to 0.25 m and names waste and cutting assumptions.
SensitivityThe two one-input changes use the same base formula and show unrounded values.
Seeded artThe eight recurrence values and four pairs can be recreated by another reader.

Score one point for each row's correct evidence and one point for an honest limitation note; four points make a complete sampler capstone. If a row is weak, revisit that linked lesson and revise the card. The stopping point is a clear artefact, not a claim of proficiency in every modelling field.
