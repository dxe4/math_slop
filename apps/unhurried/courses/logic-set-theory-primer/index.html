Four readings of a club rule

A club organizer says, “Every member has read a book, and if a member recommends a book, the club discusses it.” There is plenty to unpack: which book can depend on the member, “and” combines two requirements, and an if–then rule has one specific kind of violation. This primer gives those words precise, finite meanings. Its bounded outcome is to evaluate compound statements, read two quantifier orders, and compare finite sets. It is a complete first route through these skills, not a claim to cover all of logic or set theory.

Allow roughly three hours including the four linked lessons, your own tables, mixed practice, and the capstone. You need only be comfortable reading short sentences and checking a few cases. The articles explain their notation locally. For this course, let a club have people M={Ada, Ben} and books B={Atlas, Beacon}; a relation Read(m,b) is true when member m read book b. One row per person and one column per book makes each truth condition visible.

Module 1: Truth values

  1. What and, or, and not actually say. Build the four rows for two propositions. Keep inclusive “or” in mind when both inputs are true.
  2. The surprising truth of if–then. Mark the single violating row, then distinguish the rule from its converse.

The bridge is this: a club policy can be split into small propositions for a particular person and book. Let P mean “Ada recommends Atlas” and Q mean “the club discusses Atlas.” P→Q says the policy is broken only if Ada recommends Atlas and the club does not discuss it. If Ada does not recommend Atlas, the policy says nothing about whether Atlas is discussed for another reason. Write this row before judging the policy as a whole.

Module 2: People and objects

  1. A set is its members, not its drawing. Use membership to compare the club's lists of members and books; ignore roster order and repetitions.
  2. Every person has a book: whose book?. Move from one person-book statement to quantified sentences, retaining the domain of each variable.

The module bridge changes the unit of work. A truth table evaluates one choice of P and Q; a relation table records many choices of person and book. “Every member read some book” requires a Yes in each person row. “Some book was read by every member” requires one book column filled with Yes. The first requirement can hold without the second. A set supplies the domain over which a quantifier ranges, so writing M and B is part of formalizing the sentence, not optional decoration.

Worked mixed practice

Take M={Ada, Ben} and B={Atlas, Beacon}. Suppose Ada read Atlas only and Ben read Beacon only. First evaluate ∀m∈M ∃b∈B Read(m,b): Ada uses Atlas, Ben uses Beacon, so it is true. Next evaluate ∃b∈B ∀m∈M Read(m,b): Atlas fails on Ben and Beacon fails on Ada, so it is false. The table is a countermodel to the mistaken assertion that the two sentences mean the same thing.

Now let P mean “Ada recommends Atlas” and Q mean “the club discusses Atlas.” Suppose P is true and Q false. P∨Q is true because at least one input is true; P∧Q is false because both are required; P→Q is false because this is its unique violating row. This one situation combines three connective checks with a concrete policy decision. It is not enough to say “the rule feels broken”; name the antecedent and consequent truth values.

Finally compare rosters A={Ada,Ben} and C={Ben,Ada,Ada}. Their printed lists differ, but the corresponding sets are equal: every distinct member of A is in C and every distinct member of C is in A. This two-direction check is the same discipline as checking all relevant rows or columns in the relation table.

Capstone: translate a policy and expose a misreading

The exact club policy is: “Every member has read at least one book from B. If a member recommends a book from B, the club discusses that book.” Let Rec(m,b) and Disc(b) mean recommendation and discussion. Write the policy with M and B as domains. Build a complete two-member, two-book Read table that satisfies the first clause but refutes the interpretation “there is one book every member has read.” Then choose one recommendation and discussion situation that violates the second clause. State whether “Ada did not recommend Atlas, but Atlas was discussed” violates it.

Capstone hint

Use one different book in each person row. The policy's second clause is universal over both members and books; its violation needs Rec true and Disc false for one pair.

Model solution

The policy is [∀m∈M ∃b∈B Read(m,b)] ∧ [∀m∈M ∀b∈B (Rec(m,b)→Disc(b))]. Make Read(Ada,Atlas) and Read(Ben,Beacon) true and the other two Read cells false. Each member row has a witness, so the first clause is true. Neither book column has two Yes cells, so ∃b∈B ∀m∈M Read(m,b) is false. Set Rec(Ada,Atlas)=true and Disc(Atlas)=false; that pair makes its implication false and therefore violates the second clause. If Ada did not recommend Atlas but it was discussed, the implication for that pair is true: its antecedent is false and its consequent true. The policy may still fail elsewhere, so that single case does not establish the whole universal clause.

Self-review rubric. Award one point each for naming both domains, translating the two clauses with the correct quantifier order, giving all four Read cells, identifying the failed shared-book columns, specifying a true-antecedent/false-consequent violation, and explaining the nonviolating case. A full response earns six points. If your answer only gives symbols, add a witness or failed cell; if it only gives a story, add the exact scoped sentence.

A stopping point you can test

You have completed this primer when you can take an ordinary club sentence, state its domains, identify its witnesses or violations, and defend one truth value with a complete small table. That is a useful independent skill. If you want to continue, the accelerated route adds systematic negation, function inverses, and equivalence classes. Its extra work depends on writing short proofs, not merely recognizing a correct row.
