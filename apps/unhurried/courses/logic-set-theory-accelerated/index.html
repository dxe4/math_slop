Sets and membership

A set records which objects belong to a collection. In roster notation, braces surround its members: A={1,3,5}. Writing 3∈A says that 3 belongs to A; writing 2∉A says that 2 does not. Repeating a member or changing the listing order leaves the set unchanged.

Worked example. Let B={3,4}. The union A∪B contains every object in either set. The intersection A∩B contains exactly the objects in both sets.

A∪B={1,3,4,5}A∩B={3}

The empty set, written ∅, has no members. A subset C⊆A has all its members in A. The subset may equal the whole set; the symbol does not require a smaller collection.

Try one. With C={1,5}, find C∩B and decide whether C⊆A.

Worked answer

C and B have no common member, so C∩B=∅. Both 1 and 5 belong to A, hence C⊆A. Empty intersection and subset inclusion ask different questions.

Watch the object. The number 3 and the set {3} are different objects. Here 3∈A and {3}⊆A are both true, but they express different relationships.

Restore proof fluency through small structures

This route is for someone who remembers elementary set notation but wants to recover exact scope and short proofs. Its bounded outcomes are to negate quantified claims correctly, prove a two-sided inverse criterion, and partition integers by an equivalence relation. The six linked lessons cover distinct tools: propositional implication, quantified choices, negation, finite subsets, functions, and relations. Plan roughly five active hours including the proofs and capstone; the article reading itself is shorter.

A quick recap supplies the needed language. A function f:A→B assigns one output in B to each a∈A; injective means no collision and surjective means no unused target. A relation R on a set is a yes/no condition on ordered pairs. For integers, a≡b (mod n) means n divides a−b. A universal claim needs every instance; an existential claim needs one witness. If any of these words is rusty, read its article first and return here.

Module 1: Scope

  1. The surprising truth of if–then. Recover the false row P true, Q false and the valid contrapositive.
  2. Every person has a book: whose book?. Use separate versus common witnesses to test the order of ∀ and ∃.
  3. Negating an everyone claim. Negate from the outside inward and translate the final witness pattern back into words.

The bridge through this module is a proof obligation. “Every timetable slot has some trained volunteer” means ∀s∃v T(v,s); refuting it requires one slot s for which every volunteer v fails T(v,s). One absent volunteer at one slot is too weak. If someone proposes a single volunteer who covers all slots, that is the stronger ∃v∀s T(v,s). To test an assertion, first settle its quantifier order, then negate it exactly. An implication inside the condition can have its own false row; do not swap its converse for its negation.

Module 2: Structure

  1. Why n objects have 2^n subsets. Prove the finite bijection with binary strings rather than relying on a list of examples.
  2. When can a function be undone?. Prove both directions of the inverse–bijection result.
  3. Grouping by an equivalence relation. Check reflexivity, symmetry, and transitivity before naming classes.

The bridge here is reversible description. A subset of a finite set has a unique bit string and every bit string names one subset. A bijective function has a unique input for each codomain output, so an inverse exists. An equivalence relation groups objects whose classes are identical or disjoint. These are different claims: a relation need not be a function, and a function need not be invertible. The common habit is to prove that each proposed object is well defined and that no cases are omitted.

Worked mixed practice

Suppose three timeslots S={0,1,2} each need a volunteer from V={Ada,Ben}. Let T(Ada,0), T(Ada,2), and T(Ben,1) be true, with other pairs false. Then ∀s∈S∃v∈V T(v,s) is true, while ∃v∈V∀s∈S T(v,s) is false. The exact negation of the first claim would be ∃s∈S∀v∈V ¬T(v,s), which is false in this table. The exact negation of the common-volunteer claim is ∀v∈V∃s∈S ¬T(v,s), which is true: Ada misses slot 1 and Ben misses slots 0 and 2.

Now encode the coverage set of each volunteer as a subset of S in order 0,1,2. Ada gets 101 and Ben gets 010. These bit strings are not a claim that the volunteers are functions from S; they merely encode two subsets. There are 2³=8 possible coverage subsets. If we define f:V→℘(S) by sending a volunteer to the set of slots covered, f is injective in this example because the two coverage sets differ. It is not surjective onto all eight subsets: ∅, for example, is unused. Thus a two-sided inverse on the whole power set does not exist. Changing the codomain to the two observed coverage sets makes f bijective. This connects quantifiers, power sets, and inverses without conflating them.

Capstone: a modular timetable partition

An event repeats every four days. On ℤ define a~b iff 4 divides a−b. Prove that ~ is an equivalence relation, identify all four classes, and give a short “if and only if” proof that [a]=[b] exactly when 4 divides a−b. Then give two semantic countermodels: one showing ∀s∃v T(v,s) does not imply ∃v∀s T(v,s), and one showing an implication is not generally equivalent to its converse. Work with explicitly named finite domains and truth values.

Capstone hint

For transitivity, add two divisible differences. For class equality, use a∈[a] and transfer membership. For countermodels, two slots and two volunteers suffice; a converse failure needs P false and Q true.

Model solution

Reflexivity holds because a−a=0=4·0. If a−b=4k, then b−a=4(−k), giving symmetry. If a−b=4k and b−c=4l, then a−c=4(k+l), giving transitivity. Every integer has exactly one remainder 0, 1, 2, or 3 on division by 4, so the classes are [0], [1], [2], and [3]. If 4|(a−b), then a~b. For any x~a, adding x−a and a−b gives x~b, so [a]⊆[b]; symmetry gives the reverse inclusion, hence equality. Conversely, if [a]=[b], reflexivity puts a in [a], hence a in [b], so a~b and 4|(a−b). For the quantifier countermodel, take S={morning, evening}, V={Ada,Ben}, and only T(Ada,morning) and T(Ben,evening) true. Each slot has a volunteer but no one covers both. For the converse countermodel, let P=“it rains” be false and Q=“event moves indoors” true; P→Q is true while Q→P is false.

Self-review rubric. Give one point each for the three relation properties with their algebra, four distinct remainder classes, both directions of the class iff, a complete relation countermodel with named domains, and a truth assignment that separates implication from converse. An eight-point answer is complete. If you only list classes, add a proof that overlap cannot produce a fifth class; if you only draw a timetable, write which quantified sentence each row or column satisfies.

When this route is complete

You can stop when you can state a claim's domain, negate it without changing its meaning, prove a relation's three properties, and explain why a proposed inverse covers every target. These are reusable proof habits, not a full course in mathematical logic. The deep route takes a narrower step into infinity and a limit on unrestricted set formation; it assumes you can already write arguments like the ones above.
