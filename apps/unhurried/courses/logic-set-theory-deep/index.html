Two infinite claims with different proof boundaries

Finite subsets can be encoded by binary strings. Infinite binary sequences also look like strings of choices, but no natural-numbered list catches them all. A second boundary appears when someone tries to turn every condition on sets into a set: the self-membership condition yields Russell’s contradiction. This course studies those two arguments closely. Its bounded outcomes are a written diagonal proof and an exact explanation of why unrestricted comprehension fails. It does not claim to survey cardinal arithmetic, all of axiomatic set theory, or philosophical foundations.

Allow roughly seven active hours if you work the four articles, write the proof variants without looking, and complete the capstone. You should already know the meanings of ∀, ∃, a function, a bijection, and proof by contradiction. A short recap: a bijection pairs each object on one side with exactly one object on the other; a surjection from ℕ onto a set would enumerate that set. For a set A, ℘(A) consists of its subsets. A binary sequence is a function from positive integers to {0,1}. The course makes its main assumptions explicit in each proof.

Module 1: Finite foundations

  1. Why n objects have 2^n subsets. Reconstruct the map between subsets and length-n binary strings. Verify injectivity and surjectivity separately, including the empty set.
  2. When can a function be undone?. Recover the proof that a two-sided inverse exists exactly for a bijection, and watch how the codomain affects surjectivity.

The bridge is the meaning of “every.” The finite power-set proof pairs every subset with one string and every string with one subset, because there are finitely many coordinate positions. For infinite sequences, each object has infinitely many coordinates. You may still define a bitwise map, but you cannot conclude that a list indexed by ℕ is complete merely by having displayed many rows. Surjectivity is a quantified claim: for every candidate sequence there must be some row where it appears. The diagonal proof targets precisely that claim.

As a warm-up, take A={p,q,r}. The map S↦(indicator of p∈S, indicator of q∈S, indicator of r∈S), where each indicator is 1 when membership holds and 0 otherwise, sends {p,r} to 101. Its inverse sends 011 to {q,r}. A finite list of all eight strings is possible. Notice that the inverse here changes representation, not the number of objects. The later theorem says something stronger about infinite sequences: no proposed list indexed by ℕ can be surjective onto all of them.

Module 2: Infinite constructions

  1. Why no list catches every binary sequence. State the assumed enumeration and define one bit dₙ opposite the nth bit of row n. Finish with an arbitrary row k.
  2. The collection that cannot be a set. Identify unrestricted comprehension, substitute the proposed set into its own defining condition, and locate the restricted alternative's extra domain condition.

These arguments both use a constructed object, but their conclusions differ. Diagonalization starts with an arbitrary list of valid binary sequences and constructs another valid sequence absent from it. Russell’s paradox starts with an overly broad existence rule and derives a contradiction, so that rule must be rejected. In the first proof, the new object exists by an explicit coordinate rule. In the second, the supposed set's existence is exactly the assumption under test. Do not describe both results as “self-reference means infinity is impossible.” That sentence identifies neither hypothesis nor conclusion.

Worked mixed proof practice

Suppose someone lists binary sequences as a⁽¹⁾, a⁽²⁾, … and says row 17 might be the sequence obtained by flipping diagonal bits. Define dₙ=1−aₙₙ for every n. At position 17, d₁₇=1−a₁₇,₁₇, so d₁₇ differs from row 17's seventeenth bit. Thus row 17 cannot be d. The same sentence works with any positive integer k in place of 17. This is the quantified step that a finite display cannot supply. Repeated rows do not help the list: each repeated occurrence is still defeated at its own index.

Now replace infinite sequences with finite strings. An attempted imitation might say “flip the nth bit of row n.” If row n has fewer than n bits, that instruction is undefined. Finite strings actually can be enumerated by length: first the empty string, then 0 and 1, then 00, 01, 10, 11, and so on. The set of strings of each fixed length is finite, and any particular finite string appears at its length's stage. This is a counterexample to the overbroad slogan “binary strings cannot be listed.” The precise word infinite does essential work.

For the set boundary, let A be an existing set and define R_A={x∈A:x∉x}. Substituting x=R_A is permitted and yields R_A∈R_A iff (R_A∈A and R_A∉R_A). If R_A∈A, contradiction follows, so the safe conclusion is R_A∉A. Restricted separation does not guarantee that R_A belongs to A. By contrast unrestricted comprehension removes the x∈A condition and yields R∈R iff R∉R outright. The two formulas look close but have different logical consequences. A proof must retain the domain condition through substitution.

Capstone: audit a proposed complete list

A writer claims to have a complete list L of infinite binary streams, numbered by positive integers. The first visible rows are 0000…, 1010…, 1100…, and 1111…. The writer argues: “I can inspect a thousand rows, so if my diagonal stream is not there it might be the next row; eventually I will add it.” Review this argument. Construct the stream missed by the entire proposed list, show its first four bits from the displayed rows, and prove it differs from every row. Then explain why a finite table is not the proof. Finally assess the separate claim “the collection of all objects that do not contain themselves is a set,” naming the principle required and the contradiction it causes. State one restricted formulation that avoids the immediate contradiction without claiming to prove a whole axiom system consistent.

Capstone hint

Use dₙ=1−aₙₙ, then challenge row k at bit k. For the set claim, write the membership biconditional before substituting the new set for x; for a restricted version, retain x∈A.

Model solution

Let aₙₙ denote the nth bit of row n in L and define dₙ=1−aₙₙ for every positive integer n. The displayed diagonal bits are 0, 0, 0, and 1, so d begins 1110. For any row k, its kth bit is aₖₖ while d's kth bit is 1−aₖₖ; these differ. Hence d differs from row k, and because k was arbitrary, L omits d. There is no natural-numbered next row after all natural-numbered rows. If the writer revises the enumeration so d appears at some finite index, the diagonal argument applies afresh to that revised list and constructs another missed stream. A thousand visible rows only permit a thousand checked positions, while the definition for all n and the arbitrary-k argument establish the infinite claim. For the separate set claim, unrestricted comprehension would supply R={x:x∉x} with x∈R iff x∉x for every set x. Substituting x=R yields R∈R iff R∉R, impossible under classical two-valued logic; therefore that unrestricted formation principle fails. Restricted separation instead forms R_A={x∈A:x∉x} from an already given set A. Its defining biconditional includes x∈A, so substituting R_A yields R_A∈R_A iff (R_A∈A and R_A∉R_A), which implies R_A∉A rather than a contradiction. This observation does not establish the consistency of any complete set theory.

Self-review rubric. Award one point for the explicit sequence rule, one for the correct first four bits, two for the arbitrary-row proof, one for explaining the finite-grid limitation, one for rejecting the “just append it” repair, two for the unrestricted-comprehension contradiction with its named assumption, and two for preserving the domain condition in restricted separation. Ten points require all proof boundaries. A numerical prefix without a quantified row argument earns at most two points for the sequence part; a contradiction that omits its formation assumption does not earn the set part.

Know what each proof establishes

You can stop here when you can write the diagonal proof from an arbitrary alleged enumeration without leaning on a finite picture, and when you can say exactly which set-formation assumption yields Russell’s contradiction. Those are substantial, bounded proof accomplishments. They do not grant a general verdict about every infinite set or a consistency proof for axiomatic set theory. If you revisit the material later, try stating every proof's domain and quantifier order before writing its construction.
