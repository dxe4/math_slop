Powers and logarithms

For a positive integer n, aⁿ means a multiplied by itself n times. For example, 3⁴=3×3×3×3=81. For a nonzero base, a⁰=1 and a⁻ⁿ=1/aⁿ. A negative exponent describes a reciprocal.

Worked example. With base 3, the logarithm asks which exponent produces a positive input. Since 3⁴=81, log₃(81)=4. More generally, for a positive base b different from 1, log_b(x)=y means bʸ=x, with x positive.

34=81log3(81)=4

Multiplying powers with the same base adds their exponents: 2³×2²=2⁵. For positive inputs, this becomes the logarithm rule log₂(uv)=log₂(u)+log₂(v). It is a rule about a product.

Try one. Find log₂(1/8) and explain the negative sign.

Worked answer

Because 2⁻³=1/2³=1/8, the logarithm is −3. For a base larger than 1, inputs between 0 and 1 have negative logarithms.

Watch the operation. Logarithms do not generally turn a sum into a sum: log₂(2+2)=2, while log₂(2)+log₂(2)=2 happens to agree in this case. Using 2+4 instead gives log₂(6), which differs from 1+2=3 because 2³=8.

How uncertain is the next draw?

Before a mystery bag produces its next tile, we know its rules but not its outcome. A bag with equally likely red and blue tiles feels less predictable than one that gives red almost every time. Entropy makes this comparison precise by averaging the surprise of each possible draw. The same formula also tells us the ideal average number of bits associated with the source, although it does not promise a code with exactly that length for each individual symbol.

Background capsule. For a finite list of outcomes, an expected value is a probability-weighted average: multiply each value by its chance and add. The surprise of a positive-probability event is −log₂ p bits. We take 0 log₂ 0 to mean its limit, zero, because p log₂ p tends to zero as p approaches zero from above. That convention lets an impossible outcome contribute nothing to an average; it does not give an observed impossible event finite surprise.

Three bags with two colors

Worked example. Bag A has a fair red-blue split, 1/2 each. Each observed color has 1 bit of surprise, so the average is 1 bit. Bag B has red chance 3/4 and blue chance 1/4. Red contributes (3/4)log₂(4/3), about 0.311 bit, while blue contributes (1/4)·2 = 0.5 bit. Its entropy is about 0.811 bit. Bag C always produces red. Red has zero surprise, and the impossible blue contributes zero to the average, giving entropy zero.

The blue tile in B is more surprising than either tile in A, but B's overall uncertainty is lower because blue is uncommon. Do not confuse the largest possible single surprise with its weighted average. If a finite sample from B happens to contain three red and one blue tile, its sample frequencies happen to match the model; a different four-draw sample need not.

Average surprise and a binary maximum

H(X)=−∑xp(x)log2p(x)

Exact finite claim. For a binary source with probabilities p and 1−p, entropy lies between 0 and 1 bit. Its maximum 1 occurs at p = 1/2; its minimum 0 occurs at p = 0 or 1. For 0 < p < 1, differentiating h(p) gives h′(p) = log₂((1−p)/p). It is positive below 1/2 and negative above 1/2, proving the interior maximum. Continuity with the zero-term convention gives the endpoint values. This derivation uses calculus only for the maximum; the entropy calculation itself requires no calculus.

The word bit specifies base two. Changing to natural logarithms multiplies every entropy by ln 2 and changes the unit to nats. For a larger alphabet, the analogous maximum is log₂(number of possible symbols) under a uniform distribution; that general statement needs a separate concavity argument, so the derivative just given proves only the binary case. Entropy measures uncertainty under known probabilities; it does not by itself measure meaning, value, or the accuracy of a guessed probability model.

Work with averages

Exercise 1. A source emits A with chance 1/2, B with 1/4, and C or D with 1/8 each. Calculate its entropy exactly in bits. Identify the contribution from A separately.

Hint for exercise 1

The four surprises are 1, 2, 3, and 3 bits. Multiply by the matching probabilities.

Full solution to exercise 1

The weighted terms are (1/2)·1 = 1/2, (1/4)·2 = 1/2, and two copies of (1/8)·3 = 3/8. Their sum is 1/2 + 1/2 + 3/8 + 3/8 = 7/4 bits. A alone contributes 1/2 bit. Averaging the four surprises without weights would give 9/4 bits and answer a different question.

Exercise 2. A reader claims that adding a symbol with probability zero must increase entropy because the alphabet is larger. Take a fair binary source and add a third symbol that never occurs. Find the new entropy and assess the claim.

Hint for exercise 2

Use the zero-term convention and keep the original two probabilities unchanged.

Full solution to exercise 2

The new distribution is (1/2, 1/2, 0). Its entropy is (1/2)·1 + (1/2)·1 + 0 = 1 bit, exactly as before. Merely naming an impossible symbol does not create uncertainty. The three-symbol upper bound log₂ 3 applies when three symbols can carry positive probability, with equality only for a uniform distribution across those three.

Stop at a bounded interpretation

Entropy is average self-information for a specified random variable. It is zero when its outcome is certain and, for a binary variable, at most one bit. It may be a noninteger even though a single fixed binary codeword has an integer length. The relation between entropy and actual average code length requires coding assumptions, treated in the prefix-code lesson. If a model is learned from a small sample, substituting its frequencies into the entropy formula introduces sampling error and often downward bias; that issue has its own lesson.

To test understanding, explain why a 1% event can be very surprising while the binary source containing it has low entropy. The rare event contributes only one hundredth of its large surprise to the average. The MIT information and entropy text supplies the standard finite-source definition and coding context. All bag numbers, table entries, and exercises on this page are original calculations from stipulated distributions.
