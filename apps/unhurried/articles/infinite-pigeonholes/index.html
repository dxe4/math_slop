Can a proper part match the whole?

Number hotel rooms 1, 2, 3, and so on. Move the guest in room n to room 2n. Every guest gets a new even-numbered room, no two guests collide, and every even-numbered room receives someone. The even rooms are a proper subset of all rooms, yet this assignment matches the two collections exactly. That is the first surprising feature of infinite sets we will prove, without claiming that every infinite set behaves the same way.

If you came from the short infinity discovery, this is the same doubling rule. Here we give names to its two checks and see why the stated target collection matters.

Two checks for a matching

Let ℕ+ = {1, 2, 3, …}, the positive whole numbers; the plus sign excludes zero. Let E = {2, 4, 6, …}, the positive evens. A function assigns one allowed output to every allowed input. Its domain is the input collection, and its codomain is the stated target collection.

Injective means no collisions: different inputs never share an output. Surjective means no gaps in the target: every member of the codomain is reached. A bijection passes both checks. The notation f(n) means the output of the rule f at input n, rather than multiplication.

Make a pairing, then check its coverage

Worked example. The first five pairs under f(n) = 2n are 1 ↦ 2, 2 ↦ 4, 3 ↦ 6, 4 ↦ 8, and 5 ↦ 10. The table suggests a regular matching, but its first five rows cannot cover infinitely many inputs or outputs. The general rules do that. If two inputs a and b have the same output, 2a = 2b, so a = b. For any even positive output e, the definition of E says e = 2k for some positive integer k; choose that k as input.

Finite intuition suggests that a proper subset has fewer members; for finite sets it does. The hotel pairing shows why that test does not transfer to infinite sets without modification. One still has to specify the two sets exactly: “all integers” and “positive even integers” would require a different pairing.

Prove both directions of the match

f:ℕ+→E,f(n)=2n

Read the display as “f takes positive whole numbers to positive evens, and its output at n is twice n.” The arrow between the sets specifies the domain and codomain.

Theorem. The function f is a bijection from the positive integers onto the positive even integers.

  1. Every input gets an allowed output. For any positive whole number n, twice n is positive and even. Thus the rule really does take inputs in ℕ+ to outputs in E.
  2. No collisions: injectivity. Suppose two inputs a and b have the same output. Then 2a = 2b. Divide by two to get a = b. So different inputs cannot collide.
  3. No missed target: surjectivity. Choose any positive even number e. By the meaning of even, e = 2k for some positive whole number k. Input k therefore has output e. In symbols, e ∈ E means “e belongs to E.”

Both matching checks hold. The proof covers every allowed input and target, not just the five rows in the table.

We say two sets have the same cardinality when a bijection pairs them. Therefore ℕ+ and E have the same cardinality, even though 1 lies in the first set and not the second. “Same cardinality” does not mean “same members”; that distinction prevents a common misunderstanding. This is a claim about the specified infinite sets and a specified map. It does not settle whether the real numbers can be listed by positive integers; Cantor’s diagonal argument addresses that different question.

One failure case is the rule g(n) = 4n from ℕ+ to E. It is injective but not surjective onto all positive even integers: 2 has no positive whole-number input giving it as output. Solving 4n = 2 would require n = 1/2. Such an input, when it exists in the domain, is called a preimage. If we changed the codomain to {4, 8, 12, …}, the same rule would be surjective. The rule and the target collection both belong to the claim.

Check collision and coverage

Exercise 1. Let O = {1, 3, 5, …}. Show that h(n) = 2n − 1 is a bijection from ℕ+ to O.

Hint for exercise 1

Solve 2a − 1 = 2b − 1, then express an arbitrary positive odd output in the same form.

Full solution to exercise 1

If h(a) = h(b), then 2a − 1 = 2b − 1, so a = b; this proves injectivity. Every positive odd integer o equals 2k − 1 for a unique positive integer k, so h(k) = o; this proves surjectivity. Thus h is a bijection.

Exercise 2. Is j(n) = n + 1 a bijection from ℕ+ to ℕ+? Give a precise failure if not.

Hint for exercise 2

Which positive integer cannot appear as an output?

Full solution to exercise 2

The map is injective: a + 1 = b + 1 implies a = b. It is not surjective onto ℕ+, because output 1 would require input 0, which is outside the domain. Therefore it is not a bijection between the stated sets.

One pairing, checked completely

The rule n ↦ 2n, read “n is sent to twice n,” pairs every positive integer with exactly one positive even integer and covers every target. That proves equal cardinality for these sets despite proper containment. A finite table is a picture, not the proof; injectivity and surjectivity are the proof obligations.
