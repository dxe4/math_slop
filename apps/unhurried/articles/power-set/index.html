Why n objects have 2^n subsets

Sets and membership

A set records which objects belong to a collection. In roster notation, braces surround its members: A={1,3,5}. Writing 3∈A says that 3 belongs to A; writing 2∉A says that 2 does not. Repeating a member or changing the listing order leaves the set unchanged.

Worked example. Let B={3,4}. The union A∪B contains every object in either set. The intersection A∩B contains exactly the objects in both sets.

A∪B={1,3,4,5}A∩B={3}

The empty set, written ∅, has no members. A subset C⊆A has all its members in A. The subset may equal the whole set; the symbol does not require a smaller collection.

Try one. With C={1,5}, find C∩B and decide whether C⊆A.

Worked answer

C and B have no common member, so C∩B=∅. Both 1 and 5 belong to A, hence C⊆A. Empty intersection and subset inclusion ask different questions.

Watch the object. The number 3 and the set {3} are different objects. Here 3∈A and {3}⊆A are both true, but they express different relationships.

Counting choices

Begin by naming one complete outcome. If you choose one of three drinks and then one of two snacks, an outcome is a drink–snack pair. Each drink has two snack choices, so there are 3×2=6 pairs. This counts combinations of choices; it does not require a probability model.

Worked example. Arrange three distinct postcards in a row. There are three choices for the first place, two remaining choices for the second, and one for the last. The result is 3×2×1=6 arrangements, written 3!.

3!=3×2×1=6

For a positive integer n, n! multiplies every integer from 1 through n. The convention 0!=1 counts the single empty arrangement. Factorials count arrangements of distinct objects when each is used exactly once.

Try one. How many two-letter codes can you make from A, B and C when repetition is forbidden?

Worked answer

Choose the first letter in three ways and the second in two ways, giving six codes: AB, AC, BA, BC, CA and CB. If repetition were allowed, the second position would have three choices too, giving nine.

Watch the rule. If different first choices allow different numbers of second choices, count those branches separately and add. A single fixed product needs the stated number of options at every stage.

Include it or skip it

Suppose a lunch menu has three optional extras: olives, herbs, and lemon. A selection can include any collection of these extras, including none and all three. The question “How many selections?” becomes a set question once order is irrelevant and each extra may be chosen at most once.

For a set A, its power set ℘(A) is the set of all subsets of A. A subset may be empty or equal to A. If A has n distinct members, choose a fixed order a₁,…,aₙ only for bookkeeping. To each subset S assign a binary string whose ith bit is 1 when aᵢ∈S and 0 otherwise. A binary string is a sequence of 0s and 1s. This is the local prerequisite capsule.

We will prove that this correspondence is a bijection and therefore |℘(A)|=2ⁿ for a finite n-member set. “Bijection” means a pairing in which every object on either side has exactly one partner. The proof is finite; infinite power sets need a separate argument and are not described by an ordinary finite exponent.

Write the eight selections

Worked example. Take A={o,h,l}, abbreviating olives, herbs, lemon. Fix the order o,h,l. The string 101 means include olives and lemon but skip herbs; it corresponds to {o,l}. The string 000 corresponds to ∅, and 111 corresponds to A itself.

Every subset of a three-element menu
BitsSubset
000∅
001{l}
010{h}
011{h,l}
100{o}
101{o,l}
110{o,h}
111{o,h,l}

The eight rows are not just a pattern to extrapolate. Each selection has one membership answer for each of the three distinct extras, so it produces one row. Conversely, each row tells us exactly which extras to include, so it produces one subset. This two-way recovery is the reason no selection is counted twice and no selection is missed.

The finite power-set theorem

Exact statement. If A is a finite set with |A|=n, where n is a nonnegative integer, then |℘(A)|=2ⁿ. For n=0, A=∅ and ℘(A)={∅}, which has one member, matching 2⁰=1.

|℘(A)|=2n

Complete finite proof. List the distinct elements as a₁,…,aₙ. Define F(S) as the length-n string with bit i equal to 1 exactly when aᵢ∈S. If F(S)=F(T), each aᵢ is in S exactly when it is in T, so S=T; thus F is injective. Given any binary string b₁…bₙ, take S={aᵢ:bᵢ=1}; then F(S) is that string, so F is surjective. Hence F is bijective. There are two independent bit choices in each of n positions, making 2ⁿ strings, and therefore 2ⁿ subsets.

A failure case appears if the menu allows two servings of the same extra. The set {o,o} is just {o}; it cannot record “two olives portions.” With three possible quantities 0, 1, or 2 per extra, the choices would be 3³, assuming independent limits, and their objects would be quantity vectors rather than subsets. The theorem’s distinct, include-or-skip assumptions matter.

Another easy confusion is ∅ versus {∅}. The first has no members; the second has one member, namely the empty set. For A=∅, the power set is {∅}, not ∅. This boundary case tests whether “all subsets” includes the empty subset, as it must.

Encode and count

1. Let A={a,b,c,d} in that order. What subset corresponds to 0101? How many subsets include a but exclude d?

Hint for question 1

Fix the first and fourth bits, then count the free middle bits.

Full solution to question 1

0101 corresponds to {b,d}. For subsets with a included and d excluded, the bits are 1??0. Each ? is independently 0 or 1, yielding 2²=4 subsets: {a}, {a,b}, {a,c}, and {a,b,c}.

2. Someone claims a two-element set A has only three subsets because “choosing none is not a choice.” Refute the count and explain the boundary case.

Hint for question 2

List the subsets of {u,v}.

Full solution to question 2

For A={u,v}, ℘(A)={∅,{u},{v},{u,v}}, which has four members. The empty set is a legitimate subset because every member of ∅ lies in A vacuously. Excluding it changes the problem to counting nonempty subsets, which would give 2²−1=3.

The listing and binary strings agree on every case because the inverse construction recovers each subset. A count alone would not show that correspondence; it could accidentally count the wrong objects.

A subset is a string of decisions

For a finite set of n distinct objects, each subset corresponds to one length-n binary string, so there are exactly 2ⁿ subsets. We proved both directions of the pairing and checked n=0. This result concerns finite n; a separate diagonal argument later shows an important difference for an infinite collection of binary decisions.

A satisfying stopping point is to encode a subset and decode it again. That reversible translation is a simple example of the bijections used throughout mathematics.
