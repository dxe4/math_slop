What does the word require?

A definition is a test with exact conditions. A number being called even does not mean that it looks familiar, ends in a preferred digit, or appeared in a list of examples. It means that the number can be written as twice an integer. The phrase “an integer” matters: halves such as 3/2 do not qualify as witnesses. Today the task is small and complete: decide whether given integers satisfy a definition, and explain each answer by showing either a witness or why no witness is possible.

Background capsule. Integers include negative whole numbers, zero, and positive whole numbers. A witness is a value that makes an existential condition true. The symbol ∃ means “there exists,” and ⇔ means “if and only if”: both directions of the statement are required. We will use arithmetic and these meanings locally; no previous proof course is needed.

Look for the hidden integer

Worked example. The formal definition is that an integer n is even exactly when there is an integer k with n = 2k. For 18, choose k = 9; the equality 18 = 2·9 is a certificate that anyone can check. For −14, choose k = −7. Negative values do not require a new rule. For 0, choose k = 0. The witness need not be positive.

Now try 19. Solving 19 = 2k would require k = 19/2, which lies strictly between 9 and 10 and is not an integer. Thus 19 is not even. Notice the different jobs: to establish evenness we produce one admissible witness; to establish failure we rule out every admissible witness. A guess such as “I tried k = 9 and it failed” is insufficient, because another integer might work.

The two directions of a definition

n is even⇔∃k∈ℤ:n=2k

Read the line aloud

“An integer n is even if and only if there is an integer k such that n equals two times k.” The set symbol ℤ names all the integers; ∈ means “belongs to,” and the colon means “such that.” Writing 2k is shorthand for 2 × k. The letter k is a name for the witness you need to find, rather than another fact you are expected to know. It can change with n: 18 uses 9, while −14 uses −7. The definition does not ask for one witness that works for every integer.

Exact claim. For every integer n, this equivalence is the criterion for evenness. The forward direction says that if n is even, an integer witness exists. The reverse direction says that whenever an integer witness exists, n is even. Here the equivalence is a definition, not a theorem discovered by testing. It licenses both uses without requiring a further proof of the vocabulary. The calculations above justify particular classifications by substitution and by showing why 19/2 is outside the allowed set.

A useful change of words is “2 divides n.” Divisibility by 2 is itself defined through an integer multiplier, so it states the same condition. But changing the domain changes the question. If k were allowed to be any real number, every integer would equal 2 times some real number, including 19 = 2·9.5. The integer restriction therefore carries the mathematical content. A frequent failure is to quote the formula while silently widening the set from which the witness is chosen.

We have classified three integers and stated the general criterion. We have not yet proved broad facts about sums or products of even numbers. Such a proof starts by introducing witnesses for the inputs and then constructs a witness for the result; the direct-proof lesson develops that move.

Use the witness test

Exercise 1. Decide whether −22 and 23 are even. Supply an integer witness for any true claim and explain a false one without relying on a last-digit rule.

Hint for exercise 1

Divide each candidate by 2 and check whether the quotient is an integer.

Full solution to exercise 1

−22 = 2·(−11), and −11 is an integer, so −22 is even. If 23 = 2k, then k = 23/2 = 11.5. No integer equals 11.5, so the required witness does not exist and 23 is not even.

Exercise 2. Someone writes, “Every integer is even because n = 2(n/2).” Locate the exact mistake, then decide whether 0 is even.

Hint for exercise 2

Ask whether the parenthesized value always belongs to ℤ.

Full solution to exercise 2

The displayed arithmetic equality is true, but n/2 need not be an integer; for n = 1 it equals 1/2. That is a counterexample to the proposed argument and claim. For n = 0, the choice k = 0 is an integer and 0 = 2·0, so 0 is even.

Keep the domain attached

To use a definition, identify its subject, its conditions, and the set from which each variable may come. A single witness establishes an “exists” statement; a missing witness must be justified across the full permitted domain. The even-number example is complete at this scale. Next, direct proof will use two witnesses to make a new one, while testing a conjecture will explain why examples alone cannot establish a statement about every integer.
