Can the group chase its own tail?

Three club members rank three possible book covers, A, B and C. Each person's list is internally consistent: if they put A above B and B above C, they put A above C. Yet the group's pairwise majority comparisons can form a circle. Counting this example shows why “let the majority settle each pair” does not always produce a complete ranking with a top choice.

Background capsule. A ranking A > B > C means A is preferred to B, B to C, and therefore A to C by that individual. In a pairwise contest between A and B, a voter supports whichever of those two appears higher on their ballot, even if their favorite is C. With three voters there is no pairwise tie if everyone ranks each pair strictly. We assume one ballot per voter, equal weights, and no abstentions.

Worked example. For A versus B, voters 1 and 3 rank A above B; voter 2 ranks B above A. Thus A beats B, 2–1. For B versus C, voters 1 and 2 rank B above C, while voter 3 ranks C above B. Thus B beats C, 2–1. For C versus A, voters 2 and 3 rank C above A, while voter 1 ranks A above C. Thus C beats A, 2–1. Every contest has a clear majority, yet the winners form A > B > C > A.

This is an exact tally from the displayed ballots. Each voter ranks transitive preferences, so the cycle does not arise from any voter contradicting themselves. It appears only after taking the three separate majority votes. If an agenda asks A against B first and then that winner against C, C beats A in the final. If it asks B against C first and then that winner against A, A beats B in the final. The agenda can matter even though the ballots are unchanged.

Why the cycle blocks a top-ranked option

Writing x ≻M y when a strict majority ranks x above y, the displayed profile establishes:

A≻MB,B≻MC,C≻MA

A strict ranking that is transitive cannot contain this loop: from A above B and B above C, transitivity would require A above C, contrary to C above A. The proof of the cycle consists of the three 2–1 counts; the proof of its incompatibility with a transitive ranking is that one contradiction. This is a counterexample to the universal claim that pairwise majority always yields a transitive social ranking. It is not a proof that every ballot profile cycles.

A Condorcet winner would beat every other option head to head. None exists here: A loses to C, B loses to A, and C loses to B. Other profiles can have a Condorcet winner. For instance, if all three voters rank A first, A defeats both B and C regardless of their lower ranks. The pairwise rule answers a different question from plurality, which counts only first places; in our cyclic profile plurality yields a three-way first-place tie.

Work from the rankings

1. Calculation. Change voter 3's ballot to A > C > B, leaving the other two ballots as shown. Count all pairwise contests. Is there still a cycle?

Hint for exercise 1

For each pair, list the voters who place the first named option above the second.

Full solution to exercise 1

A beats B by voters 1 and 3 versus voter 2, so 2–1. A beats C by voters 1 and 3 versus voter 2, also 2–1. B versus C is supported by voters 1 and 2 for B, voter 3 for C, so B beats C 2–1. The majority order is A > B > C, a transitive ranking. A is the Condorcet winner. One changed ballot can remove the cycle.

2. Explanation. In the original profile, a member proposes “choose the winner of A versus B, then compare it with C.” Who wins? What if the club first compares B versus C, then the winner with A?

Hint for exercise 2

Use the three pairwise results already counted; the final ballot is another head-to-head contest.

Full solution to exercise 2

First A beats B, then C beats A, so C wins the first agenda. In the second agenda B beats C, then A beats B, so A wins. These results do not alter any voter's ranking; they reflect the cycle plus a sequential elimination rule. The claim concerns these two agendas on this particular profile, not all sequential elections.

Majority needs a rule for cycles

Pairwise majority is decisive on each pair in this three-voter example, but the separate decisions do not combine into a transitive whole. A club that wants one winner must specify what happens with a cycle, a tie, or a chosen agenda. Different specifications can produce different winners while using the same sincere ballots.

Failure case. A 2–1 cycle is possible here because the rankings are split in a particular way. It is not inevitable. A common first choice defeats every rival, and the modified exercise produced a clear top option. The lesson identifies a limitation of unrestricted pairwise majority, not a universal defect of voters.
