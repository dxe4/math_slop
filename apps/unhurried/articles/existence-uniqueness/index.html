Finding an answer and ruling out rivals

When dividing 23 objects into boxes of 5, we can fill four boxes and leave 3 objects. That gives 23 = 5·4 + 3. A mathematical statement about quotient and remainder has two jobs: show that a suitable pair exists, and show that no different suitable pair exists. We will carry out a small construction for one number, then prove existence and uniqueness for any integer dividend and any positive divisor. The existence argument uses well-ordering: every nonempty set of nonnegative integers has a least member.

Background capsule. The division form is a = bq + r, where a, q, and r are integers, b is a positive integer, and 0 ≤ r < b. The last inequality selects the standard remainder; without it, many pairs solve the equation. Absolute value |x| is the nonnegative distance of x from 0. These definitions and integer arithmetic suffice for the uniqueness proof.

Build one pair, then try to build another

Worked example. For 23 and divisor 5, repeated subtraction gives 23 − 5 − 5 − 5 − 5 = 3, so q = 4 and r = 3. This is an explicit existence witness for this case. The tempting alternative 23 = 5·3 + 8 fails the bound because 8 is not less than 5. Likewise 23 = 5·5 − 2 fails because the remainder is negative. The bound is not decoration; it selects the canonical pair.

Worked example: a negative dividend. For dividend −7 and divisor 5, the equation is −7 = 5(−2) + 3. The remainder remains between 0 and 4 even though the dividend is negative. Choosing −7 = 5(−1) − 2 would violate the standard remainder condition. These examples show how the convention works; they do not prove that an admissible pair exists for every integer.

Why a valid pair exists and is unique

a=bq+r,0≤r<b

Uniqueness theorem. For a fixed integer a and positive integer b, at most one integer pair (q, r) satisfies this equation and bound. Proof. Suppose both a = bq + r and a = bq′ + r′ meet 0 ≤ r, r′ < b. Subtract the equations: b(q − q′) = r′ − r. The right side has absolute value less than b, since both remainders lie in the interval from 0 to b − 1. The left side is an integer multiple of positive b. Its only possible value with absolute value less than b is 0. Thus q − q′ = 0, and then r′ − r = 0. The pairs are identical.

This argument proves at most one, not at least one. Existence proof. Let S be the set {a − bq : q ∈ ℤ, a − bq ≥ 0}. It is nonempty: take q = −|a|. Because b ≥ 1, the resulting value a + b|a| is nonnegative. By well-ordering, S has a least member r, obtained from some integer q. Thus a = bq + r and r ≥ 0. If r ≥ b, then r − b = a − b(q + 1) would be a smaller nonnegative member of S, contradicting minimality. Therefore r < b. This supplies an admissible pair for every integer dividend; combined with the uniqueness proof, it proves exactly one pair exists. Well-ordering is the explicitly used integer principle.

If the bound is removed, uniqueness is false: 23 = 5·4 + 3 and 23 = 5·3 + 8 are distinct solutions. The algebra alone does not isolate a remainder. This counterexample explains exactly which hypothesis the proof uses.

Check both obligations

Exercise 1. Find the standard quotient and remainder for −17 divided by 6. Check the equation and remainder bound explicitly.

Hint for exercise 1

Look for a multiple of 6 just below −17, so the remainder is nonnegative.

Full solution to exercise 1

−17 = 6(−3) + 1. Thus q = −3 and r = 1. The equality holds because −18 + 1 = −17, and 0 ≤ 1 < 6. This constructs a valid pair for this input; the uniqueness theorem says there is no other valid pair.

Exercise 2. A student writes 31 = 7·4 + 3 and 31 = 7·3 + 10 and calls this a counterexample to uniqueness. Explain the error and give the unique standard pair.

Hint for exercise 2

Check the upper bound on each proposed remainder.

Full solution to exercise 2

Both equations are arithmetically true, but the second has remainder 10, which violates 0 ≤ r < 7. The first pair (q, r) = (4, 3) meets both conditions, so it is the standard pair. The uniqueness theorem applies only to pairs satisfying the complete definition.

Two jobs, one precise conclusion

We constructed quotient–remainder pairs in examples, used well-ordering to prove a valid pair always exists, and proved that no two valid pairs can exist for fixed inputs. If a claim says “exactly one,” ask separately where its object comes from and why competitors are impossible. Infinite bijections use a related discipline: check both halves of a function claim.
