Does the route affect the work?

A force field assigns an arrow to each point. The work along a route adds the force component in the direction of travel. In some fields only endpoints matter; in others two routes between the same endpoints have different totals. The distinction is calculable, not merely visual.

Background capsule. A parametrized path r(t)=(x(t),y(t)), a≤t≤b, lists positions in travel order. Its velocity is r′(t)=(x′(t),y′(t)). The dot product F·r′ measures the field component along motion, with a sign: moving against a force contributes negative work. A scalar potential φ has gradient ∇φ=(φx,φy); its change between endpoints can be found by ordinary substitution.

Two routes through one field

Worked example. Let F(x,y)=(y,x), from A=(0,0) to B=(1,1). The direct route r(t)=(t,t), 0≤t≤1, has F(r(t))=(t,t) and r′=(1,1). The dot product is 2t, so work is ∫₀¹2t dt=1.

Take a broken route: first (t,0), 0≤t≤1, then (1,t), 0≤t≤1. On the horizontal leg F=(0,t), velocity (1,0), and work is 0. On the vertical leg F=(t,1), velocity (0,1), and work is ∫₀¹1 dt=1. Total work is again 1. This agreement has a reason: F=∇(xy), so a potential φ(x,y)=xy increases from 0 to 1 on both routes.

Contrast G(x,y)=(−y,x). On the direct route, G(t,t)=(-t,t), orthogonal to (1,1), so work is zero. On the broken route the horizontal leg again gives zero, but the vertical leg gives G(1,t)=(-t,1) dotted with (0,1), so work is one. Same endpoints no longer guarantee same work.

Separate route shape from traversal speed. Reparameterize the direct segment as r(s)=(s²,s²), 0≤s≤1. For F=(y,x), substitution gives F(r(s))=(s²,s²) and r′(s)=(2s,2s), so the work is ∫₀¹4s³ ds=1 again. The walker starts slowly and speeds up, but follows the same oriented segment once. The velocity factor in the integral compensates for that changed timing. Reversing orientation changes the answer's sign; a change of speed preserving orientation does not. Merely integrating the field values without the velocity would lose this distinction.

Parameter formula and endpoint rule

Exact statement. For a continuous field F along a piecewise C¹ path r, its line integral is defined by the parameter formula below. If φ is C¹ on an open set containing the entire path and F=∇φ there, then the line integral equals φ(r(b))−φ(r(a)). This follows from the chain rule on each smooth path piece; intermediate endpoint terms cancel when the pieces are added.

∫CF·dr=∫abF(r(t))·r′(t)dt

Why does the formula reflect work? Partition the path into short segments Δr. Over one segment a continuous force is approximately F(r) and work approximately F(r)·Δr. Summing and refining gives the parameter integral because Δr≈r′(t)Δt. That motivation does not by itself prove all limiting details; the displayed integral is the precise definition we use.

Reversing a path reverses its integral: the velocity changes sign under reversed parametrization. In a gradient field, a round trip has zero work because start and end coincide. The converse needs conditions. A field can have zero scalar curl wherever defined and still give nonzero circulation around a hole; see the punctured-plane example. Checking curl locally is insufficient for a global potential on an arbitrary domain.

Compute and interpret work

1. Calculation. Let H(x,y)=(2x,2y) and r(t)=(t,t²), 0≤t≤1. Compute work and then identify a potential.

Hint for question 1

Substitute the path first; r′=(1,2t).

Worked solution for question 1

H(r(t))=(2t,2t²), so H·r′=2t+4t³. Its integral is [t²+t⁴]₀¹=2. A potential is φ=x²+y², whose endpoint change is φ(1,1)−φ(0,0)=2. The two methods agree.

2. Explanation. A path from A to B has work 3 in a continuous field. What is the work along exactly the same path traversed backward? Does this establish path independence?

Hint for question 2

Track the sign of velocity; then ask whether another geometric route was tested.

Worked solution for question 2

The reversed path has work −3, because its displacement direction is reversed at each point. This says nothing about other routes from A to B. Path independence requires every pair of admissible routes between the endpoints to have the same work, or equivalently every closed admissible loop to have zero circulation.

A path calculation with a test

Parametrize each piece, substitute F, dot with velocity, and integrate with travel direction intact. If you can exhibit a C¹ potential on the whole region containing the route, endpoint subtraction replaces the calculation. If you have only a zero-curl calculation, first inspect the domain for holes and the path for singularities before claiming a potential.
