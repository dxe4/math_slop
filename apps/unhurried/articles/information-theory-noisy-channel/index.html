Probability and conditioning

A probability model names the possible outcomes and their probabilities. An event is a collection of outcomes. In a finite model where every outcome is equally likely, an event's probability is its number of outcomes divided by the total number.

Worked example. Roll a fair six-sided die labelled 1 through 6. The event “greater than 3” has outcomes {4,5,6}, so its probability is 3/6=1/2. If you learn that the result is even, only {2,4,6} remain possible. These three outcomes are equally likely under the condition, and two of them are greater than 3.

P(greater than 3∣even)=23

The vertical bar reads “given.” Conditioning restricts the relevant outcomes and renormalizes their probabilities. The event you condition on must have positive probability for this ordinary ratio definition.

Try one. Given that the die result is odd, what is the probability it is less than 4?

Worked answer

The possible odd results are {1,3,5}. Two of them, 1 and 3, are less than 4, giving probability 2/3. The denominator counts the conditioned possibilities.

Watch the assumption. Counting outcomes equally works here because the die is fair. For unequal probabilities, add the assigned probabilities of the relevant outcomes.

What survives a fickle bit switch?

Suppose a device accepts a zero or one, then flips it with a fixed chance ε. A displayed bit is evidence about the input, but the amount of evidence depends on both the device and the distribution of inputs. A channel transition rule alone does not specify how uncertain the input was. This lesson computes error and remaining uncertainty for the binary symmetric channel, a small mathematical model rather than a design for a practical communication system.

Background capsule. Conditional probability P(Y=y|X=x) describes output Y once input X is fixed. A joint probability is input chance times transition chance. Entropy H(X) is average surprise in bits, and H(X|Y) measures uncertainty in X after the output is seen. The binary entropy function h₂(t)=−t log₂t−(1−t)log₂(1−t), with zero terms defined by continuity, is the entropy of a Bernoulli outcome. We assume a single channel use unless explicitly discussing repeated uses.

Follow a fair input through the switch

Worked example. Set ε=1/4, so the output agrees with the input with probability 3/4. Let the input be fair: P(X=0)=P(X=1)=1/2. The joint table has 00 and 11 each at 3/8, and 01 and 10 each at 1/8. The output is also fair because each output column totals 1/2. Seeing Y=0, the posterior input distribution is X=0 with 3/4 and X=1 with 1/4. The same uncertainty holds after Y=1, with the labels reversed.

The chance that output differs from input is 1/8+1/8=1/4. H(X)=1 bit and H(X|Y)=h₂(1/4)≈0.811 bit, so the output reveals about 0.189 bit about the input on average. If the input were always zero, the channel would still flip it on one quarter of uses, but H(X)=0 and there would be no uncertainty about the input to remove. The transition rule and the input law play different roles.

The exact error statement

P(Y≠X)=ε

Exact hypotheses. For each possible input bit x, the binary symmetric channel has P(Y≠x|X=x)=ε and P(Y=x|X=x)=1−ε, with 0≤ε≤1. Then total probability gives P(Y≠X)=ΣₓP(X=x)ε=ε, for any input distribution. With a fair input specifically, symmetry makes Y fair and gives H(X|Y)=h₂(ε) and I(X;Y)=1−h₂(ε). These latter identities are not asserted for arbitrary input weights. At ε=1/2, output is independent of input and mutual information is zero. At ε=1, output always flips, yet perfectly reveals input after reversing the bit; a large raw mismatch rate does not necessarily mean little information.

The displayed error rate assumes that the receiver guesses input by copying output. For ε>1/2 a receiver that knows the channel should invert the output, so the best single-bit decision error is min(ε,1−ε) for a fair input. The algebra above describes one channel use and exact stipulated probabilities. Independence of errors across multiple uses has not been assumed or proved, and no coding theorem or capacity claim follows from this table alone.

Keep the input law in view

Exercise 1. The switch flips with ε=1/8 and the input is fair. Find P(Y≠X), H(X|Y), and I(X;Y). Exact expressions using h₂ are enough; explain each quantity.

Hint for exercise 1

Symmetry makes the output fair and the posterior error fraction one eighth.

Full solution to exercise 1

P(Y≠X)=1/8 by the channel rule. H(X|Y)=h₂(1/8)=−(1/8)log₂(1/8)−(7/8)log₂(7/8)≈0.544 bit. Because H(X)=1 bit, I(X;Y)=1−h₂(1/8)≈0.456 bit. The first number is an error probability, while the latter two are average uncertainties in bits.

Exercise 2. A channel always flips, ε=1. The input is fair. A reader says this channel conveys no information because every output is wrong. Compute H(X|Y) and identify the mistaken assumption.

Hint for exercise 2

If Y is always the opposite of X, can you recover X from Y?

Full solution to exercise 2

Knowing Y determines X by reversing the bit, so H(X|Y)=0 and I(X;Y)=H(X)=1 bit. P(Y≠X)=1 remains true, but “wrong” here means only that copying Y as the input fails. A receiver informed of the deterministic flip decodes perfectly. The reader treated mismatch with an unadjusted guess as equivalent to lost information.

One use, one clear model

The symmetric switch has error chance ε regardless of the input law. The amount of input information carried by its output depends on that law; for fair inputs it is 1−h₂(ε) bits per use. Neither number describes all practical noise. Real channels can have asymmetric errors, memory, uncertain parameters, or constraints on the input. A channel table is an explicit mathematical assumption to test against those conditions, not a guarantee about hardware.

A useful stopping check is to write a complete joint table from an input distribution and the transition probabilities, then verify that all four cells sum to one. That same table supports conditional probabilities, entropy, and mutual information without changing denominators silently.
