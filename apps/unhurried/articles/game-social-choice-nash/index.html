Would either player change course alone?

Two players choose one of two routes through a puzzle. A pair of choices is stable in a narrow sense if neither player could earn more points by switching their own route while the other keeps theirs. This is a pure Nash equilibrium. Stability under unilateral moves does not mean both players are happy with everything, or that the outcome is best for their combined scores.

Background capsule. A payoff pair (a,b) gives row's points first and column's second. A unilateral deviation changes exactly one player's action while fixing the other's. A best response is an action that gives a player the highest payoff against the fixed opposing action; ties produce more than one best response. “Pure” means a definite action, not a lottery over actions. We will check the finite table directly.

Worked example. If column plays L, row prefers B because 5 > 4. If column plays R, row again prefers B because 1 > 0. Thus B is row's best response to either column action. If row plays T, column prefers R because 5 > 4. If row plays B, column again prefers R because 1 > 0. Their best responses meet at (B,R), giving (1,1). To check it directly, row switching alone to T would get 0 rather than 1; column switching alone to L would get 0 rather than 1. No single player profits by moving.

At (T,L), both receive 4, which each prefers to 1. Yet row could earn 5 by changing to B while column holds L. Column could earn 5 by changing to R while row holds T. So (T,L) fails the equilibrium test despite being better for both players than (B,R). The example is a stipulated incentives puzzle; it is not a claim that people cannot coordinate or that one outcome is ethically preferable.

What the equilibrium inequality proves

For a profile s* = (r*,c*), the pure Nash condition is that every player i and every available alternative action ai satisfy:

ui(s∗)≥ui(ai,s−i∗)

The subscript −i means “all the other players,” held at their proposed actions. In the displayed two-action game, there is one alternative for each player at each cell. At (B,R), the two comparisons 1 ≥ 0 and 1 ≥ 0 establish equilibrium. They are sufficient because all unilateral alternatives have been exhausted. This proof is for the finite displayed game; it does not assert an equilibrium for every pure-action game.

A best-response method reaches the same conclusion: mark row's payoff maximum in each column and column's maximum in each row. A cell marked for both is an equilibrium. This can reveal multiple equilibria or none. For example, in matching pennies, row gains by matching while column gains by mismatching. Whatever pure pair is chosen, one of them wants to switch. Randomized strategies require a separate model.

Check stability rather than appearances

1. Calculation. For the displayed table, test (T,R). Identify who can profit by switching alone and state the gain.

Hint for exercise 1

Hold row T fixed to test column; hold column R fixed to test row.

Full solution to exercise 1

At (T,R) the payoffs are (0,5). If row switches to B while column stays R, the payoffs become (1,1): row's own score increases from 0 to 1. If column switches to L while row stays T, column's score falls from 5 to 4, so column would not switch for payoff gain. Because row has a profitable deviation, (T,R) is not an equilibrium. One profitable deviation is enough to reject a candidate.

2. Construction. A coordination game pays (2,2) at (A,A), (1,1) at (B,B), and (0,0) at the two mismatches. Find every pure Nash equilibrium and explain why the higher-payoff one need not be the only equilibrium.

Hint for exercise 2

At each matching cell, compare a unilateral switch to a mismatch.

Full solution to exercise 2

At (A,A), either unilateral switch yields 0 instead of 2, so both stay: equilibrium. At (B,B), either switch yields 0 instead of 1, so both stay: another equilibrium. At (A,B), row can change to B and earn 1 rather than 0; column can change to A and earn 2 rather than 0. At (B,A), analogous improvements exist. Thus exactly the two matching cells are equilibria. Nash checks unilateral incentives at a given cell; it does not select the cell with the largest common payoff.

A local test of incentives

Pure Nash equilibrium is a complete check of one-player deviations. The crossing puzzle has a single equilibrium (B,R), while the coordination construction has two. Neither fact alone predicts which outcome real players reach. To interpret a game outside the page, the actions, information, and payoffs would need evidence.

Failure case. A game can lack a pure equilibrium, as matching pennies does. The absence of a marked cell is not a counting error when every candidate has a profitable unilateral deviation; it motivates the mixed-strategy question.
