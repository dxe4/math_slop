Can every planar map be read as simple stretches?

A linear map can shear and turn a circle into an ellipse. Singular value decomposition finds perpendicular input directions that emerge as perpendicular output directions, with nonnegative stretch factors. This description works even when the original map has no real eigenvectors or collapses a direction.

Background capsule. An orthogonal 2×2 matrix Q preserves dot products: QᵀQ=I. It may rotate or reflect; both count. A diagonal matrix Σ=diag(σ₁,σ₂) scales the coordinate axes by its diagonal entries. A singular value is nonnegative. For a matrix A, AᵀA is symmetric and nonnegative in the sense that vᵀAᵀAv=||Av||²≥0. We use the real symmetric 2×2 spectral theorem: such a matrix has an orthonormal eigenbasis. Its general proof is a named dependency here; the construction below explains what follows from it.

An ellipse with exact axes

Worked example. Take A=diag(3,1/2). An input on the unit circle can be written (cos t,sin t). Its image is (3cos t,(1/2)sin t), an ellipse with horizontal semiaxis 3 and vertical semiaxis 1/2. Here U=V=I and Σ=A. The right singular vectors are e₁,e₂; their images are 3e₁ and (1/2)e₂. The circle's area π becomes 3/2 times as large, consistent with determinant 3/2.

Now compose the stretch with a quarter-turn R=[[0,−1],[1,0]], giving B=R A=[[0,−1/2],[3,0]]. B has the same singular values 3 and 1/2. Its input e₁ goes to (0,3), and e₂ goes to (−1/2,0): the output axes have turned. But B's characteristic polynomial is λ²+3/2, so it has no real eigenvectors. Singular vectors and eigenvectors answer different questions.

Build the three factors

Exact 2D statement and bounded derivation. Every real 2×2 matrix A admits orthogonal U,V and nonnegative diagonal Σ such that

A=UΣVT

Apply the symmetric 2×2 spectral theorem to AᵀA. Choose orthonormal eigenvectors v₁,v₂ with nonnegative eigenvalues λ₁,λ₂, and set σᵢ=√λᵢ. If σᵢ>0, define uᵢ=Avᵢ/σᵢ. Their dot products satisfy uᵢ·uⱼ=(vᵢᵀAᵀAvⱼ)/(σᵢσⱼ), which equals 1 for i=j and 0 otherwise. Thus the nonzero uᵢ are orthonormal. If exactly one σ is zero, choose the remaining output unit vector perpendicular to the first u; if both are zero, A=0 and choose any orthonormal U. For a zero σ, Av=0, so the choice still makes Avᵢ=σᵢuᵢ. Put the vᵢ in V and uᵢ in U. The column equations combine to AV=UΣ, hence A=UΣVᵀ. This is a complete construction conditional on the named symmetric spectral theorem; it is not a proof of that theorem or of the higher-dimensional SVD.

The geometric order for an input is Vᵀ first, then Σ, then U. The transpose Vᵀ changes to principal input coordinates; Σ stretches or collapses; U positions the outputs. Because orthogonal matrices preserve lengths, the image of the unit circle has semiaxis lengths σ₁,σ₂. If a singular value is zero, the ellipse degenerates to a segment or point. For a nonzero matrix with two equal singular values, the principal axes are not unique. So the phrase “the unique axes” would be false.

Read lengths and limits

1. Calculation. For C=[[0,−2],[1,0]], compute CᵀC, singular values, and the images of the unit coordinate vectors. State the ellipse semiaxis lengths.

Hint for question 1

Compute the dot products of C's columns; they are perpendicular.

Full solution for question 1

The columns are (0,1) and (−2,0). Thus CᵀC=diag(1,4), with eigenvalues 1 and 4, giving singular values 1 and 2. C e₁=(0,1) has length one, and C e₂=(−2,0) has length two. The image ellipse therefore has semiaxis lengths two and one, along the horizontal and vertical output axes respectively.

2. Failure case. For D=diag(2,0), a student says no SVD exists because Av₂/σ₂ divides by zero. Explain how to finish the construction and describe the image of the unit circle.

Hint for question 2

Choose an output unit vector perpendicular to the nonzero output direction.

Full solution for question 2

DᵀD=diag(4,0), so σ₁=2 and σ₂=0. Take v₁=e₁, v₂=e₂. Then u₁=De₁/2=e₁. Choose u₂=e₂, perpendicular to u₁; no division by zero is required. U=V=I and Σ=diag(2,0) give D=UΣVᵀ. The unit circle maps to {(2cos t,0)}, the segment from (−2,0) to (2,0), not a positive-area ellipse.

Axes survive when eigenlines do not

The singular values are the square roots of the eigenvalues of AᵀA. They measure principal lengths, while U and V record output and input directions. The derivation relies on the real symmetric spectral theorem, which is deferred here. Zero singular values signal collapse; repeated ones make axes nonunique. A rotation is the sharp counterexample to equating singular vectors with eigenvectors: it preserves all lengths yet may have no real eigenline.
