Question and background

Suppose two walkers follow exactly the same route, with one taking twice as long. They report different velocities at matching clock readings but should agree on the route's length. Reparameterization is the mathematical way to separate the path from the timing.

Local capsule. A curve γ(u) has speed ||γ′(u)|| and length ∫||γ′(u)||du. An increasing function u=φ(t) changes the clock; the composite β(t)=γ(φ(t)) visits γ's points in the same order. The chain rule says β′(t)=γ′(φ(t))φ′(t). Substitution in an integral says du=φ′(t)dt when φ′ is positive and φ takes the new endpoints to the old ones.

Here “same curve” means same ordered trace, including how many times it is traversed. Equality of point sets alone is weaker: a trip once around a circle and a trip twice around it have the same image but different lengths.

A worked example

Worked example. Let γ(u)=(cos u,sin u) for 0≤u≤π, the upper semicircle. Its speed is one and its length π. Now use φ(t)=2t on 0≤t≤π/2. Then β(t)=γ(2t)=(cos 2t,sin 2t), and β′=(-2sin 2t,2cos 2t) has speed two. The new time interval has half the duration, so the length is ∫₀^{π/2}2 dt=π. The instantaneous readings change while their accumulation does not.

For a nonconstant clock, φ(t)=πt² on 0≤t≤1 also traverses this semicircle in the correct order. Its derivative 2πt vanishes at t=0. The composite's speed is 2πt, and ∫₀¹2πt dt=π. This example shows a subtle distinction: strict positivity of φ′ is a convenient hypothesis for a regular new parameter, but a smooth monotone clock with an isolated pause still gives the same length by substitution.

At t=0 the second clock has no unit velocity vector. We can still calculate its length, but a curvature formula requiring nonzero speed cannot be used at that time without changing parameter or taking a limit.

Reverse a clock carefully

Return to the unit upper semicircle γ(u)=(cos u,sin u), with 0≤u≤π. Set φ(t)=π−t for 0≤t≤π. The new path is β(t)=(−cos t,sin t), beginning at (−1,0) and ending at (1,0). Differentiation gives β′=(sin t,cos t), so its speed is one and its length is π. The original path traverses from right to left; the new one traverses from left to right.

Here φ′=−1. The chain rule changes the velocity's sign, but taking a norm changes that factor to |−1|=1. If we omitted the absolute value and integrated −1, we would obtain a negative “length,” exposing the mistake immediately. In substitution language the old integration limits reverse as well. Length is unchanged by a single reversed traversal, while an oriented tangent and signed turning depend on which way the path is followed. Keep those geometric outputs separate when changing parameters.

The statement and its boundary

Exact statement. Let γ:[a,b]→ℝⁿ be C¹ and let φ:[c,d]→[a,b] be a C¹ increasing bijection with φ(c)=a, φ(d)=b and φ′>0. Then β=γ∘φ has the same length as γ. The proof is a direct chain-rule and substitution calculation:

L(γ∘φ)=∫cd‖γ′(φ(t))‖φ′(t)dt=L(γ)

The norm of a scalar multiple normally gives an absolute value: ||γ′(φ(t))φ′(t)||=||γ′(φ(t))|| |φ′(t)|. We removed the bars only because φ′ is positive. If φ is decreasing, the same norm argument and reversed endpoints still preserve length for a single traversal; orientation changes. If φ oscillates, the new route may retrace parts and length is counted again. Thus merely saying “the images coincide” misses a key hypothesis.

This argument proves an equality of integrals. It does not establish that every arbitrary continuous curve has a smooth regular parameter, nor does it make a stopped clock regular.

Try it yourself

Exercise 1. a slower line. Start with γ(u)=(3u,4u), 0≤u≤1. Put φ(t)=t/3 for 0≤t≤3. Find both speeds and lengths.

Hint for exercise 1

Compute β(t)=γ(t/3) before differentiating.

Full solution to exercise 1

γ′=(3,4), so ||γ′||=5 and L(γ)=5. The new curve is β(t)=(t,4t/3), so β′=(1,4/3) and ||β′||=5/3. Over three time units its length is ∫₀³5/3 dt=5. The speed is one third, the duration three times as long.

Exercise 2. same image, different trip. Compare γ(u)=(cos u,sin u), 0≤u≤2π, with δ(t)=(cos 2t,sin 2t), 0≤t≤2π. Do their point sets and lengths agree?

Hint for exercise 2

Count complete revolutions, then integrate constant speeds.

Full solution to exercise 2

Both images are the unit circle. γ runs around once with speed one, so L(γ)=2π. δ runs around twice with speed two over the same interval, so L(δ)=4π. The map φ(t)=2t takes [0,2π] to [0,4π], not to γ's original parameter interval; it fails the endpoint hypothesis for a single traversal.

What to carry forward

Reparameterization preserves the length of one ordered traversal when the new clock covers the same old interval exactly once. The chain rule explains why a higher speed is balanced by a shorter time. A pause can preserve length but break regularity, while a repeated lap increases length even if a plot looks identical.

The next step is signed curvature, which measures turning per unit arc length. Its formula should be invariant under an increasing regular clock change; a decreasing change reverses the sign because it reverses the oriented traversal.
