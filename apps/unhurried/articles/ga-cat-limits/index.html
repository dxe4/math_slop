Functions and composition

A function assigns exactly one output to each allowed input. Its domain is the set of allowed inputs; its codomain is the declared set containing the outputs. Different inputs may share an output. For f(x)=x² on the real numbers, both 2 and −2 produce 4.

Worked example. Let f(x)=2x+1 and g(x)=x². The expression f(g(3)) first applies g to 3, producing 9, and then applies f to 9, producing 19. Composition writes this as (f∘g)(3).

f(g(3))=f(9)=19

For a composition to be defined, the output of the inside function must be an allowed input for the outside function. Here both functions accept every real number, so that condition holds.

Try one. Compute g(f(3)). Does changing the order preserve the result?

Worked answer

First f(3)=7, then g(7)=49. This differs from f(g(3))=19. Composition generally depends on its order; the circle symbol names the operation, rather than promising that the two orders agree.

Watch the notation. In f(3), the parentheses name the input to f. They do not mean f multiplied by 3. Read the expression from the inside out.

Which pairs really match?

Two collections may carry labels in a common set Z. We want pairs whose labels agree. This leads to a pullback: a subset of a product equipped with two projections and a universal matching property. The construction resembles a database join, but ordinary database duplicate rows and missing values have extra semantics outside this Set example.

Background capsule. A product X×Y contains every pair (x,y). A function f:X→Z assigns each x a label in Z, and g:Y→Z does the same for y. A commuting square means two composites of the same type agree. For arrows u:T→X and v:T→Y, compatibility is f∘u=g∘v:T→Z. The pullback's mediator must go from T into the set of compatible pairs.

Match finite keys exactly

Worked example. Take X={a,b,c}, Y={r,s}, Z={0,1}; define f(a)=0, f(b)=1, f(c)=0 and g(r)=0, g(s)=1. The compatible pairs are (a,r), (b,s), (c,r), since their key values match. Call this three-element set P. Projection pX:P→X takes first coordinates, and pY:P→Y takes second coordinates.

For example, let T={α,β}, u(α)=a, u(β)=b and v(α)=r, v(β)=s. The compatibility equation holds on both elements. The forced mediator m:T→P has m(α)=(a,r), m(β)=(b,s), and each projection recovers u or v. The third possible pair in P is unused, which is fine: a mediator need not be onto.

The universal matching proof

Exact statement and full proof in Set. Given functions f:X→Z and g:Y→Z, define P={(x,y)∈X×Y : f(x)=g(y)}. With restricted coordinate projections, the defining equation is

P={(x,y)∈X×Y:f(x)=g(y)}

First, f∘pX=g∘pY:P→Z because every member of P satisfies the displayed condition. Now take any set T and arrows u:T→X, v:T→Y with f∘u=g∘v. Define m(t)=(u(t),v(t)). Compatibility ensures m(t)∈P, so m:T→P is well-defined; its projections are u and v. If n:T→P has these same projections, its two coordinates at each t equal u(t) and v(t). Thus n(t)=m(t) for every t, hence n=m. This proves existence and uniqueness, for finite or infinite sets. It also handles T empty without a special construction.

The word limit describes the general pattern: a diagram has compatible cones, and a limiting cone receives a unique arrow from each compatible cone. We have proved the special pullback case in Set. We have not proved that arbitrary diagrams have limits in arbitrary categories. That broader theorem needs additional hypotheses on the category and size of the diagram; the finite matching proof does not supply them.

If one tried to include (a,s), the proposed projection square would fail there: f(a)=0 while g(s)=1. This is why taking the whole product X×Y is generally wrong. The product solves two independent observations; the pullback solves two observations constrained by a common result.

Build a matching set

1. Calculation. Let X={1,2,3}, Y={p,q}, Z={red,blue}; f sends 1 and 2 to red and 3 to blue, while g(p)=blue and g(q)=red. List P.

Hint for question 1

Group elements by their key in Z.

Full solution for question 1

The red x-values 1 and 2 match q, giving (1,q) and (2,q). The blue x-value 3 matches p, giving (3,p). No other pair has equal key values, so P={(1,q),(2,q),(3,p)}.

2. Explanation. Suppose T={t}, u(t)=1 and v(t)=p in the preceding example. Can a mediator T→P with projections u and v exist?

Hint for question 2

Check the compatibility equation before seeking a pair.

Full solution for question 2

No. f(u(t))=f(1)=red but g(v(t))=g(p)=blue. The pair (1,p) is not in P. More generally, composing a hypothetical mediator with the commuting projection square would force f∘u=g∘v, contradicting this calculation.

Where the proof ends

In Set, a pullback is the set of exactly those pairs with equal images under f and g. The pointwise argument proves both the square and the unique mediator for every compatible cone. It does not turn every informal “join” into a pullback, nor assert that every category has all limits. The arrow direction and the compatibility equation are the checks to carry into a new example.
