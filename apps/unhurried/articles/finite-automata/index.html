Sets and membership

A set records which objects belong to a collection. In roster notation, braces surround its members: A={1,3,5}. Writing 3∈A says that 3 belongs to A; writing 2∉A says that 2 does not. Repeating a member or changing the listing order leaves the set unchanged.

Worked example. Let B={3,4}. The union A∪B contains every object in either set. The intersection A∩B contains exactly the objects in both sets.

A∪B={1,3,4,5}A∩B={3}

The empty set, written ∅, has no members. A subset C⊆A has all its members in A. The subset may equal the whole set; the symbol does not require a smaller collection.

Try one. With C={1,5}, find C∩B and decide whether C⊆A.

Worked answer

C and B have no common member, so C∩B=∅. Both 1 and 5 belong to A, hence C⊆A. Empty intersection and subset inclusion ask different questions.

Watch the object. The number 3 and the set {3} are different objects. Here 3∈A and {3}⊆A are both true, but they express different relationships.

Functions and composition

A function assigns exactly one output to each allowed input. Its domain is the set of allowed inputs; its codomain is the declared set containing the outputs. Different inputs may share an output. For f(x)=x² on the real numbers, both 2 and −2 produce 4.

Worked example. Let f(x)=2x+1 and g(x)=x². The expression f(g(3)) first applies g to 3, producing 9, and then applies f to 9, producing 19. Composition writes this as (f∘g)(3).

f(g(3))=f(9)=19

For a composition to be defined, the output of the inside function must be an allowed input for the outside function. Here both functions accept every real number, so that condition holds.

Try one. Compute g(f(3)). Does changing the order preserve the result?

Worked answer

First f(3)=7, then g(7)=49. This differs from f(g(3))=19. Composition generally depends on its order; the circle symbol names the operation, rather than promising that the two orders agree.

Watch the notation. In f(3), the parentheses name the input to f. They do not mean f multiplied by 3. Read the expression from the inside out.

A tiny memory can recognize a pattern

A turnstile that alternates locked and unlocked after each coin needs only two memory states. For a mathematical machine, we can ignore the motor and ask what a finite memory can recognize from a stream of symbols. Our example reads bits and accepts exactly those strings containing an odd number of 1s. The machine never needs to store the entire string.

Background capsule. An alphabet is a finite set of symbols; here Σ={0,1}. A string is a finite sequence of those symbols, including the empty string ε. A state is a name for the machine's current memory. A transition function assigns exactly one next state to each state-symbol pair. “Accept” means the state after the entire string has been read belongs to a designated accepting set.

Walk through the bits

Worked example. Use states E and O for even and odd parity, start at E, and accept at O. Reading 0 leaves the state unchanged; reading 1 switches it. The transition table makes the whole machine explicit.

Trace 1011: E→O after 1, O→O after 0, O→E after the next 1, and E→O after the last 1. Since O is accepting, 1011 is accepted. The empty string leaves the machine at E and is rejected. So is 11, because two toggles restore E. These traces let us test the table; they do not by themselves justify the result for every string.

State the general machine and prove its meaning

A deterministic finite automaton is a tuple M=(Q,Σ,δ,q0,F). Here Q is a finite state set, Σ a finite alphabet, δ:Q×Σ→Q a total transition function, q0 a start state q0∈Q, and F⊆Q a set of accepting states. For the parity example, Q={E,O}, q0=E, and F={O}. “Total” matters: every possible state and input symbol has an instruction. A missing transition is an incomplete specification unless an explicit rejecting sink is supplied.

Claim. After reading any finite prefix, the machine is in E exactly when that prefix has an even number of 1s. Prove this by induction on prefix length. For length zero, the count is zero and state E is correct. Suppose the claim holds for a prefix. Appending 0 does not change the count and the table holds the state. Appending 1 changes parity and the table toggles the state. Thus the invariant holds for the extended prefix. At the end, acceptance at O is equivalent to an odd count. This is a complete proof for every finite binary string, not just the traced examples.

The machine reads one symbol per transition, so a string of length n uses exactly n transitions and then a final state check. This finite-state model has no unbounded counter. It can remember parity because only two categories matter, but the proof here says nothing about which languages no finite automaton can recognize. That requires a separate impossibility tool.

M=(Q,Σ,δ,q0,F)

Worked example: changing the accepting set

Keep exactly the parity transition table, but make E the sole accepting state. On input 101, the run is E → O → O → E. It now accepts, because the final count of 1s is two. On input 1, the run ends at O and rejects. The empty string stays at E and accepts without taking a transition.

The earlier state invariant is unchanged: E still means an even number of 1s and O an odd number. Only the final decision rule changed. Consequently the new machine recognizes strings with an even number of 1s. A DFA consists of its accepting set as well as its transition table and start state. Reusing a correct transition proof does not mean that every different accepting set recognizes the same language.

Try altered strings and machines

1. Trace 00101 through the parity machine and decide acceptance.

Hint for question 1

Only the 1 symbols change the state; record the state after each symbol.

Full solution to question 1

Starting E, the states after 0,0,1,0,1 are E,E,O,O,E. There are two 1s, so the final state E is rejecting. Both the trace and the parity invariant agree.

2. Someone erases the transition from O on input 0 and says the result is still a DFA for odd parity. What fails? Repair it.

Hint for question 2

Check the formal domain of δ and try string 10.

Full solution to question 2

δ must assign an output to (O,0), but the modified table does not. The run on 10 reaches O after 1 and then has no defined next state. Restore δ(O,0)=O, because adding zero does not change the number of 1s or its parity.

Remember only what matters

A finite automaton trades a full input history for a finite state that preserves exactly the information needed for its acceptance question. The parity invariant proves the chosen two states are sufficient for this language. An individual accepted trace is evidence for one word, while the induction covers all words. Patterns and machines uses a different state meaning: the suffix relevant to whether a word ends in 01.
