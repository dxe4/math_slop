How large can an exact square tile be?

A 252-by-198 rectangle can be covered with equal square tiles of side 18, but can a larger integer side work? A tile side must divide both dimensions. The greatest common divisor, gcd(a,b), is the greatest positive integer dividing both integers when at least one is nonzero. If a divides b, an integer k satisfies b = ak. That is the only definition from divisibility needed here; it is repeated so this page stands alone.

For any integers a and positive b, division with remainder gives a = qb+r with integers q and r satisfying 0 ≤ r < b. A quotient and remainder are unique under that range condition. The Euclidean algorithm repeats this division until the remainder is zero. The square-cutting picture suggests the operations for positive sides, while the remainder equations explain why the final answer is exact.

Run the ledger

Worked example. For the rectangle, 252 = 1·198+54. A 198-square leaves a 54-wide strip. Next 198 = 3·54+36, so three 54-squares leave a 36 strip. Finally 54 = 1·36+18 and 36 = 2·18+0. The last positive remainder is 18. A physical cut can be awkward to draw accurately, so the table retains every numerical obligation.

Check the answer before trusting the procedure: 252/18 = 14 and 198/18 = 11, both whole numbers. The algorithm says more than that 18 works; it says no greater common divisor exists. This is what the invariant below establishes.

The common divisors do not change

Remainder theorem. If a = qb+r, every common divisor of a and b also divides r = a−qb. Conversely, every common divisor of b and r divides a = qb+r. The two pairs therefore have exactly the same common divisors. When b is positive and 0 ≤ r < b, this gives:

gcd(a,b)=gcd(b,r)

That proof uses only the fact that a divisor of two integers divides any integer sum or difference of their multiples. It explains each row of the ledger. At the last row, gcd(36,18) = gcd(18,0) = 18 because every positive divisor of 18 divides zero, and 18 is the largest positive divisor of itself.

Termination. Every nonzero remainder is a nonnegative integer strictly smaller than the previous positive divisor. There cannot be an infinite strictly decreasing sequence of nonnegative integers: after at most finitely many such decreases, zero appears. This is a proof of termination, though it does not yet give a sharp count of steps. For inputs with signs, first replace them by absolute values. If one input is zero, gcd(a,0)=|a| for a ≠ 0; gcd(0,0) is left undefined here because there is no greatest positive common divisor.

Failure case. Rounding a quotient to the nearest integer can yield a negative remainder, breaking the displayed 0 ≤ r < b convention. For example 19 = 2·10−1 is true but is not the division step used here; the correct row is 19 = 1·10+9. The equality of gcds still holds for any integer q, but the decreasing-remainder termination argument needs a controlled remainder. A picture of rectangles alone cannot supply that guarantee.

Worked example: a zero endpoint reached early

Find gcd(84,28). The very first division is 84 = 3·28 + 0, so the procedure stops with answer 28. There is no requirement to manufacture several nonzero remainders. Every common divisor of 84 and 28 divides 28, while 28 itself divides both numbers. Thus 28 really is the greatest positive common divisor.

Compare gcd(28,84). Its first quotient is zero: 28 = 0·84 + 28. This legal row simply puts the smaller positive number second, after which the previous division applies. A zero quotient is allowed; a zero divisor is not. If the original input is (−84,28), absolute values give the same positive answer. Keeping these cases in the ledger prevents a rule about attractive rectangles from silently replacing the integer algorithm.

Do the arithmetic and defend it

1. Compute gcd(119,34) with all remainder equations. State which row shows that the answer divides both original inputs.

Hint for question 1

Subtract multiples of 34 from 119 until the remainder is below 34.

Full solution to question 1

119 = 3·34+17 and 34 = 2·17+0. Hence gcd(119,34)=gcd(34,17)=17. The final row shows 17 divides 34; the first row then gives 119 = 3·34+17, also a multiple of 17. The invariant, rather than only these checks, excludes a larger common divisor.

2. A friend stops at the first nonzero remainder and says gcd(252,198)=54. Locate the precise error.

Hint for question 2

Check whether 54 divides the previous divisor 198.

Full solution to question 2

The first remainder 54 need not be a common divisor. Here 198 = 3·54+36, so 54 does not divide 198. The invariant only says gcd(252,198)=gcd(198,54), not that the gcd equals 54. Continue until the remainder is zero; the last positive remainder is 18.

A repeated equality with a stopping rule

Euclid's algorithm is trustworthy because each row preserves the entire set of common divisors and because the positive remainders decrease. The last positive remainder is therefore the gcd. Retain the quotient ledger: reversing its equations in Bézout's identity will express that gcd as a signed combination of the starting numbers.
