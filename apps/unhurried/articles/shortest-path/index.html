Networks and degree counts

A finite simple undirected graph consists of vertices and edges. Each edge joins two different vertices, with at most one edge for each pair. “Undirected” means that AB and BA name the same connection. A drawing shows these relationships; its line lengths need not carry any information.

Worked example. Use vertices A, B, C and D, with edges AB, AC and BC. The degree of a vertex is the number of edges touching it. A, B and C each have degree 2, while D has degree 0 because it is isolated.

2+2+2+0=6=2×3

Every edge contributes one to the degree at each of its two ends. Adding all degrees therefore gives twice the number of edges. An isolated vertex still belongs to the graph and contributes zero to the sum.

Try one. Add the edge CD. What changes?

Worked answer

C's degree rises to 3, and D's rises to 1. A and B stay at 2. The degree sum becomes 8, and there are now four edges, again giving twice the edge count.

Watch the convention. A repeated connection or an edge from a vertex to itself requires a different graph convention. Keep the simple-graph assumptions explicit when translating a real network.

When is the first discovered route truly shortest?

Suppose a contact network records one link for each direct introduction. You want a route from S to T using as few introductions as possible. Breadth-first search, or BFS, explores all vertices one link away before moving to two links away. Its first arrival at T is shortest in number of edges. The phrase “in number of edges” is essential; a costly one-step trip may take longer than a cheap two-step trip.

Background capsule. A graph here is finite, simple, and undirected. A path has no repeated vertices. The distance dist(s,v) is the smallest number of edges on an s–v path; unreachable vertices have infinite distance. A queue removes the item added earliest, called first-in-first-out. BFS starts with source s in the queue, marks it distance zero, then repeatedly removes a vertex and discovers each not-yet-discovered neighbor at distance one greater. Each new vertex receives a predecessor, the vertex from which it was first discovered.

Use edges SA, SB, AC, BC, BD, CT, DT. Which route from S to T has fewest edges? We can inspect the queue and obtain a certificate of distance, rather than guess from the drawn positions.

Trace the queue and layers

Worked example. Process neighbors alphabetically. Start queue [S], with dist(S)=0. Remove S and discover A,B at distance one, giving [A,B]. Remove A and discover C at distance two, giving [B,C]. Remove B; C is already discovered, and D is new at distance two, giving [C,D]. Remove C and discover T at distance three, giving [D,T]. The predecessor chain T←C←A←S yields S,A,C,T, three edges.

S,B,D,T is another shortest route. BFS need not return a unique path; neighbor order changes predecessor choices, while the distance label remains three. The table is a finite illustration. We need an argument for every unweighted graph.

Why layers certify edge-count distance

Theorem. In a finite unweighted graph, BFS started at s labels each reachable vertex v with its shortest edge-count distance:

label(v)=dist(s,v).

Proof. Every label assigned by BFS follows a predecessor chain back to s. A vertex labeled k has a chain with k edges, so its true distance is at most k. For the reverse bound, assume an s–v path with r edges. We show by induction along that path that each vertex at path position i gets a label at most i. The start has label zero. When the predecessor at position i is processed, the next vertex is either already discovered with a label no larger than i+1, or it is discovered then with label at most i+1. The queue processes vertices in nondecreasing label order: while vertices of layer i are removed, new vertices enter at layer i+1 behind the remaining layer-i entries. Thus the next vertex cannot have been first discovered earlier with a larger label. At the endpoint, label(v)≤r for every path length r; in particular label(v)≤dist(s,v). Combine both inequalities to obtain equality. Unreachable vertices are never discovered, since every discovery extends a path from s. This proof identifies where FIFO order is used.

For the worked graph, no path of one or two edges can reach T because T's neighbors C and D are both at layer two. This is an alternative local certificate of the distance-three answer. A BFS predecessor edge for each discovered non-source vertex forms a tree on the reachable component: every vertex has one parent at a smaller layer, so there is no cycle, and the predecessor chain reaches s.

Failure case. Suppose S–T is one edge of weight 100, while S–A and A–T have weights 2 each. BFS says S–T is one edge and therefore shortest by edge count; its cost 100 exceeds the two-edge path's cost 4. The theorem does not apply to weighted total cost. A weighted shortest-path algorithm needs an explicit cost rule and its own proof. Also, changing a queue into a stack can destroy the layer order and the first-discovery guarantee.

Compute a layer and test a claim

Exercise 1. Starting at P, run BFS on edges PQ, PR, QS, RT, ST, TU, processing neighbors alphabetically. What are the distance labels and one shortest P–U path?

Hint for exercise 1

Put Q and R at layer one, then examine their new neighbors in queue order.

Full solution to exercise 1

Start P:0. Q and R are discovered at 1. Processing Q discovers S:2; processing R discovers T:2. Processing S finds T already discovered. Processing T discovers U:3. Therefore the labels are P0, Q1, R1, S2, T2, U3. The predecessor chain gives P,R,T,U, a path of three edges. No path of two edges reaches U because its only neighbor is T at layer two.

Exercise 2. Edges XY, XZ, ZY have travel times 9, 2, 2 respectively. A friend claims BFS from X gives the fastest route to Y. Evaluate the claim and identify what BFS does prove.

Hint for exercise 2

Compare the direct route's edge count and weight with the route through Z.

Full solution to exercise 2

BFS discovers Y through direct edge XY at distance one, correctly proving it has the fewest edges. That route takes 9 units. X,Z,Y uses two edges but costs 2+2=4, so it is faster. The friend's claim confuses edge count with weighted travel time; the BFS theorem only covers the former.

State what “shortest” measures

BFS labels unweighted graph vertices by minimum number of edges from a source. The queue's layer order and the predecessor chain together certify the result. Equal-length paths may coexist, and weights change the optimization problem. If you want to connect this exploration to graph structure, the predecessor links make a tree rooted at the source; trees explains its unique-route property.
