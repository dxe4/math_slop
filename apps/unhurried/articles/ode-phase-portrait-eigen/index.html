Vectors and small matrices

A vector in the coordinate plane can be represented by an ordered pair. Add vectors component by component: (1,2)+(3,−1)=(4,1). A scalar is an ordinary number used to scale a vector, so 2(1,2)=(2,4). These operations describe displacements using the chosen coordinate axes.

Worked example. A two-by-two matrix has two columns. Let its first column be (2,1) and its second be (0,3). Applied to a vector (x,y), it produces x times the first column plus y times the second.

(2013)(12)=(27)

Here (1,2) maps to 1(2,1)+2(0,3)=(2,7). The columns tell you what happens to the unit vectors (1,0) and (0,1); scaling and addition then determine every other input.

Try one. Where does the same matrix send (−1,1)?

Worked answer

Use −1(2,1)+1(0,3)=(−2,−1)+(0,3)=(−2,2). Equivalently the first output is 2x and the second is x+3y; substituting x=−1 and y=1 gives the same pair.

Watch the convention. We write input vectors as columns. Each output uses an entire row's products and sum, rather than multiplying corresponding entries independently.

Powers and logarithms

For a positive integer n, aⁿ means a multiplied by itself n times. For example, 3⁴=3×3×3×3=81. For a nonzero base, a⁰=1 and a⁻ⁿ=1/aⁿ. A negative exponent describes a reciprocal.

Worked example. With base 3, the logarithm asks which exponent produces a positive input. Since 3⁴=81, log₃(81)=4. More generally, for a positive base b different from 1, log_b(x)=y means bʸ=x, with x positive.

34=81log3(81)=4

Multiplying powers with the same base adds their exponents: 2³×2²=2⁵. For positive inputs, this becomes the logarithm rule log₂(uv)=log₂(u)+log₂(v). It is a rule about a product.

Try one. Find log₂(1/8) and explain the negative sign.

Worked answer

Because 2⁻³=1/2³=1/8, the logarithm is −3. For a base larger than 1, inputs between 0 and 1 have negative logarithms.

Watch the operation. Logarithms do not generally turn a sum into a sum: log₂(2+2)=2, while log₂(2)+log₂(2)=2 happens to agree in this case. Using 2+4 instead gives log₂(6), which differs from 1+2=3 because 2³=8.

How can a matrix draw motion?

A planar linear system gives a velocity vector at each point: u′=Au, where u=(x,y) and A is a fixed 2×2 matrix. Its phase portrait shows the resulting paths in the plane, with arrows for increasing time. Eigenvectors are especially useful because a state on one of their lines remains on that line. The sign and type of eigenvalues then reveal approach, escape, or rotation in elementary examples.

Local background. Av=λv defines an eigenvector v≠0 and eigenvalue λ. If u(0)=cv, then u(t)=ceλtv solves u′=Au, as direct differentiation shows. For two independent eigenvectors, every initial state is their linear combination, so linearity combines the two corresponding solutions.

Read three concrete matrices

Worked example. First take A=diag(−2,−1). Then x(t)=x0e−2t and y(t)=y0e−t. Both coordinates decay. Unless y0=0, a trajectory approaches the origin tangent to the slower y-axis direction, although its exact shape depends on the initial state. This is a stable node.

For A=diag(1,−2), x(t)=x0et and y(t)=y0e−2t. The y-axis approaches the origin, while any x0≠0 eventually escapes. This is a saddle, and a few trajectories approaching on the y-axis do not make the equilibrium stable.

For A=[[-1,−2],[2,−1]], write u as a complex number z=x+iy. The equation becomes z′=(−1+2i)z. Thus z(t)=e−te2itz0: it rotates counterclockwise while its radius shrinks. The origin is a stable spiral.

Prove what the picture shows

If A has two linearly independent real eigenvectors v1,v2 with eigenvalues λ1,λ2, write u0=c1v1+c2v2. Then

u(t)=c1eλ1tv1+c2eλ2tv2

Differentiating and using Avi=λivi verifies the equation and initial condition. Every solution has this form because any two solutions with the same initial state have a difference w satisfying w′=Aw, w(0)=0. For a fixed matrix, a standard norm inequality or the matrix-exponential construction gives uniqueness; alternatively, the component equations for these diagonalizable coordinates each have direct scalar uniqueness. This argument covers diagonalizable real matrices. A defective matrix needs terms such as teλt; this article does not infer its portrait solely from a missing second eigenvector.

When both real eigenvalues are negative, each exponential tends to zero, proving attraction. Stability in the formal small-start/small-trajectory sense also follows: choose coefficients continuously from the initial vector, and the decaying factors never exceed one for t≥0. If one eigenvalue is positive, arbitrarily small starts along its eigenvector eventually leave any fixed neighborhood, proving instability. If eigenvalues are −α±iβ with α>0, a real two-dimensional change of coordinates reduces the system to decay times rotation; the displayed spiral matrix makes this explicit.

Eigenvalues with zero real part require additional care. The matrix [[0,−1],[1,0]] rotates circles and is stable but not attracting. The matrix [[0,1],[0,0]] has both eigenvalues zero yet solution y(t)=y0, x(t)=x0+ty0, which is unstable. The same real part can hide different behavior when a Jordan block is present.

This is a theorem about linear constant-coefficient systems. For a nonlinear system u′=F(u), the Jacobian near an equilibrium is only a local approximation. When eigenvalues avoid the imaginary axis, a separate linearization theorem supports local conclusions under smoothness assumptions; zero-real-part cases require nonlinear analysis.

Classify with evidence

1. Solve a diagonal system

Exercise 1. For x′=−3x, y′=2y and (x(0),y(0))=(1,0.01), find the solution and classify the origin.

Hint for 1

Solve each coordinate separately, then ask whether every small initial vector stays small forever.

Worked solution for 1

x=e−3t, y=0.01e2t. The eigenvalues are −3 and 2, so the origin is a saddle. This particular path eventually leaves any bounded neighborhood because its y-coordinate grows, despite the small initial y-value.

2. Compare two zero-eigenvalue systems

Exercise 2. Why is knowing that all eigenvalues have real part zero insufficient to call a planar linear equilibrium stable?

Hint for 2

Compare a rotation matrix with an upper triangular nilpotent matrix.

Worked solution for 2

For A=[[0,−1],[1,0]], solutions rotate with constant radius, so sufficiently small starts remain equally small: stable. For B=[[0,1],[0,0]], a start (0,ε) yields (εt,ε), which eventually leaves any fixed ball: unstable. Both matrices have eigenvalues with zero real part. Jordan structure and the actual solution matter.

Use eigenvalues within their scope

For the solved linear examples, exponential modes make phase portraits and stability claims exact. Negative real parts give attraction, a positive real part gives escape, and zero real parts are a warning to inspect more structure. The linearization boundary shows an even sharper warning for nonlinear systems.
