How many repeats bring you home?

A quarter-turn of a square must be applied four times to restore the original labelled position. A half-turn needs two applications. The word order turns this return time into a property of any group element. It is a positive integer in a finite group, even when the group operation is addition and the notation looks different.

Background capsule. A group G has an associative operation, an identity and an inverse for each element. An inverse undoes an action. A subgroup is a subset that itself has the group laws using the same operation. We will first count repeats, then show that the powers of one element form such a subset.

Read the repeat notation

G names the group and g names one of its elements. Here E names the identity: the do-nothing element. Write g² for doing g twice and gk for k repeats when k is positive. By convention g⁰ = E. Write g−1 for the inverse; g−k means k repeats of that inverse. A negative power does not mean a negative number of forward moves.

Under addition, repeats are written kg instead: add g to itself k times. In addition modulo 8, [3] is the class of integers with remainder 3, and 2[3] = [6]. The identity is [0]. We write ord(g) for the least positive repeat count returning to the identity. The symbol ⟨g⟩ names the set of all integer powers, including the identity and inverse powers; it is called the cyclic subgroup generated by g.

Two return paths

Worked example. Keep the square lesson's moves: R is a clockwise quarter-turn and F is the fixed vertical reflection, with corners 1–4 clockwise from the top left. R has powers E, R, R², R³, E, …, so ord(R) = 4. F has E, F, E, …, so ord(F) = 2. In the additive group modulo 8, compare adding [2] with adding [3].

Why powers form a subgroup

The exact definition in a finite group is

ord(g)=min{k∈Z>0:gk=E}

Read this as “the smallest positive integer k for which k repeats of g give E.” The symbol ℤ>0 means positive integers; the braces collect the ones meeting the condition after the colon, and min selects the smallest. We still need to prove that this collection is nonempty when G is finite.

Statement. In a finite group, g has a least positive return m, and ⟨g⟩ is a subgroup with exactly m elements.

  1. Find some return. Suppose G has N elements. Write N + 1 powers: E, g, g², …, gN. There are more entries than possible group elements, so two entries coincide: gi = gj for indices 0 ≤ i < j ≤ N. This is the pigeonhole principle. Multiply both sides by g−i, cancelling i repeats, to get E = gj−i. Since j − i is positive, a positive return exists. Let m be the least one.
  2. Count the distinct powers before it. E, g, …, gm−1 are distinct. Otherwise two of them, at indices i < j < m, would cancel to give a positive return j − i smaller than m, contradicting its choice.
  3. Account for every integer power. Divide any integer exponent k by m: k = qm + t, where q is an integer and 0 ≤ t < m. Then gk = (gm)qgt = Eqgt = gt. This works for negative k too. Every power therefore belongs to the m-element list in step 2, so that list is exactly ⟨g⟩.
  4. Check the subgroup laws. The identity g⁰ is in the set. For any integers a and b, the product gagb = ga+b is still an integer power, and the inverse of ga is g−a, also in the set. Associativity comes from the operation in G. These are precisely the required group laws on the subset.

The subgroup argument in step 4 works even in an infinite group. Finiteness was needed for the return and finite count in steps 1–3. Powers of one fixed element commute because adding their exponents commutes; unrelated group elements may still fail to commute, as R and F do.

There is a useful divisibility test when the order is m: gk = E exactly when m divides k, meaning k is an integer multiple of m. Use k = qm + t again. The power is gt; among 0 ≤ t < m, only t = 0 gives E, by the distinctness in step 2. Conversely, if t = 0, then gk = (gm)q = E. Lagrange's theorem later connects this element order to the size of a finite group.

Find and justify return times

1. Calculation. Find the order and full generated subgroup of [4] under addition modulo 10.

Hint for question 1

Start at [0] and repeatedly add [4] until [0] first reappears.

Full solution for question 1

The successive sums are [0],[4],[8],[12]=[2],[16]=[6],[20]=[0]. No earlier positive sum was [0], so ord([4])=5 and ⟨[4]⟩={[0],[4],[8],[2],[6]}. This set is closed under addition modulo 10 and contains additive inverses, as the general proof predicts.

2. Explanation. A learner sees g6=E and declares ord(g)=6. Why is this not enough? Supply an explicit square-symmetry counterexample.

Hint for question 2

Choose a move that returns after two repetitions; six is also a multiple of two.

Full solution for question 2

For the reflection F, F² = E, so F⁶ = (F²)³ = E. Yet ord(F) = 2 because 2 is the least positive return exponent. The equation g⁶ = E only implies that the actual order divides 6, by division with remainder; possibilities include 1, 2, 3 and 6.

A finite return is guaranteed

In a finite group, repeated powers must cycle back to the identity. The first return m counts exactly the elements of the cyclic subgroup ⟨g⟩. The finite hypothesis matters: in the infinite additive group of integers, repeatedly adding 1 never returns to zero, so 1 has infinite order. A finite animation of early powers cannot certify a return that has not occurred.

For a next step, compare the size of ⟨g⟩ with the size of the whole group. The coset argument in Lagrange's theorem proves that the former divides the latter.
