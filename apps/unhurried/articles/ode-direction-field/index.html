Coordinates and slope

An ordered pair (x,y) specifies a position in the coordinate plane: x measures horizontal displacement and y measures vertical displacement from the origin. The order matters. The points (2,5) and (5,2) usually occupy different places.

Worked example. From P=(1,2) to Q=(4,8), the horizontal change is 4−1=3 and the vertical change is 8−2=6. The slope is vertical change divided by horizontal change, giving 6/3=2.

m=y2−y1x2−x1=63=2

Use the same order in both subtractions. Reversing the points gives (2−8)/(1−4)=−6/−3=2 again. A horizontal line has slope zero. A vertical line has zero horizontal change, so this quotient does not define a finite slope.

Try one. Find the slope from (−1,4) to (2,−2).

Worked answer

The horizontal change is 2−(−1)=3. The vertical change is −2−4=−6. Dividing gives slope −2. The negative sign means that y decreases as x increases along this line.

Watch the units. If x is time in hours and y is distance in kilometres, the slope has units of kilometres per hour. The scales carry mathematical information.

Can slopes tell a story before a formula does?

The rule y′=1−y assigns a slope at every point (t,y). At height y=0 the slope is +1, at y=1 it is zero, and at y=2 it is −1. Short marks with those slopes make a direction field. A differentiable solution curve must be tangent to the marks it meets. Reading the signs already suggests that y=1 is a resting level and that nearby curves move toward it as time increases.

Local background. The derivative y′ is the tangent slope dy/dt. A horizontal tangent has slope zero. An equilibrium is a constant solution y(t)=c; it exists when the rate rule gives zero at c. An initial value, such as y(0)=3, picks a particular trajectory.

Walk through a field

Worked example. Start at (0,3). The initial slope is 1−3=−2. An Euler step of width h=1/4 follows this slope for one short move: y1=3+(1/4)(−2)=2.5. The next slope is −1.5, so y2=2.5−0.375=2.125. These are approximations, not points on the exact curve. For comparison, the exact solution verified below gives y(1/4)=1+2e−1/4≈2.558 and y(1/2)=1+2e−1/2≈2.213.

Read the independent variable as well. Because 1−y has no t in it, every point at the same height receives the same slope, however far left or right it appears in the field. A solution from (t₀,y₀) is therefore y(t)=1+(y₀−1)e−(t−t₀). Shifting the starting time slides a trajectory horizontally without changing its vertical behavior. This time-shift property comes from the autonomous equation; a rate containing t would need a fresh check.

Separate a sketch from a theorem

Set z=y−1. Then z′=y′=−z. The product rule gives (etz)′=et(z+z′)=0. Therefore, on any interval where the solution is defined, etz=C. With y(0)=y0, C=y0−1, so

y(t)=1+(y0−1)e−t

Direct differentiation verifies that this formula solves y′=1−y, and substitution at t=0 checks the initial condition. The product-rule argument proves uniqueness for this equation. For t≥0 the distance from equilibrium is |y(t)−1|=|y0−1|e−t. This gives both stability (a small displacement stays small) and attraction (the displacement tends to zero).

The sign diagram is an efficient summary: below 1, 1−y>0; above 1, 1−y<0. These arrows alone do not prove that a solution exists, nor do they distinguish two different curves that might pass through the same initial point for another equation. The exact calculation does that work here. More generally, a rate function f(t,y) locally Lipschitz in y has a unique local solution through each initial point under the usual continuity assumptions; proving that theorem requires an argument beyond a field sketch.

Euler's rule yn+1=yn+h(1−yn) becomes zn+1=(1−h)zn. If 0<h<1 it approaches from one side. If 1<h<2 it alternates sides while shrinking. If h>2 it grows in magnitude, even though the exact solution always settles. This is a numerical failure, not instability in the differential equation.

Test the picture

1. Begin below equilibrium

Exercise 1. For y(0)=−1, find y(t), its initial slope and the time when it first reaches y=0.

Hint for 1

In the displayed solution, y0−1=−2. Solve e−t=1/2.

Worked solution for 1

y(t)=1−2e−t. Its initial slope is 1−(−1)=2. It reaches zero when 1−2e−t=0, hence t=ln 2. Since y′=2e−t>0, it crosses y=0 only once and approaches 1 from below.

2. Detect a misleading step

Exercise 2. Use one Euler step of width h=3 from y(0)=2. Does the output show that the exact equilibrium repels nearby solutions?

Hint for 2

Compute z1=(1−h)z0 and compare with e−3z0.

Worked solution for 2

z0=1, so Euler gives z1=−2 and y1=−1: the error from equilibrium has doubled. The exact solution gives y(3)=1+e−3≈1.050. Euler's factor −2 produces the spurious growth; it does not refute exact attraction.

What to trust

A direction field records local slopes, and sign analysis can suggest equilibria and approach directions. A verified solution and a separate uniqueness argument turn that suggestion into a conclusion for this equation. A coarse numerical walk may contradict the real curve. The cooling model uses the same exponential mechanism; the nonuniqueness example shows why a slope picture cannot settle every starting-value question.
