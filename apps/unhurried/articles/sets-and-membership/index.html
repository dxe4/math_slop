A playlist is its songs, not their order

Two friends share playlists. One writes [jazz, folk, ambient]; the other writes [ambient, jazz, folk, jazz]. As ordered lists these differ, but as sets of styles they agree: each contains exactly jazz, folk, and ambient. Set language ignores order and duplicate occurrences. That choice makes membership, rather than a drawing or a list position, the decisive test.

Write x∈A when x is a member of set A. Write A⊆B when every member of A is also a member of B; equality A=B means precisely the same members. Braces such as {jazz, folk} describe a set by listing its members. The empty set ∅ has no members. These definitions are the local prerequisite capsule; no Venn diagram convention is needed.

Our goal is to test subset and equality claims in finite examples and prove the two-inclusion criterion. We will also distinguish an element from a one-element set: jazz is not the same object as {jazz}. The latter is a set whose member is jazz.

Audit membership rather than positions

Worked example. Let A={jazz, folk, ambient} and B={ambient, jazz, folk, jazz}. Repeating jazz adds no new member. To verify A⊆B, check jazz, folk, and ambient in B. To verify B⊆A, check every distinct member of B in A. Both tests pass, so the sets are equal. A visual overlap might suggest the same result, but the membership ledger is the argument.

A different pair shows why one inclusion is insufficient. Let C={jazz, folk} and D={jazz, folk, ambient}. Every member of C occurs in D, so C⊆D. But ambient∈D and ambient∉C, so D⊄C and C≠D. The same witness, ambient, refutes both reverse inclusion and equality.

Equality has two directions

Exact statement. For any sets A and B, A=B if and only if A⊆B and B⊆A. Here A⊆B abbreviates the universal claim “for every x, if x∈A then x∈B.” The universal claim ranges over objects in the setting under discussion; it is not inferred from how shaded regions look.

A=B⇔(A⊆B∧B⊆A)

Complete proof. If A=B, each member of either is a member of the other, giving both inclusions. Conversely, assume A⊆B and B⊆A. Choose any object x. If x∈A, the first inclusion gives x∈B. If x∈B, the second gives x∈A. Therefore x∈A exactly when x∈B, for every x. By the membership definition of set equality, A=B. This argument is valid for finite or infinite sets, provided ordinary extensional sets are meant.

A common type error is to infer {jazz}∈A from jazz∈A. If A is a set of styles, it may contain jazz but not the singleton set {jazz}. In A={jazz, folk}, jazz∈A is true, while {jazz}∈A is false. The singleton is instead a subset: {jazz}⊆A. The symbols ∈ and ⊆ ask different questions.

The empty set is a subset of every set. There is no member of ∅ that can violate “every member of ∅ lies in A.” This is a proof by the absence of counterexamples, not a claim that ∅ contains a hidden object. Whether ∅ is an element of A depends on A’s actual membership.

Check both directions

1. Let A={1,2,3}, B={x∈ℤ:1≤x≤3}, and C={1,2}. Decide A=B and C=A, giving membership reasons.

Hint for question 1

List the integers between 1 and 3 inclusive; then look for a member missing from C.

Full solution to question 1

B has exactly 1, 2, and 3, so every member of A lies in B and every member of B lies in A; hence A=B. C⊆A, but 3∈A and 3∉C, so A⊄C and C≠A.

2. For S={∅,{∅}}, classify ∅∈S, {∅}∈S, and {∅}⊆S.

Hint for question 2

There are exactly two members of S; then inspect the one member of {∅}.

Full solution to question 2

Both ∅∈S and {∅}∈S are true because the roster explicitly lists both objects. Also {∅}⊆S is true: its only member, ∅, belongs to S. The expressions have different meanings even though all three happen to be true here.

If the second roster feels strange, read each pair of braces from the inside out. Membership checks one object; subset checks every member of one set against another. That distinction prepares the power set, which is itself a set of subsets.

Membership is the final check

A set is fixed by its members. Order and repetition in a roster do not change it; two inclusions prove equality. A missing element gives a concrete counterexample to an inclusion. The proof of the two-inclusion rule is general, while a finite roster is a convenient worked case.

Stop when you can explain why jazz∈A and {jazz}⊆A are different sentences. The power set takes this one step further by treating all subsets of A as members of a new set.
