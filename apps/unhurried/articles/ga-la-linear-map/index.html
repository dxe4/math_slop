Coordinates and slope

An ordered pair (x,y) specifies a position in the coordinate plane: x measures horizontal displacement and y measures vertical displacement from the origin. The order matters. The points (2,5) and (5,2) usually occupy different places.

Worked example. From P=(1,2) to Q=(4,8), the horizontal change is 4−1=3 and the vertical change is 8−2=6. The slope is vertical change divided by horizontal change, giving 6/3=2.

m=y2−y1x2−x1=63=2

Use the same order in both subtractions. Reversing the points gives (2−8)/(1−4)=−6/−3=2 again. A horizontal line has slope zero. A vertical line has zero horizontal change, so this quotient does not define a finite slope.

Try one. Find the slope from (−1,4) to (2,−2).

Worked answer

The horizontal change is 2−(−1)=3. The vertical change is −2−4=−6. Dividing gives slope −2. The negative sign means that y decreases as x increases along this line.

Watch the units. If x is time in hours and y is distance in kilometres, the slope has units of kilometres per hour. The scales carry mathematical information.

Vectors and small matrices

A vector in the coordinate plane can be represented by an ordered pair. Add vectors component by component: (1,2)+(3,−1)=(4,1). A scalar is an ordinary number used to scale a vector, so 2(1,2)=(2,4). These operations describe displacements using the chosen coordinate axes.

Worked example. A two-by-two matrix has two columns. Let its first column be (2,1) and its second be (0,3). Applied to a vector (x,y), it produces x times the first column plus y times the second.

(2013)(12)=(27)

Here (1,2) maps to 1(2,1)+2(0,3)=(2,7). The columns tell you what happens to the unit vectors (1,0) and (0,1); scaling and addition then determine every other input.

Try one. Where does the same matrix send (−1,1)?

Worked answer

Use −1(2,1)+1(0,3)=(−2,−1)+(0,3)=(−2,2). Equivalently the first output is 2x and the second is x+3y; substituting x=−1 and y=1 gives the same pair.

Watch the convention. We write input vectors as columns. Each output uses an entire row's products and sum, rather than multiplying corresponding entries independently.

Can two arrows describe a whole map?

Imagine printing a square grid on a flexible sheet, then moving every point by one consistent rule. If you know where the horizontal unit arrow and vertical unit arrow end up, can you work out where any point ends up? For a linear map, yes. The reason is an equation you can check with coordinate arithmetic.

Background capsule. A vector (x, y) is a displacement: x units horizontally and y units vertically. Add vectors coordinate by coordinate, so (2, 0) + (1, 1) = (3, 1). Multiply by a number coordinate by coordinate, so −2(1, 1) = (−2, −2). The two standard basis vectors are e1 = (1, 0) and e2 = (0, 1). Every vector has the exact decomposition (x, y) = x e1 + y e2. A linear map respects both of these operations: T(u + v) = T(u) + T(v) and T(cu) = cT(u).

Move the two unit arrows

Worked example. Suppose T sends e1 to (2, 0) and e2 to (1, 1). The first image stretches the horizontal unit arrow to length two. The second leans the vertical unit arrow one unit right. A point at (3, −2) means “three horizontal unit arrows, then two vertical unit arrows backward.” Its image must therefore be 3(2, 0) − 2(1, 1) = (4, −2).

Exact inputs and outputs for this map
Input vBasis descriptionOutput T(v)
(1, 0)e1(2, 0)
(0, 1)e2(1, 1)
(3, −2)3e1 − 2e2(4, −2)
(−1, 1)−e1 + e2(−1, 1)
(0, 0)0e1 + 0e2(0, 0)

You can reproduce every row with two multiplications and one addition. No drawing is needed to decide the output. A grid picture is useful for seeing the overall stretch and slant, but the table gives exact coordinates even when the picture is small or unavailable.

Why the two arrows are enough

Exact statement, with proof. For any linear map T from the coordinate plane to itself, knowing T(e1) and T(e2) determines T everywhere. In native notation, the central rule is

T(x,y)=xT(e1)+yT(e2)

Proof: write (x, y) as x e1 + y e2. Apply T. The addition rule lets T pass through the sum; the scaling rule lets x and y pass out. That yields the displayed formula for every real x and y. It also proves uniqueness: two linear maps agreeing on both basis vectors agree on every vector. Conversely, choose any two output vectors p and q and define T(x, y) = xp + yq. Expanding coordinates shows this rule respects both addition and scaling, so it really is linear. There are no hidden restrictions on p and q: they can even be equal or zero.

For the worked example, p = (2, 0) and q = (1, 1), so T(x, y) = x(2, 0) + y(1, 1) = (2x + y, y). The matrix is a compact record of those images: its columns are p and q, making A = [[2, 1], [0, 1]]. Multiplying this matrix by the column (x, y) reproduces the same rule. A matrix is therefore a description of a linear action once the coordinate basis is chosen; it is not an extra geometric force.

The word linear matters. Sliding every point one unit right gives S(x, y) = (x + 1, y), but S(0, 0) = (1, 0). Every linear map sends zero to zero, since T(0) = T(0 + 0) = T(0) + T(0). Thus a translation is not linear. Its two unit-arrow images alone do not license the formula above.

Try the rule yourself

1. Calculation. A linear map U sends e1 to (1, −1) and e2 to (2, 3). Find U(4, −2) and give the coordinate rule U(x, y).

Hint for question 1

Write (4, −2) = 4e1 − 2e2, then combine the two given output vectors.

Full solution for question 1

U(4, −2) = 4(1, −1) − 2(2, 3) = (4, −4) + (−4, −6) = (0, −10). For an arbitrary input, U(x, y) = x(1, −1) + y(2, 3) = (x + 2y, −x + 3y).

2. Explanation. Someone proposes F(x, y) = (x + 1, y) and says its images of e1 and e2 determine it by linearity. Identify the mistake with one decisive calculation.

Hint for question 2

Test a property every linear map must have at the zero vector.

Full solution for question 2

F(0, 0) = (1, 0), whereas a linear map must send (0, 0) to (0, 0). So F is a translation, not a linear map. The basis-image formula cannot be applied. For example, F(e1) = (2, 0) and F(e2) = (1, 1), but treating these as linear images would incorrectly predict F(0, 0) = (0, 0).

A useful stopping point

You can now rebuild a 2D linear map from two arrows: decompose the input into e1 and e2, then apply the same weights to their images. This is a full argument for every vector in the plane, rather than a pattern inferred from a few plotted points. Check T(0) = 0 before using it on a new rule; that test can disprove linearity, though passing it alone does not prove linearity.

If you want one more idea, ask what the map does to the unit square. Its two sides become T(e1) and T(e2). Their resulting area leads to the determinant in the next exploration.
