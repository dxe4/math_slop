Can one move beat another in every case?

Suppose two players submit puzzle pieces at the same time. A player may prefer one piece no matter which piece the opponent submits. That is a dominance claim. It is stronger than “this move wins when the opponent chooses left,” because it checks every possible opposing action. We will separate strict dominance, weak dominance, and equal payoffs by doing all the comparisons.

Background capsule. A payoff pair (a,b) lists row's points first and column's second. To compare row actions, hold the column action fixed and compare first coordinates. To compare column actions, hold the row action fixed and compare second coordinates. “At least as good” means ≥; “better” means >. The opponent's action is not a probability here: each case is checked separately.

Where the strict and weak cases split

Payoffs (row, column) in a two-action puzzle
Column XColumn Y
Row A(4,3)(2,2)
Row B(1,3)(2,0)

Worked example. For row, A gives 4 instead of 1 when column chooses X, and 2 instead of 2 when column chooses Y. Thus A is never worse and sometimes better: A weakly dominates B. It does not strictly dominate B because against Y the two row payoffs tie. For column, the relevant comparisons run across each fixed row. Against row A, X gives column 3 while Y gives 2. Against row B, X gives 3 while Y gives 0. Thus X strictly dominates Y. The equal 3s down the X column compare different row actions and are not a tie in either choice comparison. Notice that two players' dominance statements use different coordinates even though they use the same grid.

If the lower-right second coordinate changed from 0 to 5, column Y would beat X against row B (5 > 3), while X would still beat Y against row A (3 > 2). A single changed cell can reverse an “every case” claim. This is why checking just a favored diagonal is inadequate.

The quantifier matters

Let s and t be two actions of player i, and x an action of the opponent. The exact definition of weak dominance is:

∀x:ui(s,x)≥ui(t,x),∃x:ui(s,x)>ui(t,x)

Strict dominance replaces “≥ for every x, > for some x” with “> for every x.” In a finite table the proof is exhaustive comparison: each column (for row) or row (for column) supplies one required inequality. Equal payoffs in every case do not count as weak dominance under the definition used here, because there is no strict improvement anywhere; the actions are payoff equivalent. Some texts use “weakly dominates” for the all-≥ condition alone. Stating the convention avoids a verbal disagreement hiding a mathematical one.

Boundary. A dominant strategy is an action that dominates each alternative action. With only two actions, comparing that pair suffices. If there are three actions, beating one alternative does not establish dominance over the third. Strict dominance does not require a guess about the opponent's probabilities; it is robust to every pure opposing action and therefore to every mixture of them. Weak dominance may leave a tie under some mixtures, so a player can rationally use the other action in those cases.

Make the comparisons yourself

1. Calculation. In the displayed table, decide whether row A strictly or weakly dominates row B. Then decide whether column X strictly or weakly dominates Y.

Hint for exercise 1

Write two payoff inequalities for each player; include the equality cases.

Full solution to exercise 1

Row sees 4 > 1 against X and 2 = 2 against Y. So A weakly dominates B, but not strictly. Column sees 3 > 2 against A and 3 > 0 against B. So X strictly dominates Y. The equal 3s in column X compare different rows, so they do not affect column's decision: column compares the second numbers within each row, not across rows. Against A, column compares 3 with 2; against B, 3 with 0. Thus the initial glance at equal 3s in the X column was irrelevant to column's decision.

2. Counterexample. Change only row's payoff at (B,Y) from 2 to 5. Does A still weakly dominate B? Explain by checking both opponent actions.

Hint for exercise 2

A single failed ≥ inequality destroys weak dominance.

Full solution to exercise 2

Against X, row still gets 4 from A and 1 from B, so A is better. Against Y, row now gets 2 from A and 5 from B, so B is better. Neither A nor B weakly dominates the other: each is preferable in one opposing case. A statement about one column cannot be generalized to all columns.

A durable comparison, with a limit

Strict dominance survives every opposing action with a strict payoff gain. Weak dominance under our convention survives with at least one gain and no losses. The table's column X is strictly dominant for column; row A is merely weakly dominant for row. This language characterizes payoffs, not moral virtue or an empirical guarantee of what a person will select.

Failure case. If a player has an unlisted action, or the payoff table leaves out a relevant future consequence, an apparent dominant move can disappear when the game is modeled more fully. With the stated finite actions and scores, however, the displayed inequalities settle the claim exactly.
