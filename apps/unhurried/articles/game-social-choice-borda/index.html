Does counting second place change a winner?

A club must select one mural color from Amber A, Blue B and Coral C. Each member submits a complete ranking. Plurality counts only first places. Borda scoring gives points for every rank: with three options, 2 points for first, 1 for second, 0 for third. The same ballots can choose different winners, so a counting rule is a substantive part of the decision.

Background capsule. A ranked ballot lists each of the three colors exactly once. A plurality score is the number of first-place votes. A Borda score is the sum of assigned rank points. “Winner” means highest score under the named rule. We declare ties when the maximum score is shared; this page never silently breaks a tie by alphabetical order. Each voter has weight one and rankings are strict.

Use the same five ballots twice

Complete mural-color rankings
Number of votersRanking
2A > C > B
1B > C > A
2C > B > A

Worked example. Plurality gives A two first places, B one, and C two. Thus plurality declares a tie between A and C. Borda counts all positions. The two A > C > B ballots give A 4 points and C 2. The B > C > A ballot gives B 2 and C 1. The two C > B > A ballots give C 4 and B 2. Totals: A = 4, B = 4, C = 7. C is the unique Borda winner. The totals add to 15, matching five ballots × (2+1+0) points each; that checksum helps catch counting mistakes.

To show an outright plurality-versus-Borda reversal, add one more A > B > C voter. Plurality now gives A three first places, C two, B one, so A wins. Borda adds 2 to A and 1 to B, producing A = 6, B = 5, C = 7, so C still wins. The sixth voter did not create a tie: the rules disagree on a unique winner.

Define the score before judging it

For candidate c and voters v, let pv(c) be 2, 1 or 0 according to c's position on v's ballot. Then:

B(c)=∑vpv(c)

Exact claim. On the six-ballot profile, plurality uniquely elects A and Borda uniquely elects C under the stated point convention. The proof is the displayed rank counts and sums. The result is about these ballots and rules; it is not a theorem that Borda always chooses C-like compromises or that plurality always fails. Both methods discard information: plurality ignores lower ranks, while Borda converts ordinal positions into a fixed point spacing that voters may not feel.

For m options a common Borda convention assigns m−1 down to 0. Adding the same constant to every rank's points changes all candidate totals equally and leaves winners unchanged for a fixed number of complete ballots. Changing the gaps between ranks can change winners. If voters omit options or share ranks, additional scoring rules are required. We do not apply this formula to incomplete or tied ballots.

Count and interpret

1. Calculation. Use the six-ballot profile after adding one A > B > C voter. Change the single B > C > A ballot to B > A > C. Recalculate plurality and Borda winners.

Hint for exercise 1

First places stay the same. Only A and C exchange their Borda positions on that ballot.

Full solution to exercise 1

Plurality remains A = 3, B = 1, C = 2, so A still wins. In Borda, the changed ballot gives A one point instead of zero and C zero instead of one. Starting from A = 6, B = 5, C = 7, the totals become A = 7, B = 5, C = 6. A now wins Borda too. A change in lower ranks can change the Borda winner while leaving plurality unchanged.

2. Explanation. A member argues that Borda's winner must be the option that beats each other option by pairwise majority. Does the score definition guarantee this? Give a numerical reason to doubt that implication.

Hint for exercise 2

One score adds all rank points; a head-to-head count considers one opponent at a time.

Full solution to exercise 2

No. The Borda total measures assigned rank points across all ballots, whereas a pairwise majority asks how many voters rank c above a particular rival. The six-ballot profile illustrates the distinction: C scores 7 against A's 6. A is ranked above C by the two A > C > B voters and the added A > B > C voter, while C is ranked above A by the B > C > A voter and the two C > B > A voters. Their head-to-head contest is tied 3–3. Thus C wins Borda but is not a strict Condorcet winner, because C does not beat A head to head. A Borda score alone therefore cannot certify a Condorcet winner.

Rules answer different questions

Plurality counts first-place support; Borda rewards position across full rankings. On the six-ballot example A wins plurality and C wins Borda. The calculation is decisive only after the rule, completeness requirements and tie convention are set. A real club should decide those before seeing a disputed tally.

Failure case. With incomplete rankings or equal ranks, the 2–1–0 tally lacks a defined treatment. Also, no scoring formula proves that its winner meets every possible fairness criterion. The next question is which criteria a chosen rule actually satisfies.
