Why does division work modulo seven?

Modulo 7, [3] has inverse [5] because 3·5=15≡1. Modulo 6, [2] has no inverse: its products with [0] through [5] are [0],[2],[4],[0],[2],[4], never [1]. The difference is governed by the greatest common divisor and, for the whole quotient ring, by primality of the modulus.

Background capsule. In Z/nZ, [a][b]=[ab]. A multiplicative inverse of [a] is a class [b] with [a][b]=[1]. A field is a commutative ring with 0≠1 in which every nonzero element has an inverse. The greatest common divisor gcd(a,n) is the greatest positive integer dividing both. Bézout's identity says there are integers u,v with ua+vn=gcd(a,n). One can obtain it by repeatedly dividing with remainder: the last nonzero remainder is the gcd, and substituting backward expresses it as an integer combination. We use that stated identity as a local number-theory input.

Two tiny multiplication tables

Worked example. Modulo 7, Euclid's algorithm for 3 and 7 gives 7=2·3+1, so 1=7−2·3. Thus −2 is an inverse of 3 modulo 7, and [−2]=[5]. Multiplication confirms [3][5]=[15]=[1]. Modulo 6, gcd(2,6)=2, so no integer combination 2u+6v can equal 1. There is no inverse for [2]. More visibly, [2][3]=[0] although neither factor is zero. Each nonzero factor in such a product is called a zero divisor.

This distinction concerns multiplication. Both rings still have additive inverses for every class: modulo 6, [2]+[4]=[0]. A failed attempt to divide by [2] does not mean that modular addition has stopped being a group operation.

Units, primes and the exact criterion

[a] is invertible mod n⇔gcd(a,n)=1

Exact statement and proof. Let n≥2. If gcd(a,n)=1, Bézout gives ua+vn=1. Taking classes modulo n gives [u][a]=[1], so [u] is an inverse. Conversely, if [a][b]=[1], then ab−1=kn for some integer k. Thus ab−kn=1 is an integer combination of a and n. Every common divisor of a and n divides 1, so their gcd is 1. This proves the displayed equivalence for every class, including [0], whose gcd with n is n and which is not a unit.

Field criterion, with proof. Z/nZ is a field exactly when n is prime, for n≥2. If n=p is prime, every nonzero class [a] has p∤a, hence gcd(a,p)=1. The inverse criterion supplies an inverse, and 0≠1 because p≥2. Conversely, if n is composite, write n=uv with 1<u,v<n. Both [u] and [v] are nonzero, yet [u][v]=[n]=[0]. A field cannot contain nonzero zero divisors: multiplying xy=0 by x−1 would give y=0. Therefore Z/nZ is not a field. The argument also identifies the concrete failure, rather than merely saying that a multiplication table looks incomplete.

A nonzero residue can still be invertible for composite n. For example [5] is its own inverse modulo 6 because 25≡1, while [2] is not. The field criterion requires every nonzero residue to be invertible. The excluded n=1 case has only one class, with [0]=[1], and fails the standard field axiom 0≠1.

Find an inverse or prove none exists

1. Calculation. Find the inverse of [5] modulo 12, or justify that none exists. Then do the same for [8].

Hint for question 1

Compute each gcd with 12. For 5, use a small product; for 8, explain why an equation 8b−12k=1 is impossible.

Full solution for question 1

gcd(5,12)=1, and 5·5=25=2·12+1, so [5]−1=[5]. But gcd(8,12)=4. Every integer combination 8b−12k is divisible by 4, so it cannot equal 1; [8] has no multiplicative inverse. Indeed [8][3]=[24]=[0] with both factors nonzero.

2. Explanation. Someone claims Z/9Z is a field because [2] has an inverse. Diagnose the inference and provide a counterexample class.

Hint for question 2

A field needs inverses for every nonzero class. Look at [3].

Full solution for question 2

[2] is invertible, with [2][5]=[1], but that checks only one nonzero class. The nonzero class [3] is not invertible because gcd(3,9)=3. Also [3][3]=[0], so a field is impossible. Nine is composite, exactly as the field criterion predicts.

Division has an exact boundary

For n≥2, a residue [a] is invertible exactly when gcd(a,n)=1. Consequently every nonzero residue is invertible exactly for prime n. The proof uses Bézout's identity for existence and zero divisors for failure. A table with a few successful divisions is not enough to call a ring a field; one nonzero zero divisor settles the question in the other direction.

The same prime-versus-composite split appears when working with polynomial coefficients: over a field many familiar division algorithms work, while over a general ring extra care is needed.
