Why does a branching network have one fewer link?

A family connection chart that branches without rejoining has a route between any two people and no cycle. It is a tree. If there are seven people in such a connected chart, six links suffice; adding another link creates a cycle. The edge count is useful, but it is the structure that makes the count true.

Background capsule. A simple undirected graph has vertices and unordered edges. A path uses distinct vertices; a cycle is a closed route of at least three edges with no repeated vertex except the common start/end. A graph is connected when each pair of vertices has a path. A tree is a finite connected graph without cycles. A leaf is a degree-one vertex. Induction proves a statement for every positive integer by checking a base case and showing the n-case leads to the (n+1)-case; we will show the actual deletion step rather than invoking induction as a slogan.

Consider edges AB, BC, BD, DE, DF on vertices A through F. The network is connected, has no cycle, and contains leaves A,C,E,F. It has six vertices and five edges. We can remove F and its one edge DF, leaving another tree. Repeating that action reveals the edge formula.

Peel leaves, preserve the routes

Worked example. In the example, delete F–D, then E–D, then C–B, then D–B, then A–B. At each stage with at least two vertices, there is a leaf to remove. The remainder stays connected: a path between any two remaining vertices could not have passed through a deleted leaf as an internal stop, because that leaf had only one incident edge. It stays acyclic because deletion cannot create a cycle. Eventually one vertex and no edges remain.

Why is a leaf guaranteed? Take a longest path in a finite tree. At one end, any neighbor other than the next vertex on the path would either already lie on the path, making a cycle, or extend the path, contradicting its longest status. Thus that end has degree one. The same is true of the other end when the tree has at least two vertices.

Count links and identify the unique route

Theorem. Every finite tree with n≥1 vertices has exactly n−1 edges:

|E|=|V|−1.

Complete induction proof. A one-vertex tree has zero edges. Suppose the claim holds for every tree with n vertices. A tree T with n+1 vertices has a leaf by the longest-path argument. Delete that leaf and its incident edge. The remaining graph is connected and acyclic, hence a tree with n vertices. By the induction hypothesis it has n−1 edges. Restoring the one deleted edge gives n edges, which is (n+1)−1. This covers every finite positive size.

Another exact tree property is uniqueness of the path between any two vertices. Connectedness gives at least one path. If two distinct simple paths joined u and v, follow them to the first point at which they split and then to a point where they meet again. Those two distinct segments form a cycle, contradicting the tree definition. This proof establishes the path property for trees. Conversely, if there is exactly one path between each pair, the graph is connected by the existence part, and a cycle would give two paths between vertices on it. Thus a finite graph is a tree exactly when every pair of vertices has a unique simple path.

Failure case. The equation |E|=|V|−1 by itself does not guarantee a tree. Take a triangle on A,B,C and an isolated vertex D: there are four vertices and three edges, yet the graph is disconnected and has a cycle. The formula becomes a tree test when accompanied by a structural hypothesis, such as connectedness or acyclicity, but proving those strengthened converses requires an argument. A cycle can also appear in a connected graph after one new edge joins two vertices already linked by a path: the new edge plus the old path closes a cycle.

Use structure before the formula

Exercise 1. A connected acyclic network has nine vertices. How many edges? What happens if one new edge joins two previously nonadjacent vertices?

Hint for exercise 1

Apply the tree formula, then use the unique existing path between the endpoints of the new edge.

Full solution to exercise 1

It is a tree, so it has 9−1=8 edges. The endpoints of any new edge already have one path between them. The new edge together with that path forms a cycle. The resulting connected graph has nine edges and is no longer a tree.

Exercise 2. A report gives V={A,B,C,D,E} and edges AB,BC,CA,DE. It has |E|=|V|−1. Is it a tree? Give two independent reasons.

Hint for exercise 2

Inspect the three edges among A,B,C, then try to walk from A to D.

Full solution to exercise 2

No. AB,BC,CA make a cycle A–B–C–A, violating acyclicity. Also A and D belong to separate components, violating connectedness. Its four edges and five vertices satisfy the numerical equation, demonstrating that the equation alone does not characterize trees.

One link per new vertex

A finite tree begins with one vertex and gains each further vertex through one link without creating a cycle. The leaf-deletion proof makes |E|=|V|−1 exact, and the absence of cycles explains why each pair has a unique path. Stop here if you can verify the tree hypotheses before using its count. A tree can also arise while exploring a network layer by layer in breadth-first search.
