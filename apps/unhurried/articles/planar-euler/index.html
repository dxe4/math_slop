Why does a flat map satisfy one equation?

Draw a connected network on a sheet so that edges meet only at named vertices. The lines divide the sheet into regions, including the unbounded region outside the drawing. Count vertices V, edges E, and faces F. Their counts obey Euler's formula V−E+F=2. It is tempting to count any crossings as faces, but the equation's drawing assumptions are part of the theorem.

Background capsule. A finite simple graph has vertices and undirected edges. A plane embedding is a drawing of that graph in the plane in which edge curves have no crossings except at common endpoints. A face is a connected region left after the embedded edges are removed; the outside region counts as one. A tree is connected and has no cycle. We use the proved elementary property that a finite tree has V−1 edges. A spanning tree is a tree using every vertex of a connected graph, obtained by keeping enough edges for connectedness and deleting cycle edges.

Start with a square A–B–C–D–A. It has V=4, E=4, F=2: the inside and outside. Add diagonal AC, drawn inside. Now E=5 and F=3, because the old inside face splits into two. Both counts give 2. What makes that pattern hold beyond the square?

Start with a spanning tree

Worked example. For the square with diagonal, one spanning tree uses AB, BC, CD. It has four vertices, three edges, and only one face, the outside: a tree's arcs do not enclose a region. Add DA along its plane curve. Its endpoints were already connected through A–B–C–D, so the new edge closes a cycle and divides one existing face into two. Counts change from (4,3,1) to (4,4,2). Add AC along the already specified crossing-free curve inside the square; it splits the interior face. Counts become (4,5,3).

A graph drawn with crossings may still be planar if its edges can be redrawn to remove those crossings. The theorem concerns an actual crossing-free embedding. Counting regions in a drawing with an unmarked crossing creates a different plane graph if that crossing is treated as a vertex, and creates no vertex there if the edges merely pass over one another.

Euler's formula with its drawing assumptions

Theorem. For a finite connected plane graph, with F counting the outside face,

V−E+F=2.

Proof through edge deletion. In the given embedding, repeatedly delete an edge lying on a cycle until none remains. Such an edge is not a bridge, so deleting it preserves connectedness. In a plane embedding it borders two distinct faces; removing it merges exactly those faces, decreasing both E and F by one. The quantity V−E+F is unchanged. When no cycle remains, the connected graph is a tree. A plane tree has F=1: without a cycle there is no bounded face; equivalently, its complement remains connected. It has E=V−1 by the tree theorem, so V−E+F=V−(V−1)+1=2. Restoring the deleted edges preserves the quantity. The plane-topology step that deletion merges exactly two faces is named here; it follows from the Jordan curve separation associated with an edge on a cycle. We use that standard plane fact rather than claiming to prove the Jordan curve theorem from scratch.

This is a graph theorem about an embedding, not just an arithmetic coincidence. A disconnected plane graph with two separate triangles has V=6, E=6, F=3 (two interiors and one shared exterior), giving 3 rather than 2. More generally, a plane graph with c connected components has V−E+F=c+1, but the proof of that extension needs component bookkeeping. The connectedness hypothesis cannot be omitted.

One consequence can test planarity: a connected simple planar graph with V≥3 has E≤3V−6. Each face boundary has at least three edge occurrences, and each edge borders two faces, so 3F≤2E. Substitute F=2−V+E into that inequality to obtain E≤3V−6. The face-boundary count needs the simple graph and connectedness assumptions; bridges count twice along their face boundary. This necessary bound does not prove a graph planar when it passes.

Count with the outside face

Exercise 1. A connected crossing-free drawing has V=8 and E=11. How many faces does it have? If one new edge is drawn inside an existing face between nonadjacent boundary vertices, without crossing any edge, what are the new counts?

Hint for exercise 1

Rearrange V−E+F=2. A valid new noncrossing chord splits one face.

Full solution to exercise 1

F=2−8+11=5, including the outside. The new edge leaves V=8, raises E to 12, and splits one face, raising F to 6. The check is 8−12+6=2. This answer assumes the chord's interior lies in that face and its endpoints are distinct existing vertices.

Exercise 2. Someone draws two disjoint triangles and reports V=6, E=6, F=2 because each triangle has an inside. Explain the face-count error and why the connected theorem still cannot be used.

Hint for exercise 2

Count the region outside both triangles. Then inspect connectedness.

Full solution to exercise 2

There are three faces: two distinct interiors plus the one unbounded outside region. Thus 6−6+3=3. The graph has two connected components, violating the theorem's hypothesis; the value 3 agrees with the component extension c+1=2+1. Treating the shared outside as absent caused the original F=2 error.

The outside counts too

For a connected crossing-free plane drawing, deleting cycle edges preserves V−E+F until a spanning tree gives the value two. The proof uses an explicit plane separation fact and does not apply to arbitrary crossing drawings or disconnected graphs as stated. This is a stopping point for a finite, planar result; studying surfaces changes the equation. To revisit why the terminal graph has V−1 edges, use trees.
