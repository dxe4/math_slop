Substitution and equations

A letter in a formula stands for a value. Substitution replaces that letter everywhere with a chosen number. Parentheses help keep a negative input together: if f(x)=x²+2x, then f(−3)=(−3)²+2(−3)=9−6=3. Squaring happens before adding.

Worked example. To solve 3x+5=20, subtract 5 from both sides and then divide both sides by 3. Applying the same operation to both sides preserves the equality; the divisor here is nonzero.

3x+5=20⇒3x=15⇒x=5

Substitute the answer back: 3×5+5=20. This checks the proposed value against the original equation. The distributive rule also lets you expand a bracket: 2(x+4)=2x+8.

Try one. Solve 2(x+4)=18 and check the result.

Worked answer

Divide both sides by 2 to obtain x+4=9. Subtract 4 to get x=5. Checking gives 2(5+4)=2×9=18, as required.

Watch the sign. The values (−3)²=9 and −3²=−9 differ: the second expression applies the minus sign after squaring 3. Keep the parentheses when substituting negative values.

Networks and degree counts

A finite simple undirected graph consists of vertices and edges. Each edge joins two different vertices, with at most one edge for each pair. “Undirected” means that AB and BA name the same connection. A drawing shows these relationships; its line lengths need not carry any information.

Worked example. Use vertices A, B, C and D, with edges AB, AC and BC. The degree of a vertex is the number of edges touching it. A, B and C each have degree 2, while D has degree 0 because it is isolated.

2+2+2+0=6=2×3

Every edge contributes one to the degree at each of its two ends. Adding all degrees therefore gives twice the number of edges. An isolated vertex still belongs to the graph and contributes zero to the sum.

Try one. Add the edge CD. What changes?

Worked answer

C's degree rises to 3, and D's rises to 1. A and B stay at 2. The degree sum becomes 8, and there are now four edges, again giving twice the edge count.

Watch the convention. A repeated connection or an edge from a vertex to itself requires a different graph convention. Keep the simple-graph assumptions explicit when translating a real network.

Can rectangles pin down a curved area?

The region beneath y = x² from x = 0 to x = 1 has a curved roof. We can measure it without knowing an antiderivative: place rectangles below the roof and a second collection above it. If the two totals become arbitrarily close, they leave the area nowhere else to go.

The local background is simple. A rectangle's area is width times height. The notation Σ means “add these terms”; for example, Σ from k = 1 to 3 of k² is 1² + 2² + 3² = 14. A limit here means a number our totals can approach as closely as any specified positive tolerance.

We restrict attention to this nonnegative, continuous, increasing function on [0, 1]. Because x² increases there, the left endpoint of each interval gives its lowest height and the right endpoint its highest.

Build two sets of rectangles

Worked example. Divide [0, 1] into n equal intervals, each of width 1/n. With n = 2, left-endpoint heights are 0 and 1/4. Their total area is (1/2)(0 + 1/4) = 1/8. Right-endpoint heights are 1/4 and 1, giving (1/2)(1/4 + 1) = 5/8. The curved area lies between these totals.

The midpoint of those two bounds then has error below 0.005 from the true area. This conclusion uses both inequalities, rather than assuming the last displayed decimal is accurate. An exact area from finite sums

Exact statement and hypotheses. The continuous function x² is Riemann integrable on [0, 1]. Its integral, representing the nonnegative area, is:

Read the symbol ∫ with lower limit 0 and upper limit 1 as “accumulate from 0 to 1.” The expression x² is the function being integrated, called the integrand, and dx identifies x as the integration variable. This notation names a limit of sums; we are not setting an ordinary rectangle width equal to zero.

∫01x2dx=limn→∞(n+1)(2n+1)6n2=13

Finite-sum proof. We need the identity 1² + 2² + … + n² = n(n + 1)(2n + 1)/6. It holds for n = 1, since the right side is 1·2·3/6 = 1. If it holds for n, adding (n + 1)² gives

n(n + 1)(2n + 1)/6 + (n + 1)² = (n + 1)[n(2n + 1) + 6(n + 1)]/6 = (n + 1)(n + 2)(2n + 3)/6.

This is precisely the claimed expression with n replaced by n + 1. The base case and this step prove the identity for every positive integer by induction.

Area derivation. Each right rectangle has height (k/n)² and width 1/n. Thus Un = (1/n³)Σk² = (n + 1)(2n + 1)/(6n²). The left total instead uses k = 0 through n − 1, giving Ln = (n − 1)(2n − 1)/(6n²).

Expanding, Un = 1/3 + 1/(2n) + 1/(6n²), while Ln = 1/3 − 1/(2n) + 1/(6n²). Both approach 1/3, and their gap is exactly 1/n.

The integration principle used here is the upper-and-lower-sum criterion: a bounded function is Riemann integrable if partitions can make the upper-minus-lower sum arbitrarily small. We state this general criterion without its full construction. Our gap 1/n verifies it directly in this example; squeezing between the two limiting totals then gives area 1/3.

Check the bounds yourself

1. Calculate. Find both rectangle totals for n = 5. Do they bracket 1/3?

Hint

Substitute n = 5 into the two finite formulas.

Worked solution

L5 = 4·9/(6·25) = 0.24 and U5 = 6·11/(6·25) = 0.44. Since 0.24 < 1/3 < 0.44, they bracket the area. Their gap is 0.20 = 1/5.

2. Explain. For the decreasing function 1 − x on [0, 1], would left rectangles still give a lower bound?

Hint

Compare the function's height at the left and right ends of one interval.

Worked solution

No. The left height is now the largest, so left rectangles give an upper bound and right rectangles a lower bound. Endpoint names alone do not determine the inequality; monotonicity does.

The curve has nowhere else to go

The exact area is 1/3 because two computable bounds converge to it. We justified the square-sum identity rather than treating it as magic. This method relies on our increasing function; a general curve needs actual lower and upper heights on each interval. Later, the fundamental theorem of calculus connects this accumulation story to derivatives.
