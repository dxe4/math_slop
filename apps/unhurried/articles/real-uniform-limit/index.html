When does a limit keep continuity?

A sequence of continuous curves can approach a function that jumps. The standard example fₙ(x)=xⁿ on [0,1] crowds its change closer to the right endpoint as n grows. Every fixed x below 1 eventually sees height near zero, yet the value at 1 always stays one. We will locate exactly which convergence condition is missing, then prove a theorem that protects continuity.

Background capsule. Pointwise convergence lets the index N required for a given error depend on the input x. Uniform convergence requires one N that works at every input in the domain. The supremum of a set of nonnegative errors is its least upper bound; it need not be attained. A continuous f at a responds to a small input change near a with a small output change. We use the triangle inequality |u+w|≤|u|+|w| and ordinary ε arguments.

Follow one fixed point, then move the point

Worked example. At x=1/2, fₙ(x)=2−n tends to zero. At x=0.9 it also tends to zero, though more slowly. At x=1, fₙ(1)=1 for all n. Thus the pointwise limit f is zero on [0,1) and one at 1. It has a jump at the endpoint: inputs x<1 can be arbitrarily close to 1 while f(x)=0 remains one unit from f(1)=1.

To test uniform convergence, do not freeze x first. For each n, choose xₙ=2−1/n, which is strictly below 1 but tends to 1. Then fₙ(xₙ)=1/2 whereas f(xₙ)=0. Every n has an error of at least 1/2. In fact the supremum error is one: for x<1, |fₙ(x)−f(x)|=xⁿ, and values of x arbitrarily close to 1 make xⁿ arbitrarily close to one. The supremum is not attained on [0,1) but it is still one.

A uniform limit theorem

Exact statement. If functions fₙ:D→ℝ are continuous at a∈D and fₙ→f uniformly on D, then f is continuous at a. Here continuity uses points of D near a; no interval or compactness assumption on D is needed.

supx∈D|fn(x)−f(x)|→0

Proof. Given ε>0, uniform convergence supplies one n so large that |fₙ(x)−f(x)|<ε/3 for all x∈D, including x=a. Keep this n fixed. Continuity of this particular fₙ at a supplies δ>0 such that |x−a|<δ and x∈D imply |fₙ(x)−fₙ(a)|<ε/3. The triangle inequality gives |f(x)−f(a)|≤|f(x)−fₙ(x)|+|fₙ(x)−fₙ(a)|+|fₙ(a)−f(a)|<ε. This proves continuity. The order of choices matters: choose a single n that works for all x, then use continuity of that one function.

For xⁿ on [0,1], each fₙ is continuous, but the limit is not continuous. By the theorem, convergence cannot be uniform; our exact supremum calculation directly confirms that. Pointwise convergence alone does not permit the first and third error terms to be controlled using one n while x varies near a.

The converse is false. Continuous functions may converge pointwise to a continuous function without uniform convergence. On ℝ, fₙ(x)=x/n tends pointwise to zero, but sup over ℝ of |x/n| is unbounded for each n. The limit is continuous. So uniform convergence is a sufficient condition for preservation of continuity, not a necessary one. On restricted bounded domains the same sequence is uniform; the domain must be stated.

Audit a sequence of functions

1. Calculate. Show gₙ(x)=x/(n+1) tends uniformly to zero on [−4,4]. Give an explicit N for ε=0.01.

Hint

Maximize |x| on the given domain, then bound 4/(n+1).

Worked solution

For every x∈[−4,4], |gₙ(x)|≤4/(n+1), with equality at either endpoint. Thus the supremum error is 4/(n+1)→0. For strict error below 0.01=1/100, require n+1>400, so N=400 works for all integer n≥400. Indeed 4/401<1/100. The same N controls every x.

2. Diagnose a false proof. “Because fₙ(x)→f(x) for each x and each fₙ is continuous, we may take n large, then move x near a.” What is the missing condition?

Hint

Ask whether the chosen n still works after x changes.

Worked solution

Pointwise convergence supplies an index N(x,ε), which may change as x moves. It cannot guarantee a single n controls fₙ(x)−f(x) for all nearby x. The sequence xⁿ on [0,1] defeats the argument at a=1. Uniform convergence supplies an N(ε) valid for all x, allowing the three-term triangle-inequality proof above.

Control the error over the whole domain

The limit of xⁿ changes continuity because its error peak keeps sliding toward 1. Uniform convergence rules out that sliding peak and transfers continuity by a short ε/3 proof.
