Sets and membership

A set records which objects belong to a collection. In roster notation, braces surround its members: A={1,3,5}. Writing 3∈A says that 3 belongs to A; writing 2∉A says that 2 does not. Repeating a member or changing the listing order leaves the set unchanged.

Worked example. Let B={3,4}. The union A∪B contains every object in either set. The intersection A∩B contains exactly the objects in both sets.

A∪B={1,3,4,5}A∩B={3}

The empty set, written ∅, has no members. A subset C⊆A has all its members in A. The subset may equal the whole set; the symbol does not require a smaller collection.

Try one. With C={1,5}, find C∩B and decide whether C⊆A.

Worked answer

C and B have no common member, so C∩B=∅. Both 1 and 5 belong to A, hence C⊆A. Empty intersection and subset inclusion ask different questions.

Watch the object. The number 3 and the set {3} are different objects. Here 3∈A and {3}⊆A are both true, but they express different relationships.

Every person has a book: whose book?

At a tiny book club, Ada has read Atlas and Ben has read Beacon. Is it true that every member has read a book? Yes. Is there a book every member has read? No. Moving “a book” in front of “every member” changes the claim. Logic records the difference by the order of its quantifiers.

A domain tells us what each variable ranges over. Let X={Ada, Ben} be people and Y={Atlas, Beacon} be books. Let R(x,y) mean “person x has read book y.” The relation R is simply a set of permitted person-book pairs. The symbol ∀ means “for every” and ∃ means “there exists.” These definitions are the local prerequisite capsule; no theory of relations is assumed.

We compare ∀x∈X ∃y∈Y R(x,y) with ∃y∈Y ∀x∈X R(x,y). A witness for an existential claim is a specific object that makes it true. A counterexample to a universal claim is a specific object for which it fails. Keep those jobs separate as you read the grid.

Worked example. For the first sentence, choose a book separately after choosing each person. Ada’s witness is Atlas; Ben’s is Beacon. Every row contains a Yes, so the first sentence is true. For the second sentence, choose one book first and hold it fixed. Atlas fails on Ben; Beacon fails on Ada. No column contains two Yes entries, so the second sentence is false.

Now add a third book, Common, read by both. Both sentences become true: Common is one witness for all members. The changed table shows the stronger claim can hold; the original table shows it need not follow from the weaker one. Finite models are valuable because a single model can refute a proposed general equivalence.

An implication and its limit

Exact statement. If X and Y are nonempty sets and R is any relation on X×Y, then ∃y∈Y ∀x∈X R(x,y) implies ∀x∈X ∃y∈Y R(x,y). The reverse implication is not valid in general.

(∃y∀xR(x,y))→(∀x∃yR(x,y))

Complete proof of the forward implication. Assume one y₀ works for every x. Pick any x from X. The same y₀ is a witness for that x, so ∃y R(x,y) holds. Because x was arbitrary, the first-then-second quantifier sentence follows. The two-row table above is a complete countermodel to the converse: it satisfies the right side and falsifies the left side.

The nonempty assumption avoids a separate issue about choosing witnesses over an empty person domain. In classical semantics, if X is empty, ∀x∈X ∃y R(x,y) is vacuously true, while ∃y∈Y ∀x∈X R(x,y) depends on whether Y has a member. For the forward implication, an actual y witness still suffices even when X is empty. We restrict to a familiar club so that the worked meaning is concrete.

A common failure is to use a different y for each x while writing one y outside ∀x. That silent switch is exactly what the order forbids. Draw rows and columns if the symbols feel slippery: every row needs a Yes versus one column needs Yes everywhere.

Find the witness or the failed row

1. Let X={Iris, Jo} and Y={Red, Blue}. Iris likes Red and Blue; Jo likes Blue only. Evaluate both quantified sentences and name witnesses.

Hint for question 1

Look for a Yes in each row, then for one all-Yes column.

Full solution to question 1

Both are true. Iris has Red or Blue as a witness and Jo has Blue, so every row succeeds. Blue is a common witness: both Iris and Jo like it. The first sentence permits different witnesses, but a shared witness happens to exist here.

2. Construct a two-person, two-book relation in which ∀x∃y R(x,y) is false. State which person fails and whether ∃y∀x R(x,y) can nevertheless be true.

Hint for question 2

Give one person an empty row.

Full solution to question 2

For example, let only Ada have read Atlas and let Ben have read no book. Ben’s row has no Yes, so ∀x∃y R(x,y) is false. No book is read by Ben, so no common book exists either; ∃y∀x R(x,y) is false. It cannot be true when the first statement is false, by the proved implication.

You can reverse the roles of the two people and rename the books; the explanation must still identify the empty row. The exercise checks the implication as well as the grid reading.

Who gets to choose when?

In ∀x∃y, the choice of y may depend on x. In ∃y∀x, one y must serve every x. A common witness supplies individual witnesses, so the second form implies the first. The diagonal two-person table proves the converse fails. That is a complete proof plus a complete finite countermodel, not merely a visual suggestion.

The stopping point is the ability to produce the witness or failure for a sentence in a named domain. Negating quantified sentences is the natural next step, but it requires care with both the quantifier and the predicate.
