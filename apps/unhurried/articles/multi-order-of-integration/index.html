Turn the slices sideways

An integral over a triangular region may look hard because its first set of bounds cuts vertically. The same points can be listed horizontally. Reversing integration order is a geometric re-description of the region, followed by a theorem that permits the two iterated calculations to agree for a continuous integrand.

Background capsule. In ∫₀¹∫ₓ¹ f(x,y) dy dx, the inner integral holds x fixed and moves y from x to 1; the outer integral then moves x from 0 to 1. Inequalities define a region without reference to drawing scale. For a continuous function on a closed bounded region, its double integral can be computed by either standard slicing order when bounds describe the same region.

Describe one triangle twice

Worked example. The first bounds say 0≤x≤1 and x≤y≤1. Combine them as 0≤x≤y≤1. To choose y first, y can run from 0 to 1, and for that y, x can run from 0 to y. Hence the other order is ∫₀¹∫₀ʸ f(x,y) dx dy. No region has moved; only the order of enumeration has changed.

For f(x,y)=y, the original order gives ∫₀¹ [y²/2] from y=x to 1 dx = ∫₀¹(1−x²)/2 dx=1/3. The reversed order is shorter: ∫₀¹∫₀ʸ y dx dy=∫₀¹ y² dy=1/3. Reversing is especially useful when the new inner antiderivative is simpler, but the region description should come before the algebra.

Check a typical slice before integrating. At x=1/4 the original region contains y between 1/4 and 1; at y=1/4 the reversed region contains x between 0 and 1/4. These are different line segments through the same triangular set. A bound depending on the inner variable would not describe a fixed slice: while integrating dx, its endpoints may depend on y, which is being held constant, but cannot still depend on the moving x. Reading one slice aloud often reveals an impossible or reversed inequality before an antiderivative obscures it.

The equality and its scope

Exact statement. If f is continuous on the compact triangle D={(x,y):0≤x≤y≤1}, then both iterated integrals below exist and equal ∬Df dA. This is a standard Fubini-type result for such a region, not a consequence of symbol swapping alone. We use that theorem here and prove the equality directly for polynomial examples by calculation.

∫01∫x1f(x,y)dydx=∫01∫0yf(x,y)dxdy

The bounds can be justified without a drawing: from 0≤x≤1 and x≤y≤1 we immediately get 0≤y≤1 and 0≤x≤y. Conversely the latter inequalities imply the former. So the two descriptions are logically equivalent point by point. Once that is established, continuity on this bounded set supplies the integrability needed to exchange the order.

A failure case lies outside these hypotheses. For unbounded regions or singular integrands, separately existing iterated integrals need not be equal without absolute integrability or an appropriate theorem. Even on the triangle, changing bounds to 0≤x≤1−y would define a different triangle. A sketch can catch such mistakes, but a check of inequalities is decisive.

There is a simple area check for the bounds: setting f=1 makes either iterated integral equal the triangle’s area, 1/2. In the first order, each vertical slice has length 1−x, whose integral is 1/2. In the reversed order, each horizontal slice has length y, also integrating to 1/2. This check cannot prove equality for every f, but it catches many wrong bound reversals quickly.

Rebuild the bounds

1. Calculation. Reverse ∫₀¹∫ₓ¹ x dy dx and evaluate it in both orders.

Hint for question 1

The triangle is unchanged; hold y fixed in the reversed version.

Worked solution for question 1

The reversed integral is ∫₀¹∫₀ʸ x dx dy=∫₀¹ y²/2 dy=1/6. Originally, integrating dy gives ∫₀¹ x(1−x) dx=[x²/2−x³/3]₀¹=1/6. Both routes agree.

2. Explanation. Someone replaces the inner x bound with 0≤x≤1−y. Find a point included in the correct region but excluded by the proposed one.

Hint for question 2

Choose y near 1 and x below y but larger than 1−y.

Worked solution for question 2

The point (x,y)=(3/4,1) satisfies 0≤x≤y≤1, so it lies in D. The proposed bound requires x≤1−y=0 and excludes it. The proposed region has a different diagonal boundary; it cannot be a reversal of the original integral.

A reliable stopping rule

Translate nested bounds into simultaneous inequalities, decide the new outer interval, then solve the remaining inequalities for the new inner coordinate. The equality of integrals follows for continuous f on this compact triangle. If the integrand is singular or the region unbounded, check a suitable convergence theorem before exchanging order; the geometric bounds alone do not settle that question.
