Where can a wandering token land?

A token starts at position 0 on a numbered line. At each chime a fair coin independently sends it one step right or left. The process is random, but its possible positions and their chances can be calculated exactly. We shall separate a path, the whole record of moves, from an endpoint, the position after a chosen number of moves.

Background capsule. Independent tosses mean that knowing previous tosses does not change the chance of the next one. For a fair coin each specified sequence of three tosses has chance (1/2)³ = 1/8. We add chances for mutually exclusive sequences. A random variable here simply assigns +1 to a right move and −1 to a left move. The subscript on X₃ names the third move; S₃ names the position after three moves.

This is a model of a token whose rule never changes. It does not claim real people choose directions independently. Its usefulness is that an exact small calculation tells us what a path drawing should and should not suggest.

Count paths before counting endpoints

Worked example. After three moves, RRL, RLR and LRR all end at +1. Each has probability 1/8, so P(S₃ = 1) = 3/8. Likewise the three sequences with two left moves end at −1. RRR ends at +3 and LLL at −3. The four endpoint probabilities are 1/8, 3/8, 3/8, 1/8 from left to right. They total one, as they must.

A drawn path such as RRL is one possible history, not a representation of all histories. In particular, +1 is more likely than +3 because three paths reach it, not because any individual path to +1 is favored. The token cannot be at 0 after three unit steps: its parity alternates each chime. If an animation shows position 0 at time three, its rule or labels need checking.

The sum records every move

Sn=∑i=1nXi,Xi∈{−1,+1}

For n moves, let R be the number of rights. There are n−R lefts, so Sₙ = R−(n−R) = 2R−n. Conversely, an endpoint s requires R = (n+s)/2, which must be an integer between 0 and n. There are “n choose R” sequences with that many rights. Under independent fair moves every sequence has chance 2⁻ⁿ; hence P(Sₙ=s) = C(n,(n+s)/2)2⁻ⁿ for allowed s, and zero otherwise. This is a finite counting identity, not an approximation or a claim about eventual behavior.

Hypotheses and boundary. If the chance of right is p at every independent move, a path with R rights has probability pᴿ(1−p)ⁿ⁻ᴿ and the endpoint probability becomes C(n,R)pᴿ(1−p)ⁿ⁻ᴿ. If the token changes its rule after a left move, paths with the same number of rights may no longer have the same probability; then the counting factor alone is insufficient. Independence is what licenses multiplying fixed move probabilities.

The expected position of a fair walk is zero because right and left cancel in expectation at every chime. That does not mean the token is likely to be at zero at every time. At odd times it cannot be there at all. Average position across many independent repeats and position in one run are different objects.

Check the counting rule

1. Calculation. After four fair moves from 0, what is P(S₄ = 0)? Also give P(S₄ = 4).

Hint for question 1

Zero requires the same number of rights and lefts. Four requires all rights.

Full solution to question 1

For zero, R = (4+0)/2 = 2. Choose which two of four moves are right in C(4,2) = 6 ways. Each path has probability 1/16, so P(S₄=0)=6/16=3/8. For +4, R=4, leaving only RRRR, so P(S₄=4)=1/16. Notice that an endpoint is not itself one equally likely outcome among five listed positions.

2. Explain a failure. A biased coin moves right with chance 3/4 independently each time. After two moves, compare paths RL and RR. Does the fair-walk endpoint table still apply?

Hint for question 2

Multiply the two move chances along each specified path.

Full solution to question 2

P(RL) = (3/4)(1/4) = 3/16; P(RR) = (3/4)² = 9/16. LR also has chance 3/16, so the zero endpoint has chance 6/16, while +2 has chance 9/16 and −2 has chance 1/16. The fair table's equal path probabilities of 1/4 do not apply. Counting paths remains useful only after weighting them with the right model.

What the little walk establishes

A path is a sequence; an endpoint can collect several paths. For a fixed finite number of independent steps, count and weight those paths to obtain exact probabilities. This lesson has not established long-run recurrence, a typical distance, or a hitting time. Those questions need additional arguments and sometimes absorbing boundaries. For the latter, see a walk that stops at an edge.

A useful self-check is to recompute the three-step table for p = 1/2 by adding its four entries. The total must be one, and impossible parity values must have probability zero.
