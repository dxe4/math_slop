Can two translations agree systematically?

Two functors can send the same source category into Set while choosing different sets and functions. A natural transformation compares their outputs at every object, and requires those comparisons to respect every arrow. A single matching picture is not enough; we will verify a complete finite case.

Background capsule. A functor preserves arrow source and target, identities and composition. In Set, an arrow is a function. Let the source be the path category on one edge a:A→B, with identities 1A and 1B. We use G(a)∘ηA for “compare at A, then use G's arrow”; ηB∘F(a) means “use F's arrow, then compare at B.” Both must have type F(A)→G(B).

Two choices of data

Worked example. Define F(A)={0,1}, F(B)={u,v}, with F(a)(0)=u and F(a)(1)=v. Define G(A)={p,q}, G(B)={red,blue}, with G(a)(p)=red and G(a)(q)=blue. Each functor sends identities to identity functions; since the source has no longer nonidentity path, these data determine valid functors. Define ηA(0)=p, ηA(1)=q and ηB(u)=red, ηB(v)=blue.

The naturality square on the only nonidentity generator
x∈F(A)ηA(x)G(a)(ηA(x))F(a)(x)ηB(F(a)(x))

1qbluevblue

The last outputs match on the entire source set F(A), so this square commutes. The components ηA and ηB are ordinary functions, but the compatibility equation makes their pair a natural transformation.

A natural comparison can collapse data

Keep the same functors F and G, but define a new comparison μ by μA(0)=μA(1)=p and μB(u)=μB(v)=red. For either input x in {0,1}, the route through G first compares x to p and then sends p to red. The route through F first sends x to u or v and then compares either of those to red. Both composites are the constant function with value red, so the nonidentity naturality square commutes.

The identity squares commute because the functors preserve identities, exactly as before. These three checks cover every source arrow. Hence μ is a natural transformation even though neither component is one-to-one or onto its two-element target. Naturality is compatibility, not reversible relabeling.

If we instead make μB constant blue while leaving μA constant p, the first route still ends at red and the second ends at blue. The modified family fails naturality at both inputs. Calling both components “constant” is therefore insufficient: the chosen constants must themselves agree with the target functor's arrow.

Why a generator check is enough here

Exact statement and full finite proof. For each arrow f:X→Y in the source category, naturality requires

G(f)∘ηX=ηY∘F(f)

The table proves this equation for a. For 1A, both sides equal ηA, because F and G send identities to identities; similarly both sides at 1B equal ηB. These are all arrows in our tiny source category, so the proof is complete. In a path category with more edges, checking every generating edge also handles paths: if the equation holds for f:X→Y and g:Y→Z, substitute their equations into G(g)∘G(f)∘ηX, reassociate, and obtain ηZ∘F(g)∘F(f). Functoriality turns this into the equation for g∘f. That reasoning relies on every path being a composite of the checked edges.

Naturality is not a demand that η components are invertible. For example, constant functions can form a natural transformation when both routes send each input to the same constant. Conversely, even bijective components may fail naturality if the square does not commute. If we alter only ηB(v) to red, the row x=1 compares blue with red. That pair of functions is no longer natural, though each component still has the right domain and codomain. Componentwise definitions alone therefore cannot certify the global compatibility.

Check the square

1. Calculation. Retain F and G but set ηA(0)=q, ηA(1)=p while leaving ηB as above. Is the pair natural? Show one row.

Hint for question 1

Start at 0 and compare the two ways to reach G(B).

Full solution for question 1

At 0, G(a)(ηA(0))=G(a)(q)=blue. But ηB(F(a)(0))=ηB(u)=red. The functions F(A)→G(B) disagree, so naturality fails.

2. Explanation. Why do we not need a separate two-row table for the identity arrow 1B?

Hint for question 2

Substitute F(1B) and G(1B) in the equation.

Full solution for question 2

Functoriality gives F(1B)=idF(B) and G(1B)=idG(B). Thus G(1B)∘ηB=ηB=ηB∘F(1B) as functions F(B)→G(B). This is an algebraic proof for all elements, so another table is unnecessary.

The compatibility is the content

A natural transformation is a family of typed comparison arrows whose square commutes for every source arrow. The present proof covers our finite path category completely and explains why generator checks extend to its paths. For a category with relations or arrows not generated by a listed set, one must check the actual category, not assume this shortcut applies. The same naturality equation will control the finite Yoneda example.
