Sets and membership

A set records which objects belong to a collection. In roster notation, braces surround its members: A={1,3,5}. Writing 3∈A says that 3 belongs to A; writing 2∉A says that 2 does not. Repeating a member or changing the listing order leaves the set unchanged.

Worked example. Let B={3,4}. The union A∪B contains every object in either set. The intersection A∩B contains exactly the objects in both sets.

A∪B={1,3,4,5}A∩B={3}

The empty set, written ∅, has no members. A subset C⊆A has all its members in A. The subset may equal the whole set; the symbol does not require a smaller collection.

Try one. With C={1,5}, find C∩B and decide whether C⊆A.

Worked answer

C and B have no common member, so C∩B=∅. Both 1 and 5 belong to A, hence C⊆A. Empty intersection and subset inclusion ask different questions.

Watch the object. The number 3 and the set {3} are different objects. Here 3∈A and {3}⊆A are both true, but they express different relationships.

Functions and composition

A function assigns exactly one output to each allowed input. Its domain is the set of allowed inputs; its codomain is the declared set containing the outputs. Different inputs may share an output. For f(x)=x² on the real numbers, both 2 and −2 produce 4.

Worked example. Let f(x)=2x+1 and g(x)=x². The expression f(g(3)) first applies g to 3, producing 9, and then applies f to 9, producing 19. Composition writes this as (f∘g)(3).

f(g(3))=f(9)=19

For a composition to be defined, the output of the inside function must be an allowed input for the outside function. Here both functions accept every real number, so that condition holds.

Try one. Compute g(f(3)). Does changing the order preserve the result?

Worked answer

First f(3)=7, then g(7)=49. This differs from f(g(3))=19. Composition generally depends on its order; the circle symbol names the operation, rather than promising that the two orders agree.

Watch the notation. In f(3), the parentheses name the input to f. They do not mean f multiplied by 3. Read the expression from the inside out.

Can a coat-check ticket be undone?

A coat check assigns each deposited coat one ticket code. If two coats receive the same code, a clerk holding that code cannot tell which coat to return. If a promised code is never used, a rule that goes from every possible code back to a coat has another problem. These are two distinct obstacles to reversing a function.

A function f:A→B assigns each input in set A exactly one output in set B. A is the domain; B is the codomain. The function is injective if different inputs never share an output, and surjective if every object in B occurs as an output. A function that is both is bijective. The identity id_A sends each a∈A to itself. This is the local prerequisite capsule; no graph of a function is required.

We will prove that f has a two-sided inverse g:B→A exactly when f is bijective. The word two-sided matters: g(f(a))=a for every input and f(g(b))=b for every target. Merely recovering some observed inputs is a weaker claim.

Three small ticket systems

Worked example. Let A={coat 1, coat 2} and B={red, blue}. If f sends coat 1 to red and coat 2 to blue, then g(red)=coat 1 and g(blue)=coat 2 reverses the assignment. Both directions work: g(f(coat 2))=coat 2 and f(g(red))=red.

In the collision row, any proposed g(red) can name only one coat; it cannot satisfy both g(f(coat 1))=coat 1 and g(f(coat 2))=coat 2. In the unused-code row, any proposed g(green) must be one of the two coats, but its f-image is red or blue, never green. This separates injectivity from surjectivity even for tiny finite sets.

A two-sided inverse is exactly a bijection

Exact statement. For sets A and B and a function f:A→B, there exists a function g:B→A satisfying g∘f=id_A and f∘g=id_B if and only if f is bijective. Empty-set boundary cases follow the same definitions: a function between two empty sets is bijective and is its own inverse.

g∘f=idA,f∘g=idB

Complete proof, forward direction. Suppose such a g exists. If f(a₁)=f(a₂), apply g to both sides: g(f(a₁))=g(f(a₂)), hence a₁=a₂. So f is injective. For any b∈B, b=f(g(b)), so b is an output of f. Thus f is surjective.

Complete proof, reverse direction. Suppose f is bijective. For each b∈B, surjectivity supplies at least one a with f(a)=b, and injectivity makes that a unique. Define g(b) to be this unique a. Then g(f(a))=a by uniqueness, and f(g(b))=b by construction. The two equations hold for every a and b, so g is a two-sided inverse. This argument is about functions on sets; a numerical formula is not required.

The failure case “same formula, different codomain” is instructive. Let f:{1,2}→{1,2,3} with f(x)=x. It is injective but not surjective because 3 is unused, so it has no two-sided inverse from the entire codomain. If the codomain were {1,2}, the assignment would be bijective. Naming the domain and codomain is part of a function claim.

Two different questions about a function

Fix f:A→B. For a selected input set S⊆A, its image f(S)={f(s):s∈S} collects the outputs it reaches. For a selected target set T⊆B, its preimage f−1(T)={a∈A:f(a)∈T} collects all inputs reaching T. This set preimage exists even if f has no inverse function. The braces matter: f(a) is an element, f({a}) is a singleton set, and f−1({b}) is the set of every possible input for b. An unreachable b has an empty preimage, not an undefined set.

The preimage does not select one preferred input from a collision. Sending S forward and then taking its preimage can therefore add inputs. Starting with T, taking its preimage and sending that forward can instead remove targets that were never reached.

  • Map I: A={a,b,c}, B={0,1,2,3}, with a↦0, b↦1, c↦2. Inputs are distinct; target 3 is unused.
  • Map O: A={a,b,c,d}, B={0,1,2}, with a↦0, b↦0, c↦1, d↦2. Inputs a,b collide; every target is reached.

Worked input record: map O, S={a,c}. Collect all inputs reaching an output of S.

The fixed map: claims about all sets

Injective: no. The distinct inputs {a,b} all reach 0. Surjective: yes. Every listed target has an input.

Exact input recovery: 8 of 16 subsets of A. Exact target recovery: 8 of 8 subsets of B. Choose whole fibers for input recovery, or only reached targets for output recovery. These are finite counts for this complete map; the general proof below establishes the universal criteria.

A different direction: map I, T={1,3}. The preimage is {b}; sending it forward gives {1}. Target 3 is lost because it is never reached. In contrast T={1,2} returns exactly, although I is not surjective onto its full codomain.

The input round trip fills complete fibers

Define C(S)=f−1(f(S)). Membership gives the exact formula

C(S)={a∈A: there exists s∈S with f(a)=f(s)}.

Indeed a∈C(S) means f(a)∈f(S), which by the image definition means some s∈S has the same output. If a∈S, take s=a. This proves S⊆C(S); no selected input can be lost.

The fiber above a reached target b is f−1({b}), the entire group of inputs sharing that output. C(S) includes every member of each fiber touched by S. Hence C(S)=S exactly when S already contains every touched fiber in full. Empty S and all of A satisfy that condition even for a noninjective function. For map O, {a,c} grows to {a,b,c}, while {a,b,c} is recovered exactly; neither result changes the collision a,b.

A second application adds nothing: f(C(S))=f(S), because every newly included input has an output already reached by S, and S⊆C(S). Thus C(C(S))=C(S). This is saturation by equal-output classes, rather than a recovery of the original individual inputs. The equivalence-class lesson supplies the grouping idea; the quotient lesson already requires full saturated preimages at a seam. This calculation gives that whole-fiber requirement a finite set test.

The output round trip keeps only reached targets

Define R(T)=f(f−1(T)). Its exact value is R(T)=T∩f(A). If b∈R(T), some a∈f−1(T) has f(a)=b, so b lies both in T and in the full image f(A). Conversely, if b∈T∩f(A), an a with f(a)=b exists; that a belongs to f−1(T), so b∈R(T). The two membership implications prove the identity.

Consequently R(T)=T exactly when every selected target is reached, or T⊆f(A). No target outside T can be added. For map I, {1,3} shrinks to {1}; selecting {1,2} instead gives exact recovery even though the full codomain still contains unused 3. The continuity lesson already develops preimages of intervals; here the question is what survives both operations, before making any topological claim.

“This set” and “every set” have different strength

f is injective if and only if C(S)=S for every S⊆A. If f is injective, f(a)=f(s) forces a=s, so C adds no member. Conversely, suppose every S is recovered and f(a)=f(a′). For S={a}, the equal output puts a′ in C({a})={a}, forcing a′=a. This proves injectivity.

f is surjective if and only if R(T)=T for every T⊆B. If f(A)=B, the output identity gives R(T)=T∩B=T. Conversely, apply the assumed recovery to T=B: it gives B=R(B)=f(A). Thus f reaches its full codomain. Both universal recovery conditions together are equivalent to bijectivity, agreeing with the original inverse theorem. Success for one selected set does not establish either universal condition.

These arguments cover finite and infinite sets and do not choose representatives for every fiber. If A=∅, the sole input subset is ∅ and the empty function is injective; every output subset recovers exactly only when B=∅. A function from a nonempty A to empty B does not exist. The two finite maps in the inspector illustrate the theorem; they do not prove the assertion for arbitrary functions.

For a finite map with r reached outputs there are 2r recovered input subsets: choose whether to include each whole nonempty fiber. There are also 2r recovered target subsets: choose any subset of the reached outputs. For map I this gives 8/8 input selections and 8/16 target selections; for O it gives 8/16 input selections and 8/8 target selections. The total selection counts include empty and full sets. Empty S and full A always recover, but full target B recovers exactly when the map is surjective: it fails for I and succeeds for O.

The classical image/preimage definitions and round-trip criteria are developed in Hammack, Book of Proof, §12.6, printed pp.242–243, including exercise 12. The examples, inspector and changed task here are original. Whole-class saturation is also an existing closure construction; this clinic specializes it to equal-output classes and pairs it with target recovery. Test both recovery directions

1. Let f:{0,1,2}→{a,b,c} send 0↦b, 1↦c, 2↦a. Write its inverse and verify both equations at one input and one code.

Hint for question 1

Reverse each arrow, then compose.

Full solution to question 1

The inverse g sends a↦2, b↦0, c↦1. For input 1, g(f(1))=g(c)=1. For code a, f(g(a))=f(2)=a. Each of the three outputs appears once, so the same checks cover all inputs and codes by the definition.

2. For f:ℤ→ℤ given by f(n)=2n, decide injectivity and surjectivity; explain whether a two-sided inverse ℤ→ℤ exists.

Hint for question 2

Odd integers are possible codomain values.

Full solution to question 2

If 2m=2n, then m=n, so f is injective. It is not surjective onto ℤ because no integer maps to 1: 2n=1 has no integer solution. Therefore no two-sided inverse ℤ→ℤ exists. On the codomain of even integers, an inverse g(2n)=n does exist.

Do not confuse an inverse function with the preimage of a set. Preimages can be formed for any function; a two-sided inverse function exists exactly under the proved bijection condition.

Optional exercise 3: new function, clipped domain and whole intervals

Write an attempt before revealing a hint or answer. This task changes both the map and the kinds of sets; it is outside the inspector's controls. Let q:[−2,1]→[0,9] be q(x)=(x+1)², with S=[−1,1/2] and T=[1/4,25/4].

  1. Find the full image q([−2,1]). Decide injectivity and surjectivity onto the declared codomain, supplying witnesses.
  2. Calculate q(S) and q−1(q(S)). Give exactly the additional inputs, with endpoint status. Why can no original input be lost?
  3. Calculate q−1(T) and q(q−1(T)). Give exactly the lost targets, with endpoint status. Why can no unselected target be added?
  4. Define the different function q₊:[−1,1]→[0,4] with the same formula. Find its inverse, check both compositions on their domains, and recompute the two round trips for S and T′=T∩[0,4]. Does this make the original q invertible?
Hint for exercise 3

Put u=x+1, keeping its allowed interval. A condition L≤u²≤U produces two signed intervals before you intersect with the declared domain. A boundary already in S or already recovered is not an added or lost member. On q₊'s domain, x+1≥0, so the principal square root returns x+1.

Full solution to exercise 3

(a) For x∈[−2,1], u=x+1 ranges over [−1,2], so 0≤u²≤4. Every y∈[0,4] is attained by x=√y−1∈[−1,1]. Thus the full image is [0,4], rather than the declared [0,9]. The allowed target 9 is unreachable, so q is not surjective. Also q(−2)=q(0)=1 at distinct allowed inputs, so q is not injective.

(b) On S, u∈[0,3/2], so q(S)=[0,9/4]. Pulling that back imposes |x+1|≤3/2, giving [−5/2,1/2] before the domain restriction. Intersect with [−2,1] to obtain q−1(q(S))=[−2,1/2]. The added set is [−2,−1): −2 is newly included, while −1 was already selected. No s∈S can be lost, since its own output belongs to q(S). The set touched fibers without containing all their permitted inputs.

(c) The inequality 1/4≤(x+1)²≤25/4 gives [−7/2,−3/2]∪[−1/2,3/2] before restricting the domain. Therefore q−1(T)=[−2,−3/2]∪[−1/2,1]. The first interval maps to [1/4,1] and the second to [1/4,4], so q(q−1(T))=[1/4,4]. This is exactly T∩q([−2,1]). The lost set is (4,25/4]: 4 is reached and kept; 25/4 was selected and is lost. No unselected output can be added because membership in the preimage required the output to belong to T.

(d) For q₊, x+1∈[0,2], where squaring is one-to-one and reaches [0,4]. The inverse is r:[0,4]→[−1,1], r(y)=√y−1. For x∈[−1,1], r(q₊(x))=√((x+1)²)−1=x because x+1≥0. For y∈[0,4], q₊(r(y))=(√y)²=y. Here S remains allowed and q₊−1(q₊(S))=[−1,1/2]=S. Restate the target selection in the new codomain as T′=[1/4,4]; its preimage is [−1/2,1] and its image returns exactly T′.

Restricting the input domain and changing the codomain makes a different, bijective function. It does not repair the original q's collision or fill its missing targets. Preimages of arbitrary ambient target sets can also be defined; the named target selections here are explicitly subsets of each current codomain.

Reversal needs no collisions and no gaps

Injectivity lets a code identify at most one input; surjectivity ensures every target code identifies at least one. Together they make exactly one, giving a two-sided inverse. We proved both implications for arbitrary sets and used finite tickets to display the two failure modes.

Stop when you can name the domain and codomain and test both properties. The same concern about unique representatives will reappear when a relation groups objects into classes.
