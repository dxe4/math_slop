Sets and membership

A set records which objects belong to a collection. In roster notation, braces surround its members: A={1,3,5}. Writing 3∈A says that 3 belongs to A; writing 2∉A says that 2 does not. Repeating a member or changing the listing order leaves the set unchanged.

Worked example. Let B={3,4}. The union A∪B contains every object in either set. The intersection A∩B contains exactly the objects in both sets.

A∪B={1,3,4,5}A∩B={3}

The empty set, written ∅, has no members. A subset C⊆A has all its members in A. The subset may equal the whole set; the symbol does not require a smaller collection.

Try one. With C={1,5}, find C∩B and decide whether C⊆A.

Worked answer

C and B have no common member, so C∩B=∅. Both 1 and 5 belong to A, hence C⊆A. Empty intersection and subset inclusion ask different questions.

Watch the object. The number 3 and the set {3} are different objects. Here 3∈A and {3}⊆A are both true, but they express different relationships.

A filing rule turns on itself

Imagine a registry that is meant to contain exactly those registries that do not list themselves. Ask whether this new registry lists itself. If it does, its rule says it should not. If it does not, its rule says it should. This is a warning about which membership conditions are allowed to define sets.

Write x∈S when x is a member of set S, and x∉S when it is not. Unrestricted comprehension is the proposed principle that every property P(x) determines a set {x:P(x)} of all objects satisfying it. Here we pretend that the universe ranges over all sets and use the property x∉x. Contradiction means deriving a proposition and its negation from an assumption. These are the local prerequisites; familiarity with a formal axiomatic set theory is not required.

Our bounded claim is that unrestricted comprehension is inconsistent with ordinary classical membership reasoning. We will derive the contradiction carefully. We will not infer that everyday finite sets fail or present a full replacement axiom system.

Try both answers

Worked example. Under the unrestricted rule, form R={x:x∉x}. To decide whether an object y belongs to R, inspect whether y belongs to itself. For ordinary small sets whose members are numbers, this self-membership question usually has an easy negative answer. The decisive test, however, is y=R. Since R is purportedly a set in the same universe, the rule must answer for R too.

The table is not a computer program caught in an endless loop. It displays a logical inconsistency in the assumption that this particular property defines a set in the unrestricted universe. The two cases exhaust true and false under classical logic. Changing an example registry or adding more ordinary members cannot repair the self-membership condition.

The contradiction is conditional

Exact statement. In classical logic, the schema “for every property P, there exists a set S such that for every x, x∈S iff P(x)” is inconsistent when x ranges over all sets and P(x) may be x∉x. This is Russell’s paradox. The derivation rejects that unrestricted schema, not the use of sets in a restricted theory.

R∈R⇔R∉R

Complete derivation within the assumed schema. Instantiate comprehension with P(x) meaning x∉x. It supplies a set R satisfying, for every set x, x∈R iff x∉x. Substitute x=R. Then R∈R iff R∉R. If R∈R is true, the right side says it is false. If R∈R is false, the biconditional says the right side is true and therefore R∈R is true. No classical truth value works. Thus the assumption that such an R exists must be rejected.

The proof boundary matters. This argument does not prove that a familiar set such as {1,2} is inconsistent, nor that every collection described in words is a set. A standard restricted idea is separation: given an already existing set A, form {x∈A:P(x)}. Its result is drawn from A rather than from an alleged set of every set. We mention the restriction to locate the issue; proving a whole axiomatic system consistent is far beyond this article.

A nearby failure is the “barber who shaves exactly the villagers who do not shave themselves.” If the barber is a villager, the condition contradicts itself; if the barber is outside the village, there may be no contradiction. The domain is crucial. Likewise Russell’s derivation requires R to be among the objects over which the comprehension condition quantifies. Hiding that assumption makes the paradox seem like a trick of grammar.

Locate the assumption that breaks

1. Suppose a finite set A={1,2,3}. Define B={x∈A:x is even}. Compute B and explain why checking whether B∈B does not recreate Russell’s contradiction.

Hint for question 1

The membership rule for B applies only to x already in A.

Full solution to question 1

B={2}. Because B is a set and A contains only the numbers 1, 2, 3, B∉A in this setup. The definition says x∈B iff x∈A and x is even; substituting x=B makes the right side false because B∉A. No equation B∈B iff B∉B follows. The extra domain condition prevents the unrestricted self-membership equivalence.

2. A speaker says, “Russell’s paradox proves there are no infinite sets.” Identify the faulty inference and state what the derivation actually rules out.

Hint for question 2

Find the assumption used in the derivation.

Full solution to question 2

The derivation assumes unrestricted comprehension over all sets for the property x∉x. It shows that schema cannot hold in classical set theory. It does not use finiteness or infinity of R, and it does not rule out particular infinite sets such as the natural numbers in standard axiomatic theories. The contradiction concerns an unrestricted formation rule.

Both questions force attention to the quantifier domain. The self-membership substitution is legal in either definition, but restricted separation adds the condition R∈A; without it, the biconditional does not force a contradiction.

A condition does not always define a set

If every property defined a set over all sets, the property x∉x would define R and force R∈R iff R∉R. That is a complete conditional contradiction. It identifies an invalid formation principle; it does not invalidate the ordinary operations with specified sets used earlier in this topic.

The stopping point is to name the assumption and the substitution x=R. A deeper study of axiomatic set theory asks which restricted formation and existence principles can be adopted, but this lesson makes no consistency claim about an entire system.
