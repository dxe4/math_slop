Networks and degree counts

A finite simple undirected graph consists of vertices and edges. Each edge joins two different vertices, with at most one edge for each pair. “Undirected” means that AB and BA name the same connection. A drawing shows these relationships; its line lengths need not carry any information.

Worked example. Use vertices A, B, C and D, with edges AB, AC and BC. The degree of a vertex is the number of edges touching it. A, B and C each have degree 2, while D has degree 0 because it is isolated.

2+2+2+0=6=2×3

Every edge contributes one to the degree at each of its two ends. Adding all degrees therefore gives twice the number of edges. An isolated vertex still belongs to the graph and contributes zero to the sum.

Try one. Add the edge CD. What changes?

Worked answer

C's degree rises to 3, and D's rises to 1. A and B stay at 2. The degree sum becomes 8, and there are now four edges, again giving twice the edge count.

Watch the convention. A repeated connection or an edge from a vertex to itself requires a different graph convention. Keep the simple-graph assumptions explicit when translating a real network.

Did you retrace a street or revisit a junction?

A courier can pass through a junction twice without using the same street twice. Another courier can cross one street repeatedly. Those routes satisfy different constraints. Graph theory names the distinction so a route requirement can be tested before anybody plans an itinerary.

Background capsule. A finite simple undirected graph has named vertices and unordered pairs of distinct vertices called edges. A vertex sequence v₀,v₁,…,vₖ is a walk when each consecutive pair is an edge. Its length is k edges, even when a vertex repeats. We use the common convention that a trail is a walk with no repeated edge, while a path has no repeated vertex. A one-vertex sequence is a length-zero path. In a simple graph, a path also cannot repeat an edge.

Use a square A–B–C–D–A with diagonal A–C. The edge set is AB, BC, CD, DA, AC. We can now classify routes from their written sequences, rather than trusting a picture.

Check the sequence, one edge at a time

Worked example. The sequence A,B,C,A,D uses AB, BC, CA, AD. Every edge exists and occurs once, so this is a trail. Vertex A occurs twice, so it is not a path. Sequence A,B,C,B is a walk, because AB, BC, CB all exist, but BC and CB are the same undirected edge, so it is not a trail. Sequence D,C,B,A has three existing and distinct edges and four distinct vertices, so it is a path and a trail.

The word “strongest” here means the most restrictive definition satisfied. A path is still a trail and a walk. If a route starts and ends at the same vertex, some texts call it a closed walk; in a simple graph, a cycle has at least three edges and no other repeated vertices. We will always state the edge and vertex rules rather than rely on an ambiguous everyday meaning of “path.”

How the definitions fit together

For a path, all vertices in its sequence are distinct, giving the local mathematical condition

vi≠vjwheneveri≠j.

Read that as “different positions in the list contain different vertices.” The notation vᵢ is the vertex at position i; the starting position is zero. The path condition automatically prevents edge repetition: if the same undirected edge appeared twice, both its endpoint vertices would also appear twice. This proves the inclusion every path is a trail, and every trail is a walk. The square examples show that neither inclusion reverses: a trail can revisit A, and a walk can retrace BC.

Another useful exact claim is that whenever a walk connects distinct vertices s and t, there is a path from s to t. Take a connecting walk of the smallest possible length; one exists because walk lengths are nonnegative integers. If it repeated a vertex at positions i and j with i<j, delete the portion from after i through j. The retained sequence still joins consecutive vertices: the vertex before the removed part is the same at both ends. We obtain a shorter s–t walk, contradicting minimality. Thus the shortest chosen walk has no repeated vertex. This is a complete finite argument; it says existence of a path, not that an arbitrary walk is a path.

Do not confuse “shortest” here with travel time. Length counts edges. If one street takes 90 minutes and two others take 5 minutes each, the one-edge route has shorter graph length but longer travel time. Weighted shortest paths need edge costs and a different optimization question. A route may also be impossible: if the graph has two disconnected pieces, no walk, trail, or path crosses between them.

Classify, then simplify

Exercise 1. On edges AB, BC, CA, CD, DE, classify B,A,C,B,C,D,E as a walk, trail, or path. Give the edge sequence and identify any repetition.

Hint for exercise 1

Remember that CB and BC are the same edge in an undirected graph.

Full solution to exercise 1

The edge sequence is BA, AC, CB, BC, CD, DE. All are listed edges, so the sequence is a walk. CB and BC both name edge BC, used twice; hence it is not a trail. B and C also repeat, so it is not a path. A valid shorter path from B to E is B,C,D,E, using BC, CD, DE.

Exercise 2. A student says, “If no street is used twice, no junction can appear twice.” Test the statement on a triangle with vertices P,Q,R and an extra edge P–S.

Hint for exercise 2

Travel around the triangle, return to P, then leave for S. List every edge.

Full solution to exercise 2

The route P,Q,R,P,S uses PQ, QR, RP, PS exactly once each, so it is a trail. P appears at the start and again before S, so it is not a path. This single counterexample refutes the student's universal claim. A trail forbids repeated edges, while a path forbids repeated vertices.

Match the route word to the constraint

Write a route as a vertex sequence and check consecutive adjacency first. Then check repeated edge identities for a trail and repeated vertices for a path. Every connected pair admits a path because loops can be removed from a shortest connecting walk. That fact does not solve a visit-every-edge puzzle: such a puzzle asks for a special trail, developed in Euler trails.
