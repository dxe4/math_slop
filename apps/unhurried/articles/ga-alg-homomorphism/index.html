What survives a simplifying map?

A group homomorphism is a function that respects operations. It can collapse many inputs to one output while preserving the pattern of multiplication or addition. Reducing an integer modulo n is the cleanest example: different integers share a residue, yet adding before or after reduction gives the same class.

Background capsule. A group operation may be written multiplicatively, ab, or additively, a+b. A function φ:G→K assigns each element of G an element of K. Its image is the set of outputs it actually reaches. Its kernel is the set of inputs sent to the identity of K. For the integer group under addition, the identity is 0 and the inverse of a is −a. In Z/nZ under addition, the identity is [0]. Congruence a≡b (mod n) means n divides a−b.

Reduction modulo five

Worked example. Let φ:Z→Z/5Z send a to [a]. Then φ(7+9)=[16]=[1], while φ(7)+φ(9)=[2]+[4]=[6]=[1]. Both paths agree. The kernel is all multiples of five: [a]=[0] exactly when 5 divides a. The image is every residue class because each class has an integer representative. In particular φ is onto, but not one-to-one: 0 and 5 share an output.

This single square illustrates the rule but does not prove it for all integers. For that, use the definition of class addition: [a+b]=[a]+[b] for arbitrary a and b. The map is useful precisely because a large infinite group casts a five-element shadow with the same additive relation.

Separate injectivity from surjectivity

Consider d:Z→Z given by d(a)=2a, with addition as the operation in both groups. For arbitrary integers a,b, d(a+b)=2(a+b)=2a+2b=d(a)+d(b), so this is a homomorphism. Its kernel contains only 0, because 2a=0 forces a=0. Its image is the even integers: every output is even, and every even integer 2k is the output of k.

This map is one-to-one: equal outputs 2a=2b force a=b. It is not onto its stated codomain Z, because no integer input maps to 1. If the codomain were instead declared to be 2Z, the same formula would be onto and would have inverse 2k↦k. The formula alone therefore does not settle surjectivity; the declared target matters. Compare reduction modulo five, whose image is its whole finite target but whose kernel has many elements. Neither operation preservation nor a small kernel should be confused with both halves of bijectivity.

The operation-preserving equation

φ(ab)=φ(a)φ(b)

Exact statement and proof. For groups written multiplicatively, a homomorphism satisfies this equation for every a,b∈G. Reduction φ:Z→Z/nZ, a↦[a], is a homomorphism for every n≥2, with kernel nZ={kn:k∈Z} and image all of Z/nZ. The proof is direct: φ(a+b)=[a+b]=[a]+[b]. Also φ(a)=[0] exactly when a=kn, and every [r] is φ(r). No isomorphism theorem is needed for these conclusions.

For an arbitrary group homomorphism, φ(eG)=eK. Indeed φ(e)=φ(e)φ(e), and multiplying by φ(e)−1 gives the claim. Likewise e=φ(aa−1)=φ(a)φ(a−1), so φ(a−1)=φ(a)−1. These facts show the kernel is a subgroup: it contains e, and if a,b lie in it then φ(ab−1)=e. The image is also a subgroup because products and inverses of attained outputs are attained.

A kernel carries more information than mere size. If φ(a)=φ(b), then φ(b−1a)=e, so b−1a lies in the kernel. Conversely, that kernel condition implies φ(a)=φ(b). Thus fibers are cosets of the kernel. The first isomorphism theorem identifies the quotient by the kernel with the image, but this article has proved only the elementary kernel, image and fiber facts; the general quotient construction comes next.

Check the operation first

1. Calculation. Define ψ:Z→Z/6Z by ψ(a)=[2a]. Find its kernel and image, and verify preservation of addition.

Hint for question 1

Ask when 6 divides 2a. List the outputs of a=0,1,2,… until they repeat.

Full solution for question 1

ψ(a+b)=[2(a+b)]=[2a]+[2b]=ψ(a)+ψ(b). Its kernel consists of a with 6|2a, equivalently 3|a, so ker ψ=3Z. Its image is {[0],[2],[4]}, since these are the outputs for a=0,1,2 and then the cycle repeats.

2. Explanation. Is f:Z→Z given by f(a)=a+1 a homomorphism of additive groups? Give one decisive test.

Hint for question 2

An additive homomorphism must send 0 to 0.

Full solution for question 2

No. f(0)=1, but the target group's identity is 0. Equivalently f(0+0)=1 while f(0)+f(0)=2. The failure is not repaired by the fact that f is a bijection; an operation-preserving map has a stronger requirement than one-to-one correspondence.

What the shadow records

A homomorphism preserves products, identity and inverses. The kernel tells exactly which inputs become the identity; for integer reduction it is nZ. The image tells which outputs occur. This article proved those claims directly and did not require a general isomorphism theorem.

A tempting failure is to treat any convenient function as a homomorphism. Test the operation equation on arbitrary inputs or find a counterexample such as f(0)≠0. To turn kernel fibers into a new group, the quotient lesson explains the additional structural condition.
