Remove length without removing every point

Start with [0,1]. Remove its open middle third, then remove the open middle third of each surviving interval, and continue forever. The resulting Cantor set has zero length, yet its points cannot be listed in a sequence. We will prove both assertions with separate arguments; finite pictures of the first few stages suggest them but do not establish either infinite claim.

Background capsule. A set is countable if its members can be listed a₁,a₂,… . An uncountable set defeats every such list. Outer measure is the infimum of total lengths of countable interval covers; if covers with arbitrarily small total length exist, outer measure is zero. The nested-interval property of ℝ says closed intervals inside one another, with widths tending to zero, share exactly one real point. We use that completeness fact to attach a point to each binary choice sequence.

Record the finite stages

Worked example. Let C₀=[0,1]. At stage one, C₁=[0,1/3]∪[2/3,1]. At stage two, four closed intervals remain, each of length 1/9. At stage n there are 2n disjoint closed intervals, each of length 3−n. Their total length is (2/3)n. For example, C₃ has eight intervals of length 1/27, total 8/27. Define the limiting Cantor set C as the intersection of all Cₙ. Its endpoints survive because we remove open middle thirds.

A finite stage still has positive length. The statement about C follows by trapping C inside every stage, whose total length approaches zero. The uncountability argument must use a different invariant: at each stage there remain two choices, left and right.

Two proofs with distinct jobs

Zero-length statement. The Cantor set has Lebesgue outer measure zero:

C⊆Cn,m*(C)≤(23)n→0

Proof of zero outer measure. Each Cₙ is a finite union of closed intervals with total length (2/3)n. The definition of outer measure formally asks for open covers. Enlarge these finitely many intervals by a combined amount less than any η>0, obtaining an open cover of C of total length below (2/3)n+η. Hence m*(C)≤(2/3)n after letting η shrink. Since this holds for every n and the right side tends to zero, nonnegativity gives m*(C)=0. Outer-null sets are Lebesgue measurable in the standard construction, so their Lebesgue measure is also zero. We are relying on that standard measurability result, not proving the full measure construction here.

Uncountability statement. Each infinite binary sequence b₁b₂… selects a unique point of C: at stage k retain the left surviving third if bₖ=0 and the right surviving third if bₖ=1. The selected closed intervals are nested and have lengths 3−k, so completeness gives exactly one common point. Different binary sequences first disagree at some stage; their chosen stage intervals are separated by a removed open middle third, so their points differ. This is an injection from infinite binary sequences into C. It avoids any reliance on potentially ambiguous ternary expansions of endpoints.

The infinite binary sequences are uncountable by diagonalization. If they were listed as rows s¹,s²,…, define a new sequence t with its nth bit opposite the nth bit of row n. Then t differs from row n at position n for every n, so it is absent from the list. An injection of this uncountable collection into C proves C uncountable. The conclusion is stronger than merely saying there are infinitely many endpoints; those endpoints form only a countable subset.

There is no contradiction with countable sets being null: that theorem gives a sufficient condition, not an equivalence. Length measures geometric coverage, while cardinality counts how many distinct points a set contains.

Check the two invariants

1. Calculate. At stage four, how many intervals remain and what is their combined length? Give an open-cover bound for C.

Hint

Double the interval count and divide each length by three at every stage.

Worked solution

There are 2⁴=16 intervals, each of length 3⁻⁴=1/81, so total length is 16/81. For any η>0, enlarge the 16 closed intervals slightly so the total extra length is below η. The resulting open intervals cover C and have combined length below 16/81+η. This bound alone is not zero; repeating at arbitrarily large stages proves zero.

2. Diagnose. “At each finite stage the set consists of finitely many intervals; therefore the limit set is finite.” Why is this invalid?

Hint

Count choices across all stages, not intervals at a fixed stage.

Worked solution

The number of intervals increases with the stage: no fixed finite list persists. Every infinite left/right sequence selects a point, and two sequences differing at any stage select different points. Diagonalization shows these sequences cannot be listed. A limit of finite-stage descriptions can therefore contain uncountably many points while its total stage lengths tend to zero.

Cardinality and length part ways

The Cantor set is closed, uncountable, and outer-null. The length proof uses shrinking finite covers; the size proof uses infinitely branching choices and completeness. Neither proof by itself gives the other conclusion. A later measure course studies larger families of such sets and what “almost everywhere” permits.
