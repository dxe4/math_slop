Powers and logarithms

For a positive integer n, aⁿ means a multiplied by itself n times. For example, 3⁴=3×3×3×3=81. For a nonzero base, a⁰=1 and a⁻ⁿ=1/aⁿ. A negative exponent describes a reciprocal.

Worked example. With base 3, the logarithm asks which exponent produces a positive input. Since 3⁴=81, log₃(81)=4. More generally, for a positive base b different from 1, log_b(x)=y means bʸ=x, with x positive.

34=81log3(81)=4

Multiplying powers with the same base adds their exponents: 2³×2²=2⁵. For positive inputs, this becomes the logarithm rule log₂(uv)=log₂(u)+log₂(v). It is a rule about a product.

Try one. Find log₂(1/8) and explain the negative sign.

Worked answer

Because 2⁻³=1/2³=1/8, the logarithm is −3. For a base larger than 1, inputs between 0 and 1 have negative logarithms.

Watch the operation. Logarithms do not generally turn a sum into a sum: log₂(2+2)=2, while log₂(2)+log₂(2)=2 happens to agree in this case. Using 2+4 instead gives log₂(6), which differs from 1+2=3 because 2³=8.

An angle that cannot return unchanged

A nonzero complex number has many angle names differing by full turns. A logarithm records one of those angles, so choosing a single continuous logarithm across the entire punctured plane runs into a loop: after one circuit around zero the angle has gained 2π. A cut makes a consistent local choice possible.

Background capsule. A nonzero z has polar form z=r(cos θ+i sin θ), with r=|z|>0; θ is defined only modulo 2π. The real logarithm ln r reverses the positive real exponential. For the complex exponential, ea+ib=ea(cos b+i sin b). Thus ew=z means the real part of w is ln r and its imaginary part is one of θ+2πk, k an integer. Continuity means nearby inputs have nearby outputs in the complex modulus.

Choose and test a principal branch

Worked example. Remove the nonpositive real ray, including zero, and call the remaining domain D. Every point of D has a unique angle Arg z in (−π,π). Define Log z=ln|z|+i Arg z there. For example, Log i=iπ/2, Log(−i)=−iπ/2, and Log(1+i)=ln√2+iπ/4. Exponentiating any result recovers the input.

Approach −1 from above. Its principal angle tends to π; from below it tends to −π. The real parts of Log approach zero in both cases, but the imaginary parts differ by 2π. This is the branch jump. It is a feature of this chosen cut, not a singularity of every local logarithm at −1: a different cut can pass elsewhere and give a local logarithm around −1.

Check a product that stays in the domain. Set z=w=e3πi/4. Both principal logarithms equal 3πi/4, but zw=−i has principal logarithm −πi/2. Thus Log z+Log w=3πi/2 differs from Log(zw) by 2πi, even though all three logarithms are defined. Exponentiation erases that difference. A branch choice is therefore part of an additive logarithm identity, not just a convention for printing the answer.

A branch is a domain choice

On D, the exact formula is

Log(z)=ln|z|+iArg(z)−π<Arg(z)<π

This branch is holomorphic on D and has derivative 1/z. One local verification uses a small disk that avoids the cut: differences in angle are continuous there, and the exponential inverse theorem (or a direct local argument) gives the derivative. The broader inverse-function theorem is used here, not proved from first principles. The main topological obstruction below needs only continuity.

No global continuous logarithm on ℂ\{0}. Suppose a continuous L there satisfies eL(z)=z. On the unit circle z=eit, 0≤t≤2π, the real part of L is zero. Its imaginary part b(t) obeys eib(t)=eit, hence b(t)−t is an integer multiple of 2π. Because b(t)−t is continuous and its possible values form a discrete set, that integer is constant. Therefore b(2π)=b(0)+2π. But the endpoints represent the same point z=1, and a single-valued L must give equal values there. Contradiction.

This argument does not say every loop obstructs a logarithm. A simply connected region avoiding zero can support a branch, and a small disk around any nonzero point can. It says the entire punctured plane cannot. Nor does Log(zw)=Log z+Log w always hold for the principal branch: the angles on the right may cross the selected interval and differ from the left by 2πi.

Compute with the cut in view

1. Calculate. Find Log(−i) and Log(i·i) using the principal branch whenever the input lies in D. Explain any undefined term.

Hint for 1

Locate each input relative to the removed nonpositive real ray.

Worked solution for 1

−i lies in D, has modulus one and principal angle −π/2, so Log(−i)=−iπ/2. But i·i=−1 lies on the removed ray; Log(i·i) is undefined in this chosen branch. The multivalued complex logarithm of −1 has values i(π+2πk), but that is a different statement.

2. Explain. A reader argues that Arg is continuous on the entire unit circle because each point has some angle. Identify the quantifier error using the loop proof.

Hint for 2

“Each point has an angle” differs from “one continuous choice assigns an angle to all points.”

Worked solution for 2

Every point eit does have infinitely many angle representatives, but selecting one continuously around the whole circle would produce b(t)=t+2πk with fixed k. It would assign b(2π)=b(0)+2π to the same point 1, impossible for a single-valued choice. Pointwise existence supplies no global continuous selection.

Keep the domain in the formula

The principal Log is a coherent choice on a slit plane, and its boundary jump records the obstruction to continuing that choice around zero. The excluded ray is conventional; zero is the unavoidable obstacle. Before using a logarithm in an integral or identity, specify a branch and ensure every input stays in its domain.
