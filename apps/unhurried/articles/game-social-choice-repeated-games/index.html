Does tomorrow change today's choice?

In a one-round puzzle, each player may have an incentive to take a short-term bonus even when mutual restraint would pay both more. If the same pair plays indefinitely and notices past actions, losing future cooperation can outweigh that one-round bonus. This lesson calculates one precise threshold. It does not claim cooperation always emerges in repeated interactions.

Background capsule. A payoff pair lists row's score first and column's second. A discount factor δ between 0 and 1 weights one point next round as δ points now, a point two rounds ahead as δ², and so on. The geometric sum 1+δ+δ²+··· equals 1/(1−δ) for 0 ≤ δ < 1. We assume both players observe past actions, know the payoff table, and can condition future actions on that history.

A club's recurring choice

Row D(5,0)(1,1)

Worked example. In one round, D strictly dominates C: against C it gives 5 rather than 3, and against D it gives 1 rather than 0. So (D,D) is the unique one-round Nash equilibrium. Now suppose each player promises to play C until anyone plays D, after which both play D forever. This is a grim trigger strategy. If both comply forever, each obtains 3+3δ+3δ²+··· = 3/(1−δ).

If row defects today while column cooperates, row gets 5 today. Column observes the defection, so both use D in every later round; row then gets 1 each round. Its total is 5+δ/(1−δ). Cooperation is at least as attractive as this one-time deviation exactly when 3/(1−δ) ≥ 5+δ/(1−δ), or 3 ≥ 5−4δ, hence δ ≥ 1/2. At δ = 0.6, cooperation pays 7.5 while deviation pays 5+1.5 = 6.5. At δ = 0.4, cooperation pays 5 while deviation pays 5+2/3, so the threat does not deter.

Discounting and the incentive boundary

The repeated payoff under a path of one-round payoffs ut is:

V=∑t=0∞δtut,0≤δ<1

Exact claim. In this infinitely repeated, perfectly observed game, the specified grim-trigger profile is a subgame-perfect equilibrium when δ ≥ 1/2. The cooperative-path calculation checks the tempting one-time defection. After a defection, both use D forever; D is each player's best response to D in the one-round game, so no player gains by deviating during punishment. At any cooperative history the same comparison applies after discounting to that date. A finite sequence of deviations cannot do better than the best one-time deviation at its first point of difference; the standard one-shot deviation reasoning completes this bounded check.

There is an important boundary. If a publicly known final round exists, the last round has no future punishment, so both choose D there; backward reasoning then unravels the proposed cooperation in the earlier rounds under these assumptions. If monitoring is noisy, a false signal can start punishment, and this simple threshold no longer describes the incentives exactly. A larger discount factor is not a moral improvement; it changes the present value of future points.

Change the patience parameter

1. Calculation. Evaluate the two totals at δ = 1/2. Is cooperation strictly better than a one-time deviation?

Hint for exercise 1

Use 3/(1−δ) and 5+δ/(1−δ).

Full solution to exercise 1

Cooperation yields 3/(1/2) = 6. Defecting now and then receiving 1 forever yields 5+(1/2)/(1/2) = 6. The player is indifferent. That suffices for no profitable deviation, so grim trigger can still be an equilibrium at equality, but the threat is not strictly deterrent. The alternative always-D profile also remains an equilibrium.

2. Boundary case. Suppose the club announces that it will play exactly two rounds, and both players know this. Can the same grim-trigger reasoning support C in round one? Explain within this payoff model.

Hint for exercise 2

Start from the second and final round, then return to round one.

Full solution to exercise 2

In round two, no later payoff can punish D, and D gives each player a higher current payoff against either action. So both choose D regardless of the first-round history. Knowing the second-round outcome cannot depend on today's cooperation, each compares only first-round payoffs. D again strictly dominates C. Therefore (D,D) is played in both rounds in the standard complete-information equilibrium analysis. The infinite-horizon threat relied on indefinitely many future consequences.

A threshold, not a general promise

Repeating the same stage game can alter incentives because actions today affect future play. Under exact observation, infinite repetition and grim-trigger punishment, δ ≥ 1/2 sustains the displayed cooperative path. The one-round game still rewards defection, and the repeated game still admits always defecting. We have established one equilibrium construction, not a unique prediction.

Failure case. A known last round removes the endless punishment stream. Unknown payoffs, missed observations, or forgiveness rules would change the calculation and deserve their own specified model.
