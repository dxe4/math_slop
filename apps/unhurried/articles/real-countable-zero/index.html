How can a dense set take no length?

Every interval contains a rational number, yet all rationals together can be covered by open intervals whose total lengths add to less than any positive budget. This statement is about outer measure: it does not depend on being able to draw every interval or on the rationals being sparse. We will construct the cover and explain the gap between countability and length.

Background capsule. A set is countable if its elements can be listed as a₁,a₂,…, allowing repetitions; finite sets fit as well. An interval centered at a with radius r has length 2r. A cover is a collection of sets whose union contains the target set. For A⊆ℝ, Lebesgue outer measure m*(A) is the infimum of sums of lengths over countable open-interval covers of A. We use this definition only to establish zero outer measure; full construction of Lebesgue measure and its measurable sets is deferred.

Spend half the remaining budget each time

Worked example. Suppose the target is the set {1,1/2,1/3,…}. Give the nth listed point an open interval of length ε/2n, centered there. If ε=1/8, the first interval has length 1/16, the second 1/32, then 1/64, and so on. These intervals can overlap; overlap only makes the union shorter than the sum, never longer. Every listed point is covered, even though infinitely many points cluster at zero.

The total offered length is ε because 1/2+1/4+1/8+…=1. To verify the sum without invoking an unproved infinite manipulation, the first N terms sum to 1−2−N, as multiplication by 2 and subtraction shows. This increases to 1. We may choose ε as small as we like, independently of the number of points. The cover is an exact mathematical collection; no finite drawing can display all its intervals.

Zero outer measure for every countable set

Exact statement. If A⊆ℝ is countable, then m*(A)=0. Given an enumeration A={a₁,a₂,…} and any ε>0, define Iₙ=(aₙ−ε/2n+1,aₙ+ε/2n+1). Each Iₙ has length ε/2n, and

A⊆⋃n=1∞In,∑n=1∞|In|=ε

Proof. The displayed intervals cover every aₙ by construction, and their lengths sum to ε. By the definition of infimum, m*(A)≤ε for every ε>0. Outer measure is nonnegative, so m*(A)=0. If A is finite, list its points once and use a finite allocation, or repeat points in the infinite enumeration; either way the same bound applies. The result holds even if A is dense, because density concerns whether points occur in each open interval, whereas outer measure concerns total cover length.

Why may we call the rationals countable? For each positive denominator q and integer numerator p, p/q is rational. The integer lattice pairs (p,q) with q>0 can be enumerated by increasing |p|+q; each shell is finite. Duplicates such as 1/2=2/4 do not spoil a listing. Therefore ℚ∩[0,1] has outer measure zero. A full proof of density is separate, but countability alone suffices for this length claim.

Zero outer measure does not imply countability. The Cantor set is uncountable and has zero outer measure. Nor does measure zero mean empty: a single point already has zero outer measure. Conversely, a dense set need not have zero measure; [0,1] is dense in itself and has length one. The bridge from outer measure zero to ordinary Lebesgue measure zero uses the fact that outer-null sets are Lebesgue measurable, a standard consequence of the measure construction that we are not proving here.

Budget and logic checks

1. Calculate. Cover a listed countable set with total interval length at most 0.01 using the alternative allocation 0.03/4n. Does it work?

Hint

Use the geometric sum Σ4−n=1/3.

Worked solution

Yes. Center an interval of length 0.03/4n at the nth point. The total is 0.03(1/4+1/16+…)=0.03·(1/3)=0.01. The first N partial sum is (1−4−N)/3, which justifies the infinite total. Every point is covered regardless of overlap.

2. Repair an inference. “ℚ∩[0,1] has zero measure, so it cannot meet every small interval.” Explain the error.

Hint

Distinguish total covering length from the existence of a point in each interval.

Worked solution

The premise is true, but the conclusion is false. Between any two distinct real numbers a<b there is a rational p/q: choose q so large that q(b−a)>1, then an integer p strictly between qa and qb. Thus ℚ is dense. Its enumeration nevertheless admits covers of arbitrarily small total length. Density and measure answer different questions.

Many locations, arbitrarily little cover

A geometric allocation gives every listed point a place while keeping total length under any budget. This proves a countable set is outer-null, including dense rational sets. It does not classify all null sets or construct the full Lebesgue measure; those are later tasks.
