Can a sequence of moves reach the goal?

Imagine a counter displaying an integer. The legal moves add 4 or subtract 6. It starts at 1. Can it ever display 10? A search may fail to find a route, but a failed search does not establish impossibility unless it somehow covers every possible route. A conserved property can. Both legal changes are even, so the display stays odd. Since 10 is even, it is unreachable. We will prove this exact statement, then distinguish it from claims of reachability.

Background capsule. A state is the current displayed integer. A legal move changes it by +4 or −6, with no restriction on intermediate values. A finite sequence of legal moves is a route from the start state. An invariant is a property true at the start and preserved by every legal move; induction then makes it true after any finite number of moves. Here the relevant property is oddness, equivalently remainder 1 upon division by 2.

Watch what changes and what does not

Worked example. From 1, one +4 move reaches 5; one −6 move reaches −5. Further moves might reach 9, −1, 3, and many other values. Every displayed value in that short search is odd. Write a state as 2k + 1. Adding 4 gives 2(k + 2) + 1, and subtracting 6 gives 2(k − 3) + 1. Both new coefficients are integers. This symbolic check covers both move types at every state, not just the ones in our sample.

As a failure case for careless invariant use, alter the rule by allowing +3 once. From 1, that move reaches 4, an even state, so oddness is no longer preserved. An invariant depends on the exact move list. A property that survives most moves is not enough to rule out a goal reachable by an exceptional move.

Prove preservation before declaring impossibility

Let I(s) name the remainder of state s upon division by 2:

I(s)=smod2

This defines I for every integer state: it is 0 for an even state and 1 for an odd state. Negative states use the same nonnegative remainders; for example −5 = 2(−3) + 1, so I(−5) = 1. The claim to prove is that I(s) = 1 along every legal route from 1, not that every possible state has remainder 1.

Theorem. Starting at 1 and using only moves +4 and −6, every reachable state is odd; in particular 10 is unreachable. Proof. The start state 1 is odd. Suppose a state after some number of moves is odd, so it equals 2k + 1 for an integer k. The next state is either 2(k + 2) + 1 or 2(k − 3) + 1, both odd. By induction on the number of moves, every reachable state is odd. Since 10 = 2·5 is even, no legal route can reach it. This proof handles routes of every finite length and either choice at each step.

The theorem is one-way: reachability implies oddness. It does not say every odd integer is reachable. Indeed, the two moves change the state by multiples of 2, and here a stronger analysis happens to show more, but we have not supplied it. A particularly clear counterexample to the converse under a modified move set is a counter that starts at 1 and permits only +4: all reachable states are odd, yet 3 is not reachable. Preservation is an obstruction, not a route-construction algorithm.

There is also a useful general pattern. For a positive integer m, if every legal change is divisible by m, then the state’s remainder modulo m stays fixed. To justify it, write a change as mq; adding it does not change the remainder class. This general claim is proved by the same one-move check and induction. The modulus and legal changes must be stated before applying it.

Find and test an invariant

Exercise 1. A counter starts at 2 and each move adds 6 or subtracts 9. Prove that 4 is unreachable.

Hint for exercise 1

Both move sizes are multiples of 3. Compare the start and goal remainders modulo 3.

Full solution to exercise 1

The start state 2 has remainder 2 modulo 3. Adding 6 or subtracting 9 changes a state by a multiple of 3, so its remainder stays 2 after every move, by induction on the number of moves. The goal 4 has remainder 1 modulo 3. Therefore no sequence of allowed moves reaches 4.

Exercise 2. With the original +4/−6 moves from 1, a friend says “7 is odd, so it is reachable.” Does that conclusion follow? Find a route if one exists, and explain the logical issue.

Hint for exercise 2

Try two +4 moves, one −6 move, then another +4 move. Check the final state and consider the direction of the invariant statement.

Full solution to exercise 2

Yes, 7 is reachable: 1 → 5 → 9 → 3 → 7 uses +4, +4, −6, +4. But oddness alone did not prove it; the invariant only says reachable ⇒ odd. We needed an explicit legal route to establish reachability. The friend’s inference reversed a one-way implication even though this particular goal happens to be reachable.

A conserved fact blocks a destination

To use an invariant, prove the start has it, prove every legal move preserves it, and show the goal lacks it. The argument then rules out every finite route. A search table cannot do that by itself, and the invariant alone cannot construct a route to a compatible goal. Existence and uniqueness similarly separates two claims that are easy to blur.
