When can whole blocks be multiplied?

Reducing integers modulo n replaces every integer by a block of numbers that differ by multiples of n. The blocks can be added without ambiguity. In a general group, cosets are similar blocks, but multiplying them needs a precise condition. A quotient group exists when that condition, normality, holds.

Background capsule. For a subgroup N of G, a left coset aN is {an:n∈N}. Two cosets are equal exactly when a−1b∈N. A rule on cosets is well-defined if replacing a or b by another representative from the same coset does not change the output coset. A subgroup N is normal when gNg−1=N for every g∈G; equivalently gN=Ng. In an abelian group every subgroup is normal because elements commute.

Choose representatives, then change them

Worked example. In the additive group Z, choose N=4Z. The coset 1+N is also represented by 5, and 2+N by −2. Adding representatives gives 1+2=3 or 5+(−2)=3, so both produce 3+N. Other choices can change the integer result by a multiple of four, but never its coset. This is the quotient Z/4Z as a group of four blocks.

Contrast S₃, the permutations of {1,2,3}, with H={e,(12)}. H is a subgroup but not normal. Let a=(13) and h=(12), using right-to-left composition. The same coset aH can be represented by a or ah. If one tried to multiply it by a−1H on the right, using a gives eH, but using ah gives aha−1H=(23)H. These cosets differ because (23)∉H. So the proposed output depends on the chosen name of the input block.

Count the blocks in a finite example

Let G=Z/12Z under addition and let N={[0],[4],[8]}. Adding any two listed classes stays in N, and their additive inverses are again listed, so N is a subgroup. Since G is abelian, N is normal. There are four cosets: N, [1]+N={[1],[5],[9]}, [2]+N={[2],[6],[10]}, and [3]+N={[3],[7],[11]}. Each block has three members, accounting for all twelve elements without overlap.

Add the first nonidentity coset to the last: ([1]+N)+([3]+N)=[4]+N=N. Changing representatives to [5] and [11] gives [16]=[4] in G and again the output N. The quotient's identity is the whole block N, which contains three elements of G; it is one element of G/N. Repeating [1]+N four times first reaches N, so this quotient element has order four. By contrast [2]+N returns after two additions. The quotient records which block a sum reaches, while forgetting which of the three original members supplied its representative.

The normality criterion

(aN)(bN)=abN

Exact statement and proof. If N is normal in G, this formula gives a well-defined group operation on the left cosets G/N. Suppose aN=a′N and bN=b′N. Then a′=an₁ and b′=bn₂ for some n₁,n₂∈N. Their product is a′b′=an₁bn₂=ab(b−1n₁b)n₂. Normality puts b−1n₁b in N, so the last two factors belong to N. Therefore a′b′N=abN. The rule is independent of representatives. Associativity follows from associativity in G; eN is the identity; a−1N is the inverse of aN. Closure is automatic because abN is a coset.

Normality is also necessary for this particular multiplication rule to be well-defined. If it were well-defined, eN=nN for every n∈N. Multiplying these equal cosets on the right by bN would give bN=nbN; hence b−1nb∈N for every b,n. Replacing b by b−1 gives the reverse inclusion, so b−1Nb=N. This is normality. The S₃ computation supplies a concrete failure when it is absent.

For integers, N=nZ is normal because addition commutes. Its cosets a+nZ are precisely residue classes [a]. The quotient construction therefore explains why class addition works, while the direct clock proof remains a useful separate check. Quotient groups collapse a normal subgroup to one identity coset; they do not erase the original group operation.

Audit a quotient rule

1. Calculation. In the quotient Z/(5Z), viewed as cosets of 5Z, compute (−2+5Z)+(9+5Z), then recompute using representatives 3 and 4.

Hint for question 1

Both pairs name the same two input cosets. Add each pair and compare modulo 5.

Full solution for question 1

The first representatives add to 7, giving 7+5Z=2+5Z. The alternatives add to 3+4=7, giving the same coset. Indeed 3−(−2)=5 and 4−9=−5 are multiples of 5. This checks one instance of representative independence; normality proves all instances.

2. Explanation. In S₃, H={e,(12)}. Explain in one computation why H is not normal.

Hint for question 2

Conjugate (12) by (13).

Full solution for question 2

(13)(12)(13)=(23), which is not in H. Thus (13)H(13)−1≠H, so H is not normal. Multiplying its left cosets by the proposed representative formula is consequently ambiguous, exactly as the worked example exhibits.

What makes collapsing lawful

A quotient group replaces elements by left cosets and multiplies them through representatives. That operation is well-defined exactly when the subgroup is normal. The proof handles both directions, not just the convenient integer case. A partition into equal-size cosets by itself is insufficient: Lagrange works for any subgroup, while quotient multiplication needs normality.

Further questions include relating a homomorphism's kernel to a quotient. Kernels are always normal, but identifying the resulting quotient with the image is a separate theorem not proved here.
