What can a square reveal?

If an integer’s square is even, must the original integer be even? Trying a few squares suggests yes, but a proof needs to cover every integer. Directly starting with an even square does not immediately give a useful expression for its square root. The contrapositive changes the starting point: assume the integer is not even, hence odd, and show its square is not even. This lesson proves that precise parity claim and keeps the contrapositive separate from the converse.

Background capsule. An even integer has form 2k; an odd integer has form 2k + 1, for an integer k. Every integer is exactly one of these types, as division by 2 leaves remainder 0 or 1. For propositions P and Q, the contrapositive of P ⇒ Q is ¬Q ⇒ ¬P. These statements have the same truth value; we will also show why.

Square an odd witness

Worked example. Consider −3. It is odd because −3 = 2(−2) + 1. Its square is 9 = 2·4 + 1, also odd. The same algebra works for every odd integer: write n = 2k + 1, then expand. The square equals 4k² + 4k + 1 = 2(2k² + 2k) + 1. The parenthesized value is an integer, so the result is odd. This is more than a list of checked squares; the integer k was arbitrary.

Contrast two nearby claims. “If n² is even, then n is even” is our target. “If n is even, then n² is even” is its converse; it also happens to be true, but for a different reason. For a general implication, the converse need not be true. For example, “divisible by 4 ⇒ even” holds, while “even ⇒ divisible by 4” fails at 2.

Reverse and negate both parts

n2 even⇒n even⇔n odd⇒n2 odd

Theorem. For every integer n, if n² is even then n is even. Proof by contrapositive. Suppose n is not even. Since every integer is even or odd, n = 2k + 1 for some integer k. Expanding gives n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1. Its coefficient inside the parentheses is an integer. Therefore n² is odd, hence not even. We have proved the contrapositive, which establishes the original implication.

Why is that logical move legitimate? An implication P ⇒ Q fails only in the case P true and Q false. Its contrapositive ¬Q ⇒ ¬P fails in exactly the same case: ¬Q is true and ¬P is false precisely when Q is false and P true. This truth-condition argument proves their equivalence for any propositions. Our parity algebra then proves the relevant contrapositive; both parts are needed.

The formula is an exact integer proof, including negative k. It does not say every square is odd. If n = 2, its square is 4, so such a claim fails immediately. Always retain the hypothesis when reporting the conclusion.

Worked example: a product with an odd square

Suppose an integer n satisfies n² = 46k + 1 for some integer k. Can n be even? The right side is 2(23k) + 1, so the square is odd. To answer directly from an even-input assumption, write n = 2j. Then n² = 4j² = 2(2j²), which is even. That contradicts the odd-square condition. Therefore n is odd.

This argument uses the contrapositive of “even input implies even square,” rather than our theorem's converse without explanation. The algebra above supplies the needed forward implication. For n = 1, choosing k = 0 shows the hypothesis can actually hold. Checking that instance is useful, but the witness calculation proves the conclusion whenever the stated hypothesis holds.

Choose the correct direction

Exercise 1. Prove by contrapositive: if n² is divisible by 3, then n is divisible by 3. You may use that every integer has remainder 0, 1, or 2 after division by 3.

Hint for exercise 1

Square the two possible nonzero remainder forms modulo 3.

Full solution to exercise 1

If 3 does not divide n, then n = 3k + 1 or 3k + 2. In either case its remainder modulo 3 is 1 or 2. The notation ≡ means “has the same remainder”: 1² ≡ 1 and 2² ≡ 4 ≡ 1 (mod 3). Thus the square has remainder 1, so 3 does not divide n². This proves the contrapositive and therefore the original claim.

Exercise 2. Write the contrapositive and converse of “If 6 divides n, then 2 divides n.” State which follows automatically and refute the other if needed.

Hint for exercise 2

Reverse both clauses for the converse; reverse and negate both for the contrapositive.

Full solution to exercise 2

The contrapositive is “If 2 does not divide n, then 6 does not divide n”; it follows automatically from the true original statement. The converse is “If 2 divides n, then 6 divides n.” It is false at n = 2: 2 divides 2 but 6 does not.

The arrow that is safe to turn

Contrapositive proof reverses and negates both parts of an implication. In the square example, odd input gives odd square by a complete algebraic argument, so even square forces even input. The converse is a separate claim even when it happens to hold. Continue with induction when the statements themselves form a sequence indexed by the positive integers.
