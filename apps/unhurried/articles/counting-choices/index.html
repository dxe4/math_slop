Sets and membership

A set records which objects belong to a collection. In roster notation, braces surround its members: A={1,3,5}. Writing 3∈A says that 3 belongs to A; writing 2∉A says that 2 does not. Repeating a member or changing the listing order leaves the set unchanged.

Worked example. Let B={3,4}. The union A∪B contains every object in either set. The intersection A∩B contains exactly the objects in both sets.

A∪B={1,3,4,5}A∩B={3}

The empty set, written ∅, has no members. A subset C⊆A has all its members in A. The subset may equal the whole set; the symbol does not require a smaller collection.

Try one. With C={1,5}, find C∩B and decide whether C⊆A.

Worked answer

C and B have no common member, so C∩B=∅. Both 1 and 5 belong to A, hence C⊆A. Empty intersection and subset inclusion ask different questions.

Watch the object. The number 3 and the set {3} are different objects. Here 3∈A and {3}⊆A are both true, but they express different relationships.

A cafe menu turns two choices into many lunches.

A cafe offers three mains—soup, salad, and sandwich—and two drinks—tea and water. How many distinct lunches can you order? Writing down “three plus two” confuses choosing one item with choosing a pair. The useful question is how many complete lunches each main can start. The answer should still work if the cafe runs out of all drinks; that boundary case is a useful check on any rule.

Prerequisite capsule. A finite list is a collection whose entries can be counted. A stage is a choice made after earlier choices. An outcome records every stage, so changing either stage changes the outcome. Here a lunch means one main and one drink, each identified by its menu name; we are not counting the order in which they are consumed.

Count a concrete case

Worked example. Fix soup. It pairs with tea and water, giving two lunches. Salad gives another two, and sandwich another two. These three lists cannot overlap, because a lunch has exactly one main. Thus the answer is 2 + 2 + 2 = 6.

The multiplication 3 × 2 records three disjoint groups of two. If there are zero drinks, each main begins zero complete lunches and 3 × 0 correctly gives zero. If there is only one main, each drink determines a lunch, so 1 × 2 = 2. Read a row as a group of finished orders, rather than a list of ingredients: each entry already includes both a main and a drink.

The exact rule and its proof

From the menu to the formula

N is the total number of complete outcomes. The letter r is the number of stages, and n1, n2, … give the number of options at each stage. The small numbers are stage labels, rather than powers or multiplication: n2 means “the count at stage two.” In the menu example, r = 2, n1 = 3 and n2 = 2. Writing the labelled counts side by side means multiply them; the dots continue the product if there are more stages.

N=n1n2⋯nr

Product rule. If every first-stage option admits exactly n2 second-stage options, every resulting partial choice admits exactly n3 third-stage options, and so on, the number of complete sequences is the displayed product. This is an exact claim about finite choices, including a zero factor. For two stages, partition complete outcomes by first choice. There are n1 disjoint parts, each of size n2; adding equal parts gives the product. Repeat the argument on partial sequences to prove any finite number of stages. Notice that options may depend on earlier choices, provided the number available at that stage stays fixed. For example, choosing two different letters from A, B, C gives 3 × 2 = 6 ordered pairs although the second-stage letter list depends on the first letter. This proof counts sequences, so AB and BA remain distinct.

Where the rule fails. A tempting misuse is to multiply 3 × 2 when a drink is available only with some mains. If soup has two drinks but salad and sandwich have one each, there are 2 + 1 + 1 = 4 lunches. No single “two drinks per main” rule applies. You can partition by main and add the unequal part sizes, or redraw the choice tree. The product rule also does not turn two named stages into an unordered selection: a main and a drink have different roles.

Try two counts

Exercise 1. A workshop lets you choose one of four sessions and one of three time slots; every session runs in every slot. Count the registrations and show the disjoint-part argument.

Hint for exercise 1

Fix one session first. How many slots complete it, and can that registration also belong to another session's part?

Full solution to exercise 1

Each of four session parts contains exactly three registrations, one for each slot. The parts are disjoint because a registration names its session. Therefore 3 + 3 + 3 + 3 = 4 × 3 = 12. Listing one row per session would produce the same 12 pairs.

Exercise 2. You choose two different badges in order from five named badges. How many ordered choices are there, and why is the answer not 5 × 5?

Hint for exercise 2

After selecting the first badge, ask how many remain eligible. Do not keep the first badge in the second-stage list.

Full solution to exercise 2

There are five first choices and four remaining second choices for each one, so 5 × 4 = 20 ordered pairs. The value 5 × 5 = 25 includes five repeated pairs such as AA, forbidden by “different.” We still count AB separately from BA because the question says in order.

What to carry forward

The product rule turns a sequence of choices with fixed stage counts into a product. Its proof is a partition into disjoint groups of equal size. Before multiplying, name a complete outcome and check both the available count after earlier choices and whether order creates a new outcome. An unequal branching tree asks for a sum of branch counts; an unordered group asks a different counting question.
