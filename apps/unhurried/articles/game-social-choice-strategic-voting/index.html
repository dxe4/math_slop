Can a voter prefer to report a false favorite?

In a cover election, a ballot can express a voter's true ordering or serve as a move in a game. Suppose the rule counts only first places, and a voter cares about which cover wins. If a false first place changes the winner from their worst option to their middle option, the voter has a profitable manipulation of that rule at that profile. This lesson constructs one, with the tie convention declared before the ballots are counted.

Background capsule. A true preference A > B > C means the voter likes A best and C least. A report is the ranking they submit, which may differ. Under plurality, only each ballot's first-ranked option earns one vote. We choose the winner with most votes; if top counts tie, the fixed priority A, then B, then C breaks the tie. A manipulation exists when a voter can submit a report that selects an outcome they strictly prefer to the outcome under truthful reporting, with every other report held fixed.

Worked example. With all five reporting sincerely, plurality counts A = 2, B = 2, C = 1. The announced priority breaks the A/B tie in favor of A. Voter 5 truly ranks C > B > A, so A is their least desired result. If only voter 5 reports B > C > A instead, the first-place counts become A = 2, B = 3, C = 0. B wins without a tie. Voter 5 prefers B to A, so this misreport is profitable for them. It does not elect their top choice C; it avoids their worst outcome in this particular setting.

The strategic claim depends on what the other four ballots are, how the rule counts, and how the tie is broken. If priority favored B over A, sincere voting would already elect B and this particular misreport would not strictly improve the outcome. If one of voters 1 or 2 changed, the first-place arithmetic would change. These are features of the constructed example, not assumptions about actual club members.

Formalize the deviation

Let F(ri,r−i) be the winner chosen by the rule from voter i's report and the fixed reports of everyone else. Let ≻i be i's true strict preference. A profitable manipulation at a profile is a report ri with:

F(ri,r−i)≻iF(ti,r−i)

Here ti is the truthful ranking. In the example, the left side is B and the right side A, and voter 5 ranks B above A. That is a complete proof of manipulability for this plurality rule with this tie priority: a single counterexample suffices to refute “truthful reporting is always best.” It does not show that every voter at every profile can manipulate, nor that the misreport is guaranteed to work when the other ballots are unknown.

Strategic voting is related to game theory because a ballot is an action and the election outcome determines payoff according to a voter's preferences. It is related to social choice because the counting rule maps profiles to outcomes. A voter may lack information about others or value truthful expression for reasons not in this outcome-only model; such motives would require a richer payoff description.

Check incentives under changed rules

1. Calculation. Keep the five truthful rankings but change the fixed tie priority to B, then A, then C. What wins with sincere ballots? Does voter 5's B > C > A report strictly improve the winner for them?

Hint for exercise 1

The sincere first-place counts remain 2, 2, 1; apply the new tie rule.

Full solution to exercise 1

Sincere plurality still ties A and B at two each, but B now wins by the revised priority. Voter 5's misreport gives B three first-place votes, so B wins again. Since the selected cover is B in both cases, the misreport does not strictly improve the outcome. A change to tie handling removes this particular profitable deviation.

2. Explanation. Does the five-voter example prove that no election rule can make truthful voting safe? State exactly what it proves and what a broader theorem would require.

Hint for exercise 2

Distinguish one counterexample to one rule from a universal statement about all rules.

Full solution to exercise 2

It proves that plurality with priority A > B > C is manipulable: there exists a profile and a voter for whom a false report changes A to the more preferred B. A claim about every rule would require additional hypotheses and a proof covering all eligible rules and profiles. The displayed arithmetic concerns one named rule. It also says nothing about how likely that profile is in real elections.

What a strategic ballot demonstrates

The profitable deviation is visible in both a count and a preference comparison. Sincere reports yield A by tie priority; voter 5's misreport yields B; voter 5 truly prefers B to A. Specifying those three facts prevents “strategic” from becoming a vague label for any unusual ballot.

Failure case. Under a different tie convention the same reports do not improve the outcome. Under uncertain opponents' ballots the voter may not know which report helps. This is a finite counterexample about possible incentives under a stated rule, not a behavioral forecast.
