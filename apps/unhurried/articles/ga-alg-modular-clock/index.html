When do different integers mean the same hour?

A twelve-hour clock identifies 1, 13 and −11. The hand lands in the same place after adding any multiple of twelve. We can make that observation exact for every integer modulus n≥2, then ask whether the resulting addition obeys the group rules. A clock picture is helpful, but a proof must explain why choosing different integer names for the same position cannot change an answer.

Background capsule. Write a≡b (mod n) when n divides a−b; equivalently a−b=kn for some integer k. The residue class [a] contains all a+kn with k an integer. There are exactly n classes, represented by 0 through n−1. The class is the object; its printed representative is only a convenient name. Integer addition is associative and commutative, and every integer a has an additive opposite −a.

A calculation with two names

Worked example. Work modulo 7. Since 10≡3 and −4≡3, [10]=[−4]=[3]. Add the class [5]: 10+5=15 leaves remainder 1, while −4+5=1 leaves remainder 1. Thus [10]+[5]=[1] and [−4]+[5]=[1]. The two calculations agree despite the different representatives. Likewise, [5]+[2]=[0], so [2] is the additive inverse of [5]; [−5]=[2] is another way to write that inverse.

One row of addition modulo 7
Second class[0][1][2][3][4][5][6]
[5] plus[5][6][0][1][2][3][4]

As the second entry runs through all seven classes, the outputs also run through all seven classes. Addition by [5] merely permutes the positions. This is why the equation [5]+[x]=[1] has one solution, namely [x]=[3]. It is not an invitation to divide by 5; addition and multiplication are different operations.

Undo addition without choosing a special representative

Solve [−3]+[x]=[4] modulo 11. Add [3], the additive inverse of [−3], to both sides. Associativity and the identity law give [x]=[7]. Checking with the representative 7 gives −3+7=4. Checking with the different representative 18 gives −3+18=15, and 15 differs from 4 by 11, so it gives the same output class. Both integers name one solution in the quotient group.

There are infinitely many integer representatives, precisely 7+11k for integers k, but only one solution class. To prove uniqueness, if [x] and [y] both satisfy the equation, add [3] to both equalities; each must equal [7], hence they are the same class. This cancellation argument uses additive inverses, which exist modulo every n≥2. It never divides by a residue. A composite modulus would give the same additive cancellation even when multiplicative division fails.

From a clock to a group

Define addition of classes by the central rule

[a]+[b]=[a+b]

Exact statement and proof. For every integer n≥2, the residue classes modulo n form an abelian group under this addition. First establish well-definedness: if a′=a+kn and b′=b+ln, then (a′+b′)−(a+b)=(k+l)n. Thus [a′+b′]=[a+b], so the output depends only on input classes. Closure follows because a+b is an integer and therefore has a class. Associativity follows from integer associativity: ([a]+[b])+[c]=[(a+b)+c]=[a+(b+c)]=[a]+([b]+[c]). The identity is [0], since [a]+[0]=[a]. The inverse of [a] is [−a], since [a]+[−a]=[0]. Finally, [a]+[b]=[b]+[a] because a+b=b+a. This last property makes the group abelian.

The proof is a model for constructing operations on equivalence classes. You must check that changing a representative leaves the result unchanged before using familiar integer laws on the classes. Without that step, notation such as [a]+[b] might depend on arbitrary choices. Multiplication of classes is also well-defined, but its nonzero elements do not always have multiplicative inverses. For example [2]·[3]=[0] modulo 6, so division by [2] cannot behave like division by a nonzero real number.

Use classes rather than labels

1. Calculation. Modulo 9, solve [7]+[x]=[2]. Check your answer with representatives 16 for [7] and −7 for [2].

Hint for question 1

Add the inverse [−7] to both sides, and remember that −5 and 4 give the same class modulo 9.

Full solution for question 1

[x]=[2−7]=[−5]=[4]. Check: [7]+[4]=[11]=[2]. With the alternate names, 16+4=20 and 20−(−7)=27, a multiple of 9, so [16]+[4]=[−7] as required.

2. Explanation. Someone defines [a]⊙[b]=[a+b+1] modulo 5 and claims [0] is its identity. Test that claim and find the actual identity if one exists.

Hint for question 2

Compute [a]⊙[0]. Solve [a]⊙[e]=[a] for a possible e.

Full solution for question 2

[a]⊙[0]=[a+1], which differs from [a], so [0] is not an identity. The equation [a+e+1]=[a] requires [e+1]=[0], hence [e]=[−1]=[4]. Indeed [a]⊙[4]=[a+5]=[a], and commutativity gives [4]⊙[a]=[a]. A familiar-looking set does not fix the identity independently of its chosen operation.

The clock's precise promise

Modulo-n addition is a group operation for every n≥2 because its class rule is well-defined and inherits the required laws from integers. The additive inverse of [a] is always [−a]. The failure case is multiplication: modulo 6, nonzero [2] and [3] multiply to zero, so this lesson's group conclusion does not say every nonzero class can be divided out.

Next, repeat addition by a fixed class and count how long it takes to return to [0]. That count is the order of the element and reveals a smaller cyclic group inside the clock.
