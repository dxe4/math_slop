Functions and composition

A function assigns exactly one output to each allowed input. Its domain is the set of allowed inputs; its codomain is the declared set containing the outputs. Different inputs may share an output. For f(x)=x² on the real numbers, both 2 and −2 produce 4.

Worked example. Let f(x)=2x+1 and g(x)=x². The expression f(g(3)) first applies g to 3, producing 9, and then applies f to 9, producing 19. Composition writes this as (f∘g)(3).

f(g(3))=f(9)=19

For a composition to be defined, the output of the inside function must be an allowed input for the outside function. Here both functions accept every real number, so that condition holds.

Try one. Compute g(f(3)). Does changing the order preserve the result?

Worked answer

First f(3)=7, then g(7)=49. This differs from f(g(3))=19. Composition generally depends on its order; the circle symbol names the operation, rather than promising that the two orders agree.

Watch the notation. In f(3), the parentheses name the input to f. They do not mean f multiplied by 3. Read the expression from the inside out.

A list that misses a diary

Imagine an infinite yes/no diary: one answer for each day, with 1 for yes and 0 for no. Each answer is called a bit. Could someone list every possible diary in rows numbered 1, 2, 3, …? The rows may be infinite themselves, and the proposed list may be clever. Cantor's diagonal idea constructs one diary that differs from each listed row on a particular day.

The short infinity discovery matched positive whole numbers with positive evens. The bijection lesson checked that matching for collisions and missed targets. Here the target is different: the collection of all infinite binary diaries. We will show that every proposed numbered list misses a target.

A diary is a rule for every day

Here ℕ = {1, 2, 3, …}; days and rows start at 1. A binary sequence is an infinite diary whose every entry is 0 or 1. Writing s: ℕ → {0, 1} says that the rule s assigns one of those two bits to each positive whole-number day. Its day-n entry is sn. The subscript identifies a position; it is not a multiplier.

A numbered list is another rule: give it a row number and it supplies a whole diary. An enumeration covers every diary in the target collection. Repeated rows are allowed. A set is countable if it is finite or can be completely listed in positive whole-number positions. An infinite set that cannot be completely listed is uncountable. These words describe mathematical lists, not how long a person would take to write them.

A finite grid can show the construction, but the proof must give a difference from every numbered row, including rows far beyond the picture.

Choose a different answer on one day per row

Worked example. Suppose a proposed list begins with the four diaries below. The diagonal uses day 1 of diary 1, day 2 of diary 2, and so on. A star marks each chosen entry. Build a new diary by replacing each chosen 0 with 1 and each chosen 1 with 0.

The chosen entries are 0, 1, 0, 0, so the new diary begins 1, 0, 1, 1. It differs from row 1 on day 1, row 2 on day 2, row 3 on day 3, and row 4 on day 4. Two diaries are identical only if every day's answer agrees; one differing day is enough to rule out a match.

Before going on, point to the entry that rules out row 3. It is the third day: row 3 has 0, while the new diary has 1. The later entries in either diary cannot undo that difference.

The full construction applies the same instruction to every positive row number. Later rows determine later bits; the four displayed rows do not determine the entire new diary.

Turn the construction into a proof

Read the row and day separately

Write ar,c for the entry in row r, day c. For example, a2,3 is row 2's day-3 bit, which is 0 in the table. The comma separates the two positions. Write dn for day n of the new diary. Then an,n means the diagonal entry: row n, day n.

The notation {0, 1}ℕ names the set of all infinite binary sequences: all functions from ℕ to {0, 1}. Here the superscript names a collection of functions; it is not ordinary numerical exponentiation. A surjective list would reach every member of this collection.

Exact statement. There is no surjective function from ℕ onto {0, 1}ℕ. In words, no list with positive whole-number row labels contains every infinite binary diary.

dn=1−an,n

Read this as “the new bit on day n is one minus row n's bit on that day.” Subtracting from one flips a binary bit: 1 − 0 = 1, and 1 − 1 = 0.

  1. Allow any proposed complete list. Suppose rows 1, 2, 3, … contain every infinite binary diary. We make no assumption about how the list was ordered, and rows may repeat.
  2. Define a valid new diary. For every positive whole number n, set dn = 1 − an,n. Every row has an entry on every day. Each chosen entry is 0 or 1, so its opposite is an allowed bit too. The rule therefore specifies a whole infinite binary diary d.
  3. Rule out whichever row is named. Choose any row number k. On day k, that row contains ak,k, while d contains its opposite. The diaries differ on that day, so d is not row k. The letter k stands for an arbitrary positive row number, rather than just a row we drew.
  4. Contradict completeness. The same reasoning rules out every numbered row. Yet d is a valid binary diary, so a list containing every such diary would have to include it. This contradiction defeats the assumption that the proposed list was complete. Because the list was arbitrary, no complete list exists.

The rule defines each bit without requiring us to calculate all bits in time. The finite picture alone would show only four differences. The proof goes further by choosing any row number k and naming the day that defeats it. Thus the collection of infinite binary sequences is uncountable.

Boundary: finite strings are different. All finite binary strings can be listed: the empty string first; then 0 and 1; then 00, 01, 10, 11; then all length-three strings, and so on. Each length contributes a finite block. Any particular finite string has only finitely many earlier blocks and entries before it, so it reaches a numbered position. Trying the diary proof here can fail because a finite string in row n might have no day-n entry. Alternatively, padding all strings with zeros creates a different target: diaries eventually equal to zero. A diagonal diary need not belong to that restricted target.

Name the differing day

1. Calculate. A proposed list begins row 1 = 000…, row 2 = 101…, row 3 = 110…. What are the first three new bits, and where does the new diary differ from each displayed row?

Hint for question 1

Read day 1 of row 1, day 2 of row 2, and day 3 of row 3. Then flip those three bits.

Full solution to question 1

The chosen entries are 0, 0, 0. In particular, row 2 has second bit 0 and row 3 has third bit 0. The new diary begins 111…. It differs from row 1 on day 1, row 2 on day 2, and row 3 on day 3. Later rows determine its later bits; the displayed prefix does not tell us those bits.

2. Explain. Someone suggests that the new diary might be row 10,000, because the picture showed only four rows. Which day rules out that suggestion?

Hint for question 2

Use the proposed row number as a day number too.

Full solution to question 2

Day 10,000. The construction chooses the opposite of row 10,000's answer on that day. The two diaries therefore differ there, regardless of their earlier answers. The rule applies to that row just as it applies to the first four.

3. Change the list. Put the missing diary at the front of the old list, shifting every old row down one. Have you made a complete list?

Hint for question 3

The new list has a new diagonal. Apply the construction to that list rather than reusing the old diagonal.

Full solution to question 3

You have included the particular diary previously shown to be missing. But the proof applies to any numbered list, including the new one. Flip the new list's diagonal to construct a diary that differs from each of its rows. That new diary is absent. The theorem does not say one fixed diary is missing from every list; the constructed diary depends on the list being challenged.

One day defeats each row

No enumeration of infinite binary diaries is complete. On day n, choose the opposite of row n's answer. Then whichever row k someone names, day k proves the new diary is different. The finite table shows the construction; the arbitrary row number makes the proof infinite.

A useful place to stop is explaining that argument without the subscripts. On another evening, the diagonal sequence lab lets you change a finite display and check each differing position. Its finite rows illustrate the construction; they do not establish the infinite claim by themselves.
