Counting choices

Begin by naming one complete outcome. If you choose one of three drinks and then one of two snacks, an outcome is a drink–snack pair. Each drink has two snack choices, so there are 3×2=6 pairs. This counts combinations of choices; it does not require a probability model.

Worked example. Arrange three distinct postcards in a row. There are three choices for the first place, two remaining choices for the second, and one for the last. The result is 3×2×1=6 arrangements, written 3!.

3!=3×2×1=6

For a positive integer n, n! multiplies every integer from 1 through n. The convention 0!=1 counts the single empty arrangement. Factorials count arrangements of distinct objects when each is used exactly once.

Try one. How many two-letter codes can you make from A, B and C when repetition is forbidden?

Worked answer

Choose the first letter in three ways and the second in two ways, giving six codes: AB, AC, BA, BC, CA and CB. If repetition were allowed, the second position would have three choices too, giving nine.

Watch the rule. If different first choices allow different numbers of second choices, count those branches separately and add. A single fixed product needs the stated number of options at every stage.

BALLOON has many arrangements but repeated letters look alike.

A sign maker has letter tiles for BALLOON. Seven physical positions are available, but the two L tiles look alike and the two O tiles look alike. If we treat every tile as unique, 7! counts many different installation histories that leave exactly the same visible word. How many different seven-letter strings can the tiles actually make? A small case, AAB, reveals the issue: labeled tiles A₁,A₂,B yield six orders, yet only AAB, ABA and BAA can be read.

Prerequisite capsule. For n distinct objects, n! is the number of ordered arrangements: choose among n objects first, then n − 1, down to one. In a word, positions matter but equal letters cannot be told apart in the finished spelling. We will temporarily label equal letters to count them, then erase those temporary labels.

Count a concrete case

Worked example. Label BALLOON's repeated letters L₁,L₂ and O₁,O₂ for a moment. The seven labeled tiles have 7! = 5040 orders. Take any one visible spelling, perhaps BALLOON itself. Its two L labels can be exchanged in 2! ways without changing the spelling, and independently the two O labels can be exchanged in 2! ways. Exactly 2! × 2! = 4 labeled orders erase to that spelling. Hence the visible count is 5040/4 = 1260. The multiplicity is the same for every visible spelling because each has exactly two L positions and two O positions. For AAB, the same argument divides 3! by 2! and returns 3.

The exact rule and its proof

N=n!m1!⋯mr!

Multiset permutation theorem. Suppose a collection of n positions is filled with r letter types occurring m1, …, mr times, with their counts summing to n. The formula counts its distinct linear words. To prove it, give every occurrence a unique temporary subscript. There are n! labeled arrangements. Erase subscripts. For any resulting word, its positions for type 1 can receive those labels in m1! ways; type 2 independently has m2! ways, and so forth. Each visible word is reached by exactly the same product of labelings, so dividing is exact. A type appearing once contributes 1!, which changes nothing. If all tiles have one type, there is one visible word, as the formula says.

Where the rule fails. Do not divide by 2! merely because two tiles have the same color if they remain individually distinguishable by printed numbers. Red-1, red-2 and blue form six different numbered sequences; erasing the numbers changes the question and leaves only three color strings. The formula also assumes linear positions: arranging tiles around a circular table can identify rotations as the same outcome, and the number of equivalent labelings needs a separate argument.

Worked example: a repeated letter with a fixed position

How many visible arrangements of BANANA begin with B? Fix B in the first position. The five remaining positions contain A,A,A,N,N. Temporarily label these five tiles A₁,A₂,A₃,N₁,N₂. They have 5! = 120 arrangements. For any one visible ending, the three A labels can be placed in its A positions in 3! ways, and the two N labels in 2! ways. Every visible ending therefore has 3!·2! = 12 labeled versions. The answer is 120/12 = 10.

An independent count chooses the three A positions among the five unfilled places. There are C(5,3) = 10 choices, and the other two places must hold N. This agrees with the corrected factorial count and explains what each result counts. The fixed B contributes no new choice. If B could occupy any of the six positions, the total would instead be 6·10 = 60, because each visible word has exactly one B and therefore belongs to exactly one of six disjoint cases.

Try two counts

Exercise 1. How many distinct strings can be made from LEVEL? Show which labels you temporarily introduced.

Hint for exercise 1

Count five labeled positions, then independently exchange the two L labels and the two E labels.

Full solution to exercise 1

The labeled set L₁,L₂,E₁,E₂,V has 5! = 120 orders. Every visible LEVEL-type string corresponds to 2! exchanges of L labels and 2! exchanges of E labels, for four labeled orders. Thus 120/(2!2!) = 30 distinct strings.

Exercise 2. How many visible strings come from AABC, and how many if the two A tiles are individually numbered and their numbers remain visible?

Hint for exercise 2

Write down whether swapping the A tiles changes an outcome under each interpretation.

Full solution to exercise 2

With identical A tiles, there are 4!/2! = 12 visible letter strings. If the A tiles are marked A₁ and A₂ and these marks matter, all four objects are distinct, giving 4! = 24 strings. Each unmarked string has exactly two marked versions.

What to carry forward

The denominator counts how many labeled arrangements collapse to one visible arrangement. This is a proof obligation, not a decoration attached to a factorial. State what observers can distinguish, check that every visible outcome has the same number of hidden labelings, and only then divide. That habit prepares you to count more complicated selections without accidentally changing the notion of sameness.
