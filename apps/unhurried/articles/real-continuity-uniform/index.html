May one input tolerance serve every point?

A continuous function responds gently to small input changes near each fixed point. But the required input tolerance can depend on that point. Uniform continuity asks for one tolerance that works simultaneously across the domain. For x² this difference appears as soon as the domain stretches without bound.

Background capsule. |u−v| is the distance between real numbers u and v. Ordinary continuity at a means: for each output tolerance ε > 0 there is an input tolerance δ > 0 such that x in the domain and |x−a| < δ imply |f(x)−f(a)| < ε. The δ may depend on a. A function is Lipschitz with constant L if |f(x)−f(y)| ≤ L|x−y| for all domain points. We will prove a concrete Lipschitz bound rather than assume a compactness theorem.

Try a shared tolerance

Worked example. On [−3,3], take f(x) = x². Factoring gives |x²−y²| = |x−y||x+y|. Since |x+y| ≤ 6 on this interval, an input gap below ε/6 guarantees an output gap below ε. For example, to keep square values within 0.12, δ = 0.02 works everywhere in [−3,3]. At x = 3 and y = 2.99 the output gap is 9−8.9401 = 0.0599, comfortably below 0.12. This one sample does not establish the guarantee; the factorization does.

On the entire real line the same δ cannot work. If x is very large, even a modest fixed input change h produces |(x+h)²−x²| = |2xh+h²|. Its size grows with x. The location is what breaks the shared promise, although x² remains continuous at each individual x.

Use the bound as a resolution requirement. On [−3,3], any two recorded inputs differing by less than 0.001 have squared outputs differing by less than 0.006. This conclusion is independent of which two inputs occur. It is conservative near zero: the actual change from 0 to 0.001 is only 0.000001. Uniform continuity allows a safe common tolerance to be smaller than the best tolerance at particular points; it asks for reliability everywhere, not equal sharpness everywhere.

Put the quantifiers in their places

Exact definition. A function f on D ⊆ ℝ is uniformly continuous if

∀ε>0∃δ>0∀x,y∈D:|x−y|<δ⇒|f(x)−f(y)|<ε

The decisive order is “choose δ, then consider every pair.” For x² on [−M,M] with M > 0, |x+y| ≤ 2M. Choosing δ = ε/(2M) makes |x²−y²| < ε. If M = 0, the one-point domain is trivially uniformly continuous. The same proof works on any bounded interval by enclosing it in some [−M,M]; its endpoints need not be included. This establishes a local result directly.

Now fix ε = 1 on D = ℝ. For any proposed δ > 0, choose h = min(δ/2,1/2), so 0 < h < δ. Set y = x+h and take x > 1/(2h). Then |y²−x²| = 2xh+h² > 1. Thus no δ works for all pairs. Notice that choosing x only after seeing δ is legitimate: it disproves the universal-pair part of the definition. This is a full counterexample, not a graph-based impression.

Continuity of x² at a fixed a follows separately. If |x−a| < 1, then |x+a| ≤ 2|a|+1. Choose δ = min(1, ε/(2|a|+1)). The bound proves |x²−a²| < ε. This δ depends on a, which is why this pointwise proof does not establish uniform continuity on ℝ.

A broader theorem says every continuous function on a compact interval [a,b] is uniformly continuous. Its proof needs compactness; we do not infer it merely from the x² calculation. The unbounded-domain counterexample does not mean every unbounded-domain function fails: f(x)=2x is uniformly continuous on ℝ with δ=ε/2. Domain and growth both matter.

Work with the shared δ

1. Calculate. Give an explicit δ for f(x)=x² on [2,5] when ε=0.1, and justify it for every pair in the interval.

Hint

On [2,5], how large can x+y be?

Worked solution

Here |x+y| ≤ 10. Take δ = 0.01. If |x−y| < 0.01, then |x²−y²| = |x−y||x+y| < 0.01·10 = 0.1. The strict input inequality gives the strict output inequality even at the maximum possible sum.

2. Diagnose. Is f(x)=1/x uniformly continuous on (0,1)? Supply a decisive pair sequence.

Hint

Choose points approaching zero whose distance shrinks while reciprocal values separate.

Worked solution

Take xn=1/(n+1) and yn=1/(n+2), both in (0,1). Their distance is 1/((n+1)(n+2)) → 0, but |1/xn−1/yn| = |(n+1)−(n+2)| = 1. For ε=1/2, every δ is defeated by a sufficiently large n. The missing endpoint zero matters: continuity on an open bounded interval does not automatically give uniform continuity.

One promise or many

Ordinary continuity lets δ change with the base point; uniform continuity requires one δ for all pairs. On a bounded interval, the x² factorization gives a direct shared bound. On ℝ its growth defeats every shared δ. The optional next link is uniform convergence, which uses a similar “one bound across all x” idea for a sequence of functions.
