Can each volunteer take a distinct task?

Suppose volunteers can perform only some tasks. Giving each chosen volunteer a different suitable task is a matching problem. A quick first assignment may leave someone unmatched even when a better assignment exists. An alternating route can rearrange earlier choices without dropping anybody already assigned.

Background capsule. A bipartite graph has its vertices divided into two sets, here people L and tasks R, with edges only between the sets. An edge means a person can do a task. A matching M is a set of edges with no shared endpoints. An unmatched vertex has no incident edge in M. A path alternates between edges outside M and edges in M when successive edges switch status. An augmenting path begins and ends at unmatched vertices and alternates, starting and ending with edges outside M. In a bipartite graph the endpoints lie on opposite sides if the path is intended to add one assignment.

Take volunteers A,B,C and tasks 1,2,3. Allowed pairs are A–1, A–2, B–1, C–2, C–3. If we first assign A–1 and C–2, volunteer B remains unmatched, but the choices can be rearranged. How?

Flip an alternating path

Worked example. The path B–1–A–2–C–3 uses, in order, an unchosen edge B–1, chosen edge A–1, unchosen A–2, chosen C–2, and unchosen C–3. Its endpoints B and task 3 are unmatched. Remove the chosen path edges A–1 and C–2, then add B–1, A–2, C–3. The new matching assigns all three volunteers to distinct tasks. Two existing assignments changed, but the total count rose from two to three.

Every newly used pair was an allowed edge. Every internal vertex on the path trades one matched incident edge for one formerly unmatched edge; the endpoints each gain an incident matched edge. Vertices outside the path keep their previous status. This is a finite local operation, not a claim that every unmatched volunteer can always be accommodated.

Why augmentation increases a matching

Theorem. If P is an augmenting path for matching M, flipping membership of its edges yields another matching M′ with exactly one more edge:

|M′|=|M|+1.

Complete local proof. An augmenting path has an odd number 2k+1 of edges, alternating outside M, inside M, and so on. Therefore it has k edges of M and k+1 edges outside M. Remove its k matched edges and add its k+1 unmatched edges. Each internal path vertex loses one matched incident edge and gains one, while each unmatched endpoint gains one. Because P is a simple path, no vertex is used twice along it, and edges outside P are unaffected. Thus no vertex receives two matching edges and M′ is a matching. Its size changes by −k+(k+1)=1. The worked three-person example has k=2.

There is a stronger exact criterion, often called Berge's lemma: a matching is maximum in size exactly when it has no augmenting path. The forward direction is immediate from the theorem. For the reverse direction, compare M with a larger matching N and inspect their symmetric difference, the edges belonging to exactly one of them. Every vertex there has at most one edge from each matching, so components are alternating paths or even cycles. Since N has more edges than M, some component has more N edges and must be an alternating path beginning and ending with N edges. That path augments M. For completeness, a nontrivial component of the symmetric difference has degree at most two at every vertex. If it has a degree-one vertex, start there and follow the unique unused continuation. No branching is possible. The finite walk ends at another degree-one vertex and covers the whole component, because an unvisited attachment would create degree at least three. Thus it is a path, including a single isolated edge as the shortest case. If every vertex has degree two, following edges closes into a cycle; again no other vertex can attach without degree three, so that cycle is the component. Adjacent edges must come from different matchings, making every cycle even with equal contributions from M and N. Paths have either equal contributions or one extra edge of one matching. Since N is larger overall, at least one path has one extra N edge. Both its end edges belong to N, and its endpoints have no incident M edge, so it is an augmenting path for M. This completes the reverse implication.

Failure case. If B can do only task 1 and A can also do only task 1, no matching assigns both, no matter how cleverly we rearrange. One task cannot be paired with two people. Hall's theorem gives a complete condition for matching every person, but its general proof lies beyond this lesson. The augmenting path method does not claim every instance has a perfect assignment.

Repair or reject an assignment

Exercise 1. People P,Q and tasks x,y allow P–x, P–y, Q–x. Current matching is {P–x}. Find an augmenting path and the resulting matching.

Hint for exercise 1

Start at unmatched Q and alternate through x and P toward the unmatched task.

Full solution to exercise 1

Q–x–P–y is an augmenting path: Q–x is outside the matching, x–P is inside, and P–y is outside. Flip its edges, removing P–x and adding Q–x and P–y. The resulting matching has two edges and assigns both people. It is maximum because only two people and two tasks exist.

Exercise 2. People U,V,W can each do only tasks r or s; every person can do both. Can an augmenting path make a matching of size three? Explain the obstruction in the model.

Hint for exercise 2

Count the task vertices available as distinct partners.

Full solution to exercise 2

No. A matching uses each task at most once, and there are only two task vertices, so any matching has size at most two. For example {U–r,V–s} already reaches that bound; W has no augmenting path ending at an unmatched task because neither task is unmatched. The fact that every person is individually qualified for either task does not create a third distinct task.

Reassignment can create room

A matching is a set of compatible, nonoverlapping pairs. On an augmenting path, alternating chosen and unchosen edges lets internal vertices keep one partner while both endpoints gain one, so the matching grows by exactly one. Capacity remains a real constraint, and local improvement does not guarantee a full assignment. To test whether two drawings encode the same assignment network, see graph isomorphism.
