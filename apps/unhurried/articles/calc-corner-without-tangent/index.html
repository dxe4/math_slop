Coordinates and slope

An ordered pair (x,y) specifies a position in the coordinate plane: x measures horizontal displacement and y measures vertical displacement from the origin. The order matters. The points (2,5) and (5,2) usually occupy different places.

Worked example. From P=(1,2) to Q=(4,8), the horizontal change is 4−1=3 and the vertical change is 8−2=6. The slope is vertical change divided by horizontal change, giving 6/3=2.

m=y2−y1x2−x1=63=2

Use the same order in both subtractions. Reversing the points gives (2−8)/(1−4)=−6/−3=2 again. A horizontal line has slope zero. A vertical line has zero horizontal change, so this quotient does not define a finite slope.

Try one. Find the slope from (−1,4) to (2,−2).

Worked answer

The horizontal change is 2−(−1)=3. The vertical change is −2−4=−6. Dividing gives slope −2. The negative sign means that y decreases as x increases along this line.

Watch the units. If x is time in hours and y is distance in kilometres, the slope has units of kilometres per hour. The scales carry mathematical information.

What does a corner do to a rate?

The graph of |x| is an upright V. It is continuous at zero: its height tends to zero from either direction, matching its value there. Yet a traveller following this height graph changes direction abruptly. Can a single slope describe the graph exactly at the turn?

Background capsule. Absolute value |x| is distance from zero, so |x| = x when x ≥ 0 and |x| = −x when x < 0. A secant slope divides change in height by a nonzero horizontal step. A derivative at a is the limit of these slopes as the step tends to zero through both positive and negative values. One-sided limits inspect only one direction. A two-sided limit exists only when the two one-sided limits agree.

Try equal steps on opposite sides

Worked example. At the origin the base point is (0,0). With step h = 1/4, the second point is (1/4,1/4), and the slope is 1. With h = −1/4, the second point is (−1/4,1/4), and the slope is −1. Shrinking either step to one thousandth changes neither answer. The values do not drift towards one another.

The same calculation applies to any positive or negative nonzero step, so the table illustrates an exact fact rather than supplying the proof. Notice the height is always positive but the slope is signed: moving rightwards from a negative x to zero goes downhill.

Check a point beside the corner. At a=1/10 choose |h|<1/20. Then a+h is still positive, so [|a+h|−|a|]/h=h/h=1. The small interval around a stays entirely on one straight branch, which proves the derivative there. At zero no positive radius can exclude both branches: every neighborhood contains positive and negative inputs. The issue is therefore local geometry at the chosen base point. Translating the V changes the location of its exceptional point; multiplying its height by a nonzero constant changes the one-sided slopes but does not make them agree.

The precise obstruction

Statement. The function f(x)=|x| is continuous at zero but has no ordinary derivative there. Its right derivative is 1 and its left derivative is −1.

|h|−0h=1h>0−1h<0

Proof. On the positive side, |h|=h, so the quotient is h/h=1. On the negative side, |h|=−h, so the quotient is −h/h=−1. If a two-sided limit L existed, choosing positive steps arbitrarily close to zero would force L=1, while choosing negative steps would force L=−1. One real number cannot equal both. For continuity, however, ||h|−|0||=|h|. Given any tolerance ε>0, every |h|<ε makes the height error less than ε. These are different tests.

Elsewhere the graph has an ordinary derivative: for a>0, a sufficiently small neighbourhood stays positive and f(x)=x there, giving slope 1; for a<0 it stays negative and f(x)=−x, giving −1. The corner is one exceptional point, not a claim that absolute value is nowhere differentiable.

A function with a derivative at a must be continuous there. Indeed, f(a+h)−f(a)=h[(f(a+h)−f(a))/h], and the bracket approaches a finite derivative while h approaches zero. The converse fails here. The argument presumes a finite derivative and a point in the function's domain; it does not turn an infinite one-sided slope into an ordinary derivative.

Test the definition yourself

1. Calculate. Let g(x)=|x−2|. Find the left and right secant slopes at x=2, then decide whether g′(2) exists.

Hint for 1

Replace x with 2+h. Divide g(2+h)−g(2) by h.

Worked solution for 1

g(2+h)=|h| and g(2)=0. Thus the quotient is |h|/h. For h>0 it equals 1; for h<0 it equals −1. Both one-sided limits exist but differ, so g′(2) does not exist.

2. Explain. The function q(x)=x|x| has a V-shaped ingredient. Is it differentiable at zero? This tests whether the mere appearance of an absolute-value symbol settles the matter.

Hint for 2

Write the difference quotient at zero before inspecting signs.

Worked solution for 2

q(0)=0, so [q(h)−q(0)]/h=|h| for every h≠0. Since |h| tends to zero from both sides, q′(0)=0. The absolute-value factor is multiplied by x; this flattens the graph enough for a derivative. A visual cue alone is not a proof.

A boundary worth remembering

The derivative is a two-sided promise about secant slopes. Continuity only controls heights. At a corner, both height limits agree while slope limits disagree. For a nearby positive point, the formula changes back to an ordinary slope of 1; the failure is localized at the meeting point.
