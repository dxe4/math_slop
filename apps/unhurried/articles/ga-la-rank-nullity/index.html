Where does a lost dimension go?

A shadow of a three-dimensional object lies in a plane. Movement directly toward the lamp may disappear from the shadow, while other movements remain visible. A linear map can similarly make some input directions invisible. Rank-nullity accounts for every input direction: each contributes either to distinct output directions or to the kernel of directions mapped to zero.

Background capsule. A linear map T:V→W preserves sums and scalar multiples. Its kernel is ker T={v in V:T(v)=0}; its image is im T={T(v):v in V}. Both are vector subspaces. A basis is an independent list that spans a space, and dimension is the number of vectors in any basis. Rank means dim im T; nullity means dim ker T. We assume V is finite-dimensional. Solving T(v)=0 is a homogeneous linear system.

One direction disappears

Worked example. Consider T:R³→R² defined by T(x,y,z)=(x+y,y+z). To find the kernel, solve x+y=0 and y+z=0. Let y=t; then x=−t and z=−t. Thus ker T consists exactly of t(−1,1,−1), a one-dimensional line. The direction (−1,1,−1) is invisible: adding it to any input changes neither output coordinate.

The image is all of R². Indeed T(1,0,0)=(1,0) and T(0,0,1)=(0,1), two independent outputs; any (a,b) equals T(a,0,b). So rank is two and nullity is one. The input dimension is three: 2+1=3.

How input directions behave
InputOutputRole
(−1,1,−1)(0,0)Kernel basis
(1,0,0)(1,0)First output direction
(0,0,1)(0,1)Second output direction

Those three input vectors form a basis of R³: if their combination is zero, the middle coordinate forces the kernel coefficient to zero, and the other coordinates then force both remaining coefficients to zero. Their images explain the dimension count directly.

Every input basis can be organized this way

Rank-nullity theorem, with proof. For a linear map T:V→W with finite-dimensional domain V,

dim(kerT)+dim(imT)=dimV

Take a basis k₁,…,kr of ker T. The finite-dimensional basis-extension theorem lets us add vectors v₁,…,vs so that k₁,…,kr,v₁,…,vs is a basis of V. This step relies on that standard theorem about independent lists; a proof of basis extension is outside this article. We now prove that T(v₁),…,T(vs) is a basis of im T.

For spanning, expand any input x as a sum of k's and v's. Applying T kills all k terms, so T(x) is a combination of the T(v)'s. For independence, suppose ∑ajT(vj)=0. Then ∑ajvj belongs to ker T, hence equals some combination ∑biki. Move one side across. The independence of the full input basis forces every aj=0. Therefore image dimension is s, kernel dimension is r, and input dimension is r+s.

The theorem requires a linear map and finite-dimensional domain. It says nothing by itself about the dimension of W; the image can be a proper subspace. A zero map R³→R² has rank zero and nullity three, while the map in our example has rank two and nullity one. One cannot claim “rank plus nullity equals output dimension.”

Count visible and invisible directions

1. Calculation. Let S:R³→R² be S(x,y,z)=(x−z,2x−2z). Find a kernel basis, an image basis, rank and nullity.

Hint for question 1

Both output coordinates depend only on x−z. Set that equal to zero and choose two free variables.

Full solution for question 1

The kernel condition is x=z; y is free. Write (x,y,z)=x(1,0,1)+y(0,1,0), so those two vectors form a kernel basis. Every output is t(1,2), and t=1 is attained at input (1,0,0), so {(1,2)} is an image basis. Rank is one, nullity is two, and 1+2=3, the input dimension.

2. Explanation. A friend sees a map R³→R² and asserts its nullity must be exactly one, because 3−2=1. Give a counterexample and the corrected inequality.

Hint for question 2

Try a map sending every input to zero. Rank cannot exceed the output dimension.

Full solution for question 2

The zero map R³→R² has image {0}, so rank zero and nullity three. Rank-nullity gives nullity=3−rank. Since rank≤2, nullity≥1, but it need not equal one. Equality requires the image to fill all of R².

A dimension ledger

To use rank-nullity, solve the homogeneous equations for a kernel basis and identify independent output directions for an image basis. The proof relies on extending a kernel basis, then shows the added vectors have independent images. In finite dimensions no input direction is unaccounted for. For a 2D map, nonzero determinant is one shortcut to rank two and nullity zero; the theorem also handles rectangular matrices where a determinant is unavailable.
