What does
simplification preserve?

A shorter formula can hide a missing input, acquire extra solutions, or discard half a real domain. Keep the mathematical object in view while changing its expression.

These three investigations use exact rational probes. Their written arguments classify the cases for real parameters. Preparation: factoring, real square roots, and the positive-argument rule for real logarithms. A 60–90 minute route with selected practice is a planning estimate.

Three objects to keep distinct

An expression

A symbolic recipe such as (x²−1)/(x−1). Algebra can replace it with a simpler recipe on the inputs where the original operations are allowed.

A function

A rule with a domain; all function codomains in this workshop are ℝ. Equal values on a shared set do not make functions with different domains equal. Restriction and extension are mathematical operations too.

A solution set

The inputs satisfying an equation together with its domain conditions. A one-way implication can produce candidates that fail the original equation.

For every transformation, ask: What is allowed before? What is allowed after? Is the step reversible under those conditions?

Investigation 01

Cancel a factor, keep the hole

The condition survives the calculation

When x≠a, factor x²−a²=(x−a)(x+a) and divide by the nonzero factor. Thus fₐ(x)=x+a for every x in Dₐ. In function notation, fₐ=gₐ restricted to Dₐ. The full functions have different domains.

To solve fₐ(x)=b, the only candidate is x=b−a. It is admissible precisely when b−a≠a, or b≠2a. Therefore the original solution set is {b−a} if b≠2a and is empty if b=2a.

The limit as x approaches a is 2a, even though fₐ(a) has no value. The extension gₐ supplies that value. A different assigned value at a would define a function on ℝ, but continuity at a would require that value to equal 2a.

Investigation 02

Squaring is an implication until you restore the sign

(x−a)2=b

All parameters and inputs here are real. The square root is the nonnegative principal root, so its left side is |x−a|.

Predict: square both sides to obtain (x−a)²=b². Is every solution of that equation also a solution of the original? Test a negative b before deciding.

Keep the implication and its converse separate

If the original equation holds, squaring gives (x−a)²=b². Conversely, a squared candidate satisfies |x−a|=|b|, which equals b exactly when b≥0. The reversible statement is therefore

√((x−a)²)=b   ⇔   (x−a)²=b² and b≥0.

For b<0 there are no original solutions. For b=0 there is one, x=a. For b>0 there are two, x=a−b and x=a+b. The squared equation always has a±|b|, with the two candidates coinciding when b=0. Check candidates against the original equation and its sign condition.

Investigation 03

A logarithm rewrite can discard valid inputs

Use the real natural logarithm, defined for positive arguments. Compare Lₐ(x)=log((x−a)²) with the tempting rewrite Nₐ(x)=2log(x−a).

Predict: when x<a, the squared argument is positive. Is the rewritten logarithm still real? What absolute value restores the missing inputs?

Shown: a=1, probe x=0.

Apply the logarithm law to a positive quantity

(x−a)² is positive exactly when x≠a. On that domain, set u=|x−a|>0. The positive-argument logarithm law gives log(u²)=2log u, hence

log((x−a)2)=2log|x−a|,x≠a

The original and repaired functions have the same domain and values. The naive expression is their restriction to x>a. At x=a, none of the three real logarithms is defined; an absolute value does not fix a zero argument.

Independent practice

Change the givens, keep the conditions

Write an attempt before revealing a hint or explanation. Your writing is stored separately from the exact probe calculations and is not automatically proof-checked.

1. A factor disappears from the formula

Let F(x)=(x²−9)/(x−3) on its original real domain. Solve F(x)=6 and F(x)=7. Explain why the same cancellation produces different admissibility outcomes.

Hint

Record x≠3 before factoring. Test the unique candidate for each equation.

Worked explanation

On x≠3, F(x)=x+3. For right side 6 the only candidate is x=3, which is excluded, so there is no solution. For right side 7 the candidate x=4 is admissible and solves the original equation. Cancellation preserves the recorded restriction in both cases.

2. An extension needs the right value

Keep F from Task 1 and define H on all real inputs by H(x)=F(x) for x≠3 and H(3)=k. For which real k is H continuous at 3? Is any value of k part of the original function F?

Hint

The limit concerns nearby inputs; continuity compares that limit with the newly assigned value.

Worked explanation

The limit of F(x)=x+3 as x approaches 3 is 6. H is continuous there exactly when k=6. Every k gives an extension to a larger domain, but only this value gives a continuous extension. F itself has no value at 3, regardless of which extension is chosen.

3. Square an impossible equation

Solve √((x+2)²)=−3. Then solve the equation obtained by squaring both sides. Identify exactly which implication fails in reversing that step.

Hint

The original left side is nonnegative. Substitute each squared candidate into that original side.

Worked explanation

The original has no real solutions. Squaring gives (x+2)²=9 and candidates x=1 and x=−5. Both give original left side 3, which is not −3. Original equality implies equality of squares, but equality of squares does not preserve the sign of the right side.

4. Change the equation, not just the constant

Classify all real solutions of √((x−a)²)=x−a for a fixed real a. Does the squared equation retain that solution set?

Hint

The right side now depends on x. Its nonnegativity is an input restriction.

Worked explanation

The original is |x−a|=x−a, which holds exactly when x≥a. Squaring gives the identity (x−a)²=(x−a)² for every real x, losing the restriction. Restoring x−a≥0 recovers precisely the original half-line. The constant-b classification is useful, but cannot be copied without noticing this changed dependence.

5. Repair a logarithm identity

Compare P(x)=log((2x−3)²) and Q(x)=2log(2x−3) as real functions. Give both domains and a formula on P's full domain that matches its values.

Hint

A nonzero real has a positive square, but need not itself be positive.

Worked explanation

P has domain ℝ∖{3/2}; Q has domain (3/2,∞). The formula 2log|2x−3| agrees with P on every allowed input. Q is a restriction of P to the positive-argument half-line, not the same full real function.

6. A plausible repair that still changes the domain

A learner replaces log(u)+log(v) with log(uv) for real u,v. Classify the original and rewritten domains in ℝ². Is the formula a valid equality on the original domain? Are they the same functions on their natural real domains?

Hint

Compare “both positive” with “product positive.” Test u=v=−1.

Worked explanation

The original domain is u>0 and v>0. The rewritten domain is uv>0, which also includes both-negative pairs. The positive logarithm law proves equal values throughout the original domain. They are not the same functions on their natural real domains, since the rewritten function additionally has value log 1=0 at (−1,−1), where the original real logarithms are not defined.

Use the same habit in larger mathematics

Before a symbolic rewrite, write the domain and the direction of implication. After it, return to the original question. The same discipline appears in parameter-dependent linear systems, inverse maps, improper integrals, and homotopies that must remain in a target.
