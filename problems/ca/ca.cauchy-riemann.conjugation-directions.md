# Compare directions for conjugation

*Medium · [Complex analysis problems](index.md)*

For $f(z)=\overline z$, which of the points $z_1=0$, $z_2=1$, $z_3=i$ admit a complex derivative? Enter the corresponding indices, using $\{\}$ if none.

<details>
<summary>Hint 1</summary>

The difference quotient for conjugation depends only on the increment, not the base point.

</details>

<details>
<summary>Hint 2</summary>

Compare a real increment with a purely imaginary increment.

</details>

<details>
<summary>Worked solution</summary>

Two approach directions give incompatible derivative values at every point.

1. The quotient is $\overline h/h$ for any base point and any $h\ne0$.
2. Along real increments it equals $1$, while along purely imaginary increments it equals $-1$.
3. No common limit exists at any listed point. The index set is empty.

</details>
