# Calculate the derivative quotient of a constant

*Easy · [Calculus](index.md)*

Let $f(x)=4$ for all real x. For any a and nonzero h, evaluate \[f(a+h)−f(a)\]/h.

<details>
<summary>Worked solution</summary>

A constant function has no change over any interval.

1. Both f(a+h) and f(a) equal 4.
2. The numerator is therefore zero.
3. For h≠0 the quotient is zero.

</details>
