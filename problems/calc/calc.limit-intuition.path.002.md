# One-sided limit intuition: one sided mismatch

*Easy · [Calculus](index.md)*

For $x<0$ let $f(x)=2$; for $x>0$ let $f(x)=5$; let $f(0)=9$. Which statement is correct? Select the mathematically correct statement from the four alternatives.

**Options**

1. The two-sided limit is $9$.
2. There is no two-sided limit because the left and right limits are $2$ and $5$.
3. The two-sided limit is $7/2$.
4. The left limit is $5$ and the right limit is 2, so no two-sided limit exists.
