# An exact fractional polynomial limit

*Easy · [Calculus](index.md)*

Find lim as x tends to $1/2$ of $(3x^{2} + 2x - 4)$. You may use the fact that a polynomial is continuous at every real input, so its limit there equals its value there. Give an exact answer.

For a polynomial, continuity justifies direct substitution. This reasoning would need reconsideration for a formula undefined at the approach input.

1. Continuity gives the limit by substituting $x = 1/2$.
2. $3$($1/2$)² + $2$($1/2$) − $4 = 3/4 + 1 - 4 = -9/4$.
