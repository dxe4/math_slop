# Name convergence without absolute convergence

*Easy · [Calculus](index.md)*

A real series Σa\_n converges but $\sum|a_n|$ diverges. Return its classification as {absolute}, {conditional} or {divergent}.

<details>
<summary>Worked solution</summary>

The ordinary and absolute series are different objects.

1. The original series is convergent, so it is not classified as divergent.
2. Its absolute series diverges, so its convergence is not absolute.
3. The classification is {conditional}.
