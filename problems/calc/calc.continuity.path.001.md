# Continuity at a point: fill removable value

*Easy · [Calculus](index.md)*

For $x\neq 2$ let $f(x)=(x^{2}-4)/(x-2)$, and set $f(2)=k$. Which value of k makes f continuous at $2$? You may use the identity $(x^{2}-4)/(x-2)=x+2$ for $x\neq 2$.
