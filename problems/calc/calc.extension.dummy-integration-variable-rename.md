# Recognize a dummy variable change

*Easy · [Calculus](index.md)*

Given $\int_0^1t^2\,dt=1/3$, find ∫₀¹u²du. Only the bound variable’s name changes.

<details>
<summary>Worked solution</summary>

A bound integration symbol is a dummy name.

1. Both integrals use the same square rule on \[0,1\].
2. Renaming t to u changes no input values or differential scaling.
3. Thus the integral remains 1/3.
