# Use the tangent derivative at the origin

*Easy · [Calculus](index.md)*

In radians, find the derivative of tan x at x=0, using $(\tan x)'=\sec^2x$.

<details>
<summary>Worked solution</summary>

The tangent derivative is a squared secant.

1. At zero cos 0=1, so sec 0=1.
2. The derivative is sec²0.
3. Its value is 1.
