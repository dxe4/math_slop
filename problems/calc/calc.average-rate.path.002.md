# Average rate of change: table velocity

*Easy · [Calculus](index.md)*

A table gives position $7$ m at $2$ s and $-2$ m at $5$ s. Find the signed average velocity over this interval.

<summary>Worked solution</summary>

Elapsed time is $3$ s, so average velocity is −9/3=−3 $m/s$. The negative sign describes net direction.

1. Position change is −2−7=−9 m.
2. Elapsed time is $3$ s, so average velocity is −9/3=−3 $m/s$. The negative sign describes net direction.
