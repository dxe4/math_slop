# Exponential and logarithmic derivatives: match log rule and domain

*Medium · [Calculus](index.md)*

For real $f(x)=\ln (x-2)$, choose the correct derivative and domain. Select the mathematically correct statement from the four alternatives.

**Options**

1. $f^{\prime}(x)=1/x$ for $x>0$.
2. $f^{\prime}(x)=1/(x-2)$ for $x>2$.
3. $f^{\prime}(x)=1/(x-2)$ for all $x\neq 2$.
4. The derivative is $\ln (x-2)/(x-2)$ on $x>2$.
