# Integral substitution: return original variable and constant

*Medium · [Calculus](index.md)*

**Options**

1. $(x^{2}+1)^{2}/4+C$.
2. $(x^{2}+1)^{2}/2+C$.
3. $(x^{2}+1)^{2}+C$.
4. $(x^{2}+1)^{2}/8+C$, where C is an arbitrary real constant.
