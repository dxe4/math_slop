# Reverse an oriented work integral

*Easy · [Calculus](index.md)*

Along oriented C, $\int_CF\cdot dr=3$. Find the work along the same curve with its orientation reversed.

<details>
<summary>Worked solution</summary>

Oriented work changes sign under path reversal.

1. The reversed parametrization has opposite tangent differential.
2. Thus its work is the negative original work.
3. The result is −3.

</details>
