# Use the fundamental theorem at one point

*Easy · [Calculus](index.md)*

Let f be continuous near a, with f(a)=−3, and $F(x)=\int_0^x f(t)\,dt$. Assume f is integrable on the intervals involved. Find F′(a).

<details>
<summary>Worked solution</summary>

The fundamental theorem recovers the local integrand value.

1. The theorem gives F′(a)=f(a).
2. The supplied point value is −3.
3. Hence F′(a)=−3.
