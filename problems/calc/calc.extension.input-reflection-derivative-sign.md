# Account for reflection of the input axis

*Easy · [Calculus](index.md)*

Let $g(x)=f(-x)$ and f′(0)=5. Find g′(0).

<summary>Hint 2</summary>

The reflected point at x=0 is still zero.

<details>
<summary>Worked solution</summary>

Input reflection reverses the derivative sign.

1. The chain rule gives g′(x)=−f′(−x).
2. At zero this is −f′(0).
3. Thus g′(0)=−5.

</details>
