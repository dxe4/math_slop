# Differentiate a constant scalar field

*Easy · [Calculus](index.md)*

For the constant field f(x,y)=7, return $\nabla f$.

<details>
<summary>Worked solution</summary>

A constant scalar field has zero differential in every direction.

1. The x partial derivative is zero.
2. The y partial derivative is zero.
3. The gradient is \[0,0\].

</details>
