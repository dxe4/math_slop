# Antiderivative families: recognize arbitrary constant

*Medium · [Calculus](index.md)*

Which describes every antiderivative of $4x^{3}$ on the real line? Select the mathematically correct statement from the four alternatives.

**Options**

1. $x^{4}$ only.
2. $x^{4}+C$, for arbitrary real C.
3. $4x^{4}+C$, for arbitrary real C.
4. x⁴+Cx, for arbitrary real C.
