# Algebraic limits: cancel then limit

*Medium · [Calculus](index.md)*

Find the limit of $(x^{2}-36)/(x-6)$ as x tends to $6$. The quotient is undefined at $6$.

<summary>Worked solution</summary>

For $x\neq 6$ the quotient equals x+6, so its limit is $12$. Cancellation does not define the original quotient at $6$.
