# One-sided limit intuition: table evidence scope

*Easy · [Calculus](index.md)*

A finite table near $x=1$ lists $(0.9,1.9), (0.99,1.99), (1.01,2.01), (1.1,2.1)$, with no rule supplied. Which claim is justified? Select the mathematically correct statement from the four alternatives.

**Options**

1. The values suggest limit $2$, but the table alone does not prove it.
2. The table proves the limit is $2$.
3. The value at $x=1$ must be $2$.
4. The limit must be $1$ because the input approaches $1$.
