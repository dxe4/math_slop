# Use right endpoints while retaining signed contributions

*Medium · [Calculus](index.md)*

For $f(x)=2x-1$ on \[-1,2\], use three equal subintervals and right endpoints. Find the signed Riemann sum.

<details>
<summary>Worked solution</summary>

Endpoint selection and signs both affect the finite approximation.

1. The subinterval width is one and the right endpoints are zero, one and two.
2. The corresponding function values are negative one, one and three.
3. Their signed sum times the common width is three.
