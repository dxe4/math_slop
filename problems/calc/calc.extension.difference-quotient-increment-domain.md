# State the increment excluded from a difference quotient

*Easy · [Calculus](index.md)*

In the derivative quotient $[f(a+h)-f(a)]/h$, which real increment is always excluded before taking the limit h→0? Return a set.

<details>
<summary>Worked solution</summary>

The derivative limit uses nonzero increments approaching zero.

1. The denominator is h.
2. Division is undefined when h=0.
3. Thus the always-excluded increment set is {0}.
