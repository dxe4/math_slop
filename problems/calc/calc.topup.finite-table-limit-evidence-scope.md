# Interpret numerical evidence without claiming a proof

*Medium · [Calculus](index.md)*

A finite table at several inputs near $x=1$ shows outputs close to 4. Which conclusion follows from that table alone? Choices: It suggests a possible limit 4 but does not establish behavior at every sufficiently near input.; It proves the limit is 4 for any function agreeing with the table.; It proves the function value at 1 must be 4.; It proves continuity at 1 even if the central function value is unspecified.

**Options**

1. It suggests a possible limit 4 but does not establish behavior at every sufficiently near input.
2. It proves the limit is 4 for any function agreeing with the table.
3. It proves the function value at 1 must be 4.
4. It proves continuity at 1 even if the central function value is unspecified.

<details>
<summary>Worked solution</summary>

Finite samples can suggest but cannot alone certify a local universal claim.

1. The table constrains the function at only finitely many sampled inputs.
2. A different function can agree there and behave differently at other arbitrarily nearby inputs.
3. Thus limit four is a possible interpretation to investigate, but neither the limit nor the central value is established by the table alone.

</details>
