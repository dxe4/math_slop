# Trigonometric derivatives: recognize radian requirement

*Medium · [Calculus](index.md)*

Which derivative statement correctly accounts for angle units? Select the mathematically correct statement from the four alternatives.

**Options**

1. For a radian variable $x, d(\sin  x)/dx$=cos x; a degree variable θ has an extra $\pi /180$ factor.
2. Both conventions have derivative cos of the angle with no factor.
3. The radian derivative is −sin x.
4. The radian derivative has the factor $\pi /180$, whereas the degree derivative has no scale factor.

<summary>Worked solution</summary>

Differentiating $\sin ((\pi /180)\theta )$ introduces $\pi /180$ by the chain rule, so A states both conventions correctly.

1. A degree input corresponds to radian input $(\pi /180)$θ.
2. Differentiating $\sin((\pi/180)\theta)$ introduces $\pi/180$ by the chain rule. The radian derivative has no such conversion factor.
