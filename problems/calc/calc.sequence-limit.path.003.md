# Sequence convergence bridge: recognize nonconvergent oscillation

*Easy · [Calculus](index.md)*

For $a_{n}=(-1)^n$ with positive integer n, choose the correct statement. Select the mathematically correct statement from the four alternatives.

**Options**

1. It converges to $0$ because the signs cancel.
2. It converges to $1$.
3. It has no finite limit because its even and odd subsequences have different limits.
4. It converges to $1$ or −1 according only to the parity of its first index.

<details>
<summary>Worked solution</summary>

A convergent sequence would force both subsequences to have the same limit; these do not, so C is correct.

1. Even-indexed terms equal $1$, while odd-indexed terms equal $-1$.
2. A convergent sequence would force both subsequences to have the same limit. Their different limits rule out a finite limit for the full sequence.
