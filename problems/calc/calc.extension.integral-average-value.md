# Normalize an integral by interval length

*Easy · [Calculus](index.md)*

If $\int_1^4 f(x)\,dx=12$, find the average value of f on \[1,4\].

<details>
<summary>Hint 1</summary>

Average value is integral divided by interval length.

</details>

<details>
<summary>Hint 2</summary>

Use 4−1, not the upper endpoint alone.

</details>

<details>
<summary>Worked solution</summary>

The average is the constant height with the same signed integral.

1. The interval length is 3.
2. The average is 12/3.
3. Thus the average value is 4.

</details>
