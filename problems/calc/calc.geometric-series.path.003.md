# Geometric partial sums and series: reject invalid infinite sum formula

*Easy · [Calculus](index.md)*

Consider $2-2+2-2$+⋯ as an ordinary infinite series. Which conclusion is correct? Select the mathematically correct statement from the four alternatives.

**Options**

1. Sum $1$ by $a/(1-r)$.
2. Sum $0$ because adjacent pairs cancel.
3. The partial sums alternate between $2$ and 0, so there is no ordinary sum.
4. It converges to $2$ because its first partial sum is $2$.

<summary>Worked solution</summary>

The formula $a/(1-r)$ requires $|r|<1$ and does not apply at r=−1, so C is correct.

1. Its partial sums are $2,0,2,0$,… and have no common limit.
2. The formula $a/(1-r)$ requires $|r|<1$ and does not apply at $r=-1$. The alternating partial sums give no ordinary infinite sum.
