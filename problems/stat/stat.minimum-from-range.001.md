# Recover a minimum below zero

*Easy · [Statistics and probability](index.md)*

A finite nonempty dataset has maximum $18$ and range $25$. Using range = maximum − minimum, find the minimum.

| Given summary | Value |
| --- | --- |
| Maximum | 18 |
| Range | 25 |

```answer
{"answer":{"kind":"integer","expected":-7,"checker_scope":"Exact numeric fields for the stated data. This check does not assess a written justification or a population inference."}}
```

<details>
<summary>Hint 1</summary>

The minimum lies one full range below the maximum.

</details>

<details>
<summary>Hint 2</summary>

Solve $18$ − minimum = 25, or subtract $25$ from the maximum.

</details>

<details>
<summary>Worked solution</summary>

A range can be larger than the maximum when the minimum is negative.

1. The equation $18$ − minimum = $25$ describes the given range.
2. Thus minimum = $18 - 25 = -7$. Check: $18 - (-7) = 25$.

</details>
