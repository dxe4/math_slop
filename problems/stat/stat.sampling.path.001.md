# Recognize a simple random sample

*Easy · [Statistics and probability](index.md)*

A complete list contains $200$ households. An algorithm selects $20$ distinct households so that every $20$-household subset has equal probability. Which description applies? Select the mathematically correct statement from the four alternatives.

**Options**

1. A simple random sample of $20$ households from the listed population.
2. A voluntary-response sample because households have labels.
3. A census of all $200$ households.
4. A stratified sample because the household labels automatically define strata.

<details>
<summary>Worked solution</summary>

The sampling design is defined by the selection probabilities.

1. The algorithm gives every subset of size $20$ the same selection probability.
2. That is the stated definition of a simple random sample; only $20$ of $200$ households are selected.
