# One step forecast error

*Easy · [Statistics and probability](index.md)*

A forecast is $\widehat x=7$ and the realized value is $x=5$. With forecast error defined as $e=x-\widehat x$, what is the error?


<details>
<summary>Hint 1</summary>

Use the stated order rather than the opposite sign convention.

</details>

<details>
<summary>Hint 2</summary>

Compare the realized value with the forecast to decide whether the error should be positive or negative.

</details>

<details>
<summary>Worked solution</summary>

Forecast error is a signed observed-minus-predicted difference.

1. The definition gives $e=5-7$.
2. Hence $e=-2$.
3. The negative sign records that the forecast exceeded the realization by $2$. The absolute error would be $2$ and the squared error $4$, different requested quantities.

</details>
