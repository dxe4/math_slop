# Recover a maximum from a range

*Easy · [Statistics and probability](index.md)*

A finite nonempty dataset has minimum $4$ and range $13$. Using range = maximum − minimum, find the maximum.

| Given summary | Value |
| --- | --- |
| Minimum | 4 |
| Range | 13 |

```answer
{"answer":{"kind":"integer","expected":17,"checker_scope":"Exact numeric fields for the stated data. This check does not assess a written justification or a population inference."}}
```

<details>
<summary>Hint 1</summary>

The maximum lies one full range above the minimum.

</details>

<details>
<summary>Hint 2</summary>

Rearrange maximum − $4 = 13$.

</details>

<details>
<summary>Worked solution</summary>

The range formula can be used in reverse when one extreme is unknown.

1. Write maximum − $4 = 13$ from the stated range formula.
2. Adding $4$ gives maximum = $17$; checking $17 - 4$ recovers the given range $13$.

</details>
