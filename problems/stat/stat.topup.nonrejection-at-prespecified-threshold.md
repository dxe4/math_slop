# Apply a test decision without proving the null

*Medium · [Statistics and probability](index.md)*

A prespecified valid test reports $p=0.08$ and uses alpha=0.05, rejecting exactly when p&lt;=alpha. Which statement follows? Choices: Do not reject at this threshold; this does not prove the null true.; The null has probability 0.08.; Reject because the probability of a real effect is 0.92.; Nonrejection proves that any true effect is too small to matter in practice.

**Options**

1. Do not reject at this threshold; this does not prove the null true.
2. The null has probability 0.08.
3. Reject because the probability of a real effect is 0.92.
4. Nonrejection proves that any true effect is too small to matter in practice.

<details>
<summary>Worked solution</summary>

Nonrejection is a threshold decision with limited interpretation.

1. The reported p-value is larger than five hundredths.
2. The stipulated rejection condition therefore fails, so this test does not reject.
3. That result neither proves the null nor assigns either hypothesis a probability from the p-value alone.
