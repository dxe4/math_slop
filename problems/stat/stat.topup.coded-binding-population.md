# Separate population, sample and coded category

*Medium · [Statistics and probability](index.md)*

A library has $2000$ books and samples $80$ by simple random sampling. Binding type is coded 1=paperback, 2=hardback, 3=other. Which description is correct? Choices: Population 2000 books, sample 80 books, binding type categorical.; Population 80 books, sample 2000 books, binding type quantitative.; The integer codes make average binding type a physical measurement.; Binding type is quantitative because it has only three possible codes.

**Options**

1. Population 2000 books, sample 80 books, binding type categorical.
2. Population 80 books, sample 2000 books, binding type quantitative.
3. The integer codes make average binding type a physical measurement.
4. Binding type is quantitative because it has only three possible codes.

<details>
<summary>Worked solution</summary>

Interpret the meaning of a variable rather than the appearance of its encoding.

1. All two thousand library books form the stated population.
2. The eighty drawn books form the sample.
3. The three codes label binding categories, so binding type remains categorical.

</details>
