# Separate an average from a guaranteed outcome

*Medium · [Statistics and probability](index.md)*

A variable is $0$ or $4$, each with probability 1/2, so its expectation is $2$. Which statement is correct? Select the mathematically correct statement from the four alternatives.

**Options**

1. The expected value is $2$ even though every single trial is $0$ or $4$.
2. Every trial equals $2$ because its expected value is $2$.
3. The probability of $4$ is $2$.
4. The probability of the outcome $2$ is $1/2$.

<details>
<summary>Hint 1</summary>

A weighted average can lie between possible outcomes.

</details>

<details>
<summary>Hint 2</summary>

A probability must lie between zero and one.

</details>

<details>
<summary>Worked solution</summary>

Expectation is a model summary, not a promise about one result.

1. The weighted average is $0$($1/2$)+$4$($1/2$)=$2$.
2. Neither possible outcome equals $2$; the statement “The expected value is $2$ even though every single trial is $0$ or $4$.” correctly separates the expectation from a single trial.

</details>
