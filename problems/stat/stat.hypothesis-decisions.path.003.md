# Recognize an unaccounted search over tests

*Medium · [Statistics and probability](index.md)*

An analyst tries ten different tests, chooses the smallest p-value afterward, and reports it as a single prespecified $5$% test without any adjustment or selection model. Which assessment is appropriate? Select the mathematically correct statement from the four alternatives.

**Options**

1. The single-test $5$% error claim is not justified by this search procedure; selection must be accounted for.
2. Trying more tests guarantees the reported claim is more reliable at the same unadjusted error level.
3. The smallest p-value is automatically the probability every null is false.
4. No adjustment is needed when all ten tests use the same data.

<details>
<summary>Worked solution</summary>

Error interpretation must match the procedure that actually produced the report.

1. The actual procedure includes searching over ten tests and selecting a minimum.
2. A single prespecified-test error argument does not justify that different procedure; the statement “The single-test $5$% error claim is not justified by this search procedure; selection must be accounted for.” identifies the missing control.
