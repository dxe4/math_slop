# Distinguish the target group from observed cases

*Easy · [Statistics and probability](index.md)*

A librarian wants to describe the condition of all $2000$ books in one library and inspects $50$ of those books. Which pair correctly identifies population and sample? Select the mathematically correct statement from the four alternatives.

**Options**

1. Population: the $50$ inspected books; sample: all $2000$ books.
2. Population: every library in the country; sample: this library.
3. Population: all $2000$ books in this library; sample: the $50$ inspected books.
4. Population: all $2000$ books; sample: the $1950$ uninspected books.

<details>
<summary>Worked solution</summary>

A population follows the research question, while a sample follows the observations.

1. The question concerns all $2000$ books in the named library, so that is the population.
2. Only $50$ books were inspected, so those $50$ form the sample; the statement “Population: all $2000$ books in this library; sample: the $50$ inspected books.” is correct.
