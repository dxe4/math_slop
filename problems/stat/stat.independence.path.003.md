# Use independence to constrain a joint probability

*Easy · [Statistics and probability](index.md)*

Events A and B are stated to be independent, with $P(A)=1/2$ and $P(B)=1/2$. Find $P(A\cap B)$.

| Given information | Value |
| --- | --- |
| P A | 1/2 |
| P B | 1/2 |
| independent | true |

A model assumption can determine a joint probability from its marginals.

1. Independence gives $P(A\cap B)=P$(A)P(B).
2. The value is($1/2$)$(1/2)=1/4$.
