# Recover an extreme using the range

*Easy · [Statistics and probability](index.md)*

A nonempty finite dataset has minimum−$2$ and range $7$. What is its maximum?

| Given information | Value |
| --- | --- |
| minimum | -2 |
| range | 7 |

<details>
<summary>Hint 1</summary>

The maximum is one range above the minimum.

</details>

<details>
<summary>Hint 2</summary>

Use maximum=minimum+range.

</details>

<details>
<summary>Worked solution</summary>

The range relation also constrains missing extreme values.

1. Write maximum−$(-2)=7$.
2. The maximum is−2+7=5.

</details>
