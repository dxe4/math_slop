# Transform an expectation

*Easy · [Statistics and probability](index.md)*

A finite random variable X has $E(X)=3$. Define $Y=X+4$. Using $E(X+c)=E(X)+c$, find E(Y).

Adding a constant translates the expectation by that constant.

1. $E(Y)=E(X+4)=E(X)+4$.
2. The value is $3+4=7$.
