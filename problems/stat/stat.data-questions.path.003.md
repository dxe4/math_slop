# Recognize a recorded category

*Easy · [Statistics and probability](index.md)*

For each student, a table records a student ID and the main travel mode, chosen from walk, cycle and bus. Which statement correctly identifies the travel-mode variable? Select the mathematically correct statement from the four alternatives.

**Options**

1. It is the number of letters in the student ID.
2. It is a categorical variable recorded for each student.
3. It is the complete population of all cities.
4. Travel mode is quantitative because its categories can be assigned numerical codes.

<details>
<summary>Worked solution</summary>

Named categories describe cases even when other columns contain numerical identifiers.

1. Each student is a case and has one travel-mode label.
2. Walk, cycle and bus are categories, so the statement “It is a categorical variable recorded for each student.” describes the variable correctly.

</details>
