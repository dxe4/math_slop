# Find a voluntary-response limitation

*Easy · [Statistics and probability](index.md)*

An open poll on a cycling enthusiasts’ forum asks whether every resident in a city wants more bicycle parking. Which limitation is most direct? Select the mathematically correct statement from the four alternatives.

**Options**

1. A large number of forum votes guarantees representation of all city residents.
2. The poll is a census because any forum visitor may answer.
3. Forum participation and choosing to answer may relate to cycling preferences, so the responses need not represent all residents.
4. Thirty or more votes would guarantee representation regardless of forum selection.

<details>
<summary>Worked solution</summary>

A response mechanism can favor particular views before any calculation occurs.

1. The respondents select themselves from a forum whose topic relates to the question.
2. The target includes all residents, so respondents may differ systematically from that target; the statement “Forum participation and choosing to answer may relate to cycling preferences, so the responses need not represent all residents.” identifies this limitation.
