# Read a travel frequency table

*Easy · [Statistics and probability](index.md)*

Eighteen students each report one main way of traveling to school: $6$ walk, $3$ cycle and $9$ take a bus. What proportion of these students cycle? Give an exact fraction.

| Main travel mode | Count |
| --- | --- |
| Walk | 6 |
| Cycle | 3 |
| Bus | 9 |

<details>
<summary>Worked solution</summary>

The relevant denominator is the number of cases in the specified group.

1. The counts sum to $6 + 3 + 9 = 18$ students.
2. Three cycle, giving the proportion $3/18 = 1/6$.
