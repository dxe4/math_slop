# Distinguish assignment from population selection

*Medium · [Statistics and probability](index.md)*

Forty volunteers are randomly assigned to two study routines. Implementation is sound, there is no interference, and outcomes are measured comparably. Which claim is best supported by this design? Select the mathematically correct statement from the four alternatives.

**Options**

1. The volunteers are automatically a representative sample of all students.
2. The design supports a causal routine comparison for the participating study conditions, while population generalization needs additional justification.
3. Random assignment guarantees the routines have identical outcomes.
4. Random assignment eliminates every possible measurement error.

<details>
<summary>Worked solution</summary>

A design feature supports a particular kind of claim rather than every kind.

1. Random assignment addresses systematic treatment-group differences at allocation.
2. It supports the specified causal comparison but does not describe population sampling; the statement “The design supports a causal routine comparison for the participating study conditions, while population generalization needs additional justification.” keeps these scopes separate.
