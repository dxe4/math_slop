# Interpret failure to reject

*Medium · [Statistics and probability](index.md)*

A prespecified valid test has $p=0.20$ and $\alpha =0.05$. Which statement is justified? Select the mathematically correct statement from the four alternatives.

**Options**

1. The null is proved true.
2. The probability of an effect is exactly $80$%.
3. Fail to reject at this threshold; this does not prove that the null is true.
4. There is exactly a $20$% probability that the null is false.

<details>
<summary>Hint 1</summary>

The p-value exceeds the threshold.

</details>

<details>
<summary>Hint 2</summary>

Failure to cross a threshold is not the same as proving a model.

</details>

<details>
<summary>Worked solution</summary>

Nonrejection can reflect limited information as well as compatibility with a null model.

1. Since $0.20>0.05$, the stated rule fails to reject.
2. Neither the null’s truth nor the probability of an effect follows from that p-value; the statement “Fail to reject at this threshold; this does not prove that the null is true.” states the proper limit.

</details>
