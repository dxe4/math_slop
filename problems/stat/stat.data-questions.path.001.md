# Name the case and its recorded measurement

*Easy · [Statistics and probability](index.md)*

At noon, a survey records one temperature reading for each of $12$ weather stations. Which description matches one case and the variable? Select the mathematically correct statement from the four alternatives.

**Options**

1. Case: a weather station; variable: its noon temperature.
2. Case: the temperature unit; variable: the station count.
3. Case: the survey’s mean; variable: noon.
4. Case: the time noon; variable: the number of stations.

<details>
<summary>Worked solution</summary>

Cases are the entities observed; variables describe them.

1. Each station supplies one record, so a station is a case.
2. The property recorded for a station is its noon temperature; the statement “Case: a weather station; variable: its noon temperature.” matches both roles.
