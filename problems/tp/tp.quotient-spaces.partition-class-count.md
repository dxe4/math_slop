# Count quotient classes

*Easy · [Topology problems](index.md)*

An equivalence relation on $X=\{1,2,3,4,5\}$ has classes $\{1,2\}$, $\{3\}$ and $\{4,5\}$. How many points does the quotient set have?

```answer
{"answer":{"kind":"integer","expected":3,"checker_scope":"Exact finite set, interval, distance or count requested in the stated topology only; personal reasoning is not automatically graded."}}
```

<details>
<summary>Hint 1</summary>

A quotient point is an entire equivalence class.

</details>

<details>
<summary>Hint 2</summary>

Do not count original points separately inside a class.

</details>

<details>
<summary>Worked solution</summary>

Quotient-set cardinality is the number of distinct equivalence classes.

1. The displayed classes are disjoint and cover the original set.
2. Each class becomes exactly one quotient point.
3. There are $3$ quotient points.

</details>
