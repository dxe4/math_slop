# Use the Wang sequence for a unipotent torus bundle

*Medium · [Topology problems](index.md)*

Let Y be the mapping torus of the torus automorphism $A=\begin{pmatrix}1&1\\0&1\end{pmatrix}$. Return \[rank H₁(Y;Z), rank H₂(Y;Z), rank H₃(Y;Z)\]. You may use the Wang short exact sequences $0\to\operatorname{coker}(A_*-I\mid H_k(T^2))\to H_k(Y)\to\ker(A_*-I\mid H_{k-1}(T^2))\to0$.

<details>
<summary>Hint 1</summary>

On H₁ the matrix A−I has image generated by the first basis vector and a rank-one kernel.

</details>

<details>
<summary>Hint 2</summary>

On H₀ and H₂ the monodromy is the identity; the latter uses det A=1.

</details>

<details>
<summary>Worked solution</summary>

A torus bundle’s homology detects both fixed fiber classes and classes modulo monodromy differences.

1. On H₁(T²)=Z², A−I has matrix \[\[0,1\],\[0,0\]\], with kernel Z and cokernel Z, both torsion free. On H₀ and H₂, A\_\*−I is zero.
2. For k=1 the Wang sequence has outer terms Z and Z, so H₁ has rank 2. For k=2 it again has outer terms Z and Z, so H₂ has rank 2. These extensions split as abelian groups because the right-hand terms are free.
3. For k=3 the left term is zero and the right term is H₂(T²)=Z. Hence H₃=Z. The vector is \[2,2,1\].

</details>
