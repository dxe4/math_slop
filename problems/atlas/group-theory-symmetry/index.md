# Groups as symmetry and composition

Concrete group theory exercises using permutations, modular subgroups, square symmetries, orbits, and stabilizers.

**Objectives**

- Compute compositions with an explicit convention
- Recognize subgroups and cosets in modular examples
- Use orbit-stabilizer to count symmetries
