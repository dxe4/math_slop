# Information, coding, and optimization

Advanced applied exercises linking entropy and noisy channels to prefix codes, convex objectives, and linear programs.

**Objectives**

- Compute information quantities with logarithms base two
- Connect code lengths to source probabilities
- Certify optima using convexity or feasible vertices
