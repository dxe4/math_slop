# Linear algebra as structure

Exercises connecting elimination, basis, rank, coordinate change, projection, factorization, spectra, duality, forms, and tensors.

**Objectives**

- Interpret computations geometrically
- Move between matrix and transformation viewpoints
- Use subspaces to explain existence and uniqueness
- Audit spectral and numerical boundary cases
- Track transformation laws for maps, forms, and tensors
