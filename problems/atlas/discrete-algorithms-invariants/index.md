# Discrete algorithms and invariants

Exercises that connect algorithm traces and efficiency claims to the invariants that make them correct.

**Objectives**

- Trace algorithms with explicit state
- Identify an invariant that survives each iteration
- Separate correctness arguments from running-time estimates
