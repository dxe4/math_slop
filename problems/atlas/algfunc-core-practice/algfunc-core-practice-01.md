# Reading a function machine

*Difficulty 1 of 5 · [Algebra & Functions Core Practice](index.md) · exercise 1 of 12*

A function machine takes an input $x$ and outputs $2x+3$. What input produces the output $11$?

<details>
<summary>Hint 1</summary>

Set the rule equal to the desired output.

</details>

<details>
<summary>Hint 2</summary>

Solve $2x+3=11$ by subtracting $3$ and dividing by $2$.

</details>

<details>
<summary>Worked solution</summary>

We need the input $x$ such that $2x+3=11$. Subtract $3$ from both sides to obtain $2x=8$, then divide by $2$ to get $x=4$. Check: $2(4)+3=8+3=11$, so the answer is correct.

**Answer.** $x=4$

</details>
