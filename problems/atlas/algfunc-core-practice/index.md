# Algebra & Functions Core Practice

Twelve solved exercises spanning expressions, equations, functions, and sequences at the secondary-to-early-university level. Each item includes scaffolded hints and a fully worked solution.

**Objectives**

- Evaluate and invert simple function rules
- Expand, factor, and solve quadratic expressions while preserving conditions
- Manipulate absolute-value and rational conditions with domain awareness
- Describe transformations and compose functions with correct domain restriction
- Solve exponential equations exactly using logarithms
- Relate polynomial roots, multiplicities, and graph behavior
- Derive closed forms from recurrences and verify them inductively
