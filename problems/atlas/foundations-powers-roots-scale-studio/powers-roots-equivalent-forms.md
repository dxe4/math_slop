# Three forms, one value

*Difficulty 2 of 5 · [Powers, roots, and scale solved studio](index.md) · exercise 9 of 12*

Show that `16^(3/4)`, `(fourthroot(16))^3`, and `fourthroot(16^3)` have the same real value. Then explain why the same argument must not be copied unchanged to a negative base with an even root.

<details>
<summary>Hint 1</summary>

Evaluate the fourth root before cubing in the second form

</details>

<details>
<summary>Hint 2</summary>

An even real root requires a nonnegative radicand

</details>

<details>
<summary>Worked solution</summary>

Because the base 16 is positive, the rational-power definition permits either displayed order: `fourthroot(16)=2`, so `(fourthroot(16))^3=2^3=8`. Also `16^3=4096`, and `fourthroot(4096)=8` because `8^4=4096`. Therefore all three forms equal 8. Positivity is not decorative: for a negative base, the fourth root of the base is not a real number. Algebraic rewrites that pass through such an undefined intermediate expression are not valid real-number calculations, even if a later-looking expression seems familiar.

**Answer.** All three forms equal 8; the equivalence uses a positive base, whereas an even real root of a negative base is undefined.

</details>
