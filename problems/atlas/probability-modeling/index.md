# Probability modeling

Exercises emphasizing sample spaces, conditioning, independence, expectation, and careful interpretation.

**Objectives**

- Build a probability model before calculating
- Update sample spaces when conditioning
- Use expectation and limit claims with explicit hypotheses
- Analyze random evolution through exact recurrences, stopping, and coupling
