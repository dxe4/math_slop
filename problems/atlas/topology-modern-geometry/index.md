# Topology and modern geometry

Proof and computation exercises across point-set topology, coverings, homology, manifolds, curvature, symplectic structure, knots, and algebraic geometry.

**Objectives**

- State the hypotheses behind topological and geometric invariants
- Compute finite invariants with independent consistency checks
- Use counterexamples to mark the boundary of a theorem
- Distinguish point sets, smooth structures, metrics, and scheme structure
