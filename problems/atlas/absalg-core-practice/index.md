# Abstract Algebra Core Practice

A solved exercise set spanning rings, fields, modules, representation theory, and homological algebra. It mixes proof tasks, concrete computations in finite fields and character tables, and counterexample work to reinforce the structural viewpoint of modern algebra.

**Objectives**

- Apply ideal criteria and quotient theorems in commutative rings
- Use the tower law and minimal polynomials to control extension degrees
- Execute Sylow counting arguments to constrain finite group structure
- Prove polynomial irreducibility via Eisenstein and root tests
- Compute with finite fields, tensor products, and character tables
- Recognize when Noetherian and exactness hypotheses are essential
