# Number theory through divisibility

Solved problems in greatest common divisors, Bézout identities, modular powers, congruences, and integer equations.

**Objectives**

- Turn Euclidean divisions into a Bézout identity
- Use modular structure instead of large arithmetic
- Classify all integer solutions to a linear equation
