# Number theory and cryptography audit studio

Solved proofs and computations spanning gcds, congruences, arithmetic functions, Diophantine equations, number fields, prime distribution, curves, certificates, and security definitions.

**Objectives**

- Prove divisibility and congruence claims with every gcd condition visible
- Connect exact arithmetic computations to algebraic, analytic, and geometric structure
- Distinguish theorem, certificate, heuristic, conjecture, and open problem
- Separate cryptographic correctness from a named adversarial security property
