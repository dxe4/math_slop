# Algebra and functions from first principles

Beginner practice in substitution, equations, inequalities, and the order-sensitive composition of functions.

**Objectives**

- Substitute signed values without losing parentheses
- Preserve equivalence while solving equations and inequalities
- Evaluate composed functions in the correct order
