# Substitution with negative inputs

*Difficulty 1 of 5 · [Algebra and functions from first principles](index.md) · exercise 1 of 4*

Evaluate $2x^2 - 3xy + y$ when $x = -2$ and $y = 3$. Show how parentheses prevent the most common sign error.

<details>
<summary>Hint 1</summary>

Write $2(-2)^2 - 3(-2)(3) + 3$

</details>

<details>
<summary>Hint 2</summary>

Square $-2$ before multiplying by $2$

</details>

<details>
<summary>Worked solution</summary>

Substitution with parentheses gives $2(-2)^2 - 3(-2)(3) + 3$. Now $(-2)^2 = 4$, so the first term is $8$. Also $-3(-2)(3) = 18$. Therefore the value is $8 + 18 + 3 = 29$. Writing $-2^2$ without parentheses can be misread as $-(2^2)$, which is $-4$ rather than $4$.

**Answer.** $29$.

</details>
