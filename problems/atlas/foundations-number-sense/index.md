# Number sense in everyday quantities

Beginner exercises that connect arithmetic, fractions, percentages, rates, estimation, and reasonableness checks.

**Objectives**

- Estimate before computing an exact value
- Interpret fractions and percentages as multiplicative relationships
- Keep units attached to rate calculations
