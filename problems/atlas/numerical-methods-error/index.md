# Numerical methods with error awareness

Computational exercises in bracketing, time stepping, quadrature, and interpolation with qualitative error checks.

**Objectives**

- Carry a numerical algorithm through explicit iterations
- Report an approximation together with an error statement
- Use curvature and stability to predict error direction
