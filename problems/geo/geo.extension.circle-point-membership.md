# Identify a point on a circle

*Easy · [Geometry and trigonometry problems](index.md)*

Which point lies on $x^2+y^2=25$? Options: p: $(3,4)$; q: $(3,5)$; r: $(4,4)$; s: $(0,4)$. Enter p, q, r or s.

**Options**

1. (3,4)
2. (3,5)
3. (4,4)
4. (0,4)

<details>
<summary>Worked solution</summary>

Check the defining equation.

1. For p, $3^2+4^2=9+16=25$.
2. The values for q, r, s are respectively $34,32,16$.
3. Only p satisfies the circle equation.
