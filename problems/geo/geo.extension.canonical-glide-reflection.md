# Evaluate a glide reflection formula

*Easy · [Geometry and trigonometry problems](index.md)*

A glide reflection is given by $G(x,y)=(x+5,-y)$, a reflection in the $x$-axis followed by a parallel translation. Find $G(2,3)$ as $[x,y]$.

<details>
<summary>Worked solution</summary>

Evaluate the supplied glide-reflection rule.

1. Substitute $x=2,y=3$.
2. The first coordinate is $2+5=7$.
3. The second is $-3$, so the result is $[7,-3]$.
