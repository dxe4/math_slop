# Use perpendicular height in an oblique cylinder

*Medium · [Geometry and trigonometry problems](index.md)*

An oblique circular cylinder has congruent horizontal disk bases of radius $2$. The perpendicular distance between base planes is $9$, while a slanted generator has length $15$. By Cavalieri’s principle its volume is base area times perpendicular height. Write the volume as $q\pi$ and find $q$.

<details>
<summary>Hint 1</summary>

The generator length does not measure perpendicular height.

</details>

<details>
<summary>Hint 2</summary>

Each horizontal section has the base area $4\pi$.

</details>

<details>
<summary>Worked solution</summary>

Use the supplied section-volume principle.

1. The base area is $\pi\cdot2^2=4\pi$.
2. The perpendicular height is $9$, not the slanted length $15$.
3. Therefore $V=4\pi\cdot9=36\pi$, so $q=36$.

</details>
