# Measure a pyramid using perpendicular height

*Easy · [Geometry and trigonometry problems](index.md)*

A pyramid has base area $36$ and perpendicular height $9$. Using $V=Bh/3$, find its volume.

<details>
<summary>Worked solution</summary>

Use the pyramid volume formula.

1. Substitute $B=36$ and $h=9$.
2. The product $Bh$ is $324$.
3. Thus $V=324/3=108$.
