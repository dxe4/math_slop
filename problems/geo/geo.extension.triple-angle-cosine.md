# Evaluate a triple-angle cosine

*Medium · [Geometry and trigonometry problems](index.md)*

For a real angle $\theta$, $\cos\theta=2/3$. Find $\cos3\theta$ as a rational number.

<details>
<summary>Hint 1</summary>

Use the triple-angle identity $\cos3\theta=4\cos^3\theta-3\cos\theta$.

</details>

<details>
<summary>Hint 2</summary>

Combine the cubic and linear terms with denominator $27$.

</details>

<details>
<summary>Worked solution</summary>

Evaluate the cubic cosine identity.

1. The triple-angle identity expresses $\cos3\theta$ using only the given cosine, so no sine or quadrant choice is needed.
2. The cubic term is $4(2/3)^3=32/27$.
3. The linear term is $3(2/3)=2=54/27$.
4. The difference is $-22/27$.

</details>
