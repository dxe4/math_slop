# Respect the principal arcsine range

*Easy · [Geometry and trigonometry problems](index.md)*

Write the principal value $\arcsin(-1/2)=q\pi$, where arcsine takes values in $[-\pi/2,\pi/2]$. Find the rational number $q$.

<details>
<summary>Hint 1</summary>

Sine is odd, and $\sin(\pi/6)=1/2$.

</details>

<details>
<summary>Hint 2</summary>

Choose the negative representative in the stated principal interval.

</details>

<details>
<summary>Worked solution</summary>

Use the specified inverse-function branch.

1. By oddness, $\sin(-\pi/6)=-1/2$.
2. The angle $-\pi/6$ lies in $[-\pi/2,\pi/2]$, where sine is one-to-one.
3. Thus the principal value is $-\pi/6$ and $q=-1/6$.

</details>
