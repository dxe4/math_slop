# Compute an ellipse eccentricity

*Easy · [Geometry and trigonometry problems](index.md)*

An ellipse has semimajor axis $a=5$ and center-to-focus distance $c=4$. Using eccentricity $e=c/a$, find $e$ as a rational number.

<details>
<summary>Worked solution</summary>

Apply the eccentricity definition.

1. The supplied values satisfy $0<c<a$, as required for this ellipse.
2. The ratio is $e=4/5$.
3. It lies strictly between zero and one, consistent with an ellipse.
