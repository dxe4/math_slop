# Read an ellipse horizontal extremum

*Easy · [Geometry and trigonometry problems](index.md)*

For the ellipse $(x-2)^2/25+(y+1)^2/9=1$, find the greatest possible $x$-coordinate.

<details>
<summary>Hint 1</summary>

The center has horizontal coordinate $2$.

</details>

<details>
<summary>Hint 2</summary>

The horizontal semiaxis has length $\sqrt{25}=5$.

</details>

<details>
<summary>Worked solution</summary>

Read the translated horizontal semiaxis.

1. Nonnegativity of the second term gives $(x-2)^2\le25$.
2. Hence $x\le2+5=7$.
3. This value is attained at $y=-1$, so the maximum is $7$.

</details>
