# Apply sine oddness

*Easy · [Geometry and trigonometry problems](index.md)*

For a real angle $\theta$, $\sin\theta=2/5$. Find $\sin(-\theta)$.

<details>
<summary>Hint 1</summary>

Reflection of a unit-circle point in the horizontal axis negates its sine coordinate.

</details>

<details>
<summary>Hint 2</summary>

Use $\sin(-\theta)=-\sin\theta$.

</details>

<details>
<summary>Worked solution</summary>

Apply the odd-function identity.

1. The identity holds for every real $\theta$.
2. Substitution gives $\sin(-\theta)=-(2/5)$.
3. The result is $-2/5$, with no quadrant assumption needed.

</details>
