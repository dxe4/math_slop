# Use a complementary cofunction

*Easy · [Geometry and trigonometry problems](index.md)*

$\sin\theta=3/7$ for a real angle $\theta$. Find $\cos(\pi/2-\theta)$.

<details>
<summary>Hint 1</summary>

The cofunction identity is valid for every real angle.

</details>

<details>
<summary>Hint 2</summary>

Use $\cos(\pi/2-\theta)=\sin\theta$.

</details>

<details>
<summary>Worked solution</summary>

Apply the complementary-angle identity.

1. The cosine difference identity gives $\cos(\pi/2-\theta)=0\cos\theta+1\sin\theta$.
2. This is exactly $\sin\theta$.
3. Hence the value is $3/7$.

</details>
