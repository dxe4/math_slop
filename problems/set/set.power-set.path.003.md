# The power set of no objects

*Easy · [Set theory](index.md)*

What is $P(\varnothing )$? The symbol $\varnothing$ denotes the empty set, and $0$ denotes the ordinary number zero. Select the mathematically correct statement from the four alternatives.

**Options**

1. $\varnothing$.
2. $\{\varnothing \}$.
3. $\{0\}$.
4. {$\varnothing ,\{\varnothing \}$}.

<summary>Hint 1</summary>

Ask which subsets the empty set has.

<details>
<summary>Hint 2</summary>

The empty set is a subset of itself, and there is no nonempty subset.

</details>

<details>
<summary>Worked solution</summary>

The power set collects subsets as objects, including the empty subset.

1. The only subset of $\varnothing$ is $\varnothing$ itself.
2. Therefore $P(\varnothing )=\{\varnothing \}, a$ one-member set. It is neither empty nor the singleton containing zero. Select the statement “$\{\varnothing \}$.”.

</details>
