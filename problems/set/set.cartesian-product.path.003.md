# A product needs both coordinates

*Easy · [Set theory](index.md)*

Let $A=\{a,b\}$ and $B=\varnothing$. Enter the Cartesian product $A\times B$ as a set.

<details>
<summary>Hint 1</summary>

An ordered pair in the product needs one entry from each factor.

</details>

<details>
<summary>Hint 2</summary>

Check whether a second coordinate can be chosen.

</details>

<details>
<summary>Worked solution</summary>

An empty factor makes a Cartesian product empty.

1. A pair in $A\times B$ would have second coordinate in $B$.
2. There is no member of the empty set to serve as that coordinate.
3. Consequently the product is the empty set $\varnothing$.

</details>
