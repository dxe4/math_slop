# A singleton can itself be a member

*Easy · [Set theory](index.md)*

Let S={$\{5\},8$}, with number labels treated as ordinary numbers. Which membership statement is true? Select the mathematically correct statement from the four alternatives.

**Options**

1. $5\in S$.
2. $\{5\}\in S$.
3. $\{8\}\in S$.
4. $8$ is not a member of S.

<details>
<summary>Worked solution</summary>

Membership does not automatically pass from an inner set to the outer set.

1. The top-level members are the set $\{5\}$ and the number $8$.
2. Thus $\{5\}\in S$ is true, while $5\in S$ and $\{8\}\in S$ are false. Select the statement “$\{5\}\in S$.”.

</details>
