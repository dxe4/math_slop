# Cover without overlap

*Medium · [Set theory](index.md)*

Which collection is a partition of $X=\{1,2,3\}$? Every block must be nonempty, the blocks disjoint, and their union X. Select the mathematically correct statement from the four alternatives.

**Options**

1. {$\{1,2\},\{2,3\}$}.
2. {$\{1\},\{3\}$}.
3. {$\{1,3\},\{2\}$}.
4. {$\{1,2\},\{3\},\varnothing$}.

<details>
<summary>Worked solution</summary>

Partition requirements jointly ensure that every object belongs to exactly one block.

1. The first collection overlaps at $2$. The second leaves out $2$.
2. The third has nonempty disjoint blocks $\{1,3\}$ and $\{2\}$, covering X. Select the statement “{$\{1,3\},\{2\}$}.”.
