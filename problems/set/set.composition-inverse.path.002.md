# Reverse the assigned pairs

*Easy · [Set theory](index.md)*

The bijection h:$\{2,5\}\to \{7,9\}$ has $h(2)=9$ and $h(5)=7$. Give inverse\_of\_7=$h^{-1} (7)$ and inverse\_of\_9=$h^{-1} (9)$.

<details>
<summary>Worked solution</summary>

Inverse maps reverse a bijection’s input/output assignment.

1. Because $h(5)=7, h^{-1} (7)=5$.
2. Because $h(2)=9, h^{-1} (9)=2$.
