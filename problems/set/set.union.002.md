# Union with an empty collection

*Easy · [Set theory](index.md)*

Let A={} and $B=\{-5,1,4\}$. Give $A\cup B$.

- **A**: {}
- **B**: {-5, 1, 4}

```answer
{"answer":{"kind":"finite_integer_set","expected":[-5,1,4],"checker_scope":"Exact finite integer set; order and repeated entries do not change the set."}}
```

<details>
<summary>Hint 1</summary>

The empty set contributes no members.

</details>

<details>
<summary>Hint 2</summary>

Union still keeps every member of B. Do not add zero merely because one set is empty.

</details>

<details>
<summary>Worked solution</summary>

The empty set and the set containing zero are different collections.

1. There are no members to take from A.
2. All members of B remain, so $A\cup B=\{-5,1,4\}$.

</details>
