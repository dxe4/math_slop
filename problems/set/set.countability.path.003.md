# Finite sets are countable in this book

*Easy · [Set theory](index.md)*

**Options**

1. Only $N_{0}$ is countable; finite sets never count as countable.
2. Both are countable; F is finite and $N_{0}$ is countably infinite.
3. Neither is countable because F has letters and $N_{0}$ has no last member.
4. Only F is countable, because an infinite set has no final member.
