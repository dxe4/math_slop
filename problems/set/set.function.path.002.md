# Unused codomain elements stay out of the range

*Easy · [Set theory](index.md)*

A function has domain $\{0,1,2,3\}$, codomain $\{0,1,2,3,4,5\}$, and values $f(0)=2, f(1)=2, f(2)=4, f(3)=2$. Give its range as a set.


<details>
<summary>Hint 1</summary>

The range contains outputs actually attained by at least one domain input.

</details>

<details>
<summary>Hint 2</summary>

Repeated output values appear only once in a set.

</details>

<details>
<summary>Worked solution</summary>

Codomain is declared; range is determined by the assigned values.

1. The listed outputs are $2,2,4,2$.
2. Their distinct values are $2$ and 4, so the range is $\{2,4\}$.

</details>
