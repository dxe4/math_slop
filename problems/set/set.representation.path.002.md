# Translate a roster into a bounded description

*Easy · [Set theory](index.md)*

Let $D=\{1,2,3,4,5,6,7\}$. Which description gives exactly $\{1,3,5\}$? Select the mathematically correct statement from the four alternatives.

**Options**

1. {x∈D : x is odd and x&lt;6}.
2. {x∈D : x is odd}.
3. {x∈D : x is even and x&lt;6}.
4. {x∈D : x is odd and x&lt;5}.

<details>
<summary>Worked solution</summary>

An equivalent description must have precisely the same members.

1. The odd members of D are $1,3,5,7$. Requiring $x<6$ leaves exactly $1,3,5$.
2. The odd-only rule includes an unwanted $7$, and the even rule selects different numbers. Select the statement “{x∈D : x is odd and x&lt;6}.”.

</details>
