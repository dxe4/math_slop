# Check a subset containing a set

*Medium · [Set theory](index.md)*

Let S={$3,\{3\}$}, treating numbers as ordinary labels. Which subset statement is true? Select the mathematically correct statement from the four alternatives.

**Options**

1. {$\{3\}$}⊆S.
2. {$3,\{3\},4$}⊆S.
3. $\{4\}\subseteq S$.
4. {{$\{3\}$}}⊆S.

<summary>Worked solution</summary>

A subset test compares each candidate member with the outer roster.

1. The set {$\{3\}$} has one member, $\{3\}$, which belongs to S.
2. The other two candidates contain the outsider $4$. Therefore only A is true.
