# Distinguish no elements from one empty subset

*Medium · [Set theory](index.md)*

Which statement about $∅$ and power sets is correct? Choices: P(empty set) is the empty set.; P(empty set) is {empty set}.; P({empty set}) is {empty set}.; The empty set is a member of itself.

**Options**

1. P(empty set) is the empty set.
2. P(empty set) is {empty set}.
3. P({empty set}) is {empty set}.
4. The empty set is a member of itself.

<details>
<summary>Hint 1</summary>

The empty set has a subset even though it has no members.

</details>

<details>
<summary>Hint 2</summary>

A power set lists subsets as its elements.

</details>

<details>
<summary>Worked solution</summary>

The empty subset contributes one element to the power set.

1. The only subset of the empty set is the empty set itself.
2. Therefore its power set is the singleton whose one member is the empty set.
3. The statement P(empty set)={empty set} is correct.

</details>
