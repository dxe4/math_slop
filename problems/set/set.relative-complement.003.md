# The complement of the whole universe

*Easy · [Set theory](index.md)*

Let $U=\{-3,0,4\}$ and $A=\{-3,0,4\}$. Give $U\setminus A$. Use {} if there are no members.

- **U (universe)**: {-3, 0, 4}
- **A**: {-3, 0, 4}

<details>
<summary>Hint 1</summary>

An element belongs to this complement only if it is in U and outside A.

</details>

<details>
<summary>Hint 2</summary>

Here every member of U is also a member of A.

</details>

<details>
<summary>Worked solution</summary>

The complement of the whole universe is empty, even when the universe contains zero.

1. Each of −3, 0 and $4$ is excluded because each belongs to A.
2. Nothing remains, so $U\setminus A$={}.

</details>
