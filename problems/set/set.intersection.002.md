# Disjoint sets have an empty intersection

*Easy · [Set theory](index.md)*

Let $A=\{-2,0,2\}$ and $B=\{1,3,5\}$. Give $A\cap B$. Use {} for an empty answer.

- **A**: {-2, 0, 2}
- **B**: {1, 3, 5}

<details>

</details>

<details>
<summary>Worked solution</summary>

An empty intersection means no object satisfies both membership conditions.

1. None of −2, 0 and $2$ is listed in B.
2. There is no shared member, so $A\cap B$={}.
