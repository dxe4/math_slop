# Use event independence

*Easy · [Probability problems](index.md)*

Independent events have $P(A)=2/3$ and $P(B)=3/4$. Find $P(A\cap B)$.

<details>

<details>
<summary>Worked solution</summary>

Independent event intersections factor into marginal probabilities.

1. By independence, $P(A\cap B)=P(A)P(B)$.
2. The product is $(2/3)(3/4)=6/12$.
3. The probability is $1/2$.

</details>
