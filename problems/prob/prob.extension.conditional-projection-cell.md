# A conditional mean at a specified point

*Easy · [Probability problems](index.md)*

On a uniform space $\Omega=\{1,2,3,4\}$, $X$ has values $0,2,4,10$, respectively. The observed sigma-algebra $\mathcal G$ is generated by cells $\{1,2\},\{3,4\}$. Find the value of $E[X\mid\mathcal G]$ at point $3$.

```answer
{"answer":{"kind":"integer","expected":"7","checker_scope":"Checks the conditional-mean value at the specified positive-probability point only."}}
```

<details>
<summary>Hint 1</summary>

Determine which information cell contains the specified point.

</details>

<details>
<summary>Hint 2</summary>

Conditioning retains only the cell identity. Average the values within that cell with their conditional weights.

</details>

<details>
<summary>Worked solution</summary>

The conditional mean is a cellwise constant.

1. Point three lies in $\{3,4\}$, which contains two equally likely outcomes.
2. Given that cell, the values four and ten each have conditional probability $1/2$.
3. Their mean is $(4+10)/2=7$, so the conditional-mean value at point three is seven. Observing the cell does not reveal the exact realised value four.

The conditional mean on that cell is seven.

</details>
