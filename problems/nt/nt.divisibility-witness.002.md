# Exhibit a signed divisibility witness

*Easy · [Number theory](index.md)*

Find the integer k for which $-63 = 7k$. This integer witnesses that $7$ divides $-63$.

```answer
{"answer":{"kind":"integer","expected":-9,"checker_scope":"Checks one exact integer in this explicitly bounded calculation; does not certify the explanation."}}
```

<details>
<summary>Hint 1</summary>

The witness is a signed integer, not a remainder.

</details>

<details>
<summary>Hint 2</summary>

Divide both sides of the equality by the nonzero integer $7$.

</details>

<details>
<summary>Worked solution</summary>

Divisibility means the dividend is an integer multiple of the divisor.

1. Since $7 \times  (-9) = -63, k = -9$.
2. The quotient is an integer, so it is a valid witness that $7$ divides $-63$.

</details>
