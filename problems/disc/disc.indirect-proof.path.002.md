# Keep equality in a negation

*Medium · [Discrete mathematics](index.md)*

For real x, consider: if $x>3$, then $x^{2}>9$. Which is the exact contrapositive? Select the mathematically correct statement from the four alternatives.

**Options**

1. If $x\leq 3$, then $x^{2}\leq 9$.
2. If $x^{2}\leq 9$, then $x\leq 3$.
3. If $x^{2}>9$, then $x>3$.
4. If $x^{2}<9$, then $x<3$.
