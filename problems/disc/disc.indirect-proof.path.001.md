# Reverse an odd-square implication

*Medium · [Discrete mathematics](index.md)*

For integer n, consider: if $n^{2}$ is odd, then n is odd. Which is its contrapositive? Select the mathematically correct statement from the four alternatives.

**Options**

1. If n is even, then $n^{2}$ is even.
2. If n is odd, then $n^{2}$ is odd.
3. If $n^{2}$ is even, then n is even.
4. If n is odd, then $n^{2}$ is even.
