# Count cosets without listing them

*Easy · [Abstract algebra problems](index.md)*

How many left cosets does $\langle(1\ 2)\rangle$ have in $S_3$?

```answer
{"answer":{"kind":"integer","expected":3,"checker_scope":"Exact stated finite group or ring answer only; optional personal reasoning is not graded."}}
```

<details>
<summary>Hint 1</summary>

A transposition has order two.

</details>

<details>
<summary>Hint 2</summary>

Use the equal size of all cosets in this finite group.

</details>

<details>
<summary>Worked solution</summary>

Coset count is the group order divided by the subgroup order.

1. $S_3$ has order $3!=6$.
2. The subgroup generated by the transposition consists of the identity and that transposition, so it has order $2$.
3. The left-coset count is $6/2=3$.

</details>
