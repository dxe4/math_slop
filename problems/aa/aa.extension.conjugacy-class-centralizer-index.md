# Translate a stabilizer size into a conjugacy class size

*Easy · [Abstract algebra problems](index.md)*

A finite group has order 60 and the centralizer of g has order 12. Use $|\operatorname{Cl}(g)|=[G:C_G(g)]$ to find the conjugacy class size.


<details>
<summary>Hint 1</summary>

Conjugation is an action whose stabilizer is the centralizer.

</details>

<details>
<summary>Hint 2</summary>

The orbit size is a quotient of the two orders.

</details>

<details>
<summary>Worked solution</summary>

Conjugacy class size measures centralizer index.

1. The supplied formula gives class size \|G\|/\|C\_G(g)\|.
2. The two orders are sixty and twelve.
3. Their quotient is five.

</details>
