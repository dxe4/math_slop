# Count extension classes rather than only possible middle groups

*Medium · [Abstract algebra problems](index.md)*

Count equivalence classes of short exact Z-module sequences $0\to Z/12\to E\to Z/8\to0$, where an equivalence is the identity on the two end modules. Use a lift of the quotient generator.

<details>
<summary>Hint 1</summary>

Eight times a chosen lift lies in the identified copy of Z/12.

</details>

<details>
<summary>Hint 2</summary>

Changing the lift changes that element by eight times a kernel element.

</details>

<details>
<summary>Worked solution</summary>

The lift relation classifies extensions with fixed end identifications.

1. Write u for the distinguished kernel generator and v for a lift of the quotient generator. Then12u=0 and8v=a\*u for some a modulo twelve. Changing v by k\*u changes a by8k, and all such changes give equivalent extensions.
2. Conversely the presentation with these two relations gives the required extension: u retains exact order twelve because any relation with zero v coefficient is a multiple of12u, and the quotient generated by v has order eight.
3. Thus classes are indexed by(Z/12)/8(Z/12). The subgroup8(Z/12) is{0,4,8}, so the quotient has four elements. Different classes can have isomorphic middle groups, which is why only counting middle-group types would be insufficient.

</details>
