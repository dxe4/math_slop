# Read a counterclockwise quarter turn

*Easy · [Foundations bridge](index.md)*

Find $\sin (\pi /2)$ and $\cos (\pi /2)$. Return sin and cos as exact numbers.

```answer
{"answer":{"kind":"record_of_rationals","expected":{"sin":"1","cos":"0"},"checker_scope":"Checks only the exact stated structured result; explanation quality and general proof mastery are not assessed."}}
```

<details>
<summary>Hint 1</summary>

$\pi /2$ radians is one counterclockwise quarter turn.

</details>

<details>
<summary>Hint 2</summary>

Use the unit-circle point at the top and read vertical then horizontal coordinates.

</details>

<details>
<summary>Worked solution</summary>

Trigonometric values are coordinates on the unit circle.

1. The unit-circle point is $(0,1)$.
2. Sine is the vertical coordinate and cosine the horizontal coordinate, so sin=$1$ and cos=$0$.

</details>
