# Find when a conditional promise fails

*Easy · [Foundations bridge](index.md)*

Under material implication, P is true and Q is false. Which evaluation and reason is correct?

**Options**

1. True, because the antecedent is true.
2. False, because the antecedent is true while the consequent is false.
3. Undetermined, because the causal connection between P and Q is unknown.
4. True, because a false consequent makes a material implication true.

<details>
<summary>Hint 1</summary>

An implication promises Q whenever P holds.

</details>

<details>
<summary>Hint 2</summary>

Consider whether the specified true antecedent is accompanied by the promised consequent.

</details>

<details>
<summary>Worked solution</summary>

A material implication is false exactly when its antecedent is true and its consequent is false.

1. P holds, so the implication requires Q to hold in this case.
2. Q is false, so this is the case that makes a material implication false. Select the statement “False, because the antecedent is true while the consequent is false.”.

</details>
