# Negate an all-objects statement

*Easy · [Foundations bridge](index.md)*

The domain is $D = \{1,2,3\}$, and P(x) is a statement about x. Which is the negation of “For every x in D, P(x)”? Select the mathematically correct statement from the four alternatives.

**Options**

1. For every x in D, not P(x).
2. For some x in D, P(x).
3. For some x in D, not P(x).
4. For every member of the domain, the original property still holds.

<details>
<summary>Hint 1</summary>

An all-objects claim fails when at least one object breaks it.

</details>

<details>
<summary>Hint 2</summary>

Negating “every” introduces “some,” and the property is negated as well.

</details>

<details>
<summary>Worked solution</summary>

One counterexample is enough to negate a universal statement over the stated domain.

1. The original statement requires $P(1), P(2)$, and $P(3)$ all to hold.
2. Its negation says that at least one of those requirements fails: some x in D has not P(x). Select the statement “For some x in D, not P(x).”.

</details>
