# Recognize an empty index range

*Easy · [Foundations bridge](index.md)*

Using the convention that a finite sum is zero when its lower integer bound exceeds its upper bound, evaluate $\sum _{k=5}^4$ k.

```answer

```

<details>
<summary>Hint 1</summary>

Check the index range before calculating any terms.

</details>

<details>
<summary>Hint 2</summary>

No integer starts at five and continues upward through four.

</details>

<details>
<summary>Worked solution</summary>

The range determines whether a sum has any terms at all.

1. The lower bound five exceeds the upper bound four.
2. There are no terms, so the stated empty-sum convention gives zero.

</details>
