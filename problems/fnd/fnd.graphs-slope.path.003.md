# Find the vertical intercept

*Easy · [Foundations bridge](index.md)*

The line is $y = 2x + 3$. What is its y-coordinate where it meets the vertical axis?

```answer

```

<details>
<summary>Hint 1</summary>

Every point on the vertical axis has $x = 0$.

</details>

<details>
<summary>Hint 2</summary>

Substitute that input into the line equation.

</details>

<details>
<summary>Worked solution</summary>

An axis intercept comes from the coordinate fixed by that axis.

1. At the vertical axis $x = 0$.
2. The equation gives $y = 2 \times  0 + 3 = 3$.

</details>
