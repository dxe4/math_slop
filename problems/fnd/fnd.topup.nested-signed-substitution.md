<details>
<summary>Worked solution</summary>

Explicit bracket evaluation prevents sign errors in a nested expression.

1. The first bracket is $-2-3\cdot3=-11$, so twice it is $-22$.
2. The second bracket is $3-(-2)=5$.
3. The final value is $-22-5=-27$.
