# Find a domain using a strictly positive denominator

*Easy · [Foundations bridge](index.md)*

Give the real domain of $f(x)=1/(x^2+1)$ as an interval.

<details>
<summary>Hint 1</summary>

A real square is nonnegative.

</details>

<details>
<summary>Hint 2</summary>

Determine whether adding one can produce zero.

</details>

<details>
<summary>Worked solution</summary>

A denominator that never vanishes excludes no real inputs.

1. For every real x, x²≥0.
2. Hence x²+1≥1&gt;0, so the denominator is never zero.
3. The domain is all real numbers, (−∞,∞).

</details>
