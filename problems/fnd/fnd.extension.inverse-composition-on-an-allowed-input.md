# Use the defining inverse identity

*Easy · [Foundations bridge](index.md)*

Let f be a bijection whose domain contains 7. Find $f^{-1}(f(7))$.

<details>
<summary>Hint 1</summary>

The inverse undoes f on its domain.

</details>

<details>
<summary>Hint 2</summary>

The inner output is automatically in the inverse’s domain.

</details>

<details>
<summary>Worked solution</summary>

The inverse identity returns the original allowed input.

1. Since 7 is in the domain, f(7) exists.
2. A bijection has inverse with f⁻¹(f(x))=x on that domain.
3. Therefore the value is 7.

</details>
