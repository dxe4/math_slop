# Select a piecewise branch

*Easy · [Foundations bridge](index.md)*

Let $f(x) = x + 1$ when $x < 0$, and $f(x) = 2x$ when $x \geq  0$. Find $f(-3)$.

The input sign selects the branch.

<details>
<summary>Worked solution</summary>

The domain conditions choose the rule before the calculation begins.

1. The input $-3$ satisfies $x < 0$.
2. The selected rule gives $f(-3) = -3 + 1 = -2$.
