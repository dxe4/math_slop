# Keep the object arbitrary

*Easy · [Foundations bridge](index.md)*

Which argument proves that $n+n$ is even for every integer n? Select the mathematically correct statement from the four alternatives.

**Options**

1. For $n=1$ and $n=2$ the sums are even, so all cases follow.
2. Assume n is even; then the sum is even, which covers all integers.
3. Let n be any integer. Then $n+n=2n$, twice an integer, so it is even.
4. The doubled number $2$($n+n$) is even, so $n+n$ must be even.

<details>
<summary>Worked solution</summary>

A universal proof must cover every object in its declared domain.

1. Examples do not cover all integers, and assuming n even omits the odd integers.
2. The arbitrary-integer argument in C writes $n+n=2n$ and supplies an integer witness for every n.

</details>
