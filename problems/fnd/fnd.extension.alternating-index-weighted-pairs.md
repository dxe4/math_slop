# Pair terms in an alternating finite sum

*Medium · [Foundations bridge](index.md)*

Evaluate $\sum_{k=1}^{6}(-1)^k k$.

<details>
<summary>Hint 1</summary>

The first sign is negative because k starts at 1.

</details>

<details>
<summary>Hint 2</summary>

Pair each negative odd term with the following positive even term.

</details>

<details>
<summary>Worked solution</summary>

The index determines both magnitude and sign.

1. The sum is −1+2−3+4−5+6.
2. Grouping consecutive pairs gives (−1+2)+(−3+4)+(−5+6).
3. Each pair equals 1, so the total is 3.

</details>
