# Extend an arithmetic sequence backward to its initial index

*Medium · [Foundations bridge](index.md)*

An arithmetic sequence indexed n≥0 has a₅=11 and common difference 3. Find $a_0$.

There are five equal increments from a₀ to a₅.

<details>

<details>
<summary>Worked solution</summary>

Backward indexing uses the same constant difference with reversed direction.

1. The relation is a₅=a₀+5×3.
2. Thus 11=a₀+15.
3. Solving gives a₀=−4.

</details>
