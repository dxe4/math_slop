# Recognize the contrapositive

*Easy · [Foundations bridge](index.md)*

Take the conditional statement “If the lamp is on, then power is supplied” as given. Which statement is its contrapositive? Select the mathematically correct statement from the four alternatives.

**Options**

1. If power is not supplied, then the lamp is not on.
2. If power is supplied, then the lamp is on.
3. If the lamp is not on, then power is not supplied.
4. If power is not supplied, then the lamp is on.

<details>
<summary>Hint 1</summary>

The contrapositive reverses the roles of the two statements and negates both.

<details>
<summary>Hint 2</summary>

For “if P then Q,” use “if not Q then not P.”

</details>

<details>
<summary>Worked solution</summary>

Contraposition combines reversing the direction with negating both statements.

1. Here P is “the lamp is on” and Q is “power is supplied.”
2. The contrapositive is “if not Q then not P”: if power is not supplied, the lamp is not on. Select the statement “If power is not supplied, then the lamp is not on.”.

</details>
