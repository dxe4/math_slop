# Use an explicit indexed rule

*Easy · [Foundations bridge](index.md)*

For $a_{n}=2n-1$ with integer indices $n\geq 1$, find $a_{4}$.

```answer
{"answer":{"kind":"integer","expected":7,"checker_scope":"Checks only the exact stated structured result; explanation quality and general proof mastery are not assessed."}}
```

<details>
<summary>Hint 1</summary>

The subscript gives the value to substitute for n.

</details>

<details>
<summary>Hint 2</summary>

Evaluate $2 \times  4 - 1$.

</details>

<details>
<summary>Worked solution</summary>

An explicit rule uses the requested index as its input.

1. At $n=4$ the explicit formula gives $a_{4}=2$($4$)$-1$.
2. Thus $a_{4}=8-1=7$.

</details>
