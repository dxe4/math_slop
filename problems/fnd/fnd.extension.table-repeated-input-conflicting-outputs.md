# Identify the input that prevents a relation being a function

*Easy · [Foundations bridge](index.md)*

A relation lists pairs $(0,1),(2,3),(2,4)$. Which input is assigned two different outputs and therefore prevents this relation from being a function?

```answer
{"answer":{"kind":"integer","expected":2,"checker_scope":"Only the requested exact result in the stated domain and units is checked; the reasoning remains a personal draft."}}
```

<details>
<summary>Hint 1</summary>

Compare the first coordinates of the pairs.

</details>

<details>
<summary>Hint 2</summary>

A function can repeat an output, but cannot give one input two different outputs.

</details>

<details>
<summary>Worked solution</summary>

Functionhood concerns uniqueness of the output for each input.

1. Input 0 appears with output 1 only.
2. Input 2 appears with outputs 3 and 4.
3. Thus the conflicting input is 2.

</details>
