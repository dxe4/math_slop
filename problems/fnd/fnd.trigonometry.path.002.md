# Convert a half turn to radians

*Easy · [Foundations bridge](index.md)*

Write $180$ degrees as cπ radians. Return the exact coefficient c.

<details>
<summary>Hint 1</summary>

Use the relation $360$ degrees = $2\pi$ radians.

</details>

<details>
<summary>Hint 2</summary>

Multiply the degree value by $\pi /180$, then report the coefficient.

</details>

<details>
<summary>Worked solution</summary>

An angle is unchanged when its unit representation changes.

1. $180 \times  \pi /180 = \pi$ radians.
2. Thus $c = 1$.

</details>
