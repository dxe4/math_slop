# Recover the interval allowed by a rounded measurement

*Medium · [Foundations bridge](index.md)*

A positive mass is recorded as $8\,\mathrm{kg}$ after rounding to the nearest whole kilogram, with exact halfway cases rounded upward. Give the complete interval of possible original masses in kilograms.

<details>
<summary>Worked solution</summary>

A rounded value represents an interval with endpoint conventions.

1. The halfway boundaries are 7.5 kg and 8.5 kg.
2. The lower boundary rounds up to 8, so it is included. The upper rounds up to 9, so it is excluded.
3. The interval is \[7.5,8.5)=\[15/2,17/2).
