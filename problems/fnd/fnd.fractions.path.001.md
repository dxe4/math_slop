# Combine unlike fractional parts

Find the exact value of $2/7 + 3/4$.

<details>
<summary>Worked solution</summary>

A common unit makes addition of fractional pieces meaningful.

1. Rewrite $2/7 = 8/28$ and $3/4 = 21/28$.
2. The sum is $(8 + 21)/28 = 29/28$.

</details>
