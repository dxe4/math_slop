# Keep the header unit with its value

*Easy · [Foundations bridge](index.md)*

A table has columns “Time (hours)” and “Distance (kilometres).” One row contains $3$ and $18$ in that order. What does the entry $18$ report? Select the mathematically correct statement from the four alternatives.

**Options**

1. Eighteen hours.
2. Eighteen kilometres.
3. Eighteen kilometres per hour.
4. A speed of six kilometres per hour.
