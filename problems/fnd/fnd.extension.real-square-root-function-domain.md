# Use a radical’s real-input condition

*Easy · [Foundations bridge](index.md)*

Find the real domain of $f(x)=\sqrt{5-x}$ as an interval, using the principal square root.

<details>
<summary>Hint 1</summary>

The radicand must be nonnegative.

</details>

<details>
<summary>Hint 2</summary>

Solve 5−x≥0 and include the zero-radicand endpoint.

</details>

<details>
<summary>Worked solution</summary>

A real square root accepts zero as well as positive inputs.

1. Require 5−x≥0.
2. This is equivalent to x≤5.
3. Thus the domain is (−∞,5\].

</details>
