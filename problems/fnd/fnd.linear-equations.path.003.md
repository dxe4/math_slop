# Rearrange with a domain condition

*Easy · [Foundations bridge](index.md)*

The formula is $C = 2$πr. For real C and r, and the usual nonzero constant π, which rearrangement solves for r? Select the mathematically correct statement from the four alternatives.

**Options**

1. $r = 2$πC
2. $r = C/(2\pi )$
3. $r = C - 2\pi$
4. r = π$C/2$.

<summary>Hint 1</summary>

The coefficient of r is a nonzero multiplier.

</details>

<details>
<summary>Hint 2</summary>

Undo that multiplication by dividing the entire other side.

</details>

<details>
<summary>Worked solution</summary>

Formula rearrangement uses the same equality-preserving operations as numerical equations.

1. Divide both sides of $C = 2$πr by $2\pi$, which is nonzero.
2. The result is $r = C/(2\pi )$; select the statement “$r = C/(2\pi )$”.

</details>
