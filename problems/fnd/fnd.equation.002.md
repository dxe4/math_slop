# Undo subtraction before division

*Easy · [Foundations bridge](index.md)*

Find the real value x satisfying $5x - 7 = 8$. Give an exact value.

<details>
<summary>Hint 1</summary>

Choose an operation that removes the minus seven.

</details>

<details>
<summary>Hint 2</summary>

Add seven to both sides before dividing by five.

</details>

<details>
<summary>Worked solution</summary>

The sign of a constant determines which inverse operation removes it.

1. Add seven to both sides: $5x = 15$.
2. Divide by five to get $x = 3$. Substitution checks the answer because $5 \times  3 - 7 = 8$.

</details>
