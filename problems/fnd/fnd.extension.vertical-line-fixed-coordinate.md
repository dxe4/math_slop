# Read a vertical line’s fixed coordinate

*Easy · [Foundations bridge](index.md)*

Every point on a vertical line satisfies $x=-3$. What is the x-coordinate of any point on it?

<details>
<summary>Worked solution</summary>

A vertical line has one constant horizontal coordinate.

1. The defining equation is x=−3.
2. It holds regardless of the chosen y-coordinate.
3. Thus the requested coordinate is −3.
