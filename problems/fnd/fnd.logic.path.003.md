# Distinguish converse from contrapositive

*Easy · [Foundations bridge](index.md)*

Take the statement “If n is a multiple of six, then n is a multiple of three” as given. Which statement is its contrapositive? Select the mathematically correct statement from the four alternatives.

**Options**

1. If n is a multiple of three, then n is a multiple of six.
2. If n is not a multiple of six, then n is not a multiple of three.
3. If n is not a multiple of three, then n is not a multiple of six.
4. If n is not a multiple of three, then n is a multiple of six.

<details>
<summary>Worked solution</summary>

Reversing and negating together preserves a conditional truth value.

1. Here not Q means not a multiple of three and not P means not a multiple of six.
2. The contrapositive says that failure to be a multiple of three implies failure to be a multiple of six.
