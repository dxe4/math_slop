# Complete a definition-based parity argument

*Easy · [Foundations bridge](index.md)*

Let $m=2r$ and $n=2s$, where r and s are integers. Which step correctly proves that $m+n$ is even? Select the mathematically correct statement from the four alternatives.

**Options**

1. $m+n=r+s$.
2. $m+n=2$($r+s$), and $r+s$ is an integer.
3. $m+n=2rs$.
4. $m+n=2$($r-s$), and $r-s$ is an integer.

A definition-based proof supplies the witness demanded by the definition.

1. Substituting gives $m+n=2r+2s=2$($r+s$).
2. Since $r+s$ is an integer, this is the definition of even; select the statement “$m+n=2$($r+s$), and $r+s$ is an integer.”.
