# Calculate a temperature increase

*Easy · [Foundations bridge](index.md)*

A temperature changes from $-6$ °C to $2$ °C. Define the signed change as final minus initial temperature. What is the signed change, in degrees Celsius?

```answer

```

<details>
<summary>Hint 1</summary>

The temperature rises, so the change should be positive.

</details>

<details>
<summary>Hint 2</summary>

Subtract the initial value $-6$ from the final value $2$.

</details>

<details>
<summary>Worked solution</summary>

An endpoint change is final value minus initial value, including both signs.

1. The signed change is $2 - (-6)$.
2. Subtracting a negative adds its opposite: $2 + 6 = 8$ degrees Celsius.

</details>
