# Interpret a map scale with an output unit

*Easy · [Foundations bridge](index.md)*

A map has scale $1:2500$. A straight segment measures 4 cm on it. What real length does it represent in metres?

First multiply using centimetres on both sides of the scale.

</details>

<details>
<summary>Hint 2</summary>

Then convert the real centimetres to metres.

</details>

<details>
<summary>Worked solution</summary>

A scale ratio uses equal units before conversion.

1. The real length is 4×2500=10000 cm.
2. There are 100 cm in one metre.
3. Thus the represented length is 100 metres.

</details>
