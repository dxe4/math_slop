# Read the positive trigonometric coordinate in quadrant two

*Easy · [Foundations bridge](index.md)*

A unit-circle angle lies strictly in quadrant II. Which of the named values $\sin\theta$ and $\cos\theta$ is positive? Return a set using the literal labels {sin,cos} as needed.

<details>
<summary>Hint 1</summary>

In quadrant II the horizontal coordinate is negative and the vertical coordinate positive.

</details>

<details>
<summary>Hint 2</summary>

Cosine is horizontal; sine is vertical.

</details>

<details>
<summary>Worked solution</summary>

The signs come from the coordinate definitions on the unit circle.

1. In quadrant II, x&lt;0 and y&gt;0.
2. For the unit-circle point, cosθ=x and sinθ=y.
3. Only sin is positive, so the answer set is {sin}.

</details>
