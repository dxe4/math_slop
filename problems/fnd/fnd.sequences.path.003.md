# Respect a starting index of zero

*Easy · [Foundations bridge](index.md)*

For $b_{n}=n^{2}$ with integer indices $n\geq 0$, find the first term $b_{0}$.

<details>
<summary>Worked solution</summary>

An index convention determines which term is first.

1. The first term is $b_{0}$ because the index set begins at zero.
2. The rule gives $b_{0}=0^{2}=0$.
