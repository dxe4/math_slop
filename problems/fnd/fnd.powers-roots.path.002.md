# Use the principal square root

*Easy · [Foundations bridge](index.md)*

Find the principal real square root $\sqrt{49}$.

</details>

<details>
<summary>Hint 2</summary>

Find a nonnegative number whose square is forty-nine.

</details>

<details>
<summary>Worked solution</summary>

The square-root symbol chooses one nonnegative value.

1. Both $7$ and $-7$ square to $49$.
2. The principal square root selects the nonnegative value, so $\sqrt{49} = 7$.

</details>
