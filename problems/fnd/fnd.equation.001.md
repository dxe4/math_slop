# Undo addition and multiplication

*Easy · [Foundations bridge](index.md)*

Find the real value x satisfying $3x + 4 = 19$. Give an exact value.

<details>
<summary>Hint 1</summary>

Preserve equality by applying the same operation to both sides.

</details>

<details>
<summary>Hint 2</summary>

First remove the added four, then divide by the coefficient of x.

</details>

<details>
<summary>Worked solution</summary>

Invert the operations around the unknown in reverse order, keeping both sides equal.

1. Subtract four from both sides to get $3x = 15$.
2. Divide both sides by three: $x = 5$. Check that $3 \times  5 + 4 = 19$.

</details>
