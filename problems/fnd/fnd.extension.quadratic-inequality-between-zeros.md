# Solve a quadratic inequality without dividing by x

Give all real x satisfying $x^2\le4x$ as an interval.

<details>
<summary>Worked solution</summary>

Dividing by a variable could lose a root and reverse a sign in some cases.

1. The inequality is x²−4x=x(x−4)≤0.
2. The zeros are 0 and 4. The product is nonpositive between them and positive outside.
3. Both zero endpoints satisfy equality, so the solution is \[0,4\].

</details>
