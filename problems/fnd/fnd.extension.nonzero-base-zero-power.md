# Use the zero-exponent convention

*Easy · [Foundations bridge](index.md)*

Evaluate $7^0$, using the usual exponent laws for a nonzero base.

<details>
<summary>Hint 1</summary>

Compare 7³/7³ with the exponent subtraction rule.

</details>

<details>
<summary>Hint 2</summary>

The quotient is one and its exponent difference is zero.

</details>

<details>
<summary>Worked solution</summary>

The zero power of a nonzero base is the multiplicative identity.

1. The quotient 7³/7³ is 1.
2. The same-base exponent law writes it as 7^{3−3}=7⁰.
3. Therefore 7⁰=1; this does not address 0⁰.

</details>
