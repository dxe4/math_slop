# Find a signed temperature change

*Easy · [Foundations bridge](index.md)*

The temperature changes from $-8$ °C to −1 °C. What is final minus initial temperature, in degrees Celsius?

```answer

```

<details>
<summary>Hint 1</summary>

The final temperature is higher, so the change is positive.

</details>

<details>
<summary>Hint 2</summary>

Subtract the negative initial value from the final value.

</details>

<details>
<summary>Worked solution</summary>

A change compares endpoints while keeping their signs.

1. Final minus initial is −1 − (−8).
2. This is −1 + 8 = 7 degrees Celsius.

</details>
