# Add disjoint table cells

*Easy · [Foundations bridge](index.md)*

A table lists Group A: morning $2$, afternoon $4$; Group B: morning $3$, afternoon $1$. These four counts refer to disjoint visits. How many visits are there altogether?

```answer

```

<details>
<summary>Hint 1</summary>

The word altogether requests the total of all four cells.

</details>

<details>
<summary>Hint 2</summary>

Each visit appears in just one cell, so add each cell once.

</details>

<details>
<summary>Worked solution</summary>

A table total adds the relevant disjoint counts once each.

1. Group A has $2 + 4 = 6$ visits and Group B has $3 + 1 = 4$.
2. The total is $6 + 4 = 10$ visits.

</details>
