# Evaluate at an original hole

*Easy · [Foundations bridge](index.md)*

At $x = 7$, what is the value of the original expression $(x - 7)/(x - 7)$ over the real numbers? Select the mathematically correct statement from the four alternatives.

**Options**

1. $1$
2. $0$
3. It is undefined.
4. Positive infinity.
