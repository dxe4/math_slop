# Collect coefficients of one common term

For every real x write $7x-2x=cx$. Find c.

<details>
<summary>Worked solution</summary>

Combining like terms changes the coefficient, not the variable power.

1. Factor x to get (7−2)x.
2. The coefficient difference is 5.
3. Thus c=5 for all real x.
