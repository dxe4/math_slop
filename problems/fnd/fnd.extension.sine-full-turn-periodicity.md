# Use a full-turn identity

*Easy · [Foundations bridge](index.md)*

Given sinθ=2/5, find $\sin(\theta+2\pi)$, with angles in radians.

<details>
<summary>Hint 1</summary>

An increase by 2π is one complete turn.

</details>

<details>
<summary>Hint 2</summary>

The resulting unit-circle point has the same vertical coordinate.

</details>

<details>
<summary>Worked solution</summary>

A full turn leaves the sine value unchanged.

1. Sine has period 2π radians.
2. Therefore sin(θ+2π)=sinθ.
3. The exact value is 2/5.

</details>
