# Collect a variable from both sides

*Easy · [Foundations bridge](index.md)*

Solve $4x + 1 = 2x + 9$ over the real numbers.

<details>
<summary>Hint 1</summary>

Remove one variable term from both sides.

</details>

<details>
<summary>Hint 2</summary>

Subtract $2x$ and then subtract one.

</details>

<details>
<summary>Worked solution</summary>

A variable on both sides can be collected by the same subtraction on each side.

1. Subtract $2x$: $2x + 1 = 9$.
2. Subtract one and divide by two: 2x = 8, so $x = 4$.

</details>
