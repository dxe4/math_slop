# Find an excluded denominator input

*Easy · [Foundations bridge](index.md)*

For $g(x)=1/(x+4)$ over the real numbers, which of the listed inputs $-4,4,0$ is excluded from the domain? Enter that input as an integer.

<details>
<summary>Worked solution</summary>

Domain restrictions come from the original denominator.

1. The denominator vanishes when $x+4=0$.
2. Solving gives $x=-4$.
3. At the other listed inputs the denominator is nonzero, so $-4$ is the excluded listed input.
