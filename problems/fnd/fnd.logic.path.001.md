# Handle a false antecedent

*Easy · [Foundations bridge](index.md)*

Under material implication, P is false and Q is false. Which evaluation and reason is correct?

**Options**

1. True: the only false implication has a true antecedent and a false consequent, which is not this case.
2. False, because the consequent is false.
3. Undetermined, because a false antecedent prevents evaluating material implication.
4. False, because a material implication requires its antecedent to be true.

The truth table for implication differs from the truth table for conjunction.

1. An implication is false only when P is true and Q is false.
2. Since P is false here, the implication is true; select the statement “True: the only false implication has a true antecedent and a false consequent, which is not this case.”.
