# Read absolute value as a distance

*Easy · [Foundations bridge](index.md)*

On the real number line, find $|-13|$, the distance from −13 to zero.

<details>
<summary>Hint 2</summary>

<details>
<summary>Worked solution</summary>

Absolute value forgets direction while retaining distance.

1. The point −13 lies thirteen units to the left of zero.
2. Moving to zero requires a displacement of +13.
3. The distance, and hence the absolute value, is 13.

</details>
