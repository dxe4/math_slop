# Recover an input with an inverse

*Easy · [Foundations bridge](index.md)*

The function $f(x)=2x-6$ has real domain and codomain. Find the input x for which $f(x)=8$.

<details>
<summary>Worked solution</summary>

An inverse reverses the operations of a one-to-one rule.

1. Add six to get $2x = 14$.
2. Divide by two to get $x = 7$; $f(7)=14-6=8$.

</details>
