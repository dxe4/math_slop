# Check the hypotheses of completeness

*Medium · [Real analysis](index.md)*

Which assertion is exactly the least-upper-bound completeness property of R? Select the mathematically correct statement from the four alternatives.

**Options**

1. Every nonempty real subset bounded above has a real supremum.
2. Every real subset has a real maximum.
3. Every nonempty real subset has a finite real supremum.
4. Every nonempty bounded real subset has a real maximum.

<summary>Hint 1</summary>

A maximum adds an attainment requirement that completeness does not supply.

</details>

<details>
<summary>Hint 2</summary>

Consider whether the whole real line is bounded above.

<details>
<summary>Worked solution</summary>

The hypotheses are part of the theorem, not optional annotations.

1. Completeness concerns nonempty real sets bounded above and guarantees their least real upper bound.
2. The interval $(0,1)$ has a supremum but no maximum, so completeness does not imply maximum attainment. The unbounded set $\mathbb R$ shows why the bounded-above hypothesis is required.

</details>
