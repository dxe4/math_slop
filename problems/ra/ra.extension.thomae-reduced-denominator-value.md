# Apply a definition using lowest terms

*Easy · [Real analysis](index.md)*

On \[0,1\], Thomae's function is T(x)=0 at irrational x and T(p/q)=1/q when p/q is in lowest terms with q&gt;0. Find $T(6/15)$.

2. Its positive reduced denominator is five.
3. Thus T(6/15)=1/5.
