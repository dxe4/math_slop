# Keep the subsequential limit inside the compact set

*Medium · [Real analysis](index.md)*

A sequence has every term in $K=[-1,1]$. What does compactness guarantee? Select the mathematically correct statement from the four alternatives.

**Options**

1. The whole sequence converges.
2. Every convergent subsequence must converge to an endpoint.
3. Some subsequence converges to a point of $[-1,1]$.
4. For any preselected point of $[-1,1]$, some subsequence converges to that point.

<details>
<summary>Worked solution</summary>

Compactness extracts internal convergent subsequences.

1. Sequential compactness gives a convergent subsequence with limit in K.
2. The full sequence might alternate between $-1$ and $1$, and a constant zero sequence shows that the limit need not be an endpoint. Thus C is the exact guarantee.

</details>
